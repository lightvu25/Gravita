# Gravita — Game Feel Upgrade Blueprint

> Tài liệu chẩn đoán và thiết kế nâng cấp Game Feel cho **Gravita** (`Puzzle 2D` — Unity 6000.4.0f1 URP, 2D Top-Down, `32 PPU`), dựa trực tiếp trên cấu hình runtime trong `Assets/Scenes/GameScene.unity`, các prefab trong `Assets/Prefabs/Gameplay/` và kiến trúc 4 tầng của dự án.

### Giả Định & Cấu Hình Nền (Assumptions & Baseline)
1. **Động học trượt chuẩn**: `PlayerMovement` trong `Assets/Scenes/GameScene.unity` đang đặt `moveSpeed = 30` (tức **33.3 ms / ô** ở `cellSize = 1`), `bufferTurnsUntilStop = 1`, `maxConsecutiveRedirects = 8`. Ngưỡng tier thực tế trong `Assets/Scripts/Gameplay/VelocityTier.cs` là `Drift` (1–2 ô), `Cruise` (3–4 ô), `KineticRam` (5+ ô). Mọi timing trong tài liệu được tính theo vận tốc này (`33.3–66.7 ms` cho `Drift`, `100–133.3 ms` cho `Cruise`, `>= 166.7 ms` cho `KineticRam`, và `48` u/s khi `PhaseLaunch` `1.6x`).
2. **Kho âm thanh hiện tại**: `Assets/Data/Sound/SoundConfig.asset` hiện để trống (`clips: []`) ở toàn bộ entry gameplay và UI dù `Assets/Audio/Sounds/` đã có sẵn các gói SFX (Shapeforms & 400 Sounds Pack). Phần âm thanh quy định cách gán clip vào `SoundConfig.asset`.
3. **Chế độ Speedrun Minimal & Pixel-Perfect**: Tùy chọn `PlayerImpactFeedback.hitStopEnabled` phải tiếp tục được tôn trọng tuyệt đối; mọi hiệu ứng dùng unscaled time không được chạm vào vật lý `FixedUpdate` hay `LevelClock`. Camera cần tương thích an toàn với `PixelPerfectCamera` (`m_AssetsPPU: 32`, `320x180`, `GridSnapping: PixelSnapping`) trên `Main Camera`.

## 1. Chẩn Đoán Cốt Lõi: Vì Sao Gravita Hiện Tại Vẫn Cảm Thấy "Phẳng"?

Gravita đã có nền tảng cơ bản (`PlayerImpactFeedback`, `PlayerSquashStretch`, `PlayerLineTrail`, `CinemachineCameraShake2D`, `GameplayHapticsFeedback`, `CloseCallDetector`), nhưng cảm giác điều khiển bị "lì" và thiếu độ cuốn vì **5 nút thắt kiến trúc cảm giác**:

1. **Động học 33.3 ms/ô & cấu trúc pivot/hit-stop triệt tiêu độ nảy va đập**:
   - Với `moveSpeed = 30`, một cú trượt `Drift` (2 ô) chỉ kéo dài **67 ms**, còn `KineticRam` (5 ô) đạt tới ở **167 ms**. Trong khi đó `PlayerSquashStretch` dùng `stretchDuration = 0.18f` (`180 ms`) và tự trả về `baseScale` sau 40% thời lượng (`72 ms`), khiến Subject G-0 chưa kịp giữ dáng khí động học đã xẹp lại giữa đường trượt.
   - Sprite `Player Icon.aseprite` có pivot đáy `(0.5, 0)` (`32x32` @ `32 PPU`) và `Player/Sprite` nằm ở `localPosition = (0, -0.5, 0)` để tâm hình khớp `(0, 0)`, đồng thời `GameScene.unity` đang serialize `PlayerSquashStretch.maxDeformation = 0.3`. Khi biến dạng trục Y không bù trừ tâm pivot, đâm trần (`Vector2.up`) lại làm đỉnh sprite tụt xuống khỏi tường thay vì ép bẹt vào tường.
   - `PlayerImpactFeedback.HandleStopped()` bắn hit-stop (`0.033s` / `0.083s`) và rung mạnh **kể cả khi `WasLastStopWallImpact == false`** (`BrakeTile` / `GravityBlock`), nhưng lại **vô hiệu hóa chính camera shake của mình trong lúc đóng băng** vì `CinemachineBrain` trong `GameScene.unity` đặt `IgnoreTimeScale: 0` và `CinemachineImpulseManager.Instance.IgnoreTimeScale` mặc định `false`, còn `PlayerLineTrail.LateUpdate()` thoát sớm khi `Time.deltaTime <= 0f`, và `OnDisable()` không trả `Time.timeScale` nếu object tắt giữa hit-stop.
   - Trong `GameScene.unity`, `tier1Shake = 0` và `redirectShake = 0`; `Hit Flash White.mat` bỏ không; và khi `KineticRam` húc vỡ `CrackedBlock` (`PlayerMovement.TryCrush`), nhân vật đi xuyên không dừng (`Cracked.prefab` đặt `InteractionEffectPlayer.defaultCameraShake = 0`), nên cú húc xuyên gạch không có hit-stop, hit-flash hay rung chấn.

2. **Camera & Post-Processing bất động (và bẫy FOV của `CinemachinePixelPerfect`)**:
   - `CinemachineCameraZoom2D` đã gắn sẵn dưới `CinemachineCamera` (`normalOrthographicSize: 5.5`), nhưng **không có bất kỳ script nào gọi tới** và `Update()` dùng `Time.deltaTime`.
   - Quan trọng hơn: `Main Camera` gắn `PixelPerfectCamera` (`32 PPU`, `320x180`, `PixelSnapping`) và `CinemachineCamera` bật `CinemachinePixelPerfect`, khiến FOV thực render khi đứng yên bị làm tròn về bội số nguyên gần nhất (`CorrectCinemachineOrthoSize(5.5f) = 5.625f` tại `1280x720` và `1920x1080`). Nếu bật/tắt `CinemachinePixelPerfect` quanh mốc `5.5f` hoặc tắt hẳn extension này mà không giữ `PixelPerfectCamera.CorrectCinemachineOrthoSize(...)`, camera sẽ giật FOV 1 khung hình mỗi lần zoom hoặc bị khóa về `2.8125f`. Song song đó, `CinemachinePositionComposer.Lookahead` đang tắt và `Global Volume Profile.asset` giữ tĩnh `ChromaticAberration = 0.2`, `Vignette = 0.4`, `postExposure = -0.4`.

3. **Âm thanh phẳng, phát đè sự kiện và thiếu thang leo hòa âm**:
   - `PlayerMovement.Redirect()` phát liên tiếp `OnRedirected` rồi `OnMoveStarted`; `StartPhaseLaunch()` (khi `dist > 0`) phát `OnPhasingChanged(true)` rồi `OnRedirected` **không kèm** `OnMoveStarted`, sau đó `StepPhaseLaunch()` mới phát `OnMoveStarted` (hoặc `StopMoving()` nếu dừng); còn đảo chiều giữa đường (`pendingDirection == -moveDirection`) phát trực tiếp `OnMoveStarted` không qua `OnMoveStopped` hay `OnRedirected`. Hiện tại `EntityAudio` thiếu logic phân tách theo đúng hợp đồng sự kiện đó và `SoundManager` chưa có overload nhận `pitchMultiplier`. Các sự kiện `OnTileCrossed`, `OnVelocityTierChanged`, `OnPhasingChanged` đang im lặng hoàn toàn.

4. **Hệ thống đặt lệnh trước (`bufferTurnsUntilStop = true`) hoàn toàn vô hình**:
   - Ở tốc độ `30` ô/giây, người chơi phải bấm/vuốt hướng rẽ tiếp theo trước khi chạm tường, nhưng `PlayerMovement.pendingDirection` là biến `private` không phát event nên không có tín hiệu thị giác hay xúc giác xác nhận "lệnh rẽ đã ăn".

5. **Detector đắt giá và bề mặt mê cung chưa phản hồi**:
   - `CloseCallDetector.OnCloseCallTriggered` liên tục bắt các pha né laser (`<= 0.15s`) và lướt sượt `SentinelDrone` (`0.72..1.08` ô) nhưng có **0 subscriber** âm thanh/camera/post-process/haptics.
   - `PlayerLineTrail` kẹp `smoothedMoveSpeed` ở `28f` (thấp hơn `moveSpeed = 30` và `PhaseLaunch = 48`).
   - Đa số prefab tile (`Wedge.prefab`, `Brake.prefab`, `EnergyGate.prefab`, `FailingTile.prefab`, `GravityBlock.prefab`) hiện đặt `SpriteRenderer` và `BoxCollider2D` chung trên root (chỉ `VectorPad.prefab` có child `Visual`), khiến bất kỳ tween scale/shake ngây thơ nào lên `transform` gốc sẽ làm biến dạng collider tường/trigger nếu không tách bạch visual child.

## 2. Năm Trụ Cột Game Feel Đặc Trưng Cho Gravita

### Trụ Cột 1: Động Lực Học Bất Đối Xứng ("Snap-Hold-Release" Bù Tâm Pivot + Hit-Stop Thực Thời Gian & Húc Vỡ `CrackedBlock`)

#### Tại sao khiến Gravita cuốn và độc nhất?
Bản sắc của Gravita là **trượt thẳng không kiểm soát — dồn động năng qua từng ô — va đập cực gắt hoặc bám dừng từ trường**. Khi Subject G-0 **giữ dáng kéo giãn tăng dần theo 3 Velocity Tier suốt pha bay**, tự động **bù trừ tâm pivot `(0.5, 0)`** để ép dẹt sát bề mặt ở cả 4 hướng (trần/sàn/trái/phải), đồng thời giữ cho **camera shake + white hit-flash + vệt đuôi tiếp tục chạy mượt ngay trong `33–83 ms` đóng băng `Time.timeScale = 0`** và tách hoàn toàn cú hãm êm trên `BrakeTile`/`GravityBlock`, mỗi nhịp trượt trở nên đanh gọn như búa thủy lực. Tương tự, pha `KineticRam` húc vỡ `CrackedBlock` (không dừng trượt) vẫn nhận được một cú khựng micro hit-stop (`42 ms`), nhá trắng và giật ống kính để người chơi cảm nhận rõ tường vỡ dưới lực tông.

#### Thông số & Curve
- **Giữ dáng khí động học theo Tier (`.SetUpdate(true)` trên `visualTransform`, bù trừ pivot `(0.5, 0)`)**:
  - `Drift` (1–2 ô): scale dọc hướng trượt `+8%`, ép ngang `-4%`, thời gian vào dáng `0.028s` (`Ease.OutCubic`).
  - `Cruise` (3–4 ô): scale `+16%` / `-8%`, vào dáng `0.032s`.
  - `KineticRam` (5+ ô): scale `+25%` / `-13%`, vào dáng `0.035s`.
  - `IsPhasing` (`VectorLauncher`): scale `+32%` / `-16%` (cần `maxDeformation >= 0.45`).
- **Phản ứng khi chạm đích dừng (`OnMoveStopped`)**:
  - **Dừng từ trường (`WasLastStopWallImpact == false`, tức `BrakeTile` / `GravityBlock`)**: Tắt hoàn toàn wall Hit-Stop; rung nhẹ `magneticBrakeShake = 0.03f`, nén nhẹ `-9%` dọc / `+9%` ngang trong `0.035s`, `wallPressPx = 0`, trả về `baseScale` bằng `0.085s` (`Ease.OutBack`).
  - **Đâm tường cứng (`WasLastStopWallImpact == true`)**:
    - `Drift`: shake `0.05f`, hit-stop `0s`, nén `-12% / +12%`, ép vào tường `1.4 px` (`0.35 * 4px`), hồi `0.11s`.
    - `Cruise`: shake `0.12f`, hit-stop `0.033s`, nén `-24% / +24%`, ép `3.0 px` (`0.75 * 4px`), hồi `0.14s`, nhá `Hit Flash White.mat` trong `0.033s` realtime.
    - `KineticRam`: shake `0.24f`, hit-stop `0.083s`, snap nén cực đại `-43% / +40%` (`impactHeightPx = 16 / movingHeightPx = 28`, `impactWidthPx = 28 / movingWidthPx = 20`, nằm trong `maxDeformation = 0.45`) trong `0.015s` đầu để giữ form ép bẹt suốt thời gian đóng băng, ép `4.5 px` (`1.12 * 4px`), hồi `0.165s` (`Ease.OutBack`), nhá `Hit Flash White.mat` trong `0.055s` realtime.
- **Đâm vỡ `CrackedBlock` (`CrackedBlock.OnAnyBroken`)**: Bắn trước kiểm tra `HasCustomBreakEffect` để vẫn ăn hiệu ứng trên `Cracked.prefab`: `blockBreakShake = 0.16f` (nếu prefab chưa bật `InteractionEffectPlayer.HasConfiguredShake`), `blockBreakHitStop = 0.042s`, `kineticFlashDuration = 0.055s`, có `cooldown = 0.05s` unscaled để phá chuỗi 2 gạch liền kề không bị đóng băng đè nhau.
- **Tương thích Hit-Stop Realtime (`Time.timeScale = 0`)**:
  - `PlayerImpactFeedback` bật `CinemachineImpulseManager.Instance.IgnoreTimeScale = true` (một lần trong `OnEnable` để mọi impulse luôn đo bằng `Time.realtimeSinceStartup`), tạm bật `cinemachineBrain.IgnoreTimeScale = true` trong suốt Hit-Stop và trả lại trạng thái gốc trong `EndHitStopImmediate()` (gọi cả ở `OnDisable` / `OnDestroy`).
  - `PlayerImpactFeedback.IsHitStopActive` được `PlayerLineTrail.LateUpdate()` đọc để dùng `Time.unscaledDeltaTime` khi hit-stop (vẫn giữ `Time.deltaTime` = `0` khi mở menu Pause).
- **LineTrail Speed Cap**: Nâng `Mathf.Clamp(instSpeed, 4f, 28f)` lên `52f` để ribbon giữ đúng chiều dài động năng ở `moveSpeed = 30` và `PhaseLaunch = 48`.

```csharp
    private void HandlePendingChanged(Vector2 pendingDir)
    {

            {
                activeBufferedDir = Vector2.zero;
                PlayDismiss(consumed: false);
            }
            else
            {
                activeBufferedDir = Vector2.zero;
            }
            return;
        }

        bool isReverse = Vector2.Dot(pendingDir, playerMovement.CurrentDirection) < -0.5f;
        Color targetColor = isReverse ? reverseCancelColor : cornerTurnColor;

        arrowPivot.localPosition = (Vector3)(pendingDir * orbitRadius);
        arrowPivot.localRotation = Quaternion.Euler(0f, 0f, Mathf.Atan2(pendingDir.y, pendingDir.x) * Mathf.Rad2Deg);
```

```csharp
using System.Collections;
using DG.Tweening;
using UnityEngine;

/// <summary>
/// Reusable prefab-attached visual response for DeflectionWedge, VectorPad, BrakeTile,
/// GravityBlock, FailingTile, and EnergyGate. Strictly isolates Transform deformation to a
/// collider-free child Visual and falls back to material-only flash when Sprites sit on the physics root.
/// </summary>
public class TilePulseFeedback : MonoBehaviour
{
    [Header("Visual Target (Must Be a Collider-Free Child for Scale/Shake)")]
    [SerializeField] private Transform visualTarget;
    [SerializeField] private SpriteRenderer spriteRenderer;

    [Header("Optional Hit Flash")]
    [SerializeField] private Material flashMaterial;
    [SerializeField, Min(0f)] private float flashDuration = 0.045f;

    private IPlayerInteractable interactable;
    private FailingTile failingTile;
    private EnergyGate energyGate;

    private bool hasSafeVisualTarget;
    private Vector3 baseScale = Vector3.one;
    private Vector3 baseLocalPos = Vector3.zero;
    private Material cachedMaterial;
    private Coroutine flashRoutine;
    private bool isFlashing;
    private Sequence activeSequence;

    private void Awake()
    {
        if (!IsSafeVisualTransform(visualTarget))
            visualTarget = FindSafeVisualChild();

        hasSafeVisualTarget = IsSafeVisualTransform(visualTarget);
        if (hasSafeVisualTarget)
        {
            baseScale = visualTarget.localScale;
            baseLocalPos = visualTarget.localPosition;
        }

        if (spriteRenderer == null)
        {
            spriteRenderer = hasSafeVisualTarget
                ? visualTarget.GetComponentInChildren<SpriteRenderer>(true)
                : GetComponentInChildren<SpriteRenderer>(true);
        }

        interactable = GetComponent<IPlayerInteractable>();
        failingTile = GetComponent<FailingTile>();
        energyGate = GetComponent<EnergyGate>();
    }

    private void OnEnable()
    {
        if (interactable != null) interactable.OnPlayerInteracted += HandleInteracted;
        if (failingTile != null) failingTile.OnStateChanged += HandleFailingStateChanged;
        if (energyGate != null) energyGate.OnGateOpenStateChanged += HandleGateChanged;
    }

    private void OnDisable()
    {
        if (interactable != null) interactable.OnPlayerInteracted -= HandleInteracted;
        if (failingTile != null) failingTile.OnStateChanged -= HandleFailingStateChanged;
        if (energyGate != null) energyGate.OnGateOpenStateChanged -= HandleGateChanged;

        KillTweens();
        if (flashRoutine != null) { StopCoroutine(flashRoutine); flashRoutine = null; }
        RestoreMaterial();
        if (hasSafeVisualTarget && visualTarget != null)
        {
            visualTarget.localScale = baseScale;
            visualTarget.localPosition = baseLocalPos;
        }
    }

    private void HandleInteracted(InteractionContext ctx)
    {
        switch (ctx.Kind)
        {
            case InteractionKind.Deflect:
                if (hasSafeVisualTarget)
                {
                    Vector3 stretch = Mathf.Abs(ctx.Direction.x) >= Mathf.Abs(ctx.Direction.y)
                        ? new Vector3(baseScale.x * 1.22f, baseScale.y * 0.84f, baseScale.z)
                        : new Vector3(baseScale.x * 0.84f, baseScale.y * 1.22f, baseScale.z);
                    PlayScalePulse(stretch, 0.04f, 0.10f);
                }
                TriggerFlash();
                break;

            case InteractionKind.Brake:
                if (hasSafeVisualTarget)
                    PlayScalePulse(baseScale * 1.18f, 0.035f, 0.09f);
                else
                    TriggerFlash();
                break;

            case InteractionKind.Launch:
                if (hasSafeVisualTarget)
                    PlayScalePulse(baseScale * 1.26f, 0.04f, 0.11f);
                TriggerFlash();
                break;
        }
    }

    private void HandleFailingStateChanged(FailingTileState state)
    {
        if (!hasSafeVisualTarget)
        {
            if (state == FailingTileState.Warning || state == FailingTileState.Collapsing)
                TriggerFlash();
            return;
        }

        KillTweens();
        if (state == FailingTileState.Warning)
        {
            visualTarget.localPosition = baseLocalPos;
            visualTarget.DOShakePosition(0.55f, new Vector3(0.035f, 0.02f, 0f), 26, 90f, false, false)
                .SetUpdate(true)
                .SetLink(gameObject);
        }
        else if (state == FailingTileState.Collapsing)
        {
            visualTarget.localPosition = baseLocalPos;
            visualTarget.DOScale(baseScale * 0.65f, 0.25f)
                .SetEase(Ease.InBack)
                .SetUpdate(true)
                .SetLink(gameObject);
        }
        else
        {
            visualTarget.localPosition = baseLocalPos;
            visualTarget.localScale = baseScale;
        }
    }

    private void HandleGateChanged(bool isOpen)
    {
        if (!hasSafeVisualTarget)
        {
            TriggerFlash();
            return;
        }

        KillTweens();
        Vector3 start = isOpen
            ? new Vector3(baseScale.x * 1.15f, baseScale.y * 0.75f, baseScale.z)
            : new Vector3(baseScale.x * 0.85f, baseScale.y * 1.25f, baseScale.z);
        visualTarget.localScale = start;
        visualTarget.DOScale(baseScale, 0.12f).SetEase(Ease.OutBack).SetUpdate(true).SetLink(gameObject);
        TriggerFlash();
    }

    private void PlayScalePulse(Vector3 peakScale, float inDur, float outDur)
    {
        if (!hasSafeVisualTarget || visualTarget == null) return;
        KillTweens();
        activeSequence = DOTween.Sequence()
            .Append(visualTarget.DOScale(peakScale, inDur).SetEase(Ease.OutQuad))
            .Append(visualTarget.DOScale(baseScale, outDur).SetEase(Ease.OutBack))
            .SetUpdate(true)
            .SetLink(gameObject);
    }

    private void TriggerFlash()
    {
        if (spriteRenderer == null || flashMaterial == null || flashDuration <= 0f) return;
        if (!isFlashing) cachedMaterial = spriteRenderer.sharedMaterial;
        if (flashRoutine != null) StopCoroutine(flashRoutine);
        flashRoutine = StartCoroutine(FlashRoutine());
    }

    private IEnumerator FlashRoutine()
    {
        isFlashing = true;
        if (cachedMaterial != flashMaterial) spriteRenderer.sharedMaterial = flashMaterial;
        yield return new WaitForSecondsRealtime(flashDuration);
        RestoreMaterial();
        flashRoutine = null;
    }

    private void RestoreMaterial()
    {
        if (!isFlashing || spriteRenderer == null) return;
        if (cachedMaterial != null) spriteRenderer.sharedMaterial = cachedMaterial;
        isFlashing = false;
    }

    private void KillTweens()
    {
        if (activeSequence != null && activeSequence.IsActive()) activeSequence.Kill();
        activeSequence = null;
        if (hasSafeVisualTarget && visualTarget != null) visualTarget.DOKill();
    }

    private Transform FindSafeVisualChild()
    {
        SpriteRenderer[] renderers = GetComponentsInChildren<SpriteRenderer>(true);
        for (int i = 0; i < renderers.Length; i++)
        {
            if (renderers[i] != null && IsSafeVisualTransform(renderers[i].transform))
                return renderers[i].transform;
        }
        return null;
    }

    private bool IsSafeVisualTransform(Transform candidate)
    {
        return candidate != null
            && candidate != transform
            && candidate.GetComponent<Collider2D>() == null
            && candidate.GetComponentInChildren<Collider2D>(true) == null;
    }
}
```
