# Gravita (Puzzle 2D) — Game Feel & Kinetic Polish Upgrade Blueprint

> **Target Engine & Stack:** Unity `6000.4.0f1` (URP 2D), Cinemachine `3.1.7`, DOTween, TextMeshPro  
> **Architecture:** Event-driven SRP (`Gameplay` events -> `Feedback` & `Audio` consumers)  
> **Hard Invariants:** Deterministic `FixedUpdate` cell-center grid snapping unchanged; puzzle soft-lock rules unchanged; `CloseCallDetector` never mutates `Time.timeScale`; zero procedural `new GameObject(...)` or runtime `AddComponent<...>()` for UI/VFX/managers; DOTween sequences/tweens always invoke `.DOKill()`, `.SetUpdate(true)`, and `.SetLink(gameObject)`.

---

## 1. Architectural Premise & Foundational Design Contracts

Before touching curves or shaders, four architectural contracts must lock cleanly so polish systems reinforce puzzle readability rather than fighting Unity's camera pipeline, coroutine lifecycle, or grid determinism:

1. **Camera Framing Polarity (Paired Pixel-Perfect vs. Smooth Kinetic Framing):**
   - In `Assets/Scenes/GameScene.unity`, `Main Camera` hosts `PixelPerfectCamera` (`fileID: 519420034`, `m_Enabled: 1`, `assetsPPU: 32`, `320x180`, `cropFrame: None`), while `CinemachineCamera` hosts `CinemachinePixelPerfect` (`fileID: 1780404332`, `m_Enabled: 1`).
   - In URP 2D + Cinemachine `3.1.7`, `PixelPerfectCamera.OnEnable()` initializes `m_CinemachineCompatibilityMode = false`. Only `CinemachinePixelPerfect` sets that flag `true` when updating the virtual camera lens. Disabling `CinemachinePixelPerfect` alone leaves `PixelPerfectCamera.OnBeginCameraRendering` running and forces `m_Camera.orthographicSize = m_Internal.orthoSize` (`2.8125` at `1920x1080`) every frame—silently overriding `CinemachineCameraZoom2D` (`normalOrthographicSize = 5.5f`) and locking camera framing. Moreover, toggling pixel-perfection at dash start/stop pops between unquantized `5.50` and quantized `16.875 / 3 = 5.625` at 1080p.
   - **Contract:** **Smooth Feel Mode** (default) disables **both** `CinemachinePixelPerfect` (`1780404332`) and `PixelPerfectCamera` (`519420034`), preserving crisp texture sampling via sprite import `FilterMode.Point` while enabling continuous `5.28–5.88` zoom breathing and sub-pixel directional recoil. An optional **Retro Crisp / Reduced-Motion** accessibility toggle enables **both** components together and disables dynamic zoom/shake (`enableDynamicZoom = false`), ensuring users never experience mid-play ortho snap pops.
2. **Time-Scale Invariance & Freeze-Safe Hit-Stop:**
   - Only `PlayerImpactFeedback` may pause simulation via `Time.timeScale = 0f` on high-energy wall collisions or cracked-block breaks.
   - During hit-stop, `cinemachineBrain.IgnoreTimeScale` **and** `CinemachineImpulseManager.Instance.IgnoreTimeScale` must both be forced `true` so `CinemachineImpulseSource` shakes keep advancing while physics pauses, and a single `RestoreHitStopState()` method must run on coroutine pre-emption, enumerator `finally`, and `OnDisable()` (because `StopCoroutine` and `OnDisable` bypass coroutine `finally` blocks).
   - `CloseCallDetector` and `CloseCallFeedback` remain strictly time-scale invariant (`Time.timeScale` stays `1f`).
3. **Post-Processing Separation:**
   - `Assets/Volume/Global Volume Profile.asset` drives baseline tile/laser/UI `Bloom` (`threshold: 0.9`, `intensity: 9`, `scatter: 0.8`, `clamp: 10`) plus base `Vignette` (`0.4`) and `ChromaticAberration` (`0.2`). `VelocityRunwayFeedback` must **not** modulate `Global Volume.weight` (which would zero out scene bloom while stationary). Instead, kinetic runway and impact spikes drive a dedicated global additive `Volume` (`FeelPostVolume`, `Priority = 1`, `Weight = 0f` at rest, referencing `Assets/Volume/KineticFeelVolumeProfile.asset`), leaving baseline art untouched.
4. **Zero-Collision Audio Pooling & Material Truth:**
   - `Assets/Prefabs/Manager/AudioSystems.prefab` currently serializes `pooledAudioSourcePrefab: {fileID: 0}` and `sfxPool: [null]`, leaving `SoundManager` on a single shared fallback `AudioSource` whose `.pitch` shifts active clips mid-playback. Restoring a 10-voice `AudioSource` pool plus a fallback pitch guard eliminates pitch-bending artifacts.
   - All `SoundConfig.asset` entries (`clips: []` currently empty) map to distinct, verified WAVs in `Assets/Audio/Sounds/`. Hazard telegraphing explicitly inspects `Glow VFX.mat` (`_GlowColor`, `_GlowIntensity` on `Hazard.prefab`) and `Master Outline.mat` (`Glowing Outline.shadergraph`: `_OutlineColor`, `_Thickness` for `PulseLaser`, `OverloadedFloor`, and `FailingTile`) with clean `SpriteRenderer.color` fallback and `OnDisable()` restoration compatible with `Hazard.FreezeTarget()`.

### Pillar 1: Kinetic Velocity Runway & Phase-Launch Distortion

**Feel Goal:** Give `Drift` (1–2 tiles), `Cruise` (3–4 tiles), `KineticRam` (5+ tiles), and `VectorLauncher` phase flight escalating spatial speed—expanding camera FOV gently as momentum builds, intensifying peripheral aberration and vignette through an additive `FeelPostVolume`, and snapping cleanly back on impact or stop.

#### Exact Behavior & Curves
- **Camera Framing Contract:** Both `CinemachinePixelPerfect` (`1780404332`) and `PixelPerfectCamera` (`519420034`) stay disabled in Smooth Feel mode (`ortho` smooth breathing; sprite `FilterMode.Point` retained).
- **Dynamic Ortho Ladder (`CinemachineCameraZoom2D`):**
  - Rest (`None`): `5.50f` (damping speed `5.2f`)
  - `Drift` (1–2 tiles): `5.56f`
  - `Cruise` (3–4 tiles): `5.70f`
  - `KineticRam` (5+ tiles): `5.88f`
  - Phase Launch (`IsPhasing`): `5.96f` (damping speed `9.5f`)
  - Impact / Close-Call Micro-Punch (`PulseOrthographicSize`): instant `deltaOrtho` (`-0.22f` on wall slam) for `0.025s` -> `OutCubic` recovery over `0.11s` using unscaled time, during which `CinemachineCameraZoom2D.Update()` suspends lerping so `Update()` never fights the punch.
- **Additive Volume Weight (`Assets/Volume/KineticFeelVolumeProfile.asset` on `FeelPostVolume`):**
  - Profile configured at full effect (`Weight = 1.0` reference): `ChromaticAberration.intensity = 0.35`, `Vignette.intensity = 0.24`, `Bloom.intensity = 1.8` (additive glow accent), `LensDistortion.intensity = -0.10`.
  - Runtime `feelVolume.weight` ramps via unscaled `Time.unscaledDeltaTime`: `0.00f` (`None`) -> `0.22f` (`Drift`) -> `0.45f` (`Cruise`) -> `0.68f` (`KineticRam`) -> `0.85f` (`IsPhasing`).
- **Hit-Stop Freeze Safety:** `VelocityRunwayFeedback.Update()` early-returns if `Time.deltaTime <= 0f` (matching `PlayerLineTrail.LateUpdate()`'s existing `if (dt <= 0f) return;` gate) so volume/camera state holds crisply across freeze frames.

#### Camera Zoom Upgrade (`Assets/Scripts/Feedback/CinemachineCameraZoom2D.cs`)
Preserve `SetTargetOrthographicSize` and `SetNormalOrthographicSize`, add DOTween unscaled punch (`DOKill` / `SetUpdate(true)` / `SetLink(gameObject)`), and guard `Update()`:

```csharp
using DG.Tweening;
using UnityEngine;
using Unity.Cinemachine;

// Add fields to CinemachineCameraZoom2D:
private Sequence orthoPulseSequence;
private float pulseBaseOrthoSize;

private void Update()
{
    if (cinemachineCamera == null) return;
    if (orthoPulseSequence != null && orthoPulseSequence.IsActive()) return;

    float dt = Time.unscaledDeltaTime;
    float current = cinemachineCamera.Lens.OrthographicSize;
    if (Mathf.Approximately(current, targetOrthographicSize)) return;

    var lens = cinemachineCamera.Lens;
    lens.OrthographicSize = Mathf.Lerp(current, targetOrthographicSize, 1f - Mathf.Exp(-zoomSpeed * dt));
    cinemachineCamera.Lens = lens;
}

public void PulseOrthographicSize(float deltaOrtho, float holdSeconds = 0.025f, float recoverSeconds = 0.11f)
{
    if (cinemachineCamera == null) return;
    orthoPulseSequence?.Kill();

    float baseOrtho = targetOrthographicSize;
    float punched = Mathf.Max(2.5f, baseOrtho + deltaOrtho);

    var lens = cinemachineCamera.Lens;
    lens.OrthographicSize = punched;
    cinemachineCamera.Lens = lens;

    orthoPulseSequence = DOTween.Sequence()
        .SetUpdate(true)
        .SetLink(gameObject);

    if (holdSeconds > 0f)
        orthoPulseSequence.AppendInterval(holdSeconds);

    orthoPulseSequence.Append(
        DOTween.To(
            () => cinemachineCamera.Lens.OrthographicSize,
            val =>
            {
                var l = cinemachineCamera.Lens;
                l.OrthographicSize = val;
                cinemachineCamera.Lens = l;
            },
            targetOrthographicSize,
            recoverSeconds
        ).SetEase(Ease.OutCubic)
    );
}

private void OnDisable()
{
    orthoPulseSequence?.Kill();
    orthoPulseSequence = null;
}
```

#### Concrete Runway Script (`Assets/Scripts/Feedback/VelocityRunwayFeedback.cs`)
Handles `SetPhasing(false) -> OnPhaseLanded -> OnMoveStarted(KineticRam)` cleanly without losing runway zoom on valid exits or stranding at `5.96` on cancel/idle:

```csharp
using UnityEngine;
using UnityEngine.Rendering;

namespace Assets.Scripts.Feedback
{
    public class VelocityRunwayFeedback : MonoBehaviour
    {
        [Header("References")]
        [SerializeField] private PlayerMovement playerMovement;
        [SerializeField] private CinemachineCameraZoom2D cameraZoom;
        [SerializeField] private Volume feelVolume;

        [Header("Accessibility")]
        [SerializeField] private bool enableDynamicZoom = true;

        [Header("Orthographic Targets")]
        [SerializeField] private float restOrtho = 5.50f;
        [SerializeField] private float driftOrtho = 5.56f;
        [SerializeField] private float cruiseOrtho = 5.70f;
        [SerializeField] private float kineticOrtho = 5.88f;
        [SerializeField] private float phaseOrtho = 5.96f;

        [Header("Additive Volume Weight Targets")]
        [SerializeField] private float driftWeight = 0.22f;
        [SerializeField] private float cruiseWeight = 0.45f;
        [SerializeField] private float kineticWeight = 0.68f;
        [SerializeField] private float phaseWeight = 0.85f;
        [SerializeField] private float weightDampSpeed = 10f;

        private float targetVolumeWeight;

        private void OnEnable()
        {
            if (playerMovement == null) return;
            playerMovement.OnVelocityTierChanged += HandleTierChanged;
            playerMovement.OnPhasingChanged += HandlePhasingChanged;
            playerMovement.OnMoveStarted += HandleMoveStarted;
            playerMovement.OnMoveStopped += HandleMoveStopped;

            if (cameraZoom != null && enableDynamicZoom)
                cameraZoom.SetNormalOrthographicSize(restOrtho);

            RefreshFromPlayerState();
        }

        private void OnDisable()
        {
            if (playerMovement != null)
            {
                playerMovement.OnVelocityTierChanged -= HandleTierChanged;
                playerMovement.OnPhasingChanged -= HandlePhasingChanged;
                playerMovement.OnMoveStarted -= HandleMoveStarted;
                playerMovement.OnMoveStopped -= HandleMoveStopped;
            }

            if (feelVolume != null)
                feelVolume.weight = 0f;
        }

        private void Update()
        {
            if (Time.deltaTime <= 0f || feelVolume == null) return;
            feelVolume.weight = Mathf.Lerp(
                feelVolume.weight,
                targetVolumeWeight,
                1f - Mathf.Exp(-weightDampSpeed * Time.unscaledDeltaTime)
            );
        }

        private void HandleTierChanged(VelocityTier tier)
        {
            if (playerMovement != null && playerMovement.IsPhasing) return;
            ApplyTierState(tier);
        }

        private void HandlePhasingChanged(bool isPhasing)
        {
            if (isPhasing)
            {
                if (enableDynamicZoom && cameraZoom != null)
                    cameraZoom.SetTargetOrthographicSize(phaseOrtho);
                targetVolumeWeight = phaseWeight;
                return;
            }

            // Reset immediately on phase exit/cancel so Freeze/ResetDirectionHistory never strands at 5.96;
            // if StepPhaseLaunch continues moving, HandleMoveStarted fires synchronously right after and re-applies KineticRam.
            ApplyTierState(VelocityTier.None);
        }

        private void HandleMoveStarted(Vector2 _)
        {
            RefreshFromPlayerState();
        }

        private void HandleMoveStopped()
        {
            // Never gate out stops with !wasPhasing; Reset to rest cleanly.
            ApplyTierState(VelocityTier.None);
        }

        private void RefreshFromPlayerState()
        {
            if (playerMovement == null) return;
            if (playerMovement.IsPhasing)
            {
                HandlePhasingChanged(true);
                return;
            }

            ApplyTierState(playerMovement.IsMoving ? playerMovement.CurrentTier : VelocityTier.None);
        }

        private void ApplyTierState(VelocityTier tier)
        {
            float ortho = restOrtho;
            float weight = 0f;

            switch (tier)
            {
                case VelocityTier.Drift:
                    ortho = driftOrtho;
                    weight = driftWeight;
                    break;
                case VelocityTier.Cruise:
                    ortho = cruiseOrtho;
                    weight = cruiseWeight;
                    break;
                case VelocityTier.KineticRam:
                    ortho = kineticOrtho;
                    weight = kineticWeight;
                    break;
            }

            if (enableDynamicZoom && cameraZoom != null)
                cameraZoom.SetTargetOrthographicSize(ortho);

            targetVolumeWeight = weight;
        }
    }
}
```

### Pillar 2: Directional Impact Physics, Freeze-Safe Hit-Stop & Vector Recoil

**Feel Goal:** Make wall hits, cracked-block breaks, and magnetic-brake halts feel physically distinct—delivering instant contact sparks at the exact collision point, directional camera impulse along the travel vector, freeze-safe unscaled hit-stop scaled to impact speed, and soft magnetic deceleration on `Brake` pads.

#### Exact Event Ordering & Timing Matrix
In `PlayerMovement`, `OnWallImpact(normal)` fires **before** `StopMoving(wallImpact: true)` commits `LastImpactTier`, `WasLastStopWallImpact`, and `OnMoveStopped()`. Therefore:
- `HandleWallImpact(Vector2 normal)` is scoped strictly to contact-point burst VFX (reading `movement.CurrentTier` because `LastImpactTier` is not committed yet).
- `HandleStopped()` runs after `StopMoving(...)` and routes tier-gated **Wall Impact** feedback (`WasLastStopWallImpact == true`) vs. **Magnetic Brake** settle (`WasLastStopWallImpact == false`).

| Event & Energy State | Hit-Stop (`Time.timeScale = 0`) | Directional Shake (`Vector2, force`) | Camera Ortho Punch | Contact / Break VFX | Flash / Volume Accent |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Wall Impact — `Drift`** (1–2 tiles) | `0.000s` (none) | `0.09f` (`LastMoveDirection`) | `-0.04f` | `WallImpactBurst.prefab` (small) | Subtle flash (`0.05s`) |
| **Wall Impact — `Cruise`** (3–4 tiles) | `0.032s` | `0.20f` (`LastMoveDirection`) | `-0.12f` | `WallImpactBurst.prefab` | Hit flash (`0.08s`) + `feelVolume` spike |
| **Wall Impact — `KineticRam`** (5+ tiles) | `0.055s` | `0.36f` (`LastMoveDirection`) | `-0.22f` | `WallImpactBurst.prefab` + `Particle Smoke.prefab` | Heavy hit flash (`0.11s`) + `feelVolume` spike |
| **Cracked Block Break** (`CrackedBlock.OnAnyBroken`) | `0.045s` | `0.36f` (`LastMoveDirection`) | `-0.24f` | `WallImpactBreak.prefab` (`HasCustomBreakEffect` guard) | Heavy hit flash + shard dust |
| **Magnetic Brake Stop** (`WasLastStopWallImpact == false`) | `0.000s` (none) | `0.06f` (`LastMoveDirection`) | `0.00f` (smooth return) | `Particle Cloud.prefab` soft ring (optional) | Soft blue-teal edge pulse / zero flash |
| **Phase Launch Exit Slam** (`OnPhaseLanded`) | `0.025s` | `0.24f` (`exitDir`) | `-0.14f` | `WallImpactBurst.prefab` | Brief rim glow |

#### Directional Shake Upgrade (`Assets/Scripts/Feedback/CinemachineCameraShake2D.cs`)
Add directional velocity generation using Cinemachine `3.1.7`'s verified `GenerateImpulseWithVelocity(Vector3)` API while retaining existing `ShakeCamera()` / `ShakeCamera(float force)` methods:

```csharp
// Add to CinemachineCameraShake2D.cs alongside its existing serialized CinemachineImpulseSource field:
public void ShakeCamera(Vector2 direction, float force)
{
    if (impulseSource == null || force <= 0f) return;
    Vector2 dir = direction.sqrMagnitude > 0.0001f ? direction.normalized : Vector2.down;
    impulseSource.GenerateImpulseWithVelocity(new Vector3(dir.x, dir.y, 0f) * force);
}
```

#### Leak-Proof Hit-Stop & Impact Routing (`Assets/Scripts/Feedback/PlayerImpactFeedback.cs`)
Add explicit hit-stop state restoration (`RestoreHitStopState()`), synchronize `CinemachineImpulseManager.Instance.IgnoreTimeScale = true` with `cinemachineBrain.IgnoreTimeScale = true`, call `PulseHitStop(crackedBreakHitStop)`, and split contact VFX vs. post-commit stop routing:

```csharp
using System.Collections;
using Unity.Cinemachine;
using UnityEngine;

// Key additions & replacements inside PlayerImpactFeedback.cs:
[Header("Feedback Collaborators (Inspector Assigned)")]
[SerializeField] private CinemachineBrain cinemachineBrain;
[SerializeField] private CinemachineCameraShake2D cameraShake;
[SerializeField] private CinemachineCameraZoom2D cameraZoom;
[SerializeField] private GameObject wallImpactBurstPrefab;
[SerializeField] private GameObject crackedBreakVfxPrefab;
[SerializeField] private GameObject brakeAnchorVfxPrefab;

[Header("Tier Shake & Hit-Stop Tuning")]
[SerializeField] private float driftShakeForce = 0.09f;
[SerializeField] private float cruiseShakeForce = 0.20f;
[SerializeField] private float kineticShakeForce = 0.36f;
[SerializeField] private float brakeSettleShakeForce = 0.06f;
[SerializeField] private float cruiseHitStop = 0.032f;
[SerializeField] private float kineticHitStop = 0.055f;
[SerializeField] private float crackedBreakHitStop = 0.045f;
[SerializeField] private float crackedBreakShakeForce = 0.36f;

private Coroutine hitStopRoutine;
private bool isHitStopActive;
private float preHitStopTimeScale = 1f;
private bool preHitStopBrainIgnoreTimeScale;
private bool preHitStopImpulseIgnoreTimeScale;

private void OnDisable()
{
    // Unsubscribe existing PlayerMovement / CrackedBlock / PowerUpController events here...
    if (hitStopRoutine != null)
    {
        StopCoroutine(hitStopRoutine);
        hitStopRoutine = null;
    }
    RestoreHitStopState();
}

// Fires BEFORE StopMoving(wallImpact: true): strictly scoped to contact VFX, reading CurrentTier.
private void HandleWallImpact(Vector2 normal)
{
    if (playerMovement == null || wallImpactBurstPrefab == null) return;

    Vector3 spawnPos = playerMovement.LastImpactPoint != Vector3.zero
        ? playerMovement.LastImpactPoint
        : transform.position;
    Quaternion rot = normal.sqrMagnitude > 0.001f
        ? Quaternion.FromToRotation(Vector3.up, normal)
        : Quaternion.identity;

    VfxSpawner.Spawn(wallImpactBurstPrefab, spawnPos, rot);
}

// Fires AFTER StopMoving(...): LastImpactTier, WasLastStopWallImpact, and LastMoveDirection are committed.
private void HandleStopped()
{
    if (playerMovement == null) return;
    Vector2 dir = playerMovement.LastMoveDirection.sqrMagnitude > 0.001f
        ? playerMovement.LastMoveDirection
        : Vector2.down;

    if (!playerMovement.WasLastStopWallImpact)
    {
        // Magnetic Brake / soft deceleration settle (zero hit-stop, subtle anchor nudge)
        if (cameraShake != null)
            cameraShake.ShakeCamera(dir, brakeSettleShakeForce);
        if (brakeAnchorVfxPrefab != null)
            VfxSpawner.Spawn(brakeAnchorVfxPrefab, transform.position, Quaternion.identity);
        return;
    }

    switch (playerMovement.LastImpactTier)
    {
        case VelocityTier.KineticRam:
            TriggerHitFlash(0.11f);
            if (cameraShake != null) cameraShake.ShakeCamera(dir, kineticShakeForce);
            if (cameraZoom != null) cameraZoom.PulseOrthographicSize(-0.22f, 0.025f, 0.12f);
            PulseHitStop(kineticHitStop);
            break;

        case VelocityTier.Cruise:
            TriggerHitFlash(0.08f);
            if (cameraShake != null) cameraShake.ShakeCamera(dir, cruiseShakeForce);
            if (cameraZoom != null) cameraZoom.PulseOrthographicSize(-0.12f, 0.02f, 0.10f);
            PulseHitStop(cruiseHitStop);
            break;

        default: // Drift
            TriggerHitFlash(0.05f);
            if (cameraShake != null) cameraShake.ShakeCamera(dir, driftShakeForce);
            if (cameraZoom != null) cameraZoom.PulseOrthographicSize(-0.04f, 0.01f, 0.08f);
            break;
    }
}

private void HandleBlockBroken(CrackedBlock block)
{
    Vector2 dir = playerMovement != null && playerMovement.LastMoveDirection.sqrMagnitude > 0.001f
        ? playerMovement.LastMoveDirection
        : Vector2.down;

    if (crackedBreakVfxPrefab != null && (block == null || !block.HasCustomBreakEffect))

private void PulseHitStop(float duration)
{
    if (duration <= 0f || !gameObject.activeInHierarchy) return;

    if (hitStopRoutine != null)
    {
        StopCoroutine(hitStopRoutine);
        hitStopRoutine = null;
        RestoreHitStopState();
    }

    hitStopRoutine = StartCoroutine(HitStopRoutine(duration));
}

private IEnumerator HitStopRoutine(float duration)
{
    preHitStopTimeScale = Time.timeScale;
    preHitStopBrainIgnoreTimeScale = cinemachineBrain != null && cinemachineBrain.IgnoreTimeScale;
    preHitStopImpulseIgnoreTimeScale = CinemachineImpulseManager.Instance.IgnoreTimeScale;
    isHitStopActive = true;

    Time.timeScale = 0f;
    if (cinemachineBrain != null) cinemachineBrain.IgnoreTimeScale = true;
    CinemachineImpulseManager.Instance.IgnoreTimeScale = true;

    try
    {
        float endTime = Time.realtimeSinceStartup + duration;
        while (Time.realtimeSinceStartup < endTime)
            yield return null;
    }
    finally
    {
        RestoreHitStopState();
        hitStopRoutine = null;
    }
}

private void RestoreHitStopState()
{
    if (!isHitStopActive) return;
    Time.timeScale = preHitStopTimeScale;
    if (cinemachineBrain != null) cinemachineBrain.IgnoreTimeScale = preHitStopBrainIgnoreTimeScale;
    CinemachineImpulseManager.Instance.IgnoreTimeScale = preHitStopImpulseIgnoreTimeScale;
    isHitStopActive = false;
}
```

### Pillar 3: Surface-Pinned Elastic Kinematics & Phase-Launch Elasticity

**Feel Goal:** Eliminate rubbery ease-in lag and top/side-wall air gaps on `Player/Sprite`, give every movement transition immediate frame-0 elastic snap anchored against the impacted wall or floor, and prevent synchronous `OnRedirected -> OnMoveStarted` and `OnPhaseLanded -> OnMoveStarted` sequences from canceling each other's tweens.

#### Existing Strengths vs. Real Gaps in `PlayerSquashStretch.cs`
`PlayerSquashStretch.cs` already cleans up active tweens (`KillActive()`), runs unscaled (`SetUpdate(true)`), and attaches lifecycle cleanup (`SetLink(gameObject)`) inside both `Play()` and `ResetScale()`. The actual physical bottlenecks are:
1. **Ease-In Lag:** `Deform` takes a 2-stage tween *into* target deformation instead of snapping at frame `0` to the deformed silhouette and snapping back via `Ease.OutBack`.
2. **Pivot Drift on `+Y` Ceilings & `±X` Walls:** `Player/Sprite` uses a bottom-center `(0.5, 0)` sprite pivot. Compressing `localScale.y` to `0.72` while hitting a top ceiling (`+Y`) pulls the sprite's top edge downward (`(1 - 0.72) * spriteHeight`), opening a visible gap between player and ceiling; pressing `wallPressPx = 4f` must offset toward the impacted face relative to the cached `baseLocalPosition`.
3. **Same-Stack Event Cancellation:**
   - `StartPhaseLaunch` emits `SetPhasing(true)` then immediately emits `OnRedirected`.
   - `Redirect` emits `OnRedirected` then immediately emits `OnMoveStarted`.
   - `StepPhaseLaunch` arrival emits `SetPhasing(false)` -> **`OnPhaseLanded(exitDir)`** -> `OnMoveStarted(moveDirection)` (or `StopMoving` when `phasePostDirection == Vector2.zero`).

#### Axis-Transposed `PlayPinnedImpulse` & Synchronous Suppression Guards (`PlayerSquashStretch.cs`)

| Kinetic Event | Along-Axis Scale | Perp-Axis Scale | Duration | Pin Mode | Suppression Guard |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Dash Start** (`OnMoveStarted`) | `1.24f` | `0.80f` | `0.14s` | Center-anchored | Skipped if `suppressNextMoveStart` consumed |
| **Wedge Redirect** (`OnRedirected`) | `1.28f` | `0.78f` | `0.12s` | Center-anchored | Skipped if `suppressNextRedirectFromPhase`; sets `suppressNextMoveStart = true` |

```csharp
private void HandlePhasingChanged(bool isPhasing)
{

        return;

}

private void HandleMoveStarted(Vector2 dir)

    {
        suppressNextMoveStart = false;
        return;
    }

private void HandleStopped()

    suppressNextMoveStart = false;

        PlayPinnedImpulse(playerMovement.LastMoveDirection, scaleAlong: 0.88f, scalePerp: 1.12f, duration: 0.14f, Ease.OutCubic, pressUnits: 0f, centerAnchored: true);

/// <summary>
/// Frame-0 pinned impulse deform anchored around baseScale and baseLocalPosition.
/// Transposes (scaleAlong, scalePerp) automatically by dominant axis and compensates for bottom-center (0.5, 0) sprite pivot on +Y ceilings.
/// </summary>
private void PlayPinnedImpulse(
    Vector2 dir,
    float scaleAlong,
    float scalePerp,
    float duration,
    Ease ease,
    float pressUnits,
    bool centerAnchored = false)
{
    if (visualTransform == null) return;
    KillActive();

    Vector2 d = dir.sqrMagnitude > 0.0001f ? dir.normalized : Vector2.down;
    bool horizontal = Mathf.Abs(d.x) >= Mathf.Abs(d.y);

    float sx = baseScale.x * (horizontal ? scaleAlong : scalePerp);
    float sy = baseScale.y * (horizontal ? scalePerp : scaleAlong);

    Vector3 offset = Vector3.zero;
    if (!centerAnchored)
    {
        // Push visual slightly into impacted face
        offset += new Vector3(d.x * pressUnits, d.y * pressUnits, 0f);
    }

    // Bottom-center pivot (0.5, 0): compensate vertical scale change when pressing ceiling (+Y) or center-anchored vertical stretch
    if (d.y > 0.5f || centerAnchored)
    {
        float heightDelta = (baseScale.y - sy) * spriteWorldHeight;
        offset.y += centerAnchored ? heightDelta * 0.5f : heightDelta;
    }

    visualTransform.localScale = new Vector3(sx, sy, baseScale.z);
    visualTransform.localPosition = baseLocalPosition + offset;

    activeSequence = DOTween.Sequence()
        .SetUpdate(true)
        .SetLink(gameObject)
        .Append(visualTransform.DOScale(baseScale, duration).SetEase(ease))
        .Join(visualTransform.DOLocalMove(baseLocalPosition, duration).SetEase(ease));
}
```

```csharp
            tickTimer -= Time.deltaTime;
            if (tickTimer <= 0f)
            {
                tickTimer = tickInterval;
                warningProgress = Mathf.Clamp01(warningProgress + 0.25f);
                if (SoundManager.Instance != null && soundConfig != null)
                {
                    float pitch = Mathf.Lerp(0.95f, 1.15f, warningProgress);
                    SoundManager.Instance.PlaySFX(soundConfig.hazardWarningTick, pitchOverride: pitch);
                }
            }
        }

        private void HandleHazardPhaseChanged(HazardActivation.Phase phase)
        {
            switch (phase)
            {
                case HazardActivation.Phase.Warning:
                    StartWarningPulse();
                    break;
                case HazardActivation.Phase.Active:
                    ApplyActiveState();
                    break;
                default:
                    ResetVisuals();
                    break;
            }
        }

        private void HandleFailingStateChanged(FailingTile.TileState state)
        {
            switch (state)
            {
                case FailingTile.TileState.Warning:
                    StartWarningPulse();
                    break;
                case FailingTile.TileState.Collapsing:
                case FailingTile.TileState.Collapsed:
                    ApplyActiveState();
                    break;
                default:
                    ResetVisuals();
                    break;
            }
        }

        private void StartWarningPulse()
        {
            pulseTween?.Kill();
            isWarning = true;
            tickTimer = 0f;
            warningProgress = 0f;

            if (targetRenderer == null) return;

            pulseTween = DOVirtual.Float(0f, 1f, 0.16f, t => ApplyWarningIntensity(t, warningColor))
                .SetLoops(-1, LoopType.Yoyo)
                .SetEase(Ease.InOutSine)
                .SetUpdate(false) // Pauses cleanly during hit-stop
                .SetLink(gameObject);
        }

        private void ApplyActiveState()
        {
            pulseTween?.Kill();
            isWarning = false;
            ApplyWarningIntensity(1f, activeColor);
            if (targetRenderer != null)
            {
                targetRenderer.transform.localScale = baseScale * 1.08f;
                pulseTween = targetRenderer.transform.DOScale(baseScale, 0.12f)
                    .SetEase(Ease.OutBack)
                    .SetUpdate(true)
                    .SetLink(gameObject);
            }
        }

        private void ApplyWarningIntensity(float normalized, Color tint)
        {
            if (usesGlowVfx && instancedMat != null)
            {
                instancedMat.SetColor(GlowColorId, tint);
                instancedMat.SetFloat(GlowIntensityId, Mathf.Lerp(baseGlow, warningMaxGlow, normalized));
            }
            else if (usesOutlineGraph && instancedMat != null)
            {
                instancedMat.SetColor(OutlineColorId, tint);
                instancedMat.SetFloat(ThicknessId, Mathf.Lerp(baseThickness, warningMaxThickness, normalized));
            }
            else if (targetRenderer != null)
            {
                targetRenderer.color = Color.Lerp(baseColor, tint, normalized * 0.65f);
            }
        }

        private void ResetVisuals()
        {
            pulseTween?.Kill();
            pulseTween = null;
            isWarning = false;

            if (targetRenderer != null)
            {
                targetRenderer.color = baseColor;
                targetRenderer.transform.localScale = baseScale;
            }
            if (usesGlowVfx && instancedMat != null)
                instancedMat.SetFloat(GlowIntensityId, baseGlow);
            if (usesOutlineGraph && instancedMat != null)
                instancedMat.SetFloat(ThicknessId, baseThickness);
        }
    }
}
```
