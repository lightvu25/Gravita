# Gravita — Game Feel Signature Upgrade Blueprint

## Verified Technical Baseline & Design Constraints
- **Velocity Tier Thresholds** (`Assets/Scripts/Gameplay/VelocityTier.cs`): `Drift = 1–2`, `Cruise = 3–4`, and `KineticRam = 5+` tiles (`VelocityTierUtil.FromTiles`). All feedback hooks below subscribe to `PlayerMovement.CurrentTier`, `PlayerMovement.LastImpactTier`, and `PlayerMovement.OnVelocityTierChanged` so thresholds remain decoupled from future tuning.
- **Live Scene Timing (`moveSpeed = 30`)**: `Assets/Scenes/GameScene.unity` configures `PlayerMovement.moveSpeed = 30` units/sec (`1 tile = 33.3 ms`). A 2-tile `Drift` completes in `66.7 ms` (4 frames @ 60 Hz), `Cruise` begins at `100 ms`, and `KineticRam` engages at `166.7 ms` (with `VectorLauncher` Phase Launch running at `1.6x = 48 u/s`). Numbers below are tuned for `30 u/s` (remaining valid across `24–36 u/s`).
- **Baseline Framing & Scene Values**: `CinemachineCamera.Lens.OrthographicSize = 5.5` (`CinemachineCameraZoom2D.normalOrthographicSize = 5.5`), `CinemachineBrain.IgnoreTimeScale = 0`, `CinemachineImpulseSource.DefaultVelocity = (0, -1, 0)`, `Player/Sprite` `localPosition = (0, -0.5, 0)` (bottom-center `(0.5, 0)` pivot), `PlayerSquashStretch.maxDeformation = 0.3` (overriding script default `0.45`), and `PlayerImpactFeedback` `tier1Shake = 0`, `tier2Shake = 0.1`, `tier3Shake = 0.2`, `redirectShake = 0`.
- **Architecture & Safety Rules**: All additions live as Layer 3/4 observers in `Assets/Scripts/Feedback/` and `Assets/Scripts/Audio/`. Zero runtime `new GameObject(...)` or `AddComponent<...>()`, zero changes to `PlayerMovement.FixedUpdate` / `SimulateStep`, strict respect for `CloseCallDetector`'s zero-`Time.timeScale` guarantee, and every DOTween sequence calls `KillActive()` / `.DOKill()`, `.SetUpdate(true)`, and `.SetLink(gameObject)`.

## 1. Core Game Feel Diagnosis: Why Gravita Currently Feels "Flat"

Gravita already contains impact shake, squash/stretch, trails, audio, and haptics—yet five concrete technical mismatches in the current scene and scripts mute their combined impact:

1. **Hit-Stop Freezes Camera Shake, Camera Zoom & Trail Mid-Impact**
   - `PlayerImpactFeedback.HitStopRoutine` drops `Time.timeScale = 0f` for `0.033s` (`Cruise`) and `0.083s` (`KineticRam`).
   - While `PlayerSquashStretch` *already* uses `KillActive()`, `.SetUpdate(true)`, and `.SetLink(gameObject)` on both `Play()` and `ResetScale()`, `GameScene.unity` sets `CinemachineBrain.IgnoreTimeScale = 0`, `CinemachineImpulseManager.Instance.IgnoreTimeScale` defaults to `false`, `CinemachineCameraZoom2D.Update` uses `Time.deltaTime`, and `PlayerLineTrail.LateUpdate` returns early when `Time.deltaTime <= 0f`.
   - Furthermore, `HitStopRoutine` does not check `UIManager` when restoring `Time.timeScale` (risking unfreezing a Pause/Settings popup opened mid-hit-stop) nor restore `Time.timeScale` inside `OnDisable()`.
   - **Result**: Instead of feeling like a snappy freeze-frame impact, camera shake and zoom freeze completely for up to `83 ms` and only begin moving *after* gameplay resumes.

2. **Clamp Saturation & Duration Mismatch at `30 u/s`**
   - `GameScene.unity` serializes `PlayerSquashStretch.maxDeformation = 0.3`, clamping the GDD impact target (`impactHeightPx = 16 / movingHeightPx = 28 - 1 = -0.4286`, `28 / 20 - 1 = +0.40`) flat to `±0.30` regardless of dash length.
   - Simultaneously, `stretchDuration = 0.18s` (`180 ms`) and `squashDuration = 0.22s` (`220 ms`) exceed typical 2–4 tile slides (`67–133 ms`), so wall squash truncates launch stretch mid-tween. `PlayerLineTrail.LateUpdate` also clamps `smoothedMoveSpeed` to `[4f, 28f]`, below `30 u/s` and `48 u/s` Phase Launch.

3. **Bottom-Center `(0.5, 0)` Pivot Detachment on `PlayerSquashStretch`**
   - `Sprite` (`visualTransform`) sits at `localPosition = (0, -0.5, 0)` because Subject G-0 uses a bottom-center `(0.5, 0)` sprite pivot (`1.0` unit tall). Compressing `y` during top-wall `Squash(Vector2.up)` shrinks the sprite *downward away from the ceiling*, creating visible detachment instead of flush wall compression, while mid-corridor stretches bob upward off-center.

4. **Downward-Only Shake, Misaligned 2D Particles, Stale Tier Reads & Blocked Crush Payoff**
   - `CinemachineImpulseSource.DefaultVelocity` is `(0, -1, 0)` and `CinemachineCameraShake2D` only exposes scalar `ShakeCamera(float)`, kicking vertically down on horizontal wall hits, while `tier1Shake = 0` and `redirectShake = 0` leave short hops and deflections weightless.
   - `PlayerImpactFeedback.HandleWallImpact` spawns `impactBurstPrefab` with `Quaternion.LookRotation((Vector3)normal)` (+Z forward) rather than 2D Z-axis angle (`Atan2`).
   - `PlayerMovement` fires `OnWallImpact` *before* `StopMoving` updates `LastImpactTier`, causing `EntityAudio.HandlePlayerWallImpact` (which reads `LastImpactTier`) to play the *previous* dash's impact sound tier.
   - `PlayerImpactFeedback.HandleBlockBroken` exits immediately on `block.HasCustomBreakEffect` because `Cracked.prefab` assigns `WallImpactBreak` in `InteractionEffectPlayer`.

5. **Silent High-Skill, Rhythm & Prefab Contrast Channels**
   - `PlayerMovement.OnTileCrossed` has **0 subscribers** (no runway buildup).
   - `CinemachineCameraZoom2D` is **never called anywhere**.
   - `CloseCallDetector.OnCloseCallTriggered` has **0 audio, zoom, haptic, or UI subscribers**.
   - `EntityAudio.HandlePlayerRedirected` plays one flat `wedgeRedirect` pitch, while `Brittle.prefab` puts `WallImpactBreak` in legacy `effectPrefabs` (firing break VFX even on safe Tier-1 `Crack` crossings), `Brake.prefab` / `Exit.prefab` / `Hazard.prefab` / `Wedge.prefab` are empty, and `VectorPad.prefab` (`PoppingVFX`, `defaultCameraShake = 0.04`) and `GravityBlock.prefab` (`defaultCameraShake = 0.04`) mix legacy fields with `InteractionEffectPlayer`.

     public void PlaySFXWithPitch(SoundEntry entry, float pitchOverride, float volumeMultiplier = 1f)
     {
         if (!entry.HasClips) return;
         AudioClip clip = entry.GetRandomClip();
         if (clip == null) return;

         float minInterval = Mathf.Max(0.01f, entry.minInterval);
         float now = Time.unscaledTime;

     ```csharp
     [Header("Safety Clamps")]
     [SerializeField] private float minOrthoSize = 4.6f;
     [SerializeField] private float maxOrthoSize = 6.05f;
     [SerializeField] private float maxPositivePersistentOffset = 0.50f;

     private float tierOffset;
     private float phaseOffset;
     private float currentPersistentOffset;
     private float persistentSpeed = 9f;

     private float targetPulseOffset;
     private float currentPulseOffset;
     private float pulseHoldRemaining;
     private float pulseInSpeed = 18f;
     private float pulseOutSpeed = 9f;

     private void Awake()
     {
         if (Instance != null && Instance != this) { Destroy(this); return; }
         Instance = this;
         if (cinemachineCamera == null) cinemachineCamera = GetComponent<CinemachineCamera>();
         if (cinemachineCamera != null && normalOrthographicSize <= 0.1f)
             normalOrthographicSize = cinemachineCamera.Lens.OrthographicSize;
     }

     public void SetTierOffset(float offset, float speed = 9f)
     {
         tierOffset = offset;
         persistentSpeed = Mathf.Max(0.5f, speed);
     }

     public void SetPhaseOffset(float offset, float speed = 10f)
     {
         phaseOffset = offset;
         persistentSpeed = Mathf.Max(0.5f, speed);
     }

     public void PulseOrthographicDelta(float delta, float holdSeconds, float inSpeed = 18f, float outSpeed = 9f)
     {
         targetPulseOffset = delta;
         pulseHoldRemaining = Mathf.Max(0.01f, holdSeconds);
         pulseInSpeed = Mathf.Max(1f, inSpeed);
         pulseOutSpeed = Mathf.Max(1f, outSpeed);
     }

     public void ClearAllOffsets()
     {
         tierOffset = 0f;
         phaseOffset = 0f;
         targetPulseOffset = 0f;
         pulseHoldRemaining = 0f;
     }

     private void Update()
     {
         if (cinemachineCamera == null) return;
         float dt = Time.unscaledDeltaTime;

         float desiredPersistent = Mathf.Clamp(tierOffset + phaseOffset, -0.40f, maxPositivePersistentOffset);
         currentPersistentOffset = Mathf.Lerp(currentPersistentOffset, desiredPersistent, 1f - Mathf.Exp(-persistentSpeed * dt));

         if (pulseHoldRemaining > 0f)
         {
             pulseHoldRemaining -= dt;
             currentPulseOffset = Mathf.Lerp(currentPulseOffset, targetPulseOffset, 1f - Mathf.Exp(-pulseInSpeed * dt));
         }
         else
         {
             targetPulseOffset = 0f;
             currentPulseOffset = Mathf.Lerp(currentPulseOffset, 0f, 1f - Mathf.Exp(-pulseOutSpeed * dt));
         }

         float lens = normalOrthographicSize + currentPersistentOffset + currentPulseOffset;
         cinemachineCamera.Lens.OrthographicSize = Mathf.Clamp(lens, minOrthoSize, maxOrthoSize);
     }
     ```

### Pillar 3: Billiard Bank-Shot Chain Resonance (`DeflectionWedge` & `VectorPad`)
*Turning multi-corner deflections into rhythmic combo payoff without tween or audio collisions.*

- **Why It Makes Gravita Uniquely Addictive**
  `DeflectionWedge` and `VectorPad` chain 90-degree corners while preserving `TilesTraveled` toward `KineticRam`. Currently every bounce sounds identical and triggers `redirectShake = 0`. Turning chained deflections into an ascending musical phrase with crisp corner-carving deformation rewards planning multi-bank routes.

- **Exact Numbers, Curves & Inspector Parameters**
  - **Non-Phasing Chain Counter**: `redirectChainCount` increments on `OnRedirected` *only when* `movement == null || !movement.IsPhasing` (so `VectorLauncher` Phase Launch uses Pillar 5's launch signature instead), and resets to `0` on `OnMoveStopped` or `LevelFlowController.OnLevelRestarted`.
  - **Harmonic Pitch Escalation**: `pitch = 1.00f + Mathf.Min(redirectChainCount - 1, 6) * 0.08f` (`1.00, 1.08, 1.16, 1.24, 1.32, 1.40, 1.48`), volume multiplier `Mathf.Lerp(0.85f, 1.0f, Mathf.Min(chain - 1, 4) / 4f)`.
  - **Corner-Whip Squash (`0.045s` / `45 ms` unified)**: on non-phasing `OnRedirected(Vector2 newDir)`, run a `0.045s` `.SetUpdate(true)` whip compressing perpendicular `-14%` (`-stretchAmount * 1.15f`) and stretching along `newDir` `+16%` (`+stretchAmount * 1.35f`).
  - **Same-Frame `OnMoveStarted` Guard (Critical Fix)**: Because `PlayerMovement.Redirect` fires `OnRedirected` and `OnMoveStarted` back-to-back in the same step (`PlayerMovement.cs:997-998`), both `PlayerSquashStretch` and `EntityAudio` record `suppressMoveStartedFrame = Time.frameCount` inside non-phasing `HandleRedirected` and skip `HandleMoveStarted` when `suppressMoveStartedFrame == Time.frameCount` (clearing `suppressMoveStartedFrame = -1` on consume, `HandleMoveStopped`, and `OnDisable`). This prevents `HandleMoveStarted` from killing the `0.045s` corner-whip tween and prevents `cfg.moveStart` from double-layering atop `cfg.wedgeRedirect`, while leaving delayed `StepPhaseLaunch` exits (`OnMoveStarted` after `SetPhasing(false)`) untouched.
  - **Bisector Directional Shake**: `force = redirectShake (0.045f) + 0.015f * Mathf.Min(redirectChainCount, 4)` (max `0.105f`) pushed along `(prevDir - newDir).normalized`.

- **Exact C# Integration Hooks**

Because `InteractionEffectPlayer.TriggerEffects` runs *both* legacy `effectPrefabs` and `rules` and takes `max(defaultCameraShake, rule.cameraShake)`, **clear `effectPrefabs` and set `defaultCameraShake = 0`** on `VectorPad.prefab` before adding the `InteractionKind.Deflect` rule (`alignToDirection = true`, `cameraShake = 0`, single deflect spark prefab) so it neither double-spawns VFX nor stacks a `0.04` downward shake onto the bisector impulse.

### Pillar 4: "Razor's Edge" Close-Call Adrenaline Spike (`CloseCallDetector` — Zero-`timeScale`)
