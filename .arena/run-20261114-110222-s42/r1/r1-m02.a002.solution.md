# Gravita (`Puzzle 2D`) — Game Feel Signature Blueprint

## 1. Core Game Feel Diagnosis

Gravita's deterministic grid simulation is already responsive on paper (`PlayerMovement`: `moveSpeed = 30`, `turnClearance = 0.35`, `bufferTurnsUntilStop = 1`, `cellSize = 1`, `maxConsecutiveRedirects = 8`), and several foundational feedback primitives already exist in the repository (`PlayerSquashStretch`, `PlayerImpactFeedback`, `PlayerLineTrail`, `StarCollectFeedback`, `CinemachineCameraZoom2D`, `CinemachineCameraShake2D`, `CloseCallDetector`, `InteractionEffectPlayer`, `GameplayHapticsFeedback`, `EntityAudio`, `MusicManager`). However, five concrete structural and tuning disconnects currently make gameplay feel flatter and softer than the underlying mechanics deserve:

1. **Silent Audio Assets & Unwired Ducking Targets**: All `23` serialized `SoundEntry` blocks in `Assets/Data/Sound/SoundConfig.asset` currently contain empty clip arrays (`clips: []`; `SoundConfig.cs` declares `24` fields with `currencyCountTick` unserialized), leaving every dash, impact, wedge turn, and pickup silent. Additionally, `MusicManager.musicSource` and `MusicManager.ambientSource` serialize as `{fileID: 0}` in both `AudioSystems.prefab` and `GameScene.unity`, while `MusicManager.DuckMusic(bool)` uses a fixed `0.5s` fade to `0.3f` / `1f` with no auto-unduck timer for transient win or star fanfares.
2. **Impact Contrast, Event Ordering & Time-Scale Races**: In `GameScene.unity`, `PlayerImpactFeedback` sets `tier1Shake = 0` and `redirectShake = 0` (`tier2Shake = 0.1`, `tier3Shake = 0.2`, `tier2HitStop = 0.033`, `tier3HitStop = 0.083`), stripping all tactile weight from `Drift` wall stops and corner deflections. Worse, `PlayerMovement.OnWallImpact` fires *before* `StopMoving(wallImpact: true)` updates `LastImpactTier`, so synchronous listeners reading `LastImpactTier` inside `OnWallImpact` (`EntityAudio.HandlePlayerWallImpact`) receive the *previous* dash's tier instead of live `CurrentTier`. Meanwhile, `PlayerImpactFeedback.HandleStopped` ignores `WasLastStopWallImpact` (triggering impact settle on smooth non-wall stops), `PlayerImpactFeedback.HitStopRoutine` can race `UIManager.UpdateTimeScale()` if pause opens mid-freeze, and `Main Camera`'s `CinemachineBrain` sets `IgnoreTimeScale = false`, freezing `CinemachineImpulseListener` camera shakes during hit-stop.
3. **Squash-and-Stretch Pivot Offsets, Phasing Tint Overwrite & Shader Limits**: `PlayerSquashStretch` already cleans up tweens with `.Kill()`, `.SetUpdate(true)`, `.SetLink(gameObject)`, restores equipped skins via `cosmeticApplier.RefreshEquippedSkin()`, and uses `maxDeformation = 0.3` in `GameScene.unity`. However, `Player/Sprite` sits at `localPosition (0, -0.5, 0)` tuned for `Player Icon`'s `(0.5, 0)` pivot while cosmetic skins such as `Player_Amber` use `pivot (0.5, -0.16666667)`. Scaling without normalized pivot compensation pulls the sprite *away* from North (`+Y`), East (`+X`), and West (`-X`) walls instead of compressing flush against the hit surface. Furthermore, `SetPhasing(true)` overwrites `targetSprite.color` RGB with `phaseSpriteTint` instead of tint-multiplying the equipped skin, `squashDuration (0.22s)` / `stretchDuration (0.18s)` feel loose at `30 units/s`, and `Player/Sprite` uses `Sprite-Unlit-Default.mat` while `Assets/Shaders/Hit/HitFlashSprite.shader` discards `_MainTex.rgb` and `input.color.rgb` (preventing smooth blendable hit-flashes).
4. **Root-Bound Prefab Renderers & Unpopulated Prop Feedback**: `Wedge.prefab`, `PulseLaser.prefab`, `OverloadedFloor.prefab`, and `FailingTile.prefab` place `SpriteRenderer` directly on the root GameObject alongside `BoxCollider2D` (unlike `VectorPad.prefab`, which isolates `SpriteRenderer` under a `Visual` child), and `HazardActivation.ApplyVisualState` / `FailingTile.ApplyState` overwrite `fallbackSpriteRenderer.color` on phase updates. Animating root transforms would shift `Collider2D` hitboxes, and tweening `SpriteRenderer.color` would collide with phase state colors. Elsewhere, `Brake.prefab`, `Exit.prefab`, `Hazard.prefab`, `Cracked.prefab`, and `Coin.prefab` have `defaultCameraShake = 0` and empty `effectPrefabs` on `InteractionEffectPlayer`.
5. **Ambiguous Movement Events, Haptics Ceiling & Procedural VFX Debt**: `PlayerMovement.OnRedirected` fires on both corner redirections (`Redirect`) and `VectorLauncher` phase launches (`StartPhaseLaunch`), while mid-dash reversals invoke `OnMoveStarted` without `OnMoveStopped`. `GameHaptics.EventCount = 7` drops events beyond `Death = 6` and lacks `VelocityTier` support. `Coin.prefab` and `Star.prefab` override `collectSfx`, causing `EntityAudio` to skip pitched streak handling. Finally, `PowerUpController` creates transient echo/pulse VFX via procedural `new GameObject(...)` + `AddComponent<SpriteRenderer>()` calls instead of pooled prefabs.

## 2. Five High-Impact Gravita-Specific Feel Pillars

### Pillar 1: Kinetic Snap & Collision Weight ("Stop Like Steel, Scale by VelocityTier")

#### a. Player Psychology & Rhythm
At `30 units/s` (`33.33 ms/tile`), velocity only *feels* dangerous when collision stops reward higher `VelocityTier` momentum (`Drift` -> `Cruise` -> `KineticRam`) with escalating compression, crisp micro-freeze (`hit-stop`), directional flash, unscaled camera impulse, and proportional haptics. Removing pause-vs-hit-stop races guarantees freezes feel surgical rather than glitchy.

#### b. Concrete Numbers, Curves, Durations & Inspector Parameters
- **Single-Authority Hit-Stop (`HitStopCoordinator`)**:
  - `Drift`: `0.000s` (zero hitching on 1–3 tile nudges).
  - `Cruise`: `0.032s` (`Time.timeScale = 0f`, unscaled timer).
  - `KineticRam`: `0.068s` (`Time.timeScale = 0f`).
  - `CrackedWallBreak`: `0.045s` (`Time.timeScale = 0f`), gated by `minHitStopCooldown = 0.090s` unscaled so smashing a `CrackedWall` immediately before a wall stop never double-stalls the player.
  - `HazardDeath`: `0.075s` (cleared cleanly if `LevelFlowController` cancels hit-stop on death cutscene start).
- **Camera Shake & Zoom Micro-Kick (`PlayerImpactFeedback` + `CinemachineCameraZoom2D`)**:
  - `PlayerImpactFeedback` Inspector values in `GameScene.unity`: `tier1Shake = 0.03f`, `tier2Shake = 0.12f`, `tier3Shake = 0.24f`, `redirectShake = 0.035f`, `crackedBreakShake = 0.16f`.
  - `CinemachineCameraZoom2D` transient kick: `Cruise` dips ortho size `-0.12f` (`0.04s` in `Ease.OutQuad`, `0.14s` out `Ease.OutCubic`); `KineticRam` dips `-0.24f` (`0.04s` in, `0.20s` out).
- **Pivot-Aware Squash & Stretch (`PlayerSquashStretch`)**:
  - Keep calibrated `maxDeformation = 0.30f` in `GameScene.unity`; tighten `squashDuration = 0.14f` (`Ease.OutBack`, overshoot `1.4f`), `stretchDuration = 0.12f` (`Ease.OutCubic`).
  - Dynamic wall-edge anchor: compute normalized sprite pivot `p = targetSprite.sprite.pivot / targetSprite.sprite.rect.size` and world sprite dimensions `size = targetSprite.sprite.bounds.size` (handles both `Player Icon` `(0.5, 0)` and cosmetic skins such as `Player_Amber` `(0.5, -0.16666667)` without hardcoding). Shift `spriteTransform.localPosition` along `impactDir`'s axis by `(1f - pAxis) * sizeAxis * (1f - scaleAlongAxis)` when `impactDir` is `+X`/`+Y` and `-pAxis * sizeAxis * (1f - scaleAlongAxis)` when `impactDir` is `-X`/`-Y` so North, South, East, and West impacts always stay pinned flush against the hit surface.
  - Phasing tint preservation: multiply `(equippedSkinColor * phaseSpriteTint)` during `SetPhasing(true)` rather than overwriting RGB flatly; restore via `cosmeticApplier.RefreshEquippedSkin()` on exit.
- **Shader Hit-Flash (`MaterialPropertyBlock`)**:
  - Drive `_FlashColor` and `_FlashAmount` via `MaterialPropertyBlock` (`Cruise`: white `(1,1,1,1)`, `1.0 -> 0.0` over `0.08s`; `KineticRam`: cyan-white `(0.45, 0.92, 1, 1)`, `1.0 -> 0.0` over `0.13s`, `Ease.OutCubic`).
- **Tiered Haptics (`GameHaptics` & `MostHapticsBackend`)**:
  - Expand `HapticEvent` enum from `7` entries (`0..6`) to `10` entries: add `CrackedBreak = 7`, `CloseCall = 8`, `LevelWin = 9`.
  - Update `GameHaptics.EventCount = 10` with per-event cooldowns (`CrackedBreak: 0.06s`, `CloseCall: 0.08s`, `LevelWin: 0.00s`). Bypass `GlobalMinGapSeconds` for both `Death` and `LevelWin`.
  - Map `MostHapticsBackend`: `(WallImpact, Drift -> LightImpact, Cruise -> MediumImpact, KineticRam -> RigidImpact)`, `CrackedBreak -> HeavyImpact`, `CloseCall -> Warning`, `LevelWin -> Success`.

#### c. Exact C# Hooks
- **`HitStopCoordinator` (`Assets/Scripts/Feedback/HitStopCoordinator.cs`)**:
  - Holds `[SerializeField] private LevelFlowController flowController;` (auto-resolving via `FindFirstObjectByType` only if unassigned) and checks `flowController == null || flowController.CurrentState == LevelState.Playing` before allowing gameplay freezes (`LevelFlowController.CurrentState` is an instance property, never static).
  - Becomes the **sole writer of `Time.timeScale`**: exposes `SetUIModalFreeze(bool shouldFreeze)`, `RequestFreeze(float unscaledDuration)`, and `CancelHitStop()`. When `isUIFrozen` is true, active freeze timers immediately reset to `0f` and `Time.timeScale` stays `0f` until `SetUIModalFreeze(false)` restores `1f`.
  - Subscribes to `LevelFlowController.OnLevelFailed`, `OnLevelCompleted`, and `OnLevelRestarted` to invoke `CancelHitStop()`, preventing stale freezes during `CutsceneManager.DeathRoutine` or `GoalRoutine`.
- **`UIManager`**:
  - Expose `public bool IsTimeFrozenByUI { get; private set; }`. Update `UIManager.UpdateTimeScale()` to delegate to `HitStopCoordinator.SetUIModalFreeze(shouldFreeze)` (retaining direct `Time.timeScale` fallback only if no `HitStopCoordinator` exists).
- **`PlayerImpactFeedback`**:
  - Remove `HitStopRoutine` entirely and delegate hit-stop calls to `HitStopCoordinator.RequestFreeze(...)` on `Cruise`/`KineticRam` impacts and `CrackedWall.OnAnyBroken`.
  - Fix `HandleWallImpact`: read impact tier via `playerMovement.CurrentTier` (with `playerMovement.LastImpactTier` fallback if `CurrentTier == VelocityTier.None`) because `OnWallImpact` fires *before* `StopMoving(wallImpact: true)` commits `LastImpactTier`.
  - Fix `HandleStopped`: early-return unless `playerMovement.WasLastStopWallImpact` is true so smooth teleports/non-wall stops never trigger impact recoil.
  - Replace direct color flash hacks with tracked DOTween `MaterialPropertyBlock` `_FlashAmount` animation (`.Kill()` before spawn, `.SetUpdate(true)`, `.SetLink(gameObject)`).
- **`GameplayHapticsFeedback` & `Haptics`**:
  - Introduce `ITieredHapticsBackend { void Play(HapticEvent evt, VelocityTier tier); }` implemented by `MostHapticsBackend`, plus `GameHaptics.Play(HapticEvent evt, VelocityTier tier)`. Recording test backends continue logging `HapticEvent.WallImpact` on `Cruise`/`Drift` runs (keeping existing `HapticsTests` assertions green), while `MostHapticsBackend` scales tactile force by `VelocityTier`.
  - In `GameplayHapticsFeedback.HandleWallImpact`, read `playerMovement.CurrentTier` (fallback `LastImpactTier`) when dispatching `GameHaptics.Play(HapticEvent.WallImpact, tier)`. Subscribe `CrackedWall.OnAnyBroken` -> `GameHaptics.Play(HapticEvent.CrackedBreak)` and `LevelFlowController.OnLevelCompleted` -> `GameHaptics.Play(HapticEvent.LevelWin)`.
- **`CinemachineCameraZoom2D`**:
  - Gate `Update()` on `UIManager.Instance == null || !UIManager.Instance.IsTimeFrozenByUI` and interpolate zoom using `Time.unscaledDeltaTime`. Add `PulseZoomKick(float deltaSize, float inSec, float outSec)` using `.DOKill().SetUpdate(true).SetLink(gameObject)`.

#### d. Unity Inspector & Prefab Wiring
- `GameScene.unity` -> `Main Camera` `CinemachineBrain`: set `IgnoreTimeScale = true` so `CinemachineImpulseListener` and `CinemachinePositionComposer` stay responsive during hit-stop.
- `GameScene.unity` -> `HitStopCoordinator`: assign `flowController` to `LevelFlowController`.
- `GameScene.unity` -> `PlayerImpactFeedback`: set `tier1Shake = 0.03`, `tier2Shake = 0.12`, `tier3Shake = 0.24`, `redirectShake = 0.035`.
- `GameScene.unity` -> `Player/Sprite`: replace `Sprite-Unlit-Default.mat` with the blendable hit-flash material (Phase 2) so `MaterialPropertyBlock` `_FlashAmount`/`_FlashColor` tweens blend over any equipped skin.

### Pillar 2: Input Anticipation & Corner-Chain Flow ("Buffer That Reads Like Foresight")

#### a. Player Psychology & Rhythm
Gravita shines when players queue turns mid-dash (`turnClearance = 0.35`, `bufferTurnsUntilStop = 1`) and chain `DeflectionWedge` or buffered corners across tight corridors. At `30 units/s`, two consecutive 1-tile corners span `33.33 ms` each and can execute inside a single catch-up `FixedUpdate` step burst. Feedback must never drop rapid corners, never misclassify `VectorLauncher` phase launches as corners, and always acknowledge queued direction changes immediately.

#### b. Concrete Numbers, Curves, Durations & Inspector Parameters
- **Queued Turn Foresight (`PlayerDashLeadFeedback`)**:
  - While `playerMovement.IsMoving && playerMovement.HasPendingDirection && playerMovement.PendingDirection != playerMovement.CurrentDirection`:
    - Lean `Player/Sprite` local offset toward `PendingDirection` by `0.06f` units over `0.06s` (`Ease.OutQuad`, `.DOKill().SetUpdate(true).SetLink(gameObject)`).
    - Position a pooled directional turn-chevron prefab (`VfxSpawner.Spawn`) `0.55f` units ahead of `playerMovement.transform.position` rotated along `PendingDirection`. Clear both immediately on `OnDashInitiated`, `OnCornerRedirected`, or `OnMoveStopped`.
- **Corner-Chain Escalation (`PlayerCornerAndReversalFeedback`)**:
  - Maintain `chainCount` (`0..6`), incrementing on every `OnCornerRedirected` without any `Time.frameCount` suppression so multi-step catch-up frames preserve every consecutive 1-tile corner.
  - Reset `chainCount = 0` and seed `previousDir = direction` cleanly on `OnDashInitiated(direction, isReversal)` as well as `OnMoveStopped()`.
  - Compute bisector `Vector2 bisector = incomingDir - outgoingDir`; if `bisector.sqrMagnitude < 0.001f`, fall back cleanly to `outgoingDir` to guarantee valid spark orientation. Spawn pooled corner burst via `VfxSpawner.Spawn` at `tileCenter`, scaled `1.0f + chainCount * 0.08f`.
  - Corner pitch curve (handled by `EntityAudio`): `1.0f + Mathf.Min(chainCount, 6) * 0.045f` (`1.00x` -> `1.27x`).
- **Trail Elbow Flare (`PlayerLineTrail`)**:
  - Internal `elbowWidthBoost` spikes to `1.32f` on `OnCornerRedirected` and decays back to `1.0f` over `0.11s` using `Time.unscaledDeltaTime`. Multiply into `lineRenderer.widthMultiplier = trailWidth * widthScale * elbowWidthBoost;` *inside* `RefreshTierVisuals()` so tier changes never clobber the flare.
- **Mid-Dash Reversal Punch (`OnDashInitiated(..., isReversal: true)`)**:
  - Flip-snap squash via `PlayerSquashStretch` (`(-0.22, +0.26)` deformation along `direction` over `0.11s`), spawn pooled reversal ring (`VfxSpawner.Spawn`), fire `redirectShake = 0.035f`, and route `dashReversal` SFX (`pitch = 1.05f`) through `EntityAudio`.

#### c. Exact C# Hooks
- **`PlayerMovement.cs`**:
  - Add read-only `public Vector2 PendingDirection => pendingDirection;` beside `HasPendingDirection`.
  - Add `public event Action<Vector2, bool> OnDashInitiated;` (`(direction, isReversal)`), invoked inside `SimulateStep` *only* on mid-dash reversal (`isReversal: true`, after `consecutiveRedirects = 0`) and on stationary launch (`isReversal: false`).
  - Add `public event Action<Vector2, Vector2, Vector2> OnCornerRedirected;` (`(incomingDir, outgoingDir, tileCenter)`), invoked *only* inside `PlayerMovement.Redirect(Vector2 newDirection, Vector2 snapPosition)` right *before* mutating `moveDirection = newDirection` (never invoked inside `StartPhaseLaunch`).
- **`PlayerCornerAndReversalFeedback` (`Assets/Scripts/Feedback/`)**:
  - Subscribes to `OnDashInitiated`, `OnCornerRedirected`, and `OnMoveStopped` (no `SoundManager` calls — visual bursts & camera micro-shake only).
- **`PlayerLineTrail`**:
  - Subscribes to `OnCornerRedirected` to trigger internal `elbowWidthBoost = 1.32f` combined cleanly inside `RefreshTierVisuals()`.
- **`EntityAudio`**:
  - Subscribes to `OnCornerRedirected` (escalating chain pitch) and `OnDashInitiated` (resetting chain state and triggering `dashReversal` when `isReversal == true`).

#### d. Unity Inspector & Prefab Wiring
- `GameScene.unity` -> `Player`: attach `PlayerDashLeadFeedback` and `PlayerCornerAndReversalFeedback`; assign pooled prefab fields (`turnChevronVfxPrefab`, `cornerSparkVfxPrefab`, `reversalBurstVfxPrefab`) to `VfxSpawner`-compatible prefabs.
- `Wedge.prefab` -> `InteractionEffectPlayer`: set `defaultCameraShake = 0.04` and assign pooled deflection spark prefab.

### Pillar 3: Spatial Affordance & Hazard Telegraphing ("Fair Warning Before Fatal Contact")

#### a. Player Psychology & Rhythm
Precision sliding requires total trust in grid danger states: players must read imminent laser sweeps, collapsing tiles, overload cycles, and near-misses ahead of time without hitboxes jittering by a single pixel or hazard freeze power-ups leaving ghost animations running.

#### b. Concrete Numbers, Curves, Durations & Inspector Parameters
- **Hazard Warning & Freeze Lock (`HazardTelegraphFeedback`)**:
  - Strictly gated on `!hazard.IsFrozen`: freezing hazards via Power-Up stops all warning tremble/scale loops immediately in place.
  - Warning state (`PulseLaser`, `OverloadedFloor`, `FailingTile`): apply local-space micro-tremor `±0.035f` units at `28 Hz` plus scale pulse `1.0f -> 1.07f -> 1.0f` (`0.24s` loop, `Ease.InOutSine`, `.DOKill().SetUpdate(false).SetLink(gameObject)` so pause/timescale freezes naturally) on the `Visual` child Transform.
  - In Phase 2 (once blendable hit-flash material is assigned), pulse `_FlashColor = (1.0f, 0.32f, 0.18f, 1.0f)` and `_FlashAmount = 0.0f <-> 0.45f` via `MaterialPropertyBlock`. **Never modify `fallbackSpriteRenderer.color`** (`HazardActivation.ApplyVisualState` and `FailingTile.ApplyState` keep exclusive ownership of state colors).
  - Active trigger punch: `visualTransform.DOPunchScale(Vector3.one * 0.16f, 0.14f, 6, 0.6f)`. Retain existing `InteractionEffectPlayer` shakes (`PulseLaser`: `0.12`, `OverloadedFloor`: `0.12`, `SentinelDrone`: `0.14`) and set `FailingTile`: `0.08`, `Hazard`: `0.15`.
- **Close-Call Adrenaline (`CloseCallDetector` Integration)**:
  - Per-trigger cooldown `0.45s`: play `GameHaptics.Play(HapticEvent.CloseCall)` (`Warning`), camera micro-bump `0.025f`, cyan rim flash via `MaterialPropertyBlock` (`_FlashColor = (0.35, 0.95, 1.0, 1.0)`, `_FlashAmount = 0.55 -> 0` over `0.10s`), and route `closeCallWhoosh` SFX via `EntityAudio`.
- **Interactive Tile Recoil (`TileImpactRecoil`)**:
  - Reusable visual-child recoil (`Wedge`, `GravityBlock`, `Brake`, `Cracked`): displace `visualTransform` `0.08f` units along `impactDir` + `DOPunchScale(Vector3.one * 0.14f, 0.12f, 6, 0.5f)` via `.DOKill().SetUpdate(true).SetLink(gameObject)`.
  - **Collider Safety Guard (`Awake()`)**: verify `visualTransform != null && visualTransform.GetComponent<Collider2D>() == null` (disable and log warning if violated, guaranteeing `BoxCollider2D` never translates or scales).

#### c. Exact C# Hooks
- `HazardTelegraphFeedback`: listens to `HazardActivation.OnPhaseChanged` / `FailingTile.OnStateChanged`, reads `Hazard.IsFrozen`, manipulates only `visualTransform` and `MaterialPropertyBlock`.
- `TileImpactRecoil`: validates `visualTransform` in `Awake()`/`OnValidate()`, binds to `DeflectionWedge`, `BrakeTile`, `GravityBlock`, or `CrackedWall` hit/deflect callbacks.
- `CloseCallDetector`: raises close-call event consumed by `EntityAudio` (`closeCallWhoosh`), `GameplayHapticsFeedback` (`HapticEvent.CloseCall`), and `PlayerImpactFeedback` (cyan rim flash).

#### d. Unity Inspector & Prefab Wiring
- **Required Prefab Visual-Child Restructuring (Phase 2, matching `VectorPad.prefab`)**: Extract `SpriteRenderer` from the root onto a `Visual` child GameObject (`localPosition: (0,0,0)`) while leaving `BoxCollider2D` on root across `Wedge.prefab`, `PulseLaser.prefab`, `OverloadedFloor.prefab`, and `FailingTile.prefab` (rebind `fallbackSpriteRenderer` in `HazardActivation`/`FailingTile` to the child `SpriteRenderer`). Apply the same `Visual` child separation to `Brake.prefab`, `Cracked.prefab`, `GravityBlock.prefab`, `Hazard.prefab`, `Exit.prefab`, and `SentinelDrone.prefab` before attaching `TileImpactRecoil` or `HazardTelegraphFeedback`.
- Populate `InteractionEffectPlayer` `defaultCameraShake` and pooled VFX prefabs (`Brake`: `0.03`, `GravityBlock`: `0.05`, `Cracked`: `0.14`, `Exit`: `0.10`, `Hazard`: `0.15`).

### Pillar 4: Collectible Chime Ladder & End-of-Level Closure ("Every Pickup Sings, Every Solve Resolves")

#### a. Player Psychology & Rhythm
Collecting coins along a high-speed dash should reward forward momentum with an ascending pentatonic/chromatic chime ladder, collecting stars should feel like milestone punctuation, and crossing `Exit` should stage a decisive emotional exhale (`0.45s` zoom + music duck pulse + win haptic) seamlessly aligned with `CutsceneManager.GoalRoutine`'s `0.5s` unscaled slide.

#### b. Concrete Numbers, Curves, Durations & Inspector Parameters
- **Coin Streak Chime Ladder (`EntityAudio` + `CollectibleJuiceFeedback`)**:
  - `streakWindowSeconds = 1.20f` (`Time.unscaledTime`), max tracked streak `maxStreakSteps = 8`.
  - Pitch ramp: `1.00f + coinStreak * 0.04f` (`1.00x` -> `1.32x`) dispatched via `SoundManager.PlayPitchedSFX`.
  - Set `SoundConfig.coinCollect.minInterval = 0.02f` so rapid multi-coin dashes inside one frame/sub-frame never lose chimes to `SoundManager`'s per-clip dedup guard.
  - Pooled sparkle burst (`VfxSpawner.Spawn`) scaled `1.0f + coinStreak * 0.05f`; keep `Coin.prefab` `defaultCameraShake = 0f` to avoid visual jitter during route planning.
- **Star 1 / 2 / 3 Triumph Fanfare (`EntityAudio` + Extended `StarCollectFeedback`)**:
  - Pitch steps: Star 1 = `1.00f`, Star 2 = `1.12f`, Star 3 = `1.26f`.
  - Visuals & Mix: extend the existing `StarCollectFeedback` component already on `Player` (do not create a parallel star component) to trigger pooled star shockwave (`VfxSpawner.Spawn`), `CinemachineCameraZoom2D` micro-kick (`-0.08f`, `0.04s` in / `0.12s` out), and `MusicManager.PulseDuck(0.65f, 0.18f, 0.03f, 0.25f)`.
- **Goal Closure (`Exit` / `LevelFlowController.OnLevelCompleted`)**:
  - Trigger `GameHaptics.Play(HapticEvent.LevelWin)` (`Success`, bypassing global haptic gap alongside `Death`).
  - `EntityAudio` plays `goalReached`.
  - `MusicManager.PulseDuck(0.35f, 0.45f, 0.05f, 0.60f)` (fades cleanly back toward `1f` or `0.3f` depending on UI duck state, never stuck permanently at `0.3f`).
  - `CinemachineCameraZoom2D` glides ortho size `-0.55f` over `0.45s` (`Ease.InOutCubic`, unscaled time) framing `CutsceneManager.GoalRoutine`'s `0.5s` goal slide.

#### c. Exact C# Hooks
- **Single Audio Ownership in `EntityAudio`**: `EntityAudio` remains the **only** script calling `SoundManager` for coin, star, redirect, impact, power-up, and level events. New `CollectibleJuiceFeedback` and extended `StarCollectFeedback` handle strictly pooled VFX, streak/star indices, camera kicks, and duck pulses.
- **Transient Music Pulse (`MusicManager.PulseDuck`)**:
  - Add `public void PulseDuck(float duckVolume, float holdSeconds, float attackSeconds, float releaseSeconds)` built on a tracked DOTween `Sequence` (`.DOKill().SetUpdate(true).SetLink(gameObject)`).
  - Track `bool isPersistentlyDucked` controlled by `UIAudio`'s `DuckMusic(bool)` calls so `PulseDuck`'s release phase restores to `isPersistentlyDucked ? 0.3f : 1f` instead of prematurely un-ducking a paused modal mix.
- **Reset Hooks**: Clear `coinStreak` and `starCount` inside `EntityAudio` & `CollectibleJuiceFeedback` on `LevelFlowController.OnLevelStarted` / `OnLevelRestarted`.

#### d. Unity Inspector & Prefab Wiring
- `AudioSystems.prefab` & `GameScene.unity` -> `MusicManager`: **wire `musicSource` and `ambientSource`** to live `AudioSource` components routed through `musicMixerGroup` (currently `{fileID: 0}`).
- `Coin.prefab` & `Star.prefab`: clear serialized `collectSfx` overrides so `Collectible.HasCustomCollectSfx` is `false` and `EntityAudio` plays pitched `coinCollect` / `starCollect` consistently through `SoundConfig`.
- `SoundConfig.asset`: set `coinCollect.minInterval = 0.02f`; keep `starCollect` populated with resonant bell/chime samples.

### Pillar 5: Power-Up Kinetic Signatures ("Each Tool Feels Like Its Verb")

#### a. Player Psychology & Rhythm
Gravita's three tactical power-ups (`Breaker`, `Freeze`, `Teleport` in `PowerUpController`) plus environmental `VectorLauncher` pads alter the rules of engagement. Each ability needs a clean, unmistakable sensory verb (`Armor`, `Cryo-Lock`, `Blink` vs `Phase Ram`) without procedural GameObject churn or cross-talk with corner combos.

#### b. Concrete Numbers, Curves, Durations & Inspector Parameters

## 3. Built-to-Last Architecture & Refactor Rules

1. **Zero Procedural Hierarchy Creation**: `new GameObject(...)` and runtime `AddComponent<...>()` are strictly forbidden for UI, VFX, audio, or managers. Every transient visual (corner sparks, reversal rings, turn chevrons, coin/star bursts, teleport echoes, freeze waves) must live as a pre-authored prefab referenced via `[SerializeField]` and spawned through `VfxSpawner.Spawn(...)` / `ObjectPoolManager`.
2. **Strict Visual-Child Separation (`Collider2D` Invariant)**: Root tile/entity objects own deterministic grid coordinates and `BoxCollider2D`. All position recoil, punch scaling, and tremor animations run solely on a dedicated `Visual` child GameObject, guarded in `Awake()` (`GetComponent<Collider2D>() == null`).
3. **Single Authority Ownership**:
   - `Time.timeScale`: Owned exclusively by `HitStopCoordinator` (`UIManager.UpdateTimeScale()` delegates to `SetUIModalFreeze`; `PlayerImpactFeedback.HitStopRoutine` deleted).
   - Gameplay Audio: Owned exclusively by `EntityAudio` (`Feedback` components never call `SoundManager.PlaySFX` directly for shared gameplay events).
   - Sprite Tint vs Flash: `HazardActivation`, `FailingTile`, and `PlayerCosmeticApplier` own `SpriteRenderer.color`; hit-flashes and hazard warning glows operate solely via `MaterialPropertyBlock` (`_FlashColor`, `_FlashAmount`).
4. **DOTween Lifetime & Pause Discipline**: Every UI/impact tween must call `.DOKill()` (or `.Kill()` on cached `Tween`) before creation, chain `.SetUpdate(true)` when animating across hit-stop/cutscenes (world hazard warning loops intentionally stay scaled and pause cleanly under UI Pause or `Hazard.IsFrozen`), and chain `.SetLink(gameObject)`.
5. **Deterministic Simulation Untouched**: Fixed timestep movement (`FixedUpdate`), grid snapping, `turnClearance = 0.35`, soft-lock validation, and input latency remain unaltered.
