# Gravita (Puzzle 2D) — Game Feel & Juice Architecture Blueprint

## 1. Current State Diagnosis: Why Gameplay Feels Flat

Despite solid deterministic grid-sliding mechanics (`PlayerMovement.cs`, `FixedUpdate` cell-center snapping, `moveSpeed = 30`) and clean static event hooks across `MazeTile.OnAnyPlayerInteracted`, `PlayerMovement`, `CrackedBlock`, `FailingTile`, `HazardActivation`, `Collectible`, and `CloseCallDetector`, the current presentation layer drops or suppresses sensory feedback at six structural seams:

1. **Silent Audio Runtime & Missing Event Coverage**:
   - `Assets/Data/Sound/SoundConfig.asset` defines **24** `SoundEntry` slots (`13` Gameplay + `11` UI in `SoundConfig.cs`), **all 24 currently have `clips: []`**.
   - `Assets/Prefabs/Manager/AudioSystems.prefab` leaves `MusicManager.musicSource`, `MusicManager.ambientSource`, `SoundManager.pooledAudioSourcePrefab`, `SoundManager.fallbackAudioSource`, and `SoundManager.poolContainer` unassigned (`null`).
   - `MusicManager.DuckMusic(bool)` (`Assets/Scripts/Audio/MusicManager.cs`) uses a single unkeyed tween (`DOFade(targetVolume, 0.5f)`), so overlapping UI pause ducking (`UIAudio.cs`) and gameplay close-call pulses would overwrite each other.
   - `SoundManager.cs` has `PlaySFX(SoundEntry)` with cooldown tracking (`lastPlayedTimeByClip` via `Time.unscaledTime`), but lacks a pitch/volume-override overload for combo/coin pitch escalation.

2. **Competing `Time.timeScale` Writers & Scale-Locked Presentation**:
   - Direct writes to `Time.timeScale` are scattered across four independent scripts without arbitration:
     - `UIManager.UpdateTimeScale()` (`Assets/Scripts/UI/Core/UIManager.cs:450`) sets `shouldFreeze ? 0f : 1f`.
     - `CutsceneManager.OnDisable()` and `DeathRoutine()` (`Assets/Scripts/Core/CutsceneManager.cs:122,261`) set `1f`.
     - `GameManager.OnSceneLoaded()` (`Assets/Scripts/Core/GameManager.cs:49`) sets `1f`.
     - `PlayerImpactFeedback.PulseHitStop()` (`Assets/Scripts/Feedback/PlayerImpactFeedback.cs:145-160`) reads/restores `Time.timeScale` directly inside a coroutine.
   - `PlayerLineTrail.LateUpdate()` (`Assets/Scripts/Feedback/PlayerLineTrail.cs:253`) and `CinemachineCameraZoom2D.Update()` (`Assets/Scripts/Feedback/CinemachineCameraZoom2D.cs:42`) tick on `Time.deltaTime`, freezing or stalling during hit-stop / micro time dilation. Moreover, `GameScene.unity` sets `CinemachineCameraZoom2D.normalOrthographicSize = 5.5` and `targetOrthographicSize = 5.5`, yielding zero camera zoom contrast and zero callers.

3. **Unfiltered & Misrouted Impact / Redirect Signals**:
   - `PlayerMovement.Redirect()` (`Assets/Scripts/Gameplay/PlayerMovement.cs:997-998`) fires both `OnRedirected` **and** `OnMoveStarted`. Because `LevelFlowController.cs:560` subscribes `OnMoveStarted += HandlePlayerMoveStarted`, every corner deflection falsely increments `movesUsedThisRun`. Meanwhile, `StartPhaseLaunch()` (`PlayerMovement.cs:523`) also fires `OnRedirected` while `IsPhasing` is `true`, risking false redirect combos/audio.
   - `PlayerImpactFeedback.HandleStopped()` does not check `PlayerMovement.WasLastStopWallImpact`, so soft stops on `GravityBlock` or `BrakeTile` fire wall-impact camera shake and hit-stop (`tier2Shake: 0.1 / 0.033s`, `tier3Shake: 0.2 / 0.083s` in `GameScene.unity`).
   - `PlayerSquashStretch.cs` already applies `.SetUpdate(true)` and `.SetLink(gameObject)` (`lines 185-186, 214-215`), **but** does not call `visualTransform.DOKill()` before spawning new tweens, does not subscribe to `OnRedirected`, lacks a gentle downward squash on non-wall stops, and uses `wallPressPx` without compensating for a bottom-center `(0.5, 0)` sprite pivot on upward (`Vector2.up`) ceiling impacts.

4. **Misconfigured Prefab Rules & Missing World Telegraph Hooks**:
   - `InteractionEffectPlayer.TriggerEffects()` (`Assets/Scripts/Feedback/InteractionEffectPlayer.cs:156-198`) **always** spawns every prefab in `effectPrefabs` before evaluating `rules`. Currently, both `Cracked.prefab` and `Brittle.prefab` populate `effectPrefabs` with `WallImpactBreak.prefab` and have `rules: []`, causing every `Crack` touch to look like a full shatter.
   - `CrackedBlock.TryCrush()` (`Assets/Scripts/Gameplay/CrackedBlock.cs:56-64`) returns `false` silently when `player.CurrentTier < requiredTier`, emitting zero `InteractionKind.Hit` feedback.
   - `Wedge.prefab`, `Brake.prefab`, `Exit.prefab`, and `Hazard.prefab` have `effectPrefabs: []`, `defaultCameraShake: 0`, `rules: []`. `VectorPad.prefab` has `alignToInteractionDirection: 0`. `PulseLaser.prefab` leaves `inactiveVisual`, `warningVisual`, and `activeVisual` unassigned.

5. **Runtime Procedural Allocation in `PowerUpController` & Disconnected Close-Call / Shader Plumbing**:
   - `PowerUpController.cs` falls back to `new GameObject(...)` + `AddComponent<SpriteRenderer>()` in `SpawnEchoVisual` (`lines 913-962`, using `Destroy(activeEchoObject)` instead of pooling), `SpawnRadialPulseVFX` (`lines 1448-1467`), and `SpawnDirectionalScanOrBurstVFX` (`lines 1469-1504`).
   - `CloseCallDetector.OnCloseCallTriggered` (`Action<Vector3>`) has zero subscribers, and `bonusCoins` (`5`) is suppressed because `EconomyBalanceConfig.Active.EnableLegacyExtraRewardSystems` is `false` (`0`) in `Assets/Resources/EconomyBalanceConfig.asset:72` — rendering a `+5 Coins` popup without reporting actual granted coins would lie to the player.
   - `Assets/Shaders/Hit/HitFlashSprite.shader` places `_FlashColor` in `UnityPerMaterial` (not `[PerRendererData]`), so shared-material flashes either mutate `Hit Flash White.mat` globally or break per-instance tinting.

6. **Post-Processing Headroom**:
   - `Assets/Volume/Global Volume Profile.asset` runs high baseline `Bloom` (`intensity: 9`), `Vignette` (`intensity: 0.4`), `ChromaticAberration` (`intensity: 0.2`), and `ColorAdjustments` (`postExposure: -0.4, contrast: 15`). Unclamped additive HDR flashes above `1.8` intensity blow out tiles; transient pulses must be small (`Bloom` / `ChromaticAberration` / `Vignette` offsets) and always reset cleanly to baseline.

## 2. Core Architectural Foundation (Pre-Pillar Plumbing)

All feedback systems strictly preserve the 4-Layer SRP design: gameplay state stays in `Assets/Scripts/Gameplay/`, presentation subscribers live in `Assets/Scripts/Feedback/` and `Assets/Scripts/Audio/`, and UI counters remain decoupled. `PlayerMovement.FixedUpdate()` cell-center snapping, soft-lock rules, and `moveSpeed = 30` remain untouched.

### 2.1 `TimeScaleCoordinator` (Arbitrated Time Scale Ownership)
Create a lightweight coordinator component (`Assets/Scripts/Core/TimeScaleCoordinator.cs`, placed on a persistent manager prefab alongside `GameManager`) that arbitrates named time-scale channels so Pause, Hit-Stop, Micro Slow-Mo, and Cutscenes never overwrite each other:

- **Channel Priorities & Arbitration (`Pause` > `HitStop` > `TimeDilation` > `Normal`)**:
  - `"Pause"` (from `UIManager`): absolute override (`0f` while paused).
  - `"HitStop"` (from `PlayerImpactFeedback`): `0f` brief freeze (`0.033s–0.083s`).
  - `"TimeDilation"` (from close-call micro slow-mo and transient cutscene/exit curves): e.g., `0.55f` for `0.07s` unscaled during Close-Call.
  - Resolution rule: if `"Pause"` is active, effective `Time.timeScale = 0f`; else if `"HitStop"` is active, `0f`; else resolve to the minimum scale among active `"TimeDilation"` / `"Cutscene"` overrides, returning to `"Normal"` (`1f`) when empty.
- **Mandatory Migration of All Direct Writers**:
  - `UIManager.UpdateTimeScale()` (`UIManager.cs:450`): call `TimeScaleCoordinator.SetChannel("Pause", 0f)` / `ClearChannel("Pause")` (falling back to `Time.timeScale = shouldFreeze ? 0f : 1f` if `TimeScaleCoordinator.Instance == null`).
  - `PlayerImpactFeedback.PulseHitStop()` (`PlayerImpactFeedback.cs:145-160`): acquire `"HitStop"` at `0f`, await `WaitForSecondsRealtime(duration)`, then `ClearChannel("HitStop")` in a `finally`/`OnDisable`-safe cleanup path (never restoring `1f` directly over an active `"TimeDilation"` or `"Pause"`).
  - `CutsceneManager.OnDisable()` & `DeathRoutine()` (`CutsceneManager.cs:122,261`): call `ClearChannel("HitStop")`, `ClearChannel("TimeDilation")`, and `ClearChannel("Cutscene")` instead of `Time.timeScale = 1f`.
  - `GameManager.OnSceneLoaded()` (`GameManager.cs:49`): call `TimeScaleCoordinator.ResetAll()` so scene reloads guarantee `Time.timeScale == 1f` cleanly.

### 2.2 Unscaled Presentation Timing & DOTween / Pooling Standards
- **DOTween Verified Chain**:
  - `ShortcutExtensions.DOKill` extends `UnityEngine.Component` and `UnityEngine.Material` (not `Tween`/`Sequence`), and `TweenExtensions.Kill` returns `void`.
  - Every UI/feedback tween follows:
    ```csharp
    targetComponent.DOKill();
    targetComponent.DOFade(0f, duration)
        .SetUpdate(true)
        .SetLink(gameObject)
        .OnComplete(() => ObjectPoolManager.ReturnObjectToPool(gameObject));
    ```
- **Pause-Aware Unscaled Updates**:
  - `PlayerLineTrail.LateUpdate()` (`PlayerLineTrail.cs:253`) and `CinemachineCameraZoom2D.Update()` (`CinemachineCameraZoom2D.cs:42`): skip updates when paused (`UIManager.Instance != null && UIManager.Instance.IsGamePaused` or `TimeScaleCoordinator.IsChannelActive("Pause")`), and step with `Time.unscaledDeltaTime` during active gameplay / Hit-Stop / Close-Call slow-mo. Retain `Mathf.Clamp(instSpeed, 4f, 28f)` in `PlayerLineTrail.cs:292`.
- **Single-Event Integrity on `PlayerMovement`**:
  - Remove `OnMoveStarted?.Invoke(...)` from `PlayerMovement.Redirect()` (`PlayerMovement.cs:998`). `OnMoveStarted` fires **only** on real player launches so `LevelFlowController.HandlePlayerMoveStarted` (`LevelFlowController.cs:560`) counts `movesUsedThisRun` accurately.
  - Subscribe `PlayerSquashStretch` to `PlayerMovement.OnRedirected` so directional stretch/rotation stays synced across corner deflections.
  - Guard `OnRedirected` subscribers in `ComboFeedbackController` and `EntityAudio` with `if (player.IsPhasing) return;` so `StartPhaseLaunch()` (`PlayerMovement.cs:523`) never triggers redirect SFX or combo escalation.
- **Pooling & Zero Procedural Object Creation**:
  - All transient VFX spawn via `VfxSpawner.Spawn(...)` (`Assets/Scripts/Animation/VfxSpawner.cs:29-34`) or `ObjectPoolManager.SpawnObject(...)` (`Assets/Scripts/Core/ObjectPoolManager.cs:172`), and return via `ObjectPoolManager.ReturnObjectToPool(gameObject)` (`ObjectPoolManager.cs:230`). Zero runtime `new GameObject(...)` or `AddComponent<...>()`.
- **Material-Safe Hit Flash (`HitFlashSprite.shader`)**:
  - Because `_FlashColor` lives in `UnityPerMaterial` inside `Assets/Shaders/Hit/HitFlashSprite.shader`, components using hit-flash tinting instantiate a per-instance material in `Awake()` (`flashMat = new Material(sharedHitFlashMaterial)`) and destroy it in `OnDestroy()`, ensuring per-entity flash color isolation without mutating `Hit Flash White.mat`.

- **Haptics Alignment (`GameHaptics.cs` & `HapticsTests.cs`)**:

  - All 7 existing `HapticEvent` values (`UISelect=0`, `WallImpact=1`, `GravityAnchor=2`, `PadRedirect=3`, `LaunchStart=4`, `SwitchToggle=5`, `Death=6` in `HapticEvent.cs:5-27`) are **already wired** in `GameplayHapticsFeedback.cs:52-85`, `LevelFlowController.cs:309,627`, and `SettingUI.cs:229-289`. Never add duplicate `PadRedirect`, `LaunchStart`, `SwitchToggle`, `WallImpact`, `GravityAnchor`, `UISelect`, or `Death` calls — keep existing single-event assertions in `Assets/Scripts/Editor/Tests/HapticsTests.cs` (`WallSlide`, `GravityBlockAndBrakeTile`, `PauseMenuUI`) intact.
  - Guard `GameplayHapticsFeedback` against `player.IsPhasing` on `OnRedirected` (`StartPhaseLaunch()` at `PlayerMovement.cs:523`) so phase launches do not emit spurious `PadRedirect` haptics. ## 3. Five Signature Game Feel Pillars

### Pillar 1: Kinetic Momentum & Tiered Launch Weight
**Intent**: Give each slide clear acceleration weight (`1–2` tiles = `Drift`, `3–4` tiles = `Cruise`, `5+` tiles = `KineticRam` per `VelocityTier.cs`, reacting purely to `PlayerMovement.OnVelocityTierChanged`) and fix false-positive wall feedback on anchors and ceilings.

1. **Tiered Launch & Mid-Flight Progression (`PlayerSquashStretch`, `CinemachineCameraZoom2D`, `PlayerLineTrail`)**:
   - **Launch Snap**: On `OnMoveStarted`, trigger a crisp launch stretch (`stretchX: 1.24, stretchY: 0.78`, `0.065s` OutQuad, `DOKill()` first) and launch audio (`SoundConfig.moveLaunch` / tier pitch).
   - **Dynamic Camera Zoom**: Set `CinemachineCameraZoom2D` Inspector defaults to `normalOrthographicSize = 5.5f`, `zoomSpeed = 6f`, driving `targetOrthographicSize` purely via `OnVelocityTierChanged`:
     - `Drift`: `5.50f`
     - `Cruise`: `5.65f` (subtle breathing room)
     - `KineticRam`: `5.88f` (speed pull-back) + return to `5.50f` (`0.22s` OutQuad) on `OnMoveStopped`
     - `Goal`: ease down to `4.95f` for suction focus.
   - **Tier-Scaled Trail & Speed Aura**: Driven by `OnVelocityTierChanged` (never hardcoded tile counts): widen `PlayerLineTrail` width multiplier (`1.0x` -> `1.15x` -> `1.35x`) and swap HDR trail gradient intensity safely under the Bloom budget (`<= 1.6` HDR intensity). Activate a child pooled speed-streak / aura sprite on `KineticRam` (`OnVelocityTierChanged`) that pulses smoothly and fades via DOTween on `OnMoveStopped`.
   - **Tier-Up Chime & Per-Tile Motion Ramp**: Crossing into `Cruise` or `KineticRam` mid-flight triggers a rising chime (`+8%` / `+18%` via `SoundManager.PlaySFX(..., pitchOverride, volumeScale)`), scaling tile-traverse whoosh `volumeScale` (`0.45f -> 0.85f`) with velocity tier alongside a crisp `0.06s` white outline flash (`flashAmount = 0.45f`).

2. **Wall vs. Anchor vs. Ceiling Discrimination (`PlayerImpactFeedback`, `PlayerSquashStretch`)**:
   - **Guard `PlayerImpactFeedback.HandleStopped()`**:
     - If `player.WasLastStopWallImpact == true`: execute tier-scaled hit-stop via `TimeScaleCoordinator` (`Drift: 0s`, `Cruise: 0.033s`, `KineticRam: 0.075s`), camera shake (`Drift: 0.035f`, `Cruise: 0.11f`, `KineticRam: 0.22f` directional recoil along `LastMoveDirection`), and pooled `WallImpactDust.prefab` at wall contact point oriented opposite to `LastMoveDirection`.
     - If `player.WasLastStopWallImpact == false` (stopped on `GravityBlock` or `BrakeTile`): suppress wall shake & hit-stop; trigger a soft vertical settling squash (`scaleX: 1.12, scaleY: 0.88`, `0.09s` OutBack) + anchor chime, matching `GravityBlock.prefab` (`Particle Cloud.prefab`, `0.04` shake) and `Brake.prefab` spark polish.
   - **Pivot-Aware Wall Press (`PlayerSquashStretch.cs`)**:
     - Because the player sprite uses a bottom-center `(0.5, 0)` pivot (`localPosition.y` offset by `-0.5`), pressing against an upward ceiling (`direction == Vector2.up`) with `wallPressPx` would pull the sprite downward *away* from the top wall. Apply `wallPress` directional offset symmetrically around the sprite's visual center (`+dir * pressOffset` for `left/right/down`, and scaled center-pivot compensation `+dir * (pressOffset + pivotCompensation)` for `up`), calling `visualTransform.DOKill()` before every tween.
   - **True Redirect Feel (`OnRedirected`)**:
     - With `OnMoveStarted` removed from `PlayerMovement.Redirect()`, `PlayerSquashStretch` subscribes directly to `OnRedirected` (ignoring when `player.IsPhasing`) to snap rotation & squash into the new axis, paired with `VectorPad.prefab` (`alignToInteractionDirection: 1`, `defaultCameraShake: 0.06`) and directional chevron burst VFX.

## 5. Technical Guardrails & Non-Negotiables

1. **Deterministic Physics Sacred**: `PlayerMovement.FixedUpdate()`, cell-center grid snapping, collision layers, `moveSpeed = 30`, and soft-lock recovery must never change timing or trajectory. Every presentation timer outside physics runs via unscaled time (`Time.unscaledDeltaTime`, `WaitForSecondsRealtime`, DOTween `.SetUpdate(true)`).
2. **Zero Runtime Procedural UI or VFX Objects**: Never instantiate `new GameObject(...)` or call runtime `AddComponent<...>()` for markers, pulses, scans, or popups. Author new transient prefabs (e.g., `EchoMarker.prefab`, `SkillRadialPulse.prefab`, `SkillCellScan.prefab`, `PooledAudioSource.prefab`, and the new impact/chip/spark/orb/text VFX prefabs complementing existing `WallImpactBreak.prefab`, `Particle Cloud.prefab`, `PoppingVFX.prefab`, and `Particle Explosion.prefab`) in `Assets/Prefabs/`, wire via `[SerializeField]`, spawn through `VfxSpawner.Spawn` / `ObjectPoolManager.SpawnObject`, and recycle via `ObjectPoolManager.ReturnObjectToPool`.
3. **DOTween Lifecycle Safety**: Every tween on Transforms, SpriteRenderers, or CanvasGroups must call `targetComponent.DOKill()` before creation and chain `.SetUpdate(true).SetLink(gameObject)` (never calling `.DOKill()` on a `Tween`, nor chaining `.OnComplete()` after `Kill()`).
4. **Inspector-Only UI & Explicit Scene Wiring**: Follow `AGENTS.md` strictly — never write Editor scripts to auto-create or mutate `GameScene.unity` UI hierarchies or `RectTransform` trees. Only spawn authored `ScriptableObject` / VFX prefab assets when explicitly approved, and update `recompile` + `HapticsTests.cs` after any script change.
5. **Single Ownership Rules**:
   - `TimeScaleCoordinator`: sole writer to `Time.timeScale`.
   - `EntityAudio`: sole gameplay SFX caller (no duplicate `PlaySFX` in gameplay tiles or combo tracker).
   - `CutsceneManager.GoalRoutine`: sole writer to `playerBody.position` during exit.
   - `HitFlashSprite` per-instance material: created in `Awake()`, destroyed in `OnDestroy()`, never mutating `Hit Flash White.mat` directly.
6. **Bloom & Flash Headroom**: Keep transient HDR sprite flash colors (`<= 1.6` HDR brightness) and temporary `Vignette` / `ChromaticAberration` pulses bounded and self-restoring around `Global Volume Profile.asset`'s `Bloom = 9`, `Vignette = 0.4`, `ChromaticAberration = 0.2`.
