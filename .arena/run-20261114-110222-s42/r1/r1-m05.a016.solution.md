# Gravita — Kinetic Lab Game Feel Upgrade Blueprint

> **Codebase Calibration Note (Current Truth vs. Design Targets)**
> 1. **Speed & Velocity Tiers**: In `Assets/Scenes/GameScene.unity`, `PlayerMovement.moveSpeed` is `30` units/sec (`cellSize = 1`), meaning Subject G-0 traverses **1 tile every `33.3 ms`** (and **`48 u/s`** during `StepPhaseLaunch` at `1.6x`). In `VelocityTier.cs` (and `docs/gdd.md`), `VelocityTierUtil.FromTiles(int tilesTraveled)` maps `1–2` tiles → `Drift`, `3–4` → `Cruise`, and `5+` → `KineticRam` (reaching max tier in **`167 ms`**), whereas the target spec describes `1–3 / 4–7 / 8+`. Every timing below is calibrated to the live `33.3 ms/tile` (`30 u/s`) physics loop and scales automatically if you adjust `FromTiles`.
> 2. **Close-Call & Revive Economy Flags**: `EconomyBalanceConfig.asset` sets `enableLegacyExtraRewardSystems: 0` (suppressing `CloseCallDetector`'s `bonusCoins: 5`) and `enableMidGameplayRevive: 0` (meaning `LevelFlowController.CanRevive` is always `false` and `OnPlayerRevived` never fires). Near-misses must therefore pay off through immediate audiovisual and kinetic surge, and respawn feedback must hook active restart/respawn paths rather than revive.

---

## 1. Core Game Feel Diagnosis: Why Gravita Currently Feels "Flat"

Gravita's deterministic stop-to-stop physics, velocity tiers, squash/stretch, trails, shake, and hit-stop are cleanly separated—but five concrete implementation leaks cancel out the speed and impact weight in live play:

1. **Unscaled Hit-Stop Conflicts & Missing Camera Zoom**
   - `PlayerImpactFeedback.PulseHitStop` pauses gameplay via `Time.timeScale = 0f` for `33 ms` (`Cruise`) and `83 ms` (`KineticRam`).
   - While `PlayerSquashStretch` *already* calls `KillActive()`, `.SetUpdate(true)`, and `.SetLink(gameObject)` on `OnMoveStopped`, `CinemachineCameraZoom2D` uses scaled `Time.deltaTime` (and currently has **zero callers** anywhere in code), `PlayerLineTrail.LateUpdate()` returns early when `Time.deltaTime <= 0f`, and `ReturnToPool` waits on scaled `WaitForSeconds`.
2. **Pivot Offset Mismatch, False Brake/Gravity Slams & Stale `LastImpactTier` Reads**
   - `Player/Sprite` in `GameScene.unity` sits at `localPosition (0, -0.5, 0)` with bottom-center `(0.5, 0)` pivot and `0.36 u` sprite size (`0.37 x 0.36`). `PlayerSquashStretch.Play()` applies only a raw `pressDirection * (wallPressPx / 32f)` shift without compensating for sprite height/pivot, so upward ceiling hits compress *away* from the top wall face.
   - `PlayerImpactFeedback.HandleStopped()` listens to `OnMoveStopped` **without checking `movement.WasLastStopWallImpact`**, causing soft stops on `BrakeTile` and `GravityBlock` to trigger wall-impact camera shake and hit-stop.
   - In `PlayerMovement.AdvanceSlideStep()`, `OnWallImpact?.Invoke(...)` fires *before* `StopMoving(wallImpact: true)` writes `LastImpactTier = CurrentTier`. As a result, `EntityAudio.HandlePlayerWallImpact` (which reads `playerMovement.LastImpactTier`) plays the **previous** dash's tier sound instead of the current impact tier.
3. **Omnidirectional Shake & Empty Per-Prefab Feedback**
   - `CinemachineCameraShake2D.ShakeCamera(float force)` calls `impulseSource.GenerateImpulse(force)` against a fixed `DefaultVelocity = (0, -1, 0)`, so smashing left, rebounding 90° off a wedge, and dropping down all kick the camera downward.
   - `PlayerImpactFeedback` in `GameScene.unity` sets `tier1Shake: 0`, `redirectShake: 0`, `impactAnimationPrefab: null`, and `blockBreakAnimationPrefab: null`; `CrackedBlock.OnAnyBroken` triggers zero hit-stop or camera punch; and `Brake.prefab`, `Wedge.prefab`, `Exit.prefab`, and `Hazard.prefab` all have empty `InteractionEffectPlayer`s (`effectPrefabs: []`, `defaultCameraShake: 0`, `rules: []`).
4. **167ms "Runway Blindness", Phase Speed Clipping & `Redirect()` Double-Fire**
   - At `30 u/s`, Subject G-0 reaches `KineticRam` in `0.167 s` without per-tile audio escalation, camera pull, or speed afterimages—and `PlayerLineTrail` clamps `instSpeed` to `[4f, 28f]`, clipping both normal `30 u/s` dashes and `48 u/s` `StepPhaseLaunch` transit.
   - `PlayerMovement.Redirect()` (and `StartPhaseLaunch`'s zero-distance branch) invokes **both** `OnRedirected` and `OnMoveStarted`, causing `EntityAudio` to double-play `moveStart` + `wedgeRedirect`, `PlayerSquashStretch` to trigger `HandleMoveStarted`, and `LevelFlowController.movesUsedThisRun` to overcount every wedge bounce as an extra player move.
5. **Silent Audio Wiring & Unsubscribed Signature Hooks**
   - `SoundConfig.asset` currently has `clips: []` on all `23` `SoundEntry` fields, and `AudioSystems.prefab` leaves `pooledAudioSourcePrefab`, `fallbackAudioSource`, `musicSource`, and `ambientSource` unassigned (`null`), collapsing `SoundManager.sfxPool` from `initialPoolSize = 10` down to a single `AudioSource` shared with `RandomPitchAudio`.
   - `CloseCallDetector.OnCloseCallTriggered` has **0 subscribers**, `Global Volume Profile.asset` (`Bloom: 9`, `Vignette: 0.4`, `ChromaticAberration: 0.2`, `ColorAdjustments`) is static at runtime, and `EnergyGate.OnLevelClockTick` clears `pendingDeferredClose` without emitting any event.

## 2. Six High-Impact Game Feel Pillars

All systems below obey the 4-layer architecture, avoid runtime `new GameObject(...)` or `AddComponent<...>()`, preserve deterministic `SimulateStep` grid physics, and guard every DOTween tween/sequence with `.DOKill()`, `.SetUpdate(true)`, and `.SetLink(gameObject)`.

### Pillar 1: Kinetic Runway Engine ("33ms-per-Tile Escalation & Dynamic Lens")

#### Why It Makes Gravita Uniquely Addictive
Because slides finish in fractions of a second (`167 ms` to reach `KineticRam`), static trail color swaps aren't enough for the player's nervous system to *feel* acceleration. Turning every crossed tile into an ascending harmonic synth tick paired with unscaled additive camera zoom-out and `KineticRam` afterimages turns long corridors into an accelerating slingshot—making players actively hunt longer lanes just to charge a Tier 3 smash.

#### Exact Numbers, Curves & Inspector Parameters
| Parameter | Target / Value | Notes |
|---|---|---|
| Tile Tick Audio Pitch (`OnTileCrossed`) | Base `0.94f`, `+0.045f` per tile, clamped `1.44f` (~11 tiles) | Volume ramps `0.16f` (`Drift`) → `0.26f` (`Cruise`) → `0.36f` (`KineticRam`) |
| Camera Base Tier Zoom (`CinemachineCameraZoom2D`) | `Drift / Idle`: `5.50` · `Cruise`: `5.72` (`+0.22`) · `KineticRam`: `6.02` (`+0.52`) | Smooth unscaled exponential damping (`zoomSpeed = 9f`) on `currentBaseSize` |
| Additive Lens Pulse (`PulseZoom`) | Dip `pulseOffset = -0.18` over `45 ms` (`OutQuad`) → return to `0f` over `140 ms` (`OutSine`) | Composes additively on `currentBaseSize` (`5.50`, `5.72`, or `6.02`) without fighting `Update()` |
| Afterimage Ghost Emission | Active in `KineticRam` or `Phasing`; spawn every `0.040 s` unscaled (`~1.2` tiles) | Max `5` active; fade alpha `0.42 → 0` over `0.15 s` (`OutQuad`), scale `1.0 → 0.85` |

#### Exact C# Integration Hooks
- **`SoundManager.cs`**: Add `PlaySFXWithPitch(SoundEntry entry, float pitch, float volumeScale = 1f)` clamping pitch to `[0.5f, 2.0f]` and passing it directly to `PlayResolvedClip` without mutating `SoundConfig` or using random pitch.
- **`CinemachineCameraZoom2D.cs` (Dual-Channel Unscaled Composition)**:
  Separate smooth tier zoom (`currentBaseSize`) from transient punch (`pulseOffset`) so `Update()` and DOTween never fight, and pulses always return to the live tier ortho size:
  ```csharp
  private float currentBaseSize;
  private float pulseOffset;
  private Sequence pulseSequence;

  private void Awake()
  {
      // ... existing singleton setup ...
      currentBaseSize = normalOrthographicSize > 0f ? normalOrthographicSize : 5.5f;
      if (targetOrthographicSize <= 0f) targetOrthographicSize = currentBaseSize;
  }

  private void Update()
  {
      if (cinemachineCamera == null) return;
      float alpha = 1f - Mathf.Exp(-zoomSpeed * Time.unscaledDeltaTime);
      currentBaseSize = Mathf.Lerp(currentBaseSize, targetOrthographicSize, alpha);
      cinemachineCamera.Lens.OrthographicSize = Mathf.Max(1f, currentBaseSize + pulseOffset);
  }

  public void PulseZoom(float orthoDelta, float inDuration, float outDuration)
  {
      pulseSequence?.Kill();
      pulseSequence = DOTween.Sequence()
          .Append(DOTween.To(() => pulseOffset, x => pulseOffset = x, orthoDelta, inDuration).SetEase(Ease.OutQuad))
          .Append(DOTween.To(() => pulseOffset, x => pulseOffset = x, 0f, outDuration).SetEase(Ease.OutSine))
          .SetUpdate(true)
          .SetLink(gameObject)
          .OnKill(() => pulseOffset = 0f);
  }
  ```
- **`KineticRunwayFeedback.cs` (`Assets/Scripts/Feedback/`)**:
  Subscribes to `PlayerMovement.OnTileCrossed`, `OnVelocityTierChanged`, `OnPhasingChanged`, `OnMoveStopped`, and `OnWallImpact`. Calls `CinemachineCameraZoom2D.Instance.SetTargetOrthographicSize(...)` by tier (`5.50 / 5.72 / 6.02`), triggers `PulseZoom(-0.18f, 0.045f, 0.14f)` on `Cruise`/`KineticRam` wall impacts and `CrackedBlock.OnAnyBroken`, and spawns `KineticAfterimage.prefab` via `ObjectPoolManager.SpawnObject` (never `ReturnToPool`, because `ReturnToPool` uses scaled `WaitForSeconds` and freezes during hit-stop):
  ```csharp
  public class KineticAfterimage : MonoBehaviour
  {
      [SerializeField] private SpriteRenderer spriteRenderer;
      private Sequence fadeSequence;

      public void Play(SpriteRenderer source, Color tint, float fadeDuration)
      {
          if (spriteRenderer == null || source == null) return;
          spriteRenderer.sprite = source.sprite;
          spriteRenderer.flipX = source.flipX;
          spriteRenderer.flipY = source.flipY;
          spriteRenderer.sortingLayerID = source.sortingLayerID;
          spriteRenderer.sortingOrder = source.sortingOrder - 1;
          spriteRenderer.color = tint;

          Vector3 startScale = source.transform.lossyScale;
          transform.localScale = startScale;

          fadeSequence?.Kill();
          fadeSequence = DOTween.Sequence()
              .Join(spriteRenderer.DOFade(0f, fadeDuration).SetEase(Ease.OutQuad))
              .Join(transform.DOScale(startScale * 0.85f, fadeDuration).SetEase(Ease.OutQuad))
              .SetUpdate(true)
              .SetLink(gameObject)
              .OnComplete(() => ObjectPoolManager.ReturnObjectToPool(gameObject));
      }

      private void OnDisable()
      {
          fadeSequence?.Kill();
          fadeSequence = null;
      }
  }
  ```

### Pillar 2: Directional Impact Physics, Wall-Face Compression & Break/Brake Fidelity

#### Why It Makes Gravita Uniquely Addictive
In a stop-to-stop maze, impact *is* the punctuation mark of every swipe. Fixing directional camera kick, keeping Subject G-0 pinned flush against ceilings and walls during hit-stop compression, distinguishing cushioned `BrakeTile`/`GravityBlock` stops from hard wall slams, and giving `CrackedBlock` shatters real micro-hitch weight makes every collision unmistakably physical.

#### Exact Numbers, Curves & Inspector Parameters
| Parameter | Current (`GameScene.unity`) | Recommended Target | Why |
|---|---|---|---|
| `PlayerImpactFeedback.tier1Shake` | `0` | `0.045` | Drift taps feel crisp instead of silent |
| `PlayerImpactFeedback.tier2Shake` / `tier3Shake` | `0.1` / `0.2` | `0.13` / `0.28` | Stronger contrast between Cruise and KineticRam |
| `PlayerImpactFeedback.redirectShake` | `0` | `0.08` | Gives wedge deflects a tactile kick |
| `PlayerImpactFeedback.tier1HitStop` / `tier2` / `tier3` | `0` / `0.033` / `0.083` | `0` / `0.033` / `0.070` | Preserves instant 1-tile taps while keeping `KineticRam` snappy |

   public void ShakeCamera(Vector2 direction, float force)
   {
       if (impulseSource == null || force <= 0f) return;

           ? new Vector3(direction.x, direction.y, 0f).normalized * force

     ```csharp
     // Inside PlayerSquashStretch.Play(Vector3 deformed, float duration, Vector2 pressDirection)
     Vector3 pressed = baseLocalPosition;
     if (pressDirection != Vector2.zero)
     {
         Vector2 dir = pressDirection.normalized;
         float pressWorld = wallPressPx / 32f;
         Vector2 size = spriteRenderer != null && spriteRenderer.sprite != null
             ? (Vector2)spriteRenderer.sprite.bounds.size
             : Vector2.one;
         Vector2 pivotNorm = spriteRenderer != null && spriteRenderer.sprite != null
             ? spriteRenderer.sprite.pivot / spriteRenderer.sprite.rect.size
             : new Vector2(0.5f, 0f);

         // Pin the leading edge of the deformed sprite against the wall face before pressing wallPressPx in:
         float dx = dir.x > 0.5f ? size.x * (1f - pivotNorm.x) * (baseScale.x - deformed.x)
                  : dir.x < -0.5f ? -size.x * pivotNorm.x * (baseScale.x - deformed.x) : 0f;
         float dy = dir.y > 0.5f ? size.y * (1f - pivotNorm.y) * (baseScale.y - deformed.y)
                  : dir.y < -0.5f ? -size.y * pivotNorm.y * (baseScale.y - deformed.y) : 0f;

         pressed += new Vector3(dir.x * pressWorld + dx, dir.y * pressWorld + dy, 0f);
     }
     ```

### Pillar 3: Billiard Corner-Whip & Buffered-Turn "Input Coil"

#### Why It Makes Gravita Uniquely Addictive
Gravita's puzzle flow hinges on `bufferTurnsUntilStop = true` and chained `DeflectionWedge` / `VectorPad` rebounds. At `30 u/s`, players swipe *before* reaching the wall—without visual confirmation that the turn is armed, swipes feel dropped; and because `Redirect()` currently re-invokes `OnMoveStarted`, wedge chains sound like repeated starts and miscount moves. Fixing `Redirect()` at the source and adding an "Input Coil" indicator turns cornering into crisp kinetic pinball.

|---|---|
