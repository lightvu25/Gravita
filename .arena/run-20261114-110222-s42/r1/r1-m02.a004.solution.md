# Gravita (`Puzzle 2D`) — Game Feel Signature Upgrade Blueprint

> **Engine Target:** Unity `6000.4.0f1` URP (2D Top-Down, `32 PPU`, `cellSize = 1`, `PixelPerfectCamera` `320x180`, `PlayerMovement.moveSpeed = 30` u/s = `33.3 ms/tile`).  
> **Architecture Standard:** Event-driven SRP across `Assets/Scripts/Feedback/`, `Assets/Scripts/Audio/`, and `Assets/Scripts/UI/`. Zero procedural `new GameObject()` / runtime `AddComponent<T>()`; all DOTween sequences use `.DOKill()`, `.SetUpdate(true)`, and `.SetLink(gameObject)`. `FixedUpdate` deterministic grid physics and `Collider2D` bounds stay untouched.

## Scope & Assumptions

1. **Velocity Tier Threshold Reconciliation:** `Assets/Scripts/Gameplay/VelocityTier.cs` (`VelocityTierUtil.FromTiles`) classifies `1–2` tiles as `Drift`, `3–4` tiles as `Cruise`, and `5+` tiles as `KineticRam` (`MinTilesForTier`), whereas higher-level design notes occasionally describe `1–3 / 4–7 / 8+`. All timing curves below anchor to `VelocityTierUtil.FromTiles` and `moveSpeed = 30` u/s (`Drift = 33–67 ms`, `Cruise = 100–133 ms`, `KineticRam = 167+ ms`), using `VelocityTier`-keyed Inspector fields so rebalancing thresholds never breaks feedback.
2. **Audio, VFX & Prefab Hierarchy Baseline:**
   - `Assets/Data/Sound/SoundConfig.asset` currently ships with empty `clips: []` arrays; `Assets/Prefabs/Manager/AudioSystems.prefab` and `Assets/Scenes/GameScene.unity` leave `pooledAudioSourcePrefab`, `musicSource`, and `ambientSource` unassigned (`{fileID: 0}`); and `InteractionEffectPlayer` rules on `Brake`, `Exit`, `Hazard`, and `Wedge` prefabs are empty.
   - `VectorPad.prefab` and `VectorLauncher.prefab` already separate a child `Visual` transform from the root `Collider2D`. By contrast, `EnergyGate.prefab` (`closedVisual`/`openVisual` unassigned), `Wedge.prefab`, `CircuitSwitch.prefab`, `PulseLaser.prefab`, `OverloadedFloor.prefab` (`inactiveVisual`/`warningVisual`/`activeVisual` unassigned), `Brake.prefab`, `Brittle.prefab`, `Exit.prefab`, `Hazard.prefab`, and `GravityBlock.prefab` currently have `m_Children: []` with `SpriteRenderer` and `Collider2D` together on the root `GameObject`. All script hooks below forbid transforming collider-bearing roots until child `Visual` objects are separated in Phase B.

## 1. Core Game Feel Diagnosis: Why Gravita Currently Feels Flat

Gravita already contains event hooks (`PlayerMovement`, `CloseCallDetector`, `InteractionEffectPlayer`, `GameplayHapticsFeedback`, `CinemachineCameraZoom2D`), yet feels muted in hands-on play for six concrete engineering reasons:

1. **Animation Timescales Ignore `33.3 ms/tile` Speed & Redirect Chaining:** In `GameScene.unity`, `PlayerSquashStretch` sets `stretchDuration = 0.18s` (`72 ms` out, `108 ms` back) and `squashDuration = 0.22s` (`88 ms` compress, `132 ms` recover). At `30 u/s`, a `Drift` slide (`33–67 ms`) hits the wall *before* launch stretch peaks, while a long `KineticRam` (`167+ ms`) snaps back to `baseScale` mid-corridor instead of sustaining aerodynamic tension. `HandleMoveStopped()` also applies identical `impactHeightPx = 16 / movingHeightPx = 28` squash to a 1-tile tap, a `KineticRam` slam, a `BrakeTile` stop, and a `LevelExit` freeze, ignores `OnRedirected`, lacks `.SetUpdate(true)`, and cancels only `activeSequence` instead of calling `visualTransform.DOKill()`.
2. **Bottom-Center Sprite Pivot (`localPosition = (0, -0.5, 0)`) Inverts Wall Squashes:** `Player/Sprite` (`32x32` @ `32 PPU`) scales from a `(0.5, 0)` bottom-center pivot. During `Vector2.up` (`maxDeformation = 0.3`), compressing `sy` to `0.70` drops the top face by `0.30` u (`9.6 px`) while `wallPressPx = 4` (`0.125` u) shifts upward—leaving Subject G-0 **`0.175` u (`5.6 px`) pulled away from north walls**. Conversely, `Vector2.down` shifts `localPosition.y` down by `-0.125` u, sinking the sprite **`4 px` inside south colliders**. Horizontal runs shrink toward the feet instead of center of mass.
3. **Broken Event Ordering, Missing Stop-Polarity Guard & Hit-Stop Stack/Leak Bugs:**
   - **Stale Impact Audio Tier:** `PlayerMovement.AdvanceSlideStep` (`PlayerMovement.cs:400, 429`) invokes `OnWallImpact?.Invoke(stopHit.normal)` *before* `StopMoving(wallImpact: true)` (`L769`) writes `LastImpactTier = CurrentTier`. `EntityAudio` reads `LastImpactTier`, playing the *previous* dash's tier.
   - **Redirect -> `OnMoveStarted` Event Order:** `PlayerMovement.Redirect` (`PlayerMovement.cs:996-998`) calls `OnRedirected?.Invoke(moveDirection)` immediately followed by `OnMoveStarted?.Invoke(moveDirection)` without resetting `TilesTraveled` (and `StartPhaseLaunch`/`StepPhaseLaunch` also emit `OnMoveStarted`). Subscribers that reset dash counters or launch deformation unconditionally on `OnMoveStarted` wipe ricochet chains and collapse `Cruise`/`KineticRam` stretch at every corner.
   - **Unfiltered `BrakeTile` / `GravityBlock` Stops & Hit-Stop Collisions:** `BrakeTile` and `GravityBlock` call `HaltAt` -> `StopMoving(wallImpact: false)`, leaving `LastImpactTier = CurrentTier` (`WasLastStopWallImpact = false`). Because `PlayerImpactFeedback.HandleStopped()` ignores `WasLastStopWallImpact`, non-wall stops trigger full wall shake and hit-stop. Meanwhile, `PlayerImpactFeedback.OnDisable()` stops `hitStopRoutine` without restoring `preHitStopTimeScale`, and `AdvanceSlideStep` (`L411-430`) triggers `CrackedBlock.OnAnyBroken` before solid-wall `StopMoving(true)` in the same `FixedUpdate` step—so a naive `Time.timeScale < 0.5f` guard drops wall hit-stop instead of stacking it cleanly.
   - **Premature Trail Color Reset & Speed Clamp:** `StopMoving()` invokes `ResetDashTracking()` (`OnVelocityTierChanged(None)`) *before* `OnMoveStopped`, snapping `PlayerLineTrail` back to cyan `Drift` (`headColor`) instead of holding `Cruise` gold or `KineticRam` magenta during retraction. `PlayerLineTrail.LateUpdate` (`L292`) also clamps `smoothedMoveSpeed` at `28f`, below `moveSpeed = 30` and `PhaseLaunch = 48`.
4. **Dead Momentum & Near-Miss Channels + Unwired Hit-Flash Shader:** `PlayerMovement.OnTileCrossed` has **0 subscribers**, leaving velocity escalation silent; `CloseCallDetector.OnCloseCallTriggered` has **0 external subscribers** (`CloseCallDetector` runs only its internal `0.06f` pulse and `StarBurst` VFX). Furthermore, `Player/Sprite` uses `Sprite-Lit-Default` with `Color.white`, so color-only white flashes are multiplicative no-ops even though `Assets/Shaders/Hit/Hit Flash White.mat` (`Shader "Echoes/VFX/Solid White Sprite"`) is already in the project.
5. **Pixel-Perfect Camera Conflict, Scalar Shake & Particle Up-Vector Collinearity:** `GameScene.unity` zeroes `tier1Shake` and `redirectShake`; `CinemachineCameraShake2D` emits scalar omnidirectional jitter; `PlayerImpactFeedback.HandleWallImpact` calls `Quaternion.LookRotation((Vector3)normal)` with implicit `Vector3.up` (collinear on `Vector2.up`/`Vector2.down`, rotating `WallImpactBurst.prefab`'s Cone `+Z` emitter inconsistently while `useUnscaledTime` defaults to `0`); and `CinemachineCameraZoom2D` (`5.5` ortho, `Time.deltaTime` lerp) has `0` callers while sharing `CinemachineCamera` with `CinemachinePixelPerfect` (`320x180`, `32 PPU`).
6. **Invisible Input Queueing, Unsplit Prop Visuals & Null Scene Audio Refs:** `bufferTurnsUntilStop = true` gives zero mid-dash queued confirmation or blocked-swipe tactility; `BrittleFloor`, `CircuitSwitch`, `EnergyGate`, `PulseLaser`, `OverloadedFloor`, and `LevelExit` produce flat swaps (and share root transforms with `Collider2D`); and `MusicManager.musicSource` is null in `GameScene.unity` and `AudioSystems.prefab`. *(Meanwhile `GameplayHapticsFeedback` already maps wall impacts, brake/gravity anchors, wedge/pad redirects, launches, and switches via `MazeTile.OnAnyPlayerInteracted`, `LevelFlowController` already triggers `HapticEvent.Death`, and `AudioVolumeControl` uses `HapticEvent.UISelect`.)*

#### Exact C# Integration Hooks
1. **Center-Compensated & Redirect-Safe `Assets/Scripts/Feedback/PlayerSquashStretch.cs`:**
   ```csharp
   // Add [SerializeField] Vector2 defaultPivotToCenter = new Vector2(0f, 0.5f);
   // Add [SerializeField] float sustainedGlideTransition = 0.045f;
   // Add [SerializeField] float redirectDuration = 0.035f;
   // Subscribe in OnEnable: movement.OnRedirected += HandleRedirected;

   private bool justRedirectedInFixedStep;
   private float lastRedirectFixedTime = -1f;

   private Vector2 ResolvePivotToCenter()
   {
       if (spriteRenderer == null || spriteRenderer.sprite == null)
           return defaultPivotToCenter;

       Sprite sprite = spriteRenderer.sprite;
       Vector2 rectSize = sprite.rect.size;
       if (rectSize.x <= 0.001f || rectSize.y <= 0.001f)
           return defaultPivotToCenter;

       Vector2 normPivot = new Vector2(sprite.pivot.x / rectSize.x, sprite.pivot.y / rectSize.y);
       Vector2 worldSize = sprite.bounds.size;
       return new Vector2((0.5f - normPivot.x) * worldSize.x, (0.5f - normPivot.y) * worldSize.y);
   }

   private void GetSustainedStretchForState(out float along, out float across)
   {
       if (movement != null && movement.IsPhasing) { along = 0.28f; across = -0.14f; return; }
       VelocityTier tier = movement != null ? movement.CurrentTier : VelocityTier.Drift;
       switch (tier)
       {
           case VelocityTier.KineticRam: along = 0.24f; across = -0.12f; break;
           case VelocityTier.Cruise:     along = 0.16f; across = -0.08f; break;
           default:                      along = 0.08f; across = -0.04f; break;
       }
   }

   private void HandleRedirected(Vector2 newDir)
   {
       justRedirectedInFixedStep = true;
       lastRedirectFixedTime = Time.fixedTime;
       GetSustainedStretchForState(out float along, out float across);
       ApplySustainedStretch(newDir, along, across, redirectDuration);
   }

   private void HandleMoveStarted(Vector2 dir)
   {
       // PlayerMovement.Redirect invokes OnRedirected then OnMoveStarted in the same FixedUpdate step.
       if (justRedirectedInFixedStep && Mathf.Approximately(Time.fixedTime, lastRedirectFixedTime))
       {
           justRedirectedInFixedStep = false;
           return;
       }

       justRedirectedInFixedStep = false;
       GetSustainedStretchForState(out float along, out float across);
       ApplySustainedStretch(dir, along, across, stretchInDuration);
   }
   ```
   - `ComputeCompensatedLocalPosition(targetScale, pressDirection, pressPx)` shifts by `pivotToCenter * (baseScale - targetScale)` plus wall pin `(dir * (0.5f * (1f - scaleAlong) + pressPx / 32f))`.
   - `HandleMoveStopped()` clears `justRedirectedInFixedStep`: returns immediately if `movement.InputLocked` (yields to `ExitCaptureFeedback`); if `movement.WasLastStopWallImpact` is false, relaxes cleanly to `baseScale` / `baseLocalPosition` over `0.06s`; if true, applies tier-scaled wall squash (`2/4/6 px` press, holds peak compression for the tier's unscaled hit-stop duration, rebounds via `Ease.OutBack`).

### Pillar 2: Directional Impact, Shader Hit-Flash & Stop Polarity (Wall-Slam vs. Mag-Brake)

#### Why It Makes Gravita Uniquely Addictive
Gravita stops `30 u/s` motion in two opposite ways: slamming a solid wall/`CrackedBlock`, or gliding onto a `BrakeTile`/`GravityBlock` magnetic floor arrest. Giving wall impacts directional camera punch, owned stacking hit-stop, normal-aligned `+Z` spark cones, and crisp solid-white shader flashes—while keeping magnetic floor stops at **zero shake and zero hit-stop**—makes impacts hit harder through polarity.

### Pillar 3: Pinball Ricochet Chain Symphony (`DeflectionWedge`, `VectorPad`, `VectorLauncher`)

#### Why It Makes Gravita Uniquely Addictive
`PlayerMovement` preserves `TilesTraveled` across up to `maxConsecutiveRedirects = 8` corner deflections (`DeflectionWedge`, `VectorPad`) and `VectorLauncher` blasts Subject G-0 at aerial speed. Turning chained rebounds into an ascending **pentatonic pinball instrument** with spring-loaded bumper pads turns multi-corner routes into pure flow.

#### Exact Numbers, Curves & Parameters
| Parameter | Exact Value | Purpose |
|---|---|---|
| **Pentatonic Redirect Scale (`semitones`)** | `[0, 2, 4, 7, 9, 12, 14, 16]` (`1.000x` -> `2.520x`) | Ascending major pentatonic arpeggio for redirects `1..8`; always harmonious |
| **Directional Corner Impulse** | `0.08f + 0.015f * Min(chainCount - 1, 6)` along corner bisector `Normalize(newDir - oldDir)` | Crisp directional kick scaling smoothly from `#1` (`0.08`) to `#7` (`0.17`) |
| **Wedge / Pad Bumper Recoil** | `DOPunchScale((0.22f, 0.22f, 0f), 0.14f, vibrato: 6, elasticity: 0.6f)` on child `Visual` + `0.045s` `Hit Flash White.mat` swap | Mechanical pinball flex strictly decoupled from root `Collider2D` bounds |
| **`VectorLauncher` Pre-Throw Snap** | `0.035s` visual coil `(0.88, 1.15)` on `VectorLauncher/Visual` -> chevron burst (`InteractionKind.Launch`) | Immediate aerial-launch anticipation |

#### Exact C# Integration Hooks
1. **New `Assets/Scripts/Feedback/RicochetChainTracker.cs` (attached to `Player`):**
   - Subscribes to `movement.OnMoveStarted`, `movement.OnRedirected(Vector2 newDir)`, and `movement.OnMoveStopped`.

     private int chainCount;
     private Vector2 previousDir;
     private bool dashActive;
     private bool suppressNextMoveStartedFromRedirect;
     private float lastRedirectFixedTime = -1f;

     private void HandleMoveStarted(Vector2 dir)
     {
         if (suppressNextMoveStartedFromRedirect && Mathf.Approximately(Time.fixedTime, lastRedirectFixedTime))
         {
             suppressNextMoveStartedFromRedirect = false;
             return;
         }

         suppressNextMoveStartedFromRedirect = false;
         dashActive = true;
         chainCount = 0;
         previousDir = dir;
     }

     private void HandleRedirected(Vector2 newDir)
     {
         if (movement != null && movement.IsPhasing) return;

         if (!dashActive)
         {
             dashActive = true;
             previousDir = movement != null && movement.LastMoveDirection != Vector2.zero
                 ? movement.LastMoveDirection
                 : newDir;
         }

         chainCount++;
         suppressNextMoveStartedFromRedirect = true;
         lastRedirectFixedTime = Time.fixedTime;

         Vector2 cornerImpulse = (newDir - previousDir).sqrMagnitude > 0.01f
             ? (newDir - previousDir).normalized
             : newDir;
         float force = redirectBaseShake + redirectStepShake * Mathf.Min(chainCount - 1, 6);
         CinemachineCameraShake2D.Instance?.ShakeDirectional(cornerImpulse, force);

         int idx = Mathf.Min(chainCount - 1, PentatonicSemitones.Length - 1);
         float pitch = Mathf.Pow(1.059463094f, PentatonicSemitones[idx]);
         OnRicochetStep?.Invoke(chainCount, pitch, cornerImpulse); // consumed by EntityAudio
         previousDir = newDir;
     }

     private void HandleMoveStopped()
     {
         dashActive = false;
         suppressNextMoveStartedFromRedirect = false;
         chainCount = 0;
         previousDir = Vector2.zero;
     }
