# Gravita Game Feel Engineering Blueprint

**Target Engine / Project**: `Puzzle 2D` (`Gravita`, Unity `6000.4.0f1` URP 2D)  
**Architecture Model**: Strict SRP, event-driven presentation components in `Assets/Scripts/Feedback/`, deterministic `FixedUpdate` cell-center grid simulation preserved without physics mutation, zero runtime `new GameObject` / `AddComponent` allocation for VFX/UI/audio/materials, and strict DOTween lifecycle hygiene (`.DOKill()`, `.SetUpdate(...)`, `.SetLink(gameObject)`).

---

## 1. Core Loop Feel Diagnosis & Architectural Invariants

Playing **Gravita** exposes four high-leverage presentation gaps layered on top of a tight grid simulation (`PlayerMovement.moveSpeed = 30`, i.e., `33.3 ms/tile`):

1. **Stale Impact Order & Missing Tier Differentiation**: In `Assets/Scripts/Gameplay/PlayerMovement.cs`, `OnWallImpact` (`lines 400, 429`) fires *before* `StopMoving(bool wallImpact)` (`line 762`) commits `LastImpactTier = CurrentTier` (`line 769`) and `WasLastStopWallImpact = wallImpact`, while `PlayerImpactFeedback.HandleStopped` (`Assets/Scripts/Feedback/PlayerImpactFeedback.cs:79-100`) ignores `WasLastStopWallImpact`—leaking `tier2Shake` (`0.1`) and `tier3Shake` (`0.2`) onto non-wall `BrakeTile` (Soft Anchor) stops. Meanwhile, `PlayerSquashStretch` (`Assets/Scripts/Feedback/PlayerSquashStretch.cs:26-27`) clamps `squashDuration` and `stretchDuration` with `[Min(0.05f)]` and slow defaults (`0.22f` / `0.18f`) that outlast entire 1–3 tile slides (`33.3–100 ms`).
2. **Competing Time-Scale & Camera Authorities**: `PlayerImpactFeedback.HitStopRoutine` (`lines 153-160`) writes `Time.timeScale` independently of `UIManager.UpdateTimeScale()` (`Assets/Scripts/UI/Core/UIManager.cs:438-451`), and `UIManager.IsAnyPopupOpen` (`line 45`) counts `freezeTime: 0` screens (`Shop=6, Mission=8, Setting=9, Login=10, CoinBonus=12` in `Assets/Scenes/GameScene.unity:25397-25425`). Simultaneously, `Main Camera`'s `CinemachineBrain` (`IgnoreTimeScale: 0`, `GameScene.unity:10639`), `CinemachineImpulseManager.IgnoreTimeScale` (`false`), `PooledParticlePlayer`, and `PooledAnimationPlayer` halt during `Time.timeScale == 0`, while `CinemachinePixelPerfect` (`m_Enabled: 1`, `GameScene.unity:35526-35530`) and `PixelPerfectCamera` (`GameScene.unity:10668-10680`) override smooth zoom.
3. **Silent Gameplay Feedback Channels**: `Assets/Data/Sound/SoundConfig.asset` currently ships with unpopulated `clips: []` arrays, `SoundManager.PlaySFX` lacks a per-call pitch override for combo/chain/cadence escalation, `GameScene.unity` zeroes `tier1Shake` (`0`) and leaves `Wedge.prefab`, `Brake.prefab`, `Exit.prefab`, and `Hazard.prefab` with empty `InteractionEffectPlayer.effectPrefabs` and `defaultCameraShake: 0`.
4. **Input Queue Opacity & Secondary Loop Polish**: `PlayerMovement` queues buffered turns (`QueueDirection` `221-240`, `SimulateStep` `277-294`) without emitting visual/audio/haptic confirmation; `CloseCallDetector` (`CloseCallDetector.cs:99`) permits repeatable per-hazard bonus coins on the same run; and `PowerUpController.SpawnRadialPulseVFX` / `SpawnDirectionalScanOrBurstVFX` allocate transient `new GameObject` instances instead of pooling through `VfxSpawner`.

### Hard Architectural Invariants
- **Zero Simulation Side Effects**: `Time.timeScale` is **only** frozen by time-freezing UI popups and transient impact hit-stop (`<= 45 ms`). `CloseCallDetector` preserves `Assets/Scripts/Feedback/CloseCallDetector.cs:10` (*"never modifies `Time.timeScale`"*), keeping deterministic `FixedUpdate` tile stepping untouched.
- **No Unauthorized Scene Script Mutation**: Scene/prefab Inspector edits and `SoundConfig.asset` population are executed strictly through manual Inspector setup and asset authoring.

```csharp
using Unity.Cinemachine;
using UnityEngine;

[DisallowMultipleComponent]
public sealed class TimeScaleArbitrator : MonoBehaviour
{
    public static TimeScaleArbitrator Instance { get; private set; }

    [SerializeField] private UIManager uiManager;

    private float _hitStopUntilUnscaled;
    private bool _controllingTimeScale;

    public bool IsPaused => uiManager != null && uiManager.HasTimeFreezingPopupOpen;
    public bool IsHitStopActive => !IsPaused && Time.unscaledTime < _hitStopUntilUnscaled;

    private void Awake()
    {
        if (Instance != null && Instance != this)
        {
            Destroy(gameObject);
            return;
        }

        Instance = this;
        if (CinemachineImpulseManager.Instance != null)
            CinemachineImpulseManager.Instance.IgnoreTimeScale = true;
    }

    private void OnDestroy()
    {
        if (Instance == this)
        {
            if (_controllingTimeScale)
                Time.timeScale = 1f;
            Instance = null;
        }
    }

    public void RequestHitStop(float durationSeconds)
    {
        if (durationSeconds <= 0f || IsPaused)
            return;

        _hitStopUntilUnscaled = Mathf.Max(_hitStopUntilUnscaled, Time.unscaledTime + durationSeconds);
        ResolveTimeScale(false);
    }

    public void ResolveTimeScale(bool? explicitUiFreeze = null)
    {
        bool paused = explicitUiFreeze ?? IsPaused;
        if (paused)
        {
            _hitStopUntilUnscaled = 0f;
            CinemachineImpulseManager.Instance?.Clear();
            Time.timeScale = 0f;
            _controllingTimeScale = true;
            return;
        }

        if (Time.unscaledTime < _hitStopUntilUnscaled)
        {
            Time.timeScale = 0f;
            _controllingTimeScale = true;
            return;
        }

        _hitStopUntilUnscaled = 0f;
        if (_controllingTimeScale || explicitUiFreeze.HasValue)
        {
            Time.timeScale = 1f;
            _controllingTimeScale = false;
        }
    }

    private void LateUpdate()
    {
        if (_hitStopUntilUnscaled > 0f || _controllingTimeScale)
            ResolveTimeScale();
    }
}
```

```csharp
    _channelOffsets[idx] = orthoDelta;

    _channelActive[idx] = false;
```

### 4.2 Isolated `BufferedTurnFeedback` (`Assets/Scripts/Feedback/BufferedTurnFeedback.cs`)
Animates **strictly** child `Player/BufferedChevron` (`chevronPivot`, `chevronRenderer`), leaving `Player/Sprite` (`{0, -0.5, 0}`) untouched:

```csharp
using DG.Tweening;
using UnityEngine;

[DisallowMultipleComponent]
public sealed class BufferedTurnFeedback : MonoBehaviour
{
    [SerializeField] private PlayerMovement playerMovement;
    [SerializeField] private Transform chevronPivot;
    [SerializeField] private SpriteRenderer chevronRenderer;
    [SerializeField] private SoundManager soundManager;
    [SerializeField] private SoundConfig soundConfig;
    [SerializeField] private float orbitRadius = 0.55f;
    [SerializeField] private Color queuedColor = new Color(0.4f, 0.95f, 1f, 0.95f);
    [SerializeField] private Color rejectedColor = new Color(1f, 0.25f, 0.32f, 1f);

    private Tween _scaleTween;
    private Tween _posTween;
    private Tween _fadeTween;
    private Vector2 _lastQueuedDir = Vector2.up;

    private void Awake()
    {
        if (soundManager == null)
            soundManager = FindFirstObjectByType<SoundManager>();

        if (chevronRenderer != null)
        {
            Color c = chevronRenderer.color;
            c.a = 0f;
            chevronRenderer.color = c;
        }
    }

    private void OnEnable()
    {
        if (playerMovement != null)
            playerMovement.OnBufferedTurnChanged += HandleBufferedTurnChanged;
    }

    private void OnDisable()
    {
        if (playerMovement != null)
            playerMovement.OnBufferedTurnChanged -= HandleBufferedTurnChanged;
        KillTweens();
    }

    private void KillTweens()
    {
        _scaleTween?.Kill();
        _posTween?.Kill();
        _fadeTween?.Kill();
    }

    private void HandleBufferedTurnChanged(PlayerMovement.BufferedTurnFeedbackEvent evt)
    {
        if (chevronPivot == null || chevronRenderer == null)
            return;

        KillTweens();
        Vector2 dir = evt.Direction.sqrMagnitude > 0.01f ? evt.Direction.normalized : _lastQueuedDir;

        switch (evt.State)
        {
            case PlayerMovement.BufferedTurnEventState.Queued:
                _lastQueuedDir = dir;
                chevronPivot.localPosition = (Vector3)(dir * orbitRadius);
                chevronPivot.localRotation = Quaternion.FromToRotation(Vector3.up, dir);
                chevronPivot.localScale = Vector3.one * 0.6f;
                chevronRenderer.color = queuedColor;
                _scaleTween = DOTween.Sequence()
                    .Append(chevronPivot.DOScale(1.15f, 0.04f).SetEase(Ease.OutQuad))
                    .Append(chevronPivot.DOScale(1.0f, 0.04f).SetEase(Ease.InOutSine))
                    .SetUpdate(true)
                    .SetLink(chevronPivot.gameObject);
                PlayCue(soundConfig != null ? soundConfig.bufferQueueClick : null, HapticEvent.BufferQueue);
                break;

            case PlayerMovement.BufferedTurnEventState.Consumed:
                chevronPivot.localScale = Vector3.one;
                _posTween = chevronPivot.DOLocalMove((Vector3)(dir * (orbitRadius + 0.25f)), 0.07f)
                    .SetEase(Ease.OutQuad).SetUpdate(true).SetLink(chevronPivot.gameObject);
                _fadeTween = chevronRenderer.DOFade(0f, 0.07f)
                    .SetUpdate(true).SetLink(chevronRenderer.gameObject);
                break;

            case PlayerMovement.BufferedTurnEventState.Rejected:
                chevronPivot.localPosition = (Vector3)(dir * orbitRadius);
                chevronPivot.localRotation = Quaternion.FromToRotation(Vector3.up, dir);
                chevronRenderer.color = rejectedColor;
                _posTween = chevronPivot.DOShakePosition(0.10f, 0.08f, 24, 90f, false, true)
                    .SetUpdate(true).SetLink(chevronPivot.gameObject);
                _fadeTween = chevronRenderer.DOFade(0f, 0.12f)
                    .SetUpdate(true).SetLink(chevronRenderer.gameObject);
                PlayCue(soundConfig != null ? soundConfig.bufferRejectTick : null, HapticEvent.BufferReject);
                break;

            case PlayerMovement.BufferedTurnEventState.Cleared:
                _fadeTween = chevronRenderer.DOFade(0f, 0.05f)
                    .SetUpdate(true).SetLink(chevronRenderer.gameObject);
                break;
        }
    }

    private void PlayCue(SoundEntry entry, HapticEvent haptic)
    {
        if (soundManager != null && entry != null)
            soundManager.PlaySFX(entry);
        GameHaptics.Play(haptic);
    }
}
```
