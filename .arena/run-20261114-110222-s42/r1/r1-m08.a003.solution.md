# Gravita — Game Feel Architecture & Implementation Blueprint

**Target Project:** Gravita (`Puzzle 2D` — Unity `6000.4.0f1` URP)  
**Design Constraints:** Event-driven SRP components, zero runtime `new GameObject(...)` or `AddComponent<...>()`, DOTween strictly chained with `.DOKill()`, `.SetUpdate(true)`, `.SetLink(gameObject)`, and zero alterations to `PlayerMovement.FixedUpdate` determinism or grid physics.

---

## 1. Core Game Feel Diagnosis: Why Gravita Currently Feels Flat

Code, scene (`Assets/Scenes/GameScene.unity`, `Assets/Scenes/Bootstrap.unity`), and prefab inspection reveal six specific structural bottlenecks behind the game's muted kinetic sensation:

1. **High-Speed Runway (`moveSpeed = 30`) Without Progressive Cadence or State Separation**
   - `PlayerMovement` traverses 30 tiles/second and emits `OnTileCrossed(int)` and `OnVelocityTierChanged(VelocityTier)` (`Drift` 1–2, `Cruise` 3–4, `KineticRam` 5+).
   - No system currently listens to `OnTileCrossed` for rhythmic audio ticks or zoom tension, `SoundConfig` lacks progressive runway/anchor/phase entries, and `PlayerSquashStretch.HandleTierChanged` only handles `Cruise` and `KineticRam` via transient `Play(...)` calls that immediately spring back to `baseScale` instead of holding an aerodynamic dash silhouette.
2. **Sprite Pivot Drift & Unfiltered `PlayerSquashStretch` Stops**
   - `PlayerSquashStretch` already calls `.SetUpdate(true).SetLink(gameObject)` on `ResetScale()` and `Play()`, and `GameScene.unity` clamps `maxDeformation` to `0.3` (overriding the script default `0.45`).
   - However, `Assets/Sprites/Entities/Player Icon.aseprite` (`32x32`) uses a bottom-center `(0.5, 0)` pivot offset at `Player/Sprite` (`localPosition = (0, -0.5, 0)`). Scaling vertically in `Deform(...)` without proportional Y-anchor compensation shifts the sprite's visual center off the tile.
   - Furthermore, `HandleMoveStopped()` fires `Squash(lastDirection, pressWall)` whenever `OnMoveStopped` emits — including non-wall halts (`Freeze()`, `TeleportTo()`, `HaltAt()`), `HandleRedirected` is unsubscribed, and `HandlePhasingChanged` alters tint (`phaseSpriteTint`) with zero launch stretch or landing squash.
3. **Neutralized Camera Zoom & Hit-Stop Frozen Camera Shakes/Trail**
   - `CinemachineCameraZoom2D` exists on `CinemachineCamera/Zoom` (`normalOrthographicSize = 5.5`, `zoomSpeed = 4`), but no gameplay script calls it, `Update()` multiplies by scaled `Time.deltaTime`, and two camera locks nullify any `OrthographicSize` changes:
     - `CinemachinePixelPerfect` (`m_Enabled: 1` on `CinemachineCamera`) invokes `PixelPerfectCamera.CorrectCinemachineOrthoSize` at `Stage.Body`, snapping any target in `(4.8214, 6.75)` at `1920x1080` (`32` PPU, `320x180` reference) to `5.625f`.
     - Disabling only `CinemachinePixelPerfect` leaves `m_CinemachineCompatibilityMode = false` (set in `PixelPerfectCamera.OnEnable()`), causing `PixelPerfectCamera.OnBeginCameraRendering` on `Main Camera` to force `m_Camera.orthographicSize = m_Internal.orthoSize`.
   - During hit-stop (`PlayerImpactFeedback.HitStopRoutine` drops `Time.timeScale = 0` for `tier2HitStop = 0.033s` and `tier3HitStop = 0.083s`), `Main Camera`'s `CinemachineBrain.IgnoreTimeScale` is `false` (`0`), `CinemachineImpulseManager.Instance.IgnoreTimeScale` defaults to `false`, and `PlayerLineTrail.LateUpdate()` checks `Time.deltaTime <= 0f`, stalling impulse shake progression and trail decay until hit-stop ends.
4. **Unfiltered Stop/Redirect Events & Missing Tier-3 Shatter Punch**
   - `PlayerImpactFeedback.HandleStopped()` reads `LastImpactTier` without gating on `movement.WasLastStopWallImpact`, causing `Freeze()`, `TeleportTo()`, and `HaltAt()` stops to trigger impact shake/hit-stop, while `GameScene.unity` sets `tier1Shake = 0` and `redirectShake = 0`.
   - `PlayerMovement.StartPhaseLaunch()` calls `SetPhasing(true)` immediately before invoking `OnRedirected?.Invoke(lastMoveDirection)`, so unguarded `OnRedirected` listeners misclassify `VectorLauncher` phase launches as wedge deflections.
   - `PlayerImpactFeedback.HandleBlockBroken(CrackedBlock)` spawns particles/animation without camera trauma, hit-stop reinforcement, or haptic kick.
5. **Silent Turn Buffering & Incomplete Audio Pooling**
   - `PlayerMovement` stores `pendingDirection` (`bufferTurnsUntilStop = 1`), exposes `HasPendingDirection`, and clears or executes the buffered direction on impact — with zero world chevron indicator or latch tick.
   - In `Assets/Prefabs/Manager/AudioSystems.prefab` and `Assets/Scenes/Bootstrap.unity`, `SoundManager.pooledAudioSourcePrefab` is unassigned (`{fileID: 0}`), so `InitializePool()` creates zero pooled `AudioSource` instances and `PlayResolvedClip` mutates `fallbackAudioSource.pitch` globally right before `PlayOneShot` (retroactively bending in-flight notes). Meanwhile `EntityAudio.HandleCoinCollected` shares `SoundManager.lastPlayedTimeByClip` cooldown suppression (`0.02s`), choking rapid multi-coin pickup arpeggios.
6. **Uneven Prefab Effects, Procedural Power-Up VFX & Unwired Edge Haptics**
   - While `GravityBlock.prefab` (`0.04` shake), `EnergyGate.prefab` (`0.05` shake + VFX), `CircuitSwitch.prefab` (`0.03` shake + VFX), `VectorPad.prefab` (`0.04`), `VectorLauncher.prefab` (`0.1`), `FailingTile.prefab` (`0.08`), `PulseLaser.prefab` (`0.12`), and `SentinelDrone.prefab` (`0.14`) already carry configured feedback, `Brake.prefab`, `Exit.prefab`, `Hazard.prefab`, and `Wedge.prefab` have `effectPrefabs: []` and `defaultCameraShake: 0`.
   - `PowerUpController` constructs procedural `new GameObject` VFX at runtime (`SpawnRadialPulseVFX`, `SpawnDirectionalScanOrBurstVFX`) instead of spawning pooled/serialized VFX prefabs via `VfxSpawner.Spawn(...)`.
   - `GameplayHapticsFeedback` already covers `WallImpact`, `GravityAnchor`, `PadRedirect`, `LaunchStart`, `SwitchToggle`, and `Death` (verified at `GameHaptics.EventCount = 7`), leaving `CrackedBlock.OnAnyBroken`, `CloseCallDetector.OnCloseCallTriggered`, and `PowerUpController.OnAnyPowerUpUsed` without tactile feedback.

## 2. Game Feel Pillars (Specifications, Compilable Code & Wiring)

### Pillar 1 — Kinetic Runway Escalation & Silhouette Continuity

**Player Psychology & Rhythmic Feel**  
Every dash should feel like an accelerating magnetic railgun rather than a constant-velocity translation. Crossing tiles establishes a faint ascending tempo (`1, 2, 3, 4...`), locking into `KineticRam` (`5+`) triggers a crisp harmonic lock-in chime + FOV dip + sustained aerodynamic elongation, and every squash/stretch preserves the character's tile center cleanly without vertical pivot bobbing.

**Numerical Specifications**
- **Tile Cadence (`OnTileCrossed`)**: Subtly ascending tick from tile `1` to `8`: pitch `0.94f + Mathf.Min(tiles - 1, 7) * 0.045f` (`0.94 -> 1.255`), volume multiplier `0.42f + Mathf.Clamp01(tiles / 6f) * 0.28f`.
- **Sustained Silhouettes (`PlayerSquashStretch`)**:
  - `VelocityTier.Drift` (`1–2` tiles): `+0.07` length, `-0.035` thickness (`0.07s` ease out).
  - `VelocityTier.Cruise` (`3–4` tiles): `+0.13` length, `-0.06` thickness (`0.08s` ease out).
  - `VelocityTier.KineticRam` (`5+` tiles): sustained `+0.19` length, `-0.08` thickness + initial `+0.24 / -0.10` snap pulse (`0.12s`), **plus** a `0.06f` zoom punch (`5.5f -> 5.44f`) and `SoundConfig.kineticLockIn` chime.
  - Pivot Compensation (`32 PPU`, bottom-center `(0.5, 0)` sprite pivot at `baseLocalPosition.y = -0.5`): `compensatedY = baseLocalPosition.y * (targetScale.y / Mathf.Max(0.01f, baseScale.y))` so sprite center remains locked to `(0, 0)` during all Y-axis deformations.
  - Note on `maxDeformation`: keep at `0.30` (tight pixel fidelity) or raise in `GameScene.unity` Inspector to `0.38` for punchier Tier-3 slams.

Create `Assets/Scripts/Feedback/RunwayCadenceFeedback.cs`:

```csharp
using UnityEngine;

/// <summary>
/// Emits rhythmic tile-crossing cadence audio and KineticRam lock-in feedback.
/// Reads SoundManager.Instance.PlaySFX overload (Pitch-safe pooled playback).
/// </summary>
[DisallowMultipleComponent]
[RequireComponent(typeof(PlayerMovement))]
public class RunwayCadenceFeedback : MonoBehaviour
{
    [Header("Cadence Audio")]
    [SerializeField] private float baseTickPitch = 0.94f;
    [SerializeField] private float pitchStepPerTile = 0.045f;
    [SerializeField, Min(1)] private int maxPitchStepTiles = 7;

    [Header("Kinetic Ram Lock-In")]
    [SerializeField] private float kineticZoomDip = 0.06f;
    [SerializeField] private float kineticZoomHoldSeconds = 0.09f;

    private PlayerMovement movement;
    private bool kineticNotifiedThisDash;

    private void Awake()
    {
        movement = GetComponent<PlayerMovement>();
    }

    private void OnEnable()
    {
        if (movement == null) return;
        movement.OnMoveStarted += HandleMoveStarted;
        movement.OnMoveStopped += HandleMoveStopped;
        movement.OnTileCrossed += HandleTileCrossed;
        movement.OnVelocityTierChanged += HandleTierChanged;
    }

    private void OnDisable()
    {
        if (movement == null) return;
        movement.OnMoveStarted -= HandleMoveStarted;
        movement.OnMoveStopped -= HandleMoveStopped;
        movement.OnTileCrossed -= HandleTileCrossed;
        movement.OnVelocityTierChanged -= HandleTierChanged;
    }

    private void HandleMoveStarted(Vector2 _)
    {
        kineticNotifiedThisDash = false;
    }

    private void HandleMoveStopped()
    {
        kineticNotifiedThisDash = false;
        CinemachineCameraZoom2D.Instance?.SetNormalOrthographicSize();
    }

    private void HandleTileCrossed(int tilesTraveled)
    {
        if (tilesTraveled <= 0 || SoundManager.Instance == null || SoundManager.Instance.Config == null)
            return;

        int step = Mathf.Min(tilesTraveled - 1, maxPitchStepTiles);
        float pitch = baseTickPitch + step * pitchStepPerTile;
        float volumeMult = 0.65f + Mathf.Clamp01(tilesTraveled / 6f) * 0.35f;

        SoundManager.Instance.PlaySFX(
            SoundManager.Instance.Config.tileTick,
            pitchOverride: pitch,
            volumeMultiplier: volumeMult,
            bypassInterval: true);
    }

    private void HandleTierChanged(VelocityTier tier)
    {
        if (tier != VelocityTier.KineticRam || kineticNotifiedThisDash)
            return;

        kineticNotifiedThisDash = true;

        if (SoundManager.Instance != null && SoundManager.Instance.Config != null)
            SoundManager.Instance.PlaySFX(SoundManager.Instance.Config.kineticLockIn);

        if (CinemachineCameraZoom2D.Instance != null && kineticZoomDip > 0f)
        {
            float baseSize = CinemachineCameraZoom2D.Instance.NormalOrthographicSize;
            CinemachineCameraZoom2D.Instance.PulseZoom(
                Mathf.Max(2f, baseSize - kineticZoomDip),
                kineticZoomHoldSeconds);
        }
    }
}
```

Upgrade `PlayerSquashStretch.cs` (additions/replacements to `Assets/Scripts/Feedback/PlayerSquashStretch.cs`):

```csharp
// Add fields to PlayerSquashStretch:
private Vector3 restScale;
private bool brakeSquashTriggeredThisDash;

// Update Awake():
restScale = baseScale;

// Update OnEnable() / OnDisable():
// Subscribe/unsubscribe movement.OnRedirected += HandleRedirected;
// and MazeTile.OnAnyPlayerInteracted += HandleTileInteracted;
// Reset restScale = baseScale and brakeSquashTriggeredThisDash = false inside OnDisable().

private void HandleMoveStarted(Vector2 direction)
{
    lastDirection = direction;
    restScale = baseScale;
    brakeSquashTriggeredThisDash = false;
    Stretch(direction);
}

private void HandleMoveStopped()
{
    restScale = baseScale;
    if (brakeSquashTriggeredThisDash)
    {
        brakeSquashTriggeredThisDash = false;
        return; // Preserve the soft anchor settle started by HandleTileInteracted(InteractionKind.Brake).
    }

    if (movement != null && !movement.WasLastStopWallImpact)
    {
        // Freeze, TeleportTo, and HaltAt should never play wall-slam squash.
        ResetScale();
        return;
    }

    Squash(lastDirection, pressIntoWall: true);
}

private void HandleTierChanged(VelocityTier tier)
{
    switch (tier)
    {
        case VelocityTier.None:
            restScale = baseScale;
            if (movement != null && !movement.IsMoving)
                return;
            ApplySustained(restScale, 0.08f);
            break;

        case VelocityTier.Drift:
            restScale = Deform(lastDirection, +stretchAmount * 0.55f, -stretchAmount * 0.25f);
            ApplySustained(restScale, 0.07f);
            break;

        case VelocityTier.Cruise:
            restScale = Deform(lastDirection, +stretchAmount, -stretchAmount * 0.45f);
            ApplySustained(restScale, 0.08f);
            break;

        case VelocityTier.KineticRam:
            restScale = Deform(lastDirection, +stretchAmount * 1.45f, -stretchAmount * 0.55f);
            Vector3 snapPeak = Deform(lastDirection, +stretchAmount * 1.85f, -stretchAmount * 0.65f);
            Play(snapPeak, stretchDuration * 0.7f);
            break;
    }
}

private void HandleRedirected(Vector2 newDirection)
{
    if (movement != null && movement.IsPhasing) return;
    if (newDirection == Vector2.zero) return;

    lastDirection = newDirection;
    Vector3 pulse = Deform(newDirection, +stretchAmount * 1.35f, -stretchAmount * 0.5f);
    Play(pulse, stretchDuration * 0.7f);
}

private void HandlePhasingChanged(bool phasing)
{
    if (phasing)
    {
        if (spriteRenderer != null && hasBaseColor)
        {
            if (!isPhasingVisual)
                baseSpriteColor = spriteRenderer.color;
            isPhasingVisual = true;
            spriteRenderer.color = phaseSpriteTint;
        }

        Vector3 launchStretch = Deform(lastDirection, +stretchAmount * 1.5f, -stretchAmount * 0.55f);
        Play(launchStretch, stretchDuration * 0.8f);
        return;
    }

    isPhasingVisual = false;
    RestoreSpriteColor();
    Vector3 landSquash = Deform(lastDirection, -stretchAmount * 0.9f, +stretchAmount * 0.6f);
    Play(landSquash, squashDuration * 0.65f);
}

private void HandleTileInteracted(MazeTile tile, InteractionContext context)
{
    if (context.Kind != InteractionKind.Brake) return;

    brakeSquashTriggeredThisDash = true;
    restScale = baseScale;
    Vector3 anchorSettle = Deform(lastDirection, -stretchAmount * 1.15f, +stretchAmount * 0.8f);
    Play(anchorSettle, squashDuration * 0.8f);
}

private Vector3 ComputePivotCompensatedPosition(Vector3 targetScale, Vector2 pressDirection)
{
    float safeBaseY = Mathf.Max(0.01f, baseScale.y);
    float compensatedY = baseLocalPosition.y * (targetScale.y / safeBaseY);
    Vector3 anchorPos = new Vector3(baseLocalPosition.x, compensatedY, baseLocalPosition.z);

    if (pressDirection != Vector2.zero)
        anchorPos += (Vector3)(pressDirection.normalized * (wallPressPx / 32f));

    return anchorPos;
}

private void ApplySustained(Vector3 targetScale, float duration)
{
    if (visualTransform == null) return;

    Vector3 targetPos = ComputePivotCompensatedPosition(targetScale, Vector2.zero);
    visualTransform.DOKill();
    KillActive();
    activeSequence = DOTween.Sequence()
        .Append(visualTransform.DOScale(targetScale, duration).SetEase(Ease.OutQuad))
        .Join(visualTransform.DOLocalMove(targetPos, duration).SetEase(Ease.OutQuad))
        .SetUpdate(true)
        .SetLink(gameObject);
}

public void ResetScale()
{
    if (visualTransform == null) return;
    Vector3 targetPos = ComputePivotCompensatedPosition(restScale, Vector2.zero);
    visualTransform.DOKill();
    KillActive();
    activeSequence = DOTween.Sequence()
        .Append(visualTransform.DOScale(restScale, squashDuration * 0.5f).SetEase(returnEase))
        .Join(visualTransform.DOLocalMove(targetPos, squashDuration * 0.5f).SetEase(returnEase))
        .SetUpdate(true)
        .SetLink(gameObject);
}

private void Play(Vector3 deformed, float duration, Vector2 pressDirection = default)
{
    if (visualTransform == null) return;

    Vector3 pressed = ComputePivotCompensatedPosition(deformed, pressDirection);
    Vector3 settlePos = ComputePivotCompensatedPosition(restScale, Vector2.zero);

    visualTransform.DOKill();
    KillActive();
    activeSequence = DOTween.Sequence()
        .Append(visualTransform.DOScale(deformed, duration * 0.4f).SetEase(Ease.OutQuad))
        .Join(visualTransform.DOLocalMove(pressed, duration * 0.4f).SetEase(Ease.OutQuad))
        .Append(visualTransform.DOScale(restScale, duration * 0.6f).SetEase(returnEase))
        .Join(visualTransform.DOLocalMove(settlePos, duration * 0.6f).SetEase(returnEase))
        .SetUpdate(true)
        .SetLink(gameObject);
}
```

### Pillar 2 — Heavy Terminal Impacts, Unscaled Camera Shakes & Anchor Weight

**Player Psychology & Rhythmic Feel**  
High-velocity impacts must stop *weightily* without sluggish camera stalls, while magnetic/friction anchors (`GravityBlock` / `BrakeTile`) feel distinctly cushioned rather than harsh brick walls — and `Freeze()`, `TeleportTo()`, and `HaltAt()` stops remain clean and quiet.

**Numerical Specifications**
- **Camera Zoom Pipeline Unlock**:
  - `CinemachineCamera`: disable `CinemachinePixelPerfect` (`m_Enabled = false`).
  - `Main Camera`: disable `PixelPerfectCamera` (`m_Enabled = false`) so `OnBeginCameraRendering` does not force `m_Camera.orthographicSize = m_Internal.orthoSize` when `!m_CinemachineCompatibilityMode`. *(Trade-off: disabling both swaps strict integer pixel-snapping for sub-pixel smooth camera zoom (`5.5f -> 5.38f..5.45f`). If strict pixel-perfect rendering on `Main Camera` must remain enabled, replace all `CinemachineCameraZoom2D` micro-zooms with radial burst/impulse trauma pulses instead of orthographic lens changes.)*
  - `CinemachineCameraZoom2D`: `zoomSpeed = 8f` (`Update()` runs on `Time.unscaledDeltaTime`), returning smoothly to `normalOrthographicSize` (`5.5f`).
- **Wall Stop Tiers (`PlayerImpactFeedback` Inspector in `GameScene.unity`)**:
  - `Drift` (`WasLastStopWallImpact == true`): `tier1Shake = 0.06`, `tier1HitStop = 0f`.
  - `Cruise` (`WasLastStopWallImpact == true`): `tier2Shake = 0.15`, `tier2HitStop = 0.033f`, zoom `normal - 0.05f` for `0.06s`.
  - `KineticRam` (`WasLastStopWallImpact == true`): `tier3Shake = 0.28`, `tier3HitStop = 0.083f`, zoom `normal - 0.12f` for `0.09s`.
  - `redirectShake = 0.06` (guarded by `!movement.IsPhasing`).
  - `CrackedBlock.OnAnyBroken`: additive trauma shake `0.18`, zoom `normal - 0.14f` for `0.10s`, hit-stop `0.065s`.
- **Anchors (`InteractionKind.Brake` only)**:
  - `GravityBlock.prefab`: retain `InteractionEffectPlayer.defaultCameraShake = 0.04` (no duplicate code shake); trigger subtle zoom pull `normal - 0.04f` for `0.06s` and play `SoundConfig.gravityAnchor`.
  - `Brake.prefab`: configure `InteractionEffectPlayer.defaultCameraShake = 0.035` + friction smoke VFX on the prefab; play `SoundConfig.brakeSkid`.

```csharp
using System.Collections;
using Unity.Cinemachine;
using UnityEngine;
using UnityEngine.Serialization;

public class CinemachineCameraZoom2D : MonoBehaviour
{
    public static CinemachineCameraZoom2D Instance { get; private set; }

    [FormerlySerializedAs("NORMAL_ORTHOGRAPHIC_SIZE")]
    [SerializeField] private float normalOrthographicSize = 5.5f;
    [SerializeField] private CinemachineCamera cinemachineCamera;
    [SerializeField] private float targetOrthographicSize = 5.5f;
    [SerializeField] private float zoomSpeed = 8f;

    public float NormalOrthographicSize => normalOrthographicSize;

    private Coroutine zoomPulseRoutine;

    private void Awake()
    {
        if (Instance != null && Instance != this)
        {
            Destroy(this);
            return;
        }

        Instance = this;
        if (cinemachineCamera == null)
            cinemachineCamera = GetComponent<CinemachineCamera>();
    }

    private void OnDestroy()
    {
        if (Instance == this)
            Instance = null;
    }

    private void Update()
    {
        if (cinemachineCamera == null)
            return;

        cinemachineCamera.Lens.OrthographicSize = Mathf.Lerp(
            cinemachineCamera.Lens.OrthographicSize,
            targetOrthographicSize,
            Time.unscaledDeltaTime * zoomSpeed);
    }

    public void SetTargetOrthographicSize(float targetOrthographicSize)
    {
        this.targetOrthographicSize = targetOrthographicSize;
    }

    public void SetNormalOrthographicSize()
    {
        if (zoomPulseRoutine != null)
        {
            StopCoroutine(zoomPulseRoutine);
            zoomPulseRoutine = null;
        }
        SetTargetOrthographicSize(normalOrthographicSize);
    }

    public void PulseZoom(float targetSize, float holdUnscaledSeconds = 0.08f)
    {
        if (!isActiveAndEnabled) return;
        if (zoomPulseRoutine != null)
            StopCoroutine(zoomPulseRoutine);
        zoomPulseRoutine = StartCoroutine(PulseZoomRoutine(targetSize, holdUnscaledSeconds));
    }

    private IEnumerator PulseZoomRoutine(float targetSize, float holdUnscaledSeconds)
    {
        targetOrthographicSize = targetSize;
        if (holdUnscaledSeconds > 0f)
            yield return new WaitForSecondsRealtime(holdUnscaledSeconds);
        targetOrthographicSize = normalOrthographicSize;
        zoomPulseRoutine = null;
    }
}
```

```csharp
            ? block.LastBreakWorldPosition
            : block.transform.position;

        if (blockBreakAnimationPrefab != null)
            PrefabAnimationSpawner.SpawnEffect(blockBreakAnimationPrefab, pos, Quaternion.identity);

    {
        if (!hitStopEnabled || Time.timeScale < 0.5f) return;

        if (hitStopRoutine != null)
        {
            StopCoroutine(hitStopRoutine);
            RestoreHitStopState();
        }
        hitStopRoutine = StartCoroutine(HitStopRoutine(duration));
    }

    private IEnumerator HitStopRoutine(float duration)
    {
        preHitStopTimeScale = Time.timeScale;
        cachedBrain = CinemachineBrain.ActiveBrainCount > 0 ? CinemachineBrain.GetActiveBrain(0) : null;
        if (cachedBrain != null)
        {
            prevBrainIgnoreTimeScale = cachedBrain.IgnoreTimeScale;
            cachedBrain.IgnoreTimeScale = true;
            hasOverriddenBrain = true;
        }

        IsHitStopActive = true;
        Time.timeScale = 0f;

        try
        {
            yield return new WaitForSecondsRealtime(duration);
        }
        finally
        {
            RestoreHitStopState();
            hitStopRoutine = null;
        }
    }

    private void RestoreHitStopState()
    {
        if (IsHitStopActive)
            Time.timeScale = preHitStopTimeScale > 0f ? preHitStopTimeScale : 1f;

        if (hasOverriddenBrain && cachedBrain != null)
            cachedBrain.IgnoreTimeScale = prevBrainIgnoreTimeScale;

        hasOverriddenBrain = false;
        cachedBrain = null;
        IsHitStopActive = false;
    }
}
```

```csharp
[SerializeField, Min(4)] private int maxPoolSize = 24;

// Add PlaySFX pitch-override overload in SoundManager:
public void PlaySFX(SoundEntry entry, float pitchOverride, float volumeMultiplier = 1f, bool bypassInterval = false)
{
    if (!entry.HasClips)
        return;

    AudioClip clip = entry.GetRandomClip();
    if (clip == null)
        return;

    float now = Time.unscaledTime;
    if (!bypassInterval)
    {
        float minInterval = Mathf.Max(0.01f, entry.minInterval);
        if (lastPlayedTimeByClip.TryGetValue(clip, out float lastTime) && now - lastTime < minInterval)
            return;
    }

    lastPlayedTimeByClip[clip] = now;
    float resolvedVolume = Mathf.Clamp01(entry.GetResolvedVolume() * Mathf.Clamp01(volumeMultiplier));
    PlayResolvedClip(clip, resolvedVolume, Mathf.Clamp(pitchOverride, 0.25f, 3f));
}

// Harden GetAvailableAudioSource() and PlayResolvedClip(...) so active playing clips never get pitch-warped:
private AudioSource GetAvailableAudioSource()
{
    for (int i = sfxPool.Count - 1; i >= 0; i--)
    {
        AudioSource source = sfxPool[i];
        if (source == null)
        {
            sfxPool.RemoveAt(i);
            continue;
        }
        if (!source.isPlaying)
            return source;
    }

    if (pooledAudioSourcePrefab != null && sfxPool.Count < maxPoolSize)
        return SpawnPooledAudioSource();

    if (sfxPool.Count > 0)
    {
        // Steal oldest voice cleanly only when pool hits maxPoolSize.
        AudioSource stolen = sfxPool[0];
        sfxPool.RemoveAt(0);
        sfxPool.Add(stolen);
        stolen.Stop();
        return stolen;
    }

    return fallbackAudioSource;
}

private void PlayResolvedClip(AudioClip clip, float volume, float pitch)
{
    if (clip == null || this == null || !gameObject.activeInHierarchy)
        return;

    AudioSource source = GetAvailableAudioSource();
    if (source == null)
        return;

    if (source.isPlaying)
    {
        // Emergency fallback only (when pooledAudioSourcePrefab is null): never overwrite an in-flight pitch.
        source.PlayOneShot(clip, volume);
        return;
    }

    source.pitch = pitch;
    source.clip = clip;
    source.volume = volume;
    source.Play();
}
```

Create `Assets/Scripts/Feedback/CloseCallFeedback.cs`:

```csharp
using UnityEngine;

/// <summary>
/// Pure visual/audio/zoom reaction to CloseCallDetector.OnCloseCallTriggered.
/// Never alters Time.timeScale so corridor routing velocity remains uninterrupted.
/// </summary>
[DisallowMultipleComponent]
public class CloseCallFeedback : MonoBehaviour
{
    [SerializeField] private GameObject closeCallArcPrefab;
    [SerializeField, Min(0f)] private float zoomDip = 0.08f;
    [SerializeField, Min(0f)] private float zoomHoldSeconds = 0.07f;

    private void OnEnable()
    {
        CloseCallDetector.OnCloseCallTriggered += HandleCloseCall;
    }

    private void OnDisable()
    {
        CloseCallDetector.OnCloseCallTriggered -= HandleCloseCall;
    }

    private void HandleCloseCall(Vector3 threatWorldPos)
    {
        Vector3 delta = threatWorldPos - transform.position;
        Vector3 midPoint = Vector3.Lerp(transform.position, threatWorldPos, 0.5f);
        Quaternion rot = delta.sqrMagnitude > 0.0001f
            ? Quaternion.LookRotation(delta.normalized)
            : Quaternion.identity;

        if (closeCallArcPrefab != null)
            VfxSpawner.Spawn(closeCallArcPrefab, midPoint, rot);

        if (CinemachineCameraZoom2D.Instance != null && zoomDip > 0f)
        {
            float baseSize = CinemachineCameraZoom2D.Instance.NormalOrthographicSize;
            CinemachineCameraZoom2D.Instance.PulseZoom(Mathf.Max(2f, baseSize - zoomDip), zoomHoldSeconds);
        }

        if (SoundManager.Instance != null && SoundManager.Instance.Config != null)
            SoundManager.Instance.PlaySFX(SoundManager.Instance.Config.closeCallArc);
    }
}
```
