# Thiết Kế Hệ Thống Game Feel Đặc Trưng — **Gravita (Puzzle 2D)**

## 1. Triết Lý & Danh Tính Cảm Giác (Identity & Feel Architecture)

**Gravita** là puzzle trượt quán tính tốc độ cao (`moveSpeed = 30 u/s` trên hệ lưới `PPU = 32`), nơi người chơi không nhích từng bước mà **"bắn mình như viên bi trọng lực"** qua hành lang hẹp, tích lũy động năng theo tầng vận tốc (`VelocityTier`: `Drift` 1–2 ô, `Cruise` 3–4 ô, `KineticRam` 5+ ô), bẻ góc qua `DeflectionWedge`, vượt `VectorLauncher` (`Phase Launch`), và né `Hazard` trong gang tấc.

Danh tính Game Feel mục tiêu: **"Sắc bén – Đàn hồi – Có trọng lượng nhưng không cản trở tư duy"** (*Tactile Kinetic Pinball-Dash*). Mọi lớp phản hồi (Haptic, Audio, Squash/Stretch, Trail, Camera Zoom, Post-Processing, VFX) đều tuân thủ tuyệt đối 4 nguyên tắc kiến trúc:
1. **Tách biệt Layer 4 (Feedback) khỏi Layer 2 (Grid Physics)**: `PlayerMovement` giữ nguyên 100% tính tất định của thuật toán lưới và các mốc dừng; mọi tín hiệu phản hồi chỉ đọc sự kiện và trạng thái tức thời.
2. **An toàn với Time-Scale & Object Pool**: Mọi animation/tween phản hồi va chạm, pop-up và VFX đều dùng `Time.unscaledDeltaTime` / `.SetUpdate(true)`. Thành phần dùng `ObjectPoolManager` (vốn chỉ `SetActive(false)` qua `ReturnAllActiveObjects()` chứ không `Destroy`) bắt buộc lưu handle tween, hủy trong `OnDisable()`, gắn `.SetLink(gameObject, LinkBehaviour.KillOnDisable)` và kiểm tra `activeInHierarchy` trước khi trả về pool.
3. **Không khởi tạo cấu trúc UI/VFX bằng code thuần**: Mọi VFX, ghost và pop-up đều là **Prefab dựng sẵn** gắn script tối giản, prewarm qua `ObjectPoolManager` — tuyệt đối không dùng `new GameObject(...)` hay `AddComponent<...>()` lúc runtime.
4. **Hòa âm giữa Cinemachine và Zoom động**: Ở `GameScene.unity`, `Main Camera` đang gắn `PixelPerfectCamera` (`m_AssetsPPU: 32`, `320x180`) và `CinemachineCamera` gắn `CinemachinePixelPerfect` (`m_Enabled: 1`, `Lens.OrthographicSize: 5.5`). Vì `CinemachinePixelPerfect` khóa `orthoSize` tại `Stage.Body` mỗi frame, và nếu chỉ tắt riêng nó thì `PixelPerfectCamera.OnBeginCameraRendering` vẫn ép `m_Camera.orthographicSize = m_Internal.orthoSize` (`2.8125` ở 1080p khi `m_CinemachineCompatibilityMode == false`), cần **tắt đồng thời cả `CinemachinePixelPerfect` và `PixelPerfectCamera`**, đồng thời bật **`CinemachineBrain.IgnoreTimeScale = true`** để zoom và camera shake hoạt động mượt ngay trong cửa sổ Hit-Stop.

### Trụ Cột 3: Bẻ Góc Bi-a & Nạp Trước Hướng Rẽ (Bank-Shot Cornering & Input Pre-Buffering)
*Làm nổi bật khoảnh khắc nảy `DeflectionWedge` (`OnRedirected`) và phản hồi tức thì khi người chơi xếp hàng nút rẽ (`Turn Buffer`).*

1. **Bank-Shot Snap (`OnRedirected`)**:
   - Trong `PlayerMovement.Redirect` và `StartPhaseLaunch`, `OnRedirected` và `OnMoveStarted` bắn đồng bộ liên tiếp trên cùng một frame; đồng thời `lastMoveDirection` bị ghi đè thành hướng mới *trước* khi `OnRedirected` được gọi.
   - Do đó:
     - `PlayerImpactFeedback` tự lưu `trackedMoveDir` từ `OnMoveStarted` để tính chính xác phân giác góc nảy `(-trackedMoveDir + newDir).normalized` khi xoay `redirectBurstPrefab` + bắn `redirectShake = 0.08f`.
     - `PlayerSquashStretch` bật `suppressNextMoveStartedStretch = true` trong `HandleRedirected` khi `!playerMovement.IsPhasing`, để `HandleMoveStarted` kế tiếp **không** xóa mất chuỗi **Bank-Shot Snap (`95 ms`)**: nén nhanh `35 ms` (`0.86 / 1.14`) rồi bung `60 ms` theo trục `newDir`.
     - `PlayerLineTrail` kích hoạt **Width/Emission Surge (`140 ms`)** cho hiệu ứng "quất roi" qua góc vuông.
2. **Turn Buffer Indicator (`PlayerTurnBufferIndicator`)**:
   - `PlayerMovement` phát sự kiện `OnPendingDirectionChanged` từ helper `SetPendingDirection(...)` (thay 8 phép gán rời rạc biến `pendingDirection`) — không cần `Update()` poll liên tục.
   - Hiện `chevronTransform` (child SpriteRenderer cấu hình sẵn trên Player Prefab) xoay về hướng `pendingDir` với alpha `0.85f`.
   - Tính tích có hướng có dấu trên cả 4 hướng di chuyển chính (`crossZ = currentDir.x * pendingDir.y - currentDir.y * pendingDir.x`): nghiêng `visualTransform` về bên chuẩn bị rẽ `±5°` (`+5°` khi `crossZ > 0`, `-5°` khi `crossZ < 0`, `0°` khi quay đầu 180° hoặc đứng yên).
   - **An toàn Tween giữa các script**: `PlayerTurnBufferIndicator` giữ riêng `Tween activeTiltTween` và `Tween activeChevronTween` — tuyệt đối không gọi `visualTransform.DOKill()`, tránh ngắt nhầm `activeScaleSequence` của `PlayerSquashStretch` trên cùng `Sprite` transform.

### Trụ Cột 4: Cảnh Báo Sát Nút & Thế Giới Tương Tác (Close-Call Overdrive & Reactive World)
1. **Close-Call Overdrive (`CloseCallDetector` + `CloseCallOverdriveFeedback` + `CloseCallPopup`)**:
   - `CloseCallDetector` phát `OnAnyCloseCall(Vector3 worldPos)` tại điểm thưởng `bonusCoins` & `cameraPulseForce`.
   - `CloseCallOverdriveFeedback` sinh `CloseCallPopup` từ `ObjectPoolManager`, đánh camera zoom punch `-0.20f` (`120 ms`), phát `SoundConfig.closeCallChime` và `GameHaptics.Play(HapticEvent.PadRedirect)` (`SoftImpact`).
   - `CloseCallPopup` dùng `Sequence activeSequence` với `.Insert(0f, ...)` để chuyển động nổi lên `DOMoveY` + `DOFade` chạy trọn `[0.00s, 0.50s]` song song với nhịp Scale Pop `[0.00s → 0.07s → 0.15s]`, và `.SetLink(gameObject, LinkBehaviour.KillOnDisable)`.
2. **Thế Giới Tương Tác (`InteractionEffectPlayer` & World Events)**:
   - Theo cấu hình Prefab hiện tại: `VectorLauncher` (`defaultCameraShake: 0.1` + VFX sẵn), `GravityBlock` (`defaultCameraShake: 0.04` + VFX sẵn), `Brittle` & `FailingTile` (đã có `effectPrefabs` vỡ gạch). Các Prefab đang để trống (`Brake`, `Exit`, `Hazard`, `Wedge` với `effectPrefabs: []`, `defaultCameraShake: 0`) sẽ được gán VFX pooled + `defaultCameraShake` tương ứng trực tiếp trên Prefab Inspector.
   - Các sự kiện tĩnh `CrackedBlock.OnAnyBroken`, `CircuitSwitch.OnAnyToggled`, `EnergyGate.OnAnyGateOpenStateChanged`, `BrittleFloor.OnAnyTileBroken`, `FailingTile.OnAnyTileCollapsed` kết nối trực tiếp vào `EntityAudio` và micro-shake.

### Trụ Cột 5: Hệ Thống Âm Thanh Phân Tầng & Rung Xúc Giác Không Xung Đột (Layered Audio & Safe Haptics)
1. **Haptics (`GameplayHapticsFeedback` & `HapticsTests`)**:
   - Cả 7 giá trị trong `HapticEvent` (`UISelect`, `WallImpact`, `GravityAnchor`, `PadRedirect`, `LaunchStart`, `SwitchToggle`, `Death`) đều đã được gắn kết sẵn trong `GameplayHapticsFeedback`, `LevelFlowController` và UI Panels, kèm bộ kiểm thử tự động `HapticsTests`.
   - Vì vậy giữ nguyên toàn bộ ánh xạ hiện có của `GameplayHapticsFeedback` (tuyệt đối không gắn thêm `OnMoveStarted → LaunchStart` hay `OnRedirected → PadRedirect` gây rung đúp và sai test). Chỉ bổ sung 2 điểm chưa trùng lặp: `CrackedBlock.OnAnyBroken → HapticEvent.LaunchStart` (Medium) và `CloseCallOverdriveFeedback → HapticEvent.PadRedirect` (Soft).
2. **Audio (`SoundConfig` + `SoundManager` + `EntityAudio`)**:
   - Bổ sung 11 `SoundEntry` mới vào `SoundConfig` (`turnBufferTick`, `tierUpCruise`, `tierUpKinetic`, `phaseLaunchWhoosh`, `brakeStop`, `closeCallChime`, `switchToggle`, `energyGateChange`, `brittleCrack`, `shieldAbsorb`, `echoGhostPing`) và overload `SoundManager.PlaySFX(SoundEntry, float pitchMultiplier, float volumeScale)`.
   - Sửa lỗi tồn đọng trong `EntityAudio.HandlePlayerWallImpact`: chuyển từ `playerMovement.LastImpactTier` sang `playerMovement.CurrentTier` để âm va chạm tầng `Cruise` / `KineticRam` không bị trễ 1 nhịp dừng.
   - Chống đè âm khi bẻ góc (`Redirect`): trong `EntityAudio.HandleRedirected`, khi `!playerMovement.IsPhasing`, đặt `suppressNextMoveStartSfx = true` để `OnMoveStarted` đồng bộ tiếp theo không phát đè `moveStart` lên `wedgeRedirect`.

### 3.1. `PlayerMovement.cs` (Cập nhật nhỏ theo sự kiện Turn Buffer — giữ nguyên 100% logic vật lý)
Thêm sự kiện và helper bọc 8 điểm gán `pendingDirection` hiện hữu trong `PlayerMovement.cs`:

```csharp
public event Action<Vector2> OnPendingDirectionChanged;

private void SetPendingDirection(Vector2? nextDirection)
{
    Vector2 previous = pendingDirection ?? Vector2.zero;
    pendingDirection = nextDirection;
    Vector2 current = pendingDirection ?? Vector2.zero;

    if (previous != current)
    {
        OnPendingDirectionChanged?.Invoke(current);
    }
}
```
*Thay 8 phép gán trực tiếp `pendingDirection = ...` trong `PlayerMovement.cs` bằng `SetPendingDirection(...)`. Không thay đổi bất kỳ công thức trượt lưới, `CurrentTier`, `IsPhasing` hay thứ tự dừng.*

### 3.2. `CinemachineCameraShake2D.cs` (Mở rộng rung có hướng không phá vỡ API cũ)
Thêm phương thức `ShakeDirectional` bên cạnh phương thức rung vô hướng hiện dùng cho `InteractionEffectPlayer` và `CloseCallDetector`:

```csharp
using Unity.Cinemachine;
using UnityEngine;

// Bổ sung vào CinemachineCameraShake2D.cs
public void ShakeDirectional(Vector2 direction, float force)
{
    if (force <= 0f || impulseSource == null) return;

    if (direction.sqrMagnitude < 0.0001f)
    {
        impulseSource.GenerateImpulse(force);
        return;
    }

    Vector2 dir = direction.normalized;
    impulseSource.GenerateImpulseWithVelocity(new Vector3(dir.x, dir.y, 0f) * force);
}
```

### 3.3. `CinemachineCameraZoom2D.cs` (Unscaled Time + Single Owner + PixelPerfect Guard)
```csharp
using Unity.Cinemachine;
using UnityEngine;

namespace EchoesOfGravity.Feedback
{
    public class CinemachineCameraZoom2D : MonoBehaviour
    {
        [Header("References")]
        [SerializeField] private CinemachineCamera cinemachineCamera;
        [Tooltip("Gắn cả CinemachinePixelPerfect (trên CinemachineCamera) và PixelPerfectCamera (trên Main Camera) để đảm bảo tắt đồng thời khi dùng zoom động.")]
        [SerializeField] private Behaviour[] pixelPerfectBehavioursToDisable;

        [Header("Orthographic Lens Baseline (khớp GameScene = 5.5)")]
        [SerializeField] private float normalOrthographicSize = 5.50f;
        [SerializeField] private float minOrthographicSize = 4.60f;
        [SerializeField] private float maxOrthographicSize = 7.10f;
        [SerializeField] private float defaultSmoothTime = 0.22f;

        private float persistentOffset;
        private float persistentSmoothTime;
        private float punchOffset;
        private float punchHoldTimer;
        private float punchRecoverSmoothTime = 0.16f;

        private float currentOrtho;
        private float zoomVelocity;

        private void Awake()
        {
            DisablePixelPerfectConflicts();

            if (cinemachineCamera != null)
            {
                cinemachineCamera.Lens.OrthographicSize = normalOrthographicSize;
            }

            currentOrtho = normalOrthographicSize;
            persistentSmoothTime = defaultSmoothTime;
        }

        private void OnEnable()
        {
            DisablePixelPerfectConflicts();
            ResetZoomImmediate();
        }

        private void DisablePixelPerfectConflicts()
        {
            if (pixelPerfectBehavioursToDisable == null) return;
            for (int i = 0; i < pixelPerfectBehavioursToDisable.Length; i++)
            {
                if (pixelPerfectBehavioursToDisable[i] != null && pixelPerfectBehavioursToDisable[i].enabled)
                {
                    pixelPerfectBehavioursToDisable[i].enabled = false;
                }
            }
        }

        public void SetTargetOffset(float offset, float smoothTime = -1f)
        {
            persistentOffset = offset;
            persistentSmoothTime = smoothTime > 0f ? smoothTime : defaultSmoothTime;
        }

        public void TriggerPunch(float deltaOrtho, float holdUnscaledDuration, float recoverSmoothTime = 0.16f)
        {
            if (Mathf.Abs(deltaOrtho) >= Mathf.Abs(punchOffset) || punchHoldTimer <= 0f)
            {
                punchOffset = deltaOrtho;
                punchHoldTimer = Mathf.Max(0f, holdUnscaledDuration);
                punchRecoverSmoothTime = Mathf.Max(0.05f, recoverSmoothTime);
            }
        }

        public void ResetZoomImmediate()
        {
            persistentOffset = 0f;
            punchOffset = 0f;
            punchHoldTimer = 0f;
            zoomVelocity = 0f;
            currentOrtho = normalOrthographicSize;

            if (cinemachineCamera != null)
            {
                cinemachineCamera.Lens.OrthographicSize = currentOrtho;
            }
        }

        private void LateUpdate()
        {
            if (cinemachineCamera == null) return;

            float dt = Time.unscaledDeltaTime;
            if (dt <= 0f) return;

            if (punchHoldTimer > 0f)
            {
                punchHoldTimer -= dt;
            }
            else if (!Mathf.Approximately(punchOffset, 0f))
            {
                float decayT = 1f - Mathf.Exp(-dt / punchRecoverSmoothTime);
                punchOffset = Mathf.Lerp(punchOffset, 0f, decayT);
                if (Mathf.Abs(punchOffset) < 0.002f) punchOffset = 0f;
            }

            float target = Mathf.Clamp(
                normalOrthographicSize + persistentOffset + punchOffset,
                minOrthographicSize,
                maxOrthographicSize
            );

            float activeSmooth = punchHoldTimer > 0f ? 0.03f : persistentSmoothTime;
            currentOrtho = Mathf.SmoothDamp(currentOrtho, target, ref zoomVelocity, activeSmooth, Mathf.Infinity, dt);
            cinemachineCamera.Lens.OrthographicSize = currentOrtho;
        }
    }
}
```

### 3.4. `SpriteHitFlash.cs` (Dùng `HitFlashSprite.shader` Asset & `MaterialPropertyBlock`)
```csharp
using System.Collections;
using UnityEngine;

namespace EchoesOfGravity.Feedback
{
    public class SpriteHitFlash : MonoBehaviour
    {
        private static readonly int FlashColorId = Shader.PropertyToID("_FlashColor");

        [SerializeField] private SpriteRenderer targetRenderer;
        [Tooltip("Material dùng shader 'Echoes/VFX/Solid White Sprite' (Assets/Shaders/Hit/HitFlashSprite.shader)")]
        [SerializeField] private Material hitFlashMaterial;

        private Material originalSharedMaterial;
        private MaterialPropertyBlock propertyBlock;
        private Coroutine activeCoroutine;
        private bool isFlashing;

        private void Awake()
        {
            propertyBlock = new MaterialPropertyBlock();
            if (targetRenderer != null)
            {
                originalSharedMaterial = targetRenderer.sharedMaterial;
            }
        }

        private void OnDisable()
        {
            RestoreImmediate();
        }

        public void Play(Color hdrFlashColor, float durationUnscaled)
        {
            if (targetRenderer == null || hitFlashMaterial == null || durationUnscaled <= 0f) return;

            if (!isFlashing)
            {
                originalSharedMaterial = targetRenderer.sharedMaterial;
            }

            if (activeCoroutine != null)
            {
                StopCoroutine(activeCoroutine);
            }

            activeCoroutine = StartCoroutine(FlashRoutine(hdrFlashColor, durationUnscaled));
        }

        private IEnumerator FlashRoutine(Color hdrFlashColor, float durationUnscaled)
        {
            isFlashing = true;
            targetRenderer.sharedMaterial = hitFlashMaterial;
            targetRenderer.GetPropertyBlock(propertyBlock);
            propertyBlock.SetColor(FlashColorId, hdrFlashColor);
            targetRenderer.SetPropertyBlock(propertyBlock);

            yield return new WaitForSecondsRealtime(durationUnscaled);

            RestoreImmediate();
        }

        public void RestoreImmediate()
        {
            if (activeCoroutine != null)
            {
                StopCoroutine(activeCoroutine);
                activeCoroutine = null;
            }

            if (isFlashing && targetRenderer != null)
            {
                if (originalSharedMaterial != null)
                {
                    targetRenderer.sharedMaterial = originalSharedMaterial;
                }
                targetRenderer.SetPropertyBlock(null);
            }

            isFlashing = false;
```

```csharp
namespace EchoesOfGravity.Feedback
{
    public class PlayerSquashStretch : MonoBehaviour
    {
        private const float PixelsPerUnit = 32f;

        [Header("References")]
        [SerializeField] private PlayerMovement playerMovement;
        [SerializeField] private Transform visualTransform;
        [SerializeField] private SpriteRenderer spriteRenderer;

        [Header("Limits & Stretch (OnMoveStarted)")]
        [SerializeField] private float maxDeformation = 0.30f;
        [SerializeField] private float launchStretchAlong = 0.18f;
        [SerializeField] private float launchCompressPerp = 0.09f;
        [SerializeField] private float launchInDuration = 0.045f;
        [SerializeField] private float launchOutDuration = 0.070f;

        [Header("Per-Tier Wall Squash (OnWallImpact)")]

        [SerializeField] private float cruiseCompress = 0.22f;
        [SerializeField] private float cruisePressPixels = 4f;
        [SerializeField] private float cruiseDuration = 0.150f;

        [SerializeField] private float kineticCompress = 0.30f;

        [SerializeField] private float kineticDuration = 0.190f;

        private Sequence activeScaleSequence;

        private bool suppressNextMoveStartedStretch;
        private bool initializedBase;

        private void Awake()
        {
            CacheBaseTransform();
        }

        private void OnEnable()
        {
            CacheBaseTransform();

            if (playerMovement == null) return;
            playerMovement.OnMoveStarted += HandleMoveStarted;
            playerMovement.OnMoveStopped += HandleMoveStopped;
            playerMovement.OnRedirected += HandleRedirected;

        private void OnDisable()
        {
            if (playerMovement != null)
            {
                playerMovement.OnMoveStarted -= HandleMoveStarted;
                playerMovement.OnMoveStopped -= HandleMoveStopped;
                playerMovement.OnRedirected -= HandleRedirected;
                playerMovement.OnWallImpact -= HandleWallImpact;
                playerMovement.OnVelocityTierChanged -= HandleTierChanged;
                playerMovement.OnPhasingChanged -= HandlePhasingChanged;

            suppressNextMoveStartedStretch = false;
            KillAndResetVisual();

        private void CacheBaseTransform()

            if (initializedBase || visualTransform == null) return;
            baseLocalPos = visualTransform.localPosition;
            baseLocalScale = visualTransform.localScale;
            initializedBase = true;

        private Vector3 GetVisualCenterLocalOffset()
        {
            if (spriteRenderer == null || spriteRenderer.sprite == null)
            {
                return Vector3.zero;
            }

            Vector3 spriteCenter = spriteRenderer.sprite.bounds.center;
            return new Vector3(
                spriteCenter.x * baseLocalScale.x,
                spriteCenter.y * baseLocalScale.y,
                0f
            );
        }

        private Vector3 AxisScale(Vector2 dir, float alongOffset, float perpOffset)
        {
            float clampedAlong = Mathf.Clamp(alongOffset, -maxDeformation, maxDeformation);
            float clampedPerp = Mathf.Clamp(perpOffset, -maxDeformation, maxDeformation);
            bool horizontal = Mathf.Abs(dir.x) >= Mathf.Abs(dir.y);

            float sx = 1f + (horizontal ? clampedAlong : clampedPerp);
            float sy = 1f + (horizontal ? clampedPerp : clampedAlong);
            return new Vector3(baseLocalScale.x * sx, baseLocalScale.y * sy, baseLocalScale.z);
        }

        private void HandleMoveStarted(Vector2 dir)
        {
            if (suppressNextMoveStartedStretch)
            {
                suppressNextMoveStartedStretch = false;
                return;
            }

            if (playerMovement != null && playerMovement.IsPhasing)
            {
                PlayStretch(dir, 0.24f, -0.12f, launchInDuration, launchOutDuration);
                return;
            }

            PlayStretch(dir, launchStretchAlong, -launchCompressPerp, launchInDuration, launchOutDuration);
        }

        private void HandleMoveStopped()
        {
            suppressNextMoveStartedStretch = false;
            if (playerMovement == null) return;

            if (!playerMovement.WasLastStopWallImpact && !playerMovement.InputLocked)

                PlaySquash(playerMovement.LastMoveDirection, brakeCompress, 0f, brakeDuration);
            }
        }

        private void HandleRedirected(Vector2 newDir)
        {
            if (playerMovement != null && !playerMovement.IsPhasing)
            {

                suppressNextMoveStartedStretch = true;
            }

            PlayBankShotSnap(newDir);
        }

        private void HandleWallImpact(Vector2 impactNormal)
        {
            if (playerMovement == null) return;

            // Đọc CurrentTier ngay tại thời điểm OnWallImpact (trước khi StopMoving gán LastImpactTier)
            VelocityTier tier = playerMovement.CurrentTier;

            switch (tier)

                    break;
                case VelocityTier.Cruise:
                    PlaySquash(hitAxis, cruiseCompress, cruisePressPixels, cruiseDuration);
                    break;
                default:
                    PlaySquash(hitAxis, driftCompress, driftPressPixels, driftDuration);
                    break;
            }

        private void HandleTierChanged(VelocityTier tier)
        {
            if (tier == VelocityTier.Drift || visualTransform == null || playerMovement == null) return;
            if (activeScaleSequence != null && activeScaleSequence.IsActive()) return;

            Vector3 pulse = AxisScale(playerMovement.CurrentDirection, 0.05f, 0.05f);
            activeScaleSequence = DOTween.Sequence()
                .Append(visualTransform.DOScale(pulse, 0.035f).SetEase(Ease.OutQuad))
                .Append(visualTransform.DOScale(baseLocalScale, 0.045f).SetEase(Ease.OutQuad))
                .SetUpdate(true)
                .SetLink(gameObject, LinkBehaviour.KillOnDisable);
        }

        private void HandlePhasingChanged(bool isPhasing)
        {
            if (!isPhasing || playerMovement == null) return;
            PlayStretch(playerMovement.CurrentDirection, 0.24f, -0.12f, 0.04f, 0.09f);
        }

        private void PlayStretch(Vector2 dir, float alongOffset, float perpOffset, float inTime, float outTime)
        {
            if (visualTransform == null) return;
            KillScaleSequenceOnly();

            Vector3 targetScale = AxisScale(dir, alongOffset, perpOffset);
            Vector3 pivotAdjustedPos = baseLocalPos;

            activeScaleSequence = DOTween.Sequence()
                .Append(visualTransform.DOScale(targetScale, inTime).SetEase(Ease.OutQuad))
                .Join(visualTransform.DOLocalMove(pivotAdjustedPos, inTime).SetEase(Ease.OutQuad))
                .Append(visualTransform.DOScale(baseLocalScale, outTime).SetEase(Ease.OutBack))
                .SetUpdate(true)
                .SetLink(gameObject, LinkBehaviour.KillOnDisable);
        }

        private void PlaySquash(Vector2 intoSurfaceDir, float compressAmount, float pressPixels, float totalDuration)
        {
            if (visualTransform == null) return;
            KillScaleSequenceOnly();

            float clampedCompress = Mathf.Clamp(compressAmount, 0f, maxDeformation);
            Vector3 squashedScale = AxisScale(intoSurfaceDir, -clampedCompress, clampedCompress);

            float pressWorld = pressPixels / PixelsPerUnit;
            Vector3 pressOffset = new Vector3(intoSurfaceDir.x, intoSurfaceDir.y, 0f).normalized * pressWorld;
            // Giữ tâm sprite ổn định theo cosmetic sprite hiện hành khi nén
            Vector3 centerCompensation = GetVisualCenterLocalOffset() * (clampedCompress * 0.15f);
            Vector3 pressedPos = baseLocalPos + pressOffset + centerCompensation;

            float inTime = totalDuration * 0.24f;
            float holdTime = totalDuration * 0.24f;
            float outTime = totalDuration * 0.52f;

            activeScaleSequence = DOTween.Sequence()
                .Append(visualTransform.DOScale(squashedScale, inTime).SetEase(Ease.OutQuad))
                .Join(visualTransform.DOLocalMove(pressedPos, inTime).SetEase(Ease.OutQuad))
                .AppendInterval(holdTime)
                .Append(visualTransform.DOScale(baseLocalScale, outTime).SetEase(Ease.OutBack))
                .Join(visualTransform.DOLocalMove(baseLocalPos, outTime).SetEase(Ease.OutQuad))
                .SetUpdate(true)
                .SetLink(gameObject, LinkBehaviour.KillOnDisable);
        }

        private void PlayBankShotSnap(Vector2 newDir)
        {
            if (visualTransform == null) return;
            KillScaleSequenceOnly();

            Vector3 pinchScale = AxisScale(newDir, -0.14f, 0.14f);
            Vector3 snapScale = AxisScale(newDir, 0.14f, -0.07f);

            float t1 = bankSnapDuration * 0.37f; // ~35 ms
            float t2 = bankSnapDuration * 0.33f; // ~31 ms
            float t3 = bankSnapDuration * 0.30f; // ~29 ms

            activeScaleSequence = DOTween.Sequence()
                .Append(visualTransform.DOScale(pinchScale, t1).SetEase(Ease.OutQuad))
                .Join(visualTransform.DOLocalMove(baseLocalPos, t1).SetEase(Ease.OutQuad))
                .Append(visualTransform.DOScale(snapScale, t2).SetEase(Ease.OutQuad))
                .Append(visualTransform.DOScale(baseLocalScale, t3).SetEase(Ease.OutQuad))
                .SetUpdate(true)
                .SetLink(gameObject, LinkBehaviour.KillOnDisable);
        }

        private void KillScaleSequenceOnly()
        {
            if (activeScaleSequence != null)
            {
                activeScaleSequence.Kill(false);
                activeScaleSequence = null;
            }
        }

        private void KillAndResetVisual()
        {
            KillScaleSequenceOnly();
            if (visualTransform != null && initializedBase)
            {
                visualTransform.localScale = baseLocalScale;
                visualTransform.localPosition = baseLocalPos;
            }
        }
    }
```

```csharp
private float currentLengthMultiplier = 1f;
private float redirectSurgeTimer;

// 1. Trong OnEnable / OnDisable đăng ký thêm playerMovement.OnRedirected += HandleRedirected;
private void HandleRedirected(Vector2 _)

    redirectSurgeTimer = redirectSurgeDuration;

// 2. Trong hàm cập nhật mỗi frame (thay đoạn float dt = Time.deltaTime; if (dt <= 0f) return;):
private float ResolveTrailDeltaTime()
{
    bool inHitStop = Time.timeScale <= 0f && impactFeedback != null && impactFeedback.IsInHitStop;
    return inHitStop ? Time.unscaledDeltaTime : Time.deltaTime;
}

private void UpdateTierTrailParameters(float dt)
{
    if (redirectSurgeTimer > 0f)
    {
        redirectSurgeTimer = Mathf.Max(0f, redirectSurgeTimer - dt);
    }

    float targetW = 1f;
    float targetL = 1f;

    if (playerMovement != null)
    {
        if (playerMovement.IsPhasing)
        {
            targetW = phaseWidthScale;
            targetL = phaseLengthScale;
        }
        else
        {
            switch (playerMovement.CurrentTier)
            {
                case VelocityTier.Cruise:
                    targetW = cruiseWidthScale;
                    targetL = cruiseLengthScale;
                    break;
                case VelocityTier.KineticRam:
                    targetW = kineticWidthScale;
                    targetL = kineticLengthScale;
                    break;
            }
        }
    }

    float blend = 1f - Mathf.Exp(-14f * dt);
    currentWidthMultiplier = Mathf.Lerp(currentWidthMultiplier, targetW, blend);
    currentLengthMultiplier = Mathf.Lerp(currentLengthMultiplier, targetL, blend);

    float surgeRatio = redirectSurgeDuration > 0f ? redirectSurgeTimer / redirectSurgeDuration : 0f;
    float effectiveWidth = trailWidth * (currentWidthMultiplier + redirectWidthBoost * surgeRatio);
    float speedFactor = Mathf.Clamp01(currentMoveSpeed / maxReferenceSpeed);
    float effectiveMaxLength = maxTrailLength * currentLengthMultiplier * Mathf.Lerp(0.45f, 1f, speedFactor);

    lineRenderer.widthMultiplier = effectiveWidth;
    // Dùng effectiveMaxLength thay thế maxTrailLength cố định khi cắt đuôi dải điểm
}
```

*Ghi chú*: Trong `LateUpdate()` / `Update()` của `PlayerLineTrail.cs`, luôn gọi `float dt = ResolveTrailDeltaTime(); if (dt <= 0f) return;` trước phần kiểm tra `!isActivelyMoving`, và dùng `effectiveMaxLength` khi tỉa điểm dư ở cuối vệt.

```csharp
                playerMovement.OnPhasingChanged += HandlePhasingChanged;
                playerMovement.OnMoveStopped += HandleMoveStopped;
                playerMovement.OnWallImpact += HandleWallImpact;
            }

            LevelFlowController.OnAnyHazardContacted += HandleHazardContacted;
            RefreshTargets();
        }

        private void OnDisable()
        {
            if (playerMovement != null)
            {
                playerMovement.OnVelocityTierChanged -= HandleTierChanged;
                playerMovement.OnPhasingChanged -= HandlePhasingChanged;
                playerMovement.OnMoveStopped -= HandleMoveStopped;
                playerMovement.OnWallImpact -= HandleWallImpact;
            }

            LevelFlowController.OnAnyHazardContacted -= HandleHazardContacted;
            RestoreVolumeBaseline();
        }

        private void CacheVolumeOverrides()
        {
            if (cachedVolumeBaseline || globalVolume == null || globalVolume.sharedProfile == null) return;

            VolumeProfile profile = globalVolume.profile; // Chỉ lấy runtime instance của scene Volume 1 lần
            if (profile.TryGet(out chromaticOverride)) baseChromatic = chromaticOverride.intensity.value;
            if (profile.TryGet(out bloomOverride)) baseBloom = bloomOverride.intensity.value;
            if (profile.TryGet(out vignetteOverride)) baseVignette = vignetteOverride.intensity.value;
            cachedVolumeBaseline = true;
        }

        private void RestoreVolumeBaseline()
        {
            if (!cachedVolumeBaseline) return;

            if (chromaticOverride != null) chromaticOverride.intensity.value = baseChromatic;
            if (bloomOverride != null) bloomOverride.intensity.value = baseBloom;
            if (vignetteOverride != null) vignetteOverride.intensity.value = baseVignette;
        }

        private void HandleTierChanged(VelocityTier _) => RefreshTargets();
        private void HandlePhasingChanged(bool _) => RefreshTargets();
        private void HandleMoveStopped() => RefreshTargets();

        private void HandleWallImpact(Vector2 _)
        {
            if (cameraZoom == null || playerMovement == null) return;

            // Đọc CurrentTier tại OnWallImpact thay vì LastImpactTier
            switch (playerMovement.CurrentTier)
            {
                case VelocityTier.KineticRam:
                    cameraZoom.TriggerPunch(kineticImpactPunch, 0.065f, 0.20f);
                    break;
                case VelocityTier.Cruise:
                    cameraZoom.TriggerPunch(cruiseImpactPunch, 0.045f, 0.16f);
                    break;
                default:
                    cameraZoom.TriggerPunch(driftImpactPunch, 0.030f, 0.14f);
                    break;
            }

            RefreshTargets();
        }

        private void HandleHazardContacted(LevelFlowController flow, Hazard hazard)
        {
            if (cameraZoom == null) return;
            bool shield = PowerUpController.Instance != null && PowerUpController.Instance.IsShieldActive;
            cameraZoom.TriggerPunch(shield ? -0.20f : hazardImpactPunch, shield ? 0.03f : 0.06f, 0.20f);
        }

        private void RefreshTargets()
        {
            if (playerMovement == null)
            {
                SetAllTargets(driftZoomOffset, 0f, 0f, 0f);
                return;
            }

            if (playerMovement.IsPhasing)
            {
                SetAllTargets(phaseZoomOffset, phaseChromatic, phaseBloom, phaseVignette);
                return;
            }

            if (!playerMovement.IsMoving)
            {
                SetAllTargets(driftZoomOffset, 0f, 0f, 0f);
                return;
            }

            switch (playerMovement.CurrentTier)
            {
                case VelocityTier.KineticRam:
                    SetAllTargets(kineticZoomOffset, kineticChromatic, kineticBloom, kineticVignette);
                    break;
                case VelocityTier.Cruise:
                    SetAllTargets(cruiseZoomOffset, cruiseChromatic, cruiseBloom, cruiseVignette);
                    break;
                default:
                    SetAllTargets(driftZoomOffset, 0f, 0f, 0f);
                    break;
            }
        }

        private void SetAllTargets(float zoomOff, float chrom, float bloom, float vig)
        {
            cameraZoom?.SetTargetOffset(zoomOff, zoomSmoothTime);
            targetChromaticAdd = chrom;
            targetBloomAdd = bloom;
            targetVignetteAdd = vig;
        }

        private void Update()
        {
            if (!cachedVolumeBaseline) return;

            float dt = Time.unscaledDeltaTime;
            if (dt <= 0f) return;

            float blend = 1f - Mathf.Exp(-volumeLerpSpeed * dt);
            currentChromaticAdd = Mathf.Lerp(currentChromaticAdd, targetChromaticAdd, blend);
            currentBloomAdd = Mathf.Lerp(currentBloomAdd, targetBloomAdd, blend);
            currentVignetteAdd = Mathf.Lerp(currentVignetteAdd, targetVignetteAdd, blend);

            if (chromaticOverride != null) chromaticOverride.intensity.value = Mathf.Clamp01(baseChromatic + currentChromaticAdd);
            if (bloomOverride != null) bloomOverride.intensity.value = Mathf.Max(0f, baseBloom + currentBloomAdd);
            if (vignetteOverride != null) vignetteOverride.intensity.value = Mathf.Clamp01(baseVignette + currentVignetteAdd);
        }
    }
```

```csharp
            if (visualTransform != null) visualTransform.localRotation = Quaternion.identity;
            SetChevronAlphaImmediate(0f);

        {
            RefreshIndicatorAndTilt(cachedPending);
        }

        private void HandleMoveStopped()
        {
            cachedPending = Vector2.zero;
            RefreshIndicatorAndTilt(Vector2.zero);
        }

        private void HandlePendingDirectionChanged(Vector2 pendingDir)
        {
            cachedPending = pendingDir;
            RefreshIndicatorAndTilt(pendingDir);
        }

        private void RefreshIndicatorAndTilt(Vector2 pendingDir)
        {
            bool hasPending = pendingDir.sqrMagnitude > 0.01f && playerMovement != null && playerMovement.IsMoving;

            if (chevronTransform != null && hasPending)
            {
                Vector2 norm = pendingDir.normalized;
                float angleDeg = Mathf.Atan2(norm.y, norm.x) * Mathf.Rad2Deg;
                chevronTransform.localPosition = new Vector3(norm.x * chevronRadius, norm.y * chevronRadius, 0f);
                chevronTransform.localRotation = Quaternion.Euler(0f, 0f, angleDeg);
            }

            if (chevronRenderer != null)
            {
                activeChevronAlphaTween?.Kill(false);
                activeChevronAlphaTween = chevronRenderer
                    .DOFade(hasPending ? chevronActiveAlpha : 0f, chevronFadeDuration)
                    .SetUpdate(true)
                    .SetLink(gameObject, LinkBehaviour.KillOnDisable);
            }

            float targetTiltZ = 0f;
            if (hasPending)
            {
                Vector2 travel = playerMovement.CurrentDirection;
                if (travel.sqrMagnitude > 0.01f)
                {
                    Vector2 tNorm = travel.normalized;
                    Vector2 pNorm = pendingDir.normalized;
                    // Tích có hướng 2D cho cả 4 hướng đi (Lên/Xuống/Trái/Phải)
                    float crossZ = tNorm.x * pNorm.y - tNorm.y * pNorm.x;
                    if (Mathf.Abs(crossZ) > 0.1f)
                    {
                        targetTiltZ = Mathf.Sign(crossZ) * tiltAngleDegrees;
                    }
                }
            }

            if (visualTransform != null)
            {
                activeTiltTween?.Kill(false);
                activeTiltTween = visualTransform
                    .DOLocalRotate(new Vector3(0f, 0f, targetTiltZ), tiltTweenDuration)
                    .SetEase(Ease.OutQuad)
                    .SetUpdate(true)
                    .SetLink(gameObject, LinkBehaviour.KillOnDisable);
            }
        }

        private void SetChevronAlphaImmediate(float alpha)
        {
            if (chevronRenderer == null) return;
            Color c = chevronRenderer.color;
            c.a = alpha;
            chevronRenderer.color = c;
        }

        private void KillTweens()
        {
            activeTiltTween?.Kill(false);
            activeTiltTween = null;
            activeChevronAlphaTween?.Kill(false);
            activeChevronAlphaTween = null;
        }
    }
```

```csharp
public void PlaySFX(SoundEntry entry, float pitchMultiplier, float volumeScale = 1f)
{
    if (!sfxEnabled || entry == null || !entry.HasClips || sfxSource == null) return;

    float now = Time.unscaledTime;
    if (entry.minInterval > 0f && lastPlayTimes.TryGetValue(entry, out float lastTime))

    }

    AudioClip clip = entry.GetRandomClip();

    lastPlayTimes[entry] = now;
    sfxSource.pitch = Mathf.Clamp(entry.GetResolvedPitch() * pitchMultiplier, 0.5f, 2.0f);
```

### 3.13. Chuẩn Hóa `PowerUpController.cs` Sang Prefab + `ObjectPoolManager`
Thay thế hoàn toàn việc tạo `new GameObject(...)` và `AddComponent<SpriteRenderer>()` trong `SpawnEchoVisual`, `SpawnRadialPulseVFX`, `SpawnDirectionalScanOrBurstVFX` bằng 3 script Prefab dùng `ObjectPoolManager` và `LinkBehaviour.KillOnDisable`:

```csharp
using DG.Tweening;
using UnityEngine;

namespace EchoesOfGravity.Feedback
{
    public class EchoMarkerVisual : MonoBehaviour
    {
        [SerializeField] private SpriteRenderer spriteRenderer;
        private Sequence activeSequence;

        private void OnDisable() => KillSequence();

        public void Activate(Color baseColor, float pulseScale = 1.12f, float pulseCycle = 0.65f)
        {
            KillSequence();
            transform.localScale = Vector3.one;
            if (spriteRenderer != null) spriteRenderer.color = baseColor;

            activeSequence = DOTween.Sequence()
                .Append(transform.DOScale(pulseScale, pulseCycle * 0.5f).SetEase(Ease.InOutSine))
                .Append(transform.DOScale(1.0f, pulseCycle * 0.5f).SetEase(Ease.InOutSine))
                .SetLoops(-1)
                .SetUpdate(true)
                .SetLink(gameObject, LinkBehaviour.KillOnDisable);
        }

        public void DespawnToPool()
        {
            KillSequence();
            if (gameObject.activeInHierarchy)
            {
                ObjectPoolManager.ReturnObjectToPool(gameObject);
            }
        }

        private void KillSequence()
        {
            if (activeSequence != null)
            {
                activeSequence.Kill(false);
                activeSequence = null;
            }
        }
    }

    public class PooledRadialPulseVfx : MonoBehaviour
    {
        [SerializeField] private SpriteRenderer spriteRenderer;
        private Sequence activeSequence;

        private void OnDisable() => KillSequence();

        public void Play(Color color, float startScale, float endScale, float duration)
        {

            if (spriteRenderer != null)
            {
                spriteRenderer.color = color;
            }

            activeSequence = DOTween.Sequence()
                .Append(transform.DOScale(endScale, duration).SetEase(Ease.OutCubic));

            if (spriteRenderer != null)
            {
                activeSequence.Insert(0f, spriteRenderer.DOFade(0f, duration).SetEase(Ease.OutQuad));
            }

            activeSequence
                .SetUpdate(true)
                .SetLink(gameObject, LinkBehaviour.KillOnDisable)
                .OnComplete(() =>
                {
                    activeSequence = null;
                    if (gameObject.activeInHierarchy)
                    {
                        ObjectPoolManager.ReturnObjectToPool(gameObject);
                    }
                });
        }

        private void KillSequence()
        {
            if (activeSequence != null)
            {
                activeSequence.Kill(false);
                activeSequence = null;
            }
        }
    }

    public class PooledScanCellVfx : MonoBehaviour
    {
        [SerializeField] private SpriteRenderer spriteRenderer;
        private Sequence activeSequence;

        private void OnDisable() => KillSequence();

        public void Play(Color color, float delay, float duration, float peakScale = 1.05f)
        {
            KillSequence();

            if (spriteRenderer != null)
            {
                Color c = color;
                c.a = 0f;
                spriteRenderer.color = c;
            }

            activeSequence = DOTween.Sequence();
            if (delay > 0f)
            {
                activeSequence.AppendInterval(delay);
            }

            activeSequence.Append(transform.DOScale(peakScale, duration * 0.35f).SetEase(Ease.OutQuad));
            if (spriteRenderer != null)
            {
                activeSequence.Join(spriteRenderer.DOFade(color.a, duration * 0.30f).SetEase(Ease.OutQuad));
            }

            activeSequence.Append(transform.DOScale(0.95f, duration * 0.65f).SetEase(Ease.InQuad));
            if (spriteRenderer != null)
            {
                activeSequence.Join(spriteRenderer.DOFade(0f, duration * 0.65f).SetEase(Ease.InQuad));
            }

            activeSequence
                .SetUpdate(true)
                .SetLink(gameObject, LinkBehaviour.KillOnDisable)
                .OnComplete(() =>
                {
                    activeSequence = null;
                    if (gameObject.activeInHierarchy)
                    {
                        ObjectPoolManager.ReturnObjectToPool(gameObject);
                    }
                });
        }

        private void KillSequence()
        {
            if (activeSequence != null)
            {
                activeSequence.Kill(false);
                activeSequence = null;
```
