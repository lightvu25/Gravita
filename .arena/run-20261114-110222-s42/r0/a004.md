# Gravita (`Puzzle 2D`) — Game Feel Signature Upgrade Blueprint

> **Engine Target:** Unity `6000.4.0f1` URP (2D Top-Down, `32 PPU`, `cellSize = 1`, `PixelPerfectCamera` `320x180`, `PlayerMovement.moveSpeed = 30` u/s = `33.3 ms/tile`).  
> **Architecture Standard:** Event-driven SRP across `Assets/Scripts/Feedback/`, `Assets/Scripts/Audio/`, and `Assets/Scripts/UI/`. Zero procedural `new GameObject()` / runtime `AddComponent<T>()`; all DOTween sequences use `.DOKill()`, `.SetUpdate(true)`, and `.SetLink(gameObject)`. `FixedUpdate` grid physics stay untouched.

---

## Scope & Assumptions

1. **Velocity Tier Threshold Reconciliation:** `Assets/Scripts/Gameplay/VelocityTier.cs` (`VelocityTierUtil.FromTiles`) currently classifies `1–2` tiles as `Drift`, `3–4` as `Cruise`, and `5+` as `KineticRam` (matching `docs/gdd.md`), whereas higher-level design notes sometimes describe `1–3 / 4–7 / 8+`. All timing and curves below anchor to `VelocityTierUtil.FromTiles` and `moveSpeed = 30` (`Drift = 33–67 ms`, `Cruise = 100–133 ms`, `KineticRam = 167+ ms`), using `VelocityTier`-keyed Inspector fields so rebalancing thresholds never breaks feedback.
2. **Audio & VFX Content Baseline:** `Assets/Data/Sound/SoundConfig.asset` currently ships with empty `clips: []` arrays, `AudioSystems.prefab` has `pooledAudioSourcePrefab` unassigned, and `InteractionEffectPlayer` lists on `Brake`, `Exit`, `Hazard`, and `Wedge` prefabs are empty. Code hooks below fail safely (null-guarded) until clips/prefabs are populated.

## 1. Core Game Feel Diagnosis: Why Gravita Currently Feels Flat

Gravita already contains event hooks (`PlayerMovement`, `CloseCallDetector`, `InteractionEffectPlayer`, `GameHaptics`, `CinemachineCameraZoom2D`), yet feels muted in hands-on play for six concrete engineering reasons:

1. **Animation Timescales Ignore `33.3 ms/tile` Speed:** In `GameScene.unity`, `PlayerSquashStretch` sets `stretchDuration = 0.18s` (`72 ms` out, `108 ms` back) and `squashDuration = 0.22s` (`88 ms` compress, `132 ms` recover). At `30 u/s`, a `Drift` slide (`33–67 ms`) hits the wall *before* launch stretch peaks, while a long `KineticRam` (`250+ ms`) finishes stretching and snaps back to `baseScale` mid-corridor instead of sustaining aerodynamic tension. Furthermore, `HandleMoveStopped()` applies full `impactHeightPx = 16 / movingHeightPx = 28` squash identically to a 1-tile tap and a 10-tile Ram, ignores `OnRedirected` completely, and only calls `KillActive()` instead of `visualTransform.DOKill()`.
2. **Bottom-Center Sprite Pivot (`localPosition = (0, -0.5, 0)`) Inverts Wall Squashes:** `Player/Sprite` scales from a `(0.5, 0)` bottom-center pivot. During `Vector2.up` (`maxDeformation = 0.3`), compressing `sy` to `0.70` drops the top face by `0.30` units (`9.6 px`) while `wallPressPx = 4` (`0.125` u) shifts upward—leaving Subject G-0 **`0.175` units (`5.6 px`) pulled away from the north wall**. Conversely, `Vector2.down` shifts `localPosition.y` down by `-0.125` u, sinking the sprite **`4 px` inside the south collider**. Horizontal runs shrink toward the feet instead of the center of mass.
3. **Broken Event Ordering Silences Tier Payoff & Snaps Trails Early:**
   - **Stale Impact Audio Tier:** `PlayerMovement.AdvanceSlideStep` invokes `OnWallImpact?.Invoke(stopHit.normal)` *before* `StopMoving(wallImpact: true)` writes `LastImpactTier = CurrentTier`. `EntityAudio.HandlePlayerWallImpact` reads `playerMovement.LastImpactTier`, playing the *previous* dash's tier (or `None` -> `Drift` fallback on dash #1).
   - **Premature Trail Color Reset:** `PlayerMovement.StopMoving()` triggers `ResetDashTracking()` (`OnVelocityTierChanged(VelocityTier.None)`) *before* `OnMoveStopped`. `PlayerLineTrail.HandleTierChanged` refreshes visuals immediately, snapping the retracting ribbon back to cyan `Drift` (`headColor`) on impact instead of holding `Cruise` gold or `KineticRam` magenta while retracting. `PlayerLineTrail` also clamps `smoothedMoveSpeed` at `28f`, below `moveSpeed = 30` and `PhaseLaunch = 48`.
   - **Hit-Stop `Time.timeScale` Leak Risk:** `PlayerImpactFeedback.OnDisable()` stops `hitStopRoutine` without restoring `preHitStopTimeScale`. A death, restart, or disable during `tier3HitStop` (`0.083s`) leaves `Time.timeScale = 0f`.
4. **Dead Momentum & Near-Miss Channels:** `PlayerMovement.OnTileCrossed` has **0 subscribers**, making tile-by-tile velocity buildup silent. `CloseCallDetector.OnCloseCallTriggered` has **0 external subscribers**.
5. **Pixel-Perfect Camera Conflict + Non-Directional Impacts:** `GameScene.unity` zeroes micro-impacts (`tier1Shake = 0`, `redirectShake = 0`). `CinemachineCameraShake2D` only calls scalar `GenerateImpulse(float)` (omnidirectional jitter rather than wall-normal recoil). `PlayerImpactFeedback.HandleWallImpact` uses 3D `Quaternion.LookRotation((Vector3)normal)` on 2D XY normals, twisting 2D bursts out of the XY plane. Meanwhile, `CinemachineCameraZoom2D` (`normalOrthographicSize = 5.5`) has **0 callers**—and shares `CinemachineCamera` with `CinemachinePixelPerfect`, which snaps/overwrites `Lens.OrthographicSize` every frame under `PixelPerfectCamera` (`320x180`, `32 PPU`, `GridSnapping: 1`).
6. **Invisible Input Queueing & Unwired Haptics/Props:** `bufferTurnsUntilStop = true` gives zero mid-dash visual/audio confirmation when a corner turn is pre-armed, `GameplayHapticsFeedback` ignores 4 of 7 `HapticEvent` values (`PadRedirect`, `LaunchStart`, `SwitchToggle`, `Death`), and `BrittleFloor`, `CircuitSwitch`, `EnergyGate`, and `LevelExit` produce flat state swaps.

1. **Center-Compensated Math in `Assets/Scripts/Feedback/PlayerSquashStretch.cs`:**
   ```csharp
   // Add [SerializeField] Vector2 pivotToCenter = new Vector2(0f, 0.5f);
   // Add [SerializeField] float sustainedGlideTransition = 0.045f;
   // Add [SerializeField] float redirectDuration = 0.035f;
   // Subscribe in OnEnable: movement.OnRedirected += HandleRedirected;
   // Track activeHitStopHold (injected/read from PlayerImpactFeedback or computed from tier)

   private Vector3 ComputeCompensatedLocalPosition(Vector3 targetScale, Vector2 pressDirection, float pressPx)
   {
       Vector3 pivotCompensation = new Vector3(
           pivotToCenter.x * (baseScale.x - targetScale.x),
           pivotToCenter.y * (baseScale.y - targetScale.y),
           0f);

       if (pressDirection == Vector2.zero)
           return baseLocalPosition + pivotCompensation;

       Vector2 dir = pressDirection.normalized;
       bool horizontal = Mathf.Abs(dir.x) >= Mathf.Abs(dir.y);
       float scaleAlong = horizontal ? targetScale.x / baseScale.x : targetScale.y / baseScale.y;
       float pressWorld = (pressPx / 32f);
       Vector3 wallPin = (Vector3)(dir * (0.5f * (1f - scaleAlong) + pressWorld));
       return baseLocalPosition + pivotCompensation + wallPin;
   }

   private void ApplySustainedStretch(Vector2 dir, float along, float across, float inDuration)
   {
       Vector3 targetScale = Deform(dir, along, across);
       Vector3 targetPos = ComputeCompensatedLocalPosition(targetScale, Vector2.zero, 0f);
       KillActive();
       visualTransform.DOKill();
       activeSequence = DOTween.Sequence()
           .Append(visualTransform.DOScale(targetScale, inDuration).SetEase(Ease.OutQuad))
           .Join(visualTransform.DOLocalMove(targetPos, inDuration).SetEase(Ease.OutQuad))
           .SetUpdate(true)
           .SetLink(gameObject);
   }
   ```

### Pillar 2: Directional Impact & Stop Polarity (Wall-Slam vs. Mag-Brake Contrast)

### Pillar 4: Pre-Armed Turn Telegraph & Blocked-Move Tactility (`BufferTurnsUntilStop`)

#### Why It Makes Gravita Uniquely Addictive
Because a single corridor dash finishes in `33–167 ms`, top Gravita play relies on `bufferTurnsUntilStop = true`—flicking your *next* turn while already mid-flight. Right now, queued turns are silent and invisible, making players second-guess whether an early swipe registered or whether an idle bump against a wall ignored their finger. Making buffered and blocked inputs *physically audible and visible* creates crisp arcade lock-on confidence without changing a single frame of deterministic physics.

#### Exact Numbers, Curves & Parameters
| Feature | Exact Value | Behavior |
|---|---|---|
| **Queued Arrow Orbit Offset** | `0.48` units (`15.4 px`) along `pendingDir` | Orbits tightly outside Subject G-0's `0.9x0.9` collider without overlapping wall tiles cleanly |
| **Arm Pop-In Tween** | `scale 0.55 -> 1.15` in `0.045s` (`OutBack`) -> `1.0` in `0.035s` | Snappy spring pop the exact frame `HasPendingDirection` changes |
| **Queued Idle Pulse** | `alpha 0.72 <-> 1.0` over `0.12s` loop (`Yoyo`) | Subtle shimmer while armed mid-dash |
| **Execution Flash** | `scale -> 1.30`, `alpha -> 0` over `0.055s` (`OutQuad`) | Fires when `OnMoveStarted` consumes the queued direction |
| **Audio & Haptic Lock** | `tickQueued`: pitch `1.35f`, vol `0.28f` + `HapticEvent.UISelect` | Feels like cocking a magnetic relay |
| **Idle Blocked Thud** | `visualTransform.DOLocalPunch` `dir * 0.094f` (`3 px`), `0.09s`, `vibrato = 1` + `wallBlocked` (`pitch 0.85f`, `vol 0.35f`) | Immediate rejection rattle when swiping straight into an adjacent wall from rest |

## 3. Technical Guardrails & Failure-Mode Prevention

| Risk / Failure Mode | Concrete Guardrail in This Blueprint |
|---|---|
| **Procedural Hierarchy Debt** | Strictly prohibited. All arrows, echoes, popups, and volumes are serialized child transforms, pre-placed scene objects, or pooled prefabs via `ObjectPoolManager` / `PrefabAnimationSpawner` / `ParticleSpawner`. *(Note: avoid imitating the existing runtime `new GameObject` pattern found in `PowerUpController.cs`.)* |
| **`Time.timeScale` Deadlock on Death/Reset** | `PlayerImpactFeedback.OnDisable()` **must** restore `Time.timeScale = preHitStopTimeScale` whenever `isHitStopActive` is true; `CloseCallFeedback` never writes `Time.timeScale`; Pause UI remains authoritative whenever `Time.timeScale < 0.5f`. |
| **`CinemachinePixelPerfect` Fighting Zoom** | `CinemachineCameraZoom2D` detects active `CinemachinePixelPerfect` and defers ortho changes rather than fighting frame-by-frame pixel lock; `OverdriveVolume` delivers zoom-like kinetic tunnel focus cleanly at `32 PPU`. |
| **Single `AudioSource` Pitch Bleed** | Rapid `OnTileCrossed` ticks (`33.3 ms` spacing) and simultaneous arpeggios require assigning `pooledAudioSourcePrefab` in `AudioSystems.prefab` so `SoundManager.PlaySFXWithPitch` isolates pitch per voice. |
| **DOTween Leak & Transform Drift** | Every tween calls `.DOKill()` on its target (`visualTransform`, `arrowRoot`, `overdriveVolume`, `musicSource`), binds `.SetUpdate(true)` (survives hit-stop), and binds `.SetLink(gameObject)`. `OnDisable` resets scales/positions and returns pooled echoes. |
