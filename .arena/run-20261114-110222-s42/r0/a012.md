# Gravita — Game Feel Architecture & Kinetic Upgrade Blueprint

**Target Engine / Stack:** Unity `6000.4.0f1` (URP `17.4.0`), `Cinemachine 3.1.7`, `DOTween`, `PixelPerfectCamera`, `ObjectPoolManager` / `VfxSpawner`, `SoundManager` (`SoundConfig.asset`), `GameHaptics`.

Gravita lives and dies by how **high-speed stop-to-stop inertia** feels in the player's hands. At `moveSpeed = 30` units/sec (`33.33 ms` per `1×1` grid cell), a typical slide is over in under a quarter-second. When `PlayerMovement` snaps from rest to `30 u/s` and slams to zero cleanly without leaving time for passive animations to breathe, every action blurs together unless **impact decoupling, tier ignition thresholds, materiality contrast, and input-buffer telemetry** carry the kinetic weight.

---

## 1. Assumptions & Resolved Design Trade-Offs

1. **Live `VelocityTier` Thresholds (`1–2 / 3–4 / 5+`) Are Kept as Runtime Truth**
   - `Assets/Scripts/Gameplay/VelocityTier.cs` defines `VelocityTierUtil.FromTiles(int)` and `MinTilesForTier` as **`Drift` (`1–2` tiles)**, **`Cruise` (`3–4` tiles)**, and **`KineticRam` (`5+` tiles)**, while older design notes reference `1–3 / 4–7 / 8+`.
   - At `moveSpeed = 30` (`33.33 ms/tile`), `5` tiles takes `166.7 ms` (`~10` frames at `60 FPS`), whereas `8` tiles takes `266.7 ms` and rarely appears outside long corridors in compact `1×1` puzzle grids. **Resolution:** Retain `1–2 / 3–4 / 5+` in `VelocityTier.cs` so players routinely earn `KineticRam` payoffs during real puzzle solves, and drive all VFX/SFX/camera thresholds directly from `PlayerMovement.OnVelocityTierChanged` (never hardcoded tile counts).

2. **`Time.timeScale` Hit-Stop Applies Only at Collision/Break Payoffs — Never on Close Calls**
   - `CloseCallDetector.cs` explicitly enforces that near-misses **never modify `Time.timeScale`** so `30 u/s` timing, buffered turns (`bufferTurnsUntilStop = true`, `turnClearance = 0.35`), and hazard cycles stay 100% deterministic.
   - **Resolution:** Keep `Time.timeScale = 0f` hit-stop (`33–83 ms`) strictly scoped to `PlayerImpactFeedback` at stop/break events, guarded by `hitStopEnabled`, while every impact squash, zoom pulse, hit-flash, trail snap, and Cinemachine impulse runs in **unscaled time** so hit-stop creates dramatic snap rather than freezing visual feedback.

3. **Dynamic Camera Zoom vs. `CinemachinePixelPerfect` Snap**
   - `GameScene.unity` runs `PixelPerfectCamera` (`AssetsPPU = 32`, `RefResolution = 320×180`, `GridSnapping = 1`, `UpscaleRT = 0`, `CropFrame = 0`) on `Main Camera` plus `CinemachinePixelPerfect` on `CinemachineCamera` (`Lens.OrthographicSize = 5.5`). Because `CinemachinePixelPerfect` clamps `OrthographicSize` every frame to pixel-grid multiples, smooth `CinemachineCameraZoom2D` breathing and sub-pixel impulse shakes are silently overridden or pop in integer jumps.
   - **Resolution:** Disable `CinemachinePixelPerfect` on `CinemachineCamera` during dynamic gameplay (or toggle it off dynamically whenever `|OrthographicSize - 5.5| > 0.005f` or an impulse is active), giving crisp sprites with smooth `5.28–5.88` zoom breathing and directional camera recoil.

4. **Zero Procedural Hierarchy Creation & Strict DOTween Lifecycle Discipline**
   - No runtime `new GameObject(...)` or `AddComponent<T>()`. Every new visual/audio emitter (Ghost Afterimages, Buffered-Turn Chevron, Secondary Feedback Volume, Pooled VFX) lives as pre-placed prefab/scene child slots or `ObjectPoolManager` / `VfxSpawner` assets wired via `[SerializeField]`.
   - Every UI/gameplay tween calls `.DOKill()` before creation, `.SetUpdate(true)` (surviving hit-stop and pause), and `.SetLink(gameObject)` (preventing destroyed-object callbacks).

5. **Accessibility / Photosensitivity Guards**
   - In alignment with `docs/gdd.md` (§12.3–12.4), flash effects (`Hit Flash White.mat`), screen-shake force, chromatic aberration surges, and hit-stop freeze frames expose Inspector multipliers / reduced-motion bypasses so visual accessibility settings clamp flash luminance and camera motion cleanly without disabling audio/geometric readability cues.

## 2. Core Game Feel Diagnosis (Code & Scene Audit)

Inspection of `Assets/Scripts/`, `Assets/Scenes/GameScene.unity`, `Assets/Volume/Global Volume Profile.asset`, `Assets/Data/Sound/SoundConfig.asset`, and mechanic prefabs reveals **six exact root causes** flattening Gravita's feel today:

1. **Frozen Juice During Hit-Stop (`PlayerImpactFeedback` vs. Scaled Update Loops)**
   - `PlayerImpactFeedback.HitStopRoutine` sets `Time.timeScale = 0f` for `tier2HitStop = 0.033s` and `tier3HitStop = 0.083s`.
   - Simultaneously:
     - `PlayerSquashStretch.cs` runs `DOTween` `Sequence` in `Play()` and `ResetScale()` **without `.SetUpdate(true)`** (and without `.DOKill()`).
     - `PlayerLineTrail.cs` early-returns in `LateUpdate()` whenever `Time.deltaTime <= 0f`.
     - `CinemachineCameraZoom2D.cs` interpolates using scaled `Time.deltaTime * zoomSpeed`.
     - `Main Camera`'s `CinemachineBrain` in `GameScene.unity` has `IgnoreTimeScale: 0`.
   - **Result:** During the exact freeze frames meant to amplify heavy impacts, squash-stretch, camera shake, zoom, and trail retraction all freeze dead until `Time.timeScale` returns to `1`.

2. **Speed Compression Blindness at `30 u/s` (`33.33 ms/tile`)**
   - `Drift` ends in `33–67 ms`, `Cruise` spans `67–133 ms`, and `KineticRam` hits at `167 ms` (`48 u/s` / `20.83 ms/tile` during `StartPhaseLaunch` `speedMultiplier = 1.6f`).
   - Only `PlayerLineTrail` (`cruiseWidthScale: 1.2`, `kineticRamWidthScale: 1.45`) currently shifts visually across tiers. Without discrete ignition spikes in silhouette, camera framing, post-processing, and pitch, Subject G-0 feels uniformly weightless until collision.

3. **Silenced & Zeroed-Out Impact Payoffs Across Prefabs & Scene**
   - `GameScene.unity` overrides `PlayerImpactFeedback` serialized defaults to **`tier1Shake: 0`** and **`redirectShake: 0`**, erasing short-slide crispness and wedge-bounce feedback.
   - `Cracked.prefab` assigns `WallImpactBreak` with **`defaultCameraShake: 0`**, making `CrackedBlock.HasCustomBreakEffect == true` — which triggers the early-out `if (block == null || block.HasCustomBreakEffect) return;` in `PlayerImpactFeedback.HandleBlockBroken`, completely muting hit-stop and camera shake on block shatters.
   - `Brake.prefab`, `Exit.prefab`, `Hazard.prefab`, and `Wedge.prefab` ship with `InteractionEffectPlayer.effectPrefabs: []` and `defaultCameraShake: 0`.
   - `Assets/Data/Sound/SoundConfig.asset` currently has **`clips: []`** on its SFX entries, leaving impacts and slides acoustically silent until populated.

4. **Orphaned Signature Feedback Systems (`CinemachineCameraZoom2D` & `CloseCallDetector`)**
   - `CinemachineCameraZoom2D` sits on `CinemachineCamera/Zoom` (`normalOrthographicSize = 5.5`, `zoomSpeed = 4`) with **zero callers** anywhere in the codebase.
   - `CloseCallDetector` tracks `closeCallWindowSeconds = 0.15f` and `enemyNearMissRadius = 1.08f` with `cameraPulseForce = 0.06f`, firing static event `OnCloseCallTriggered(Vector3)`, yet **zero scripts subscribe** to it (and `bonusCoins = 5` is inactive because `EconomyBalanceConfig.Active.EnableLegacyExtraRewardSystems` is disabled).

5. **Bottom-Center Pivot Distortion, Duplicate Bounce Triggers & Monotone Stops**
   - `Player/Sprite` sits at `localPosition: (0, -0.5, 0)` (bottom-center `(0.5, 0)` pivot). Uniform center-pivot squash pulls Subject G-0's top surface away from ceiling collisions (`+Y`) instead of pinning it against the wall face.
   - `PlayerMovement.Redirect` invokes `OnRedirected` followed immediately on the same stack by `OnMoveStarted`, causing `PlayerSquashStretch` and launch audio to treat every mid-flight deflection like a stationary launch.
   - `PlayerImpactFeedback.HandleStopped` treats hard wall rebounds identically to `BrakeTile` / `GravityBlock` magnetic captures instead of contrasting violent impact against smooth electromagnetic arrest.

6. **Invisible Input Queueing & Missing Deterministic Pitch Control**
   - `PlayerMovement` keeps `pendingDirection` private (exposing only `HasPendingDirection`), giving players zero chassis visual cue when queuing a corner turn during a `167 ms` slide.
   - `SoundManager.PlaySFX(SoundEntry)` only resolves random jitter via `entry.GetResolvedPitch()`, lacking a deterministic `pitchOverride` overload needed for rising combo ladders and velocity cadence.

## 3. Six High-Impact Game Feel Pillars for Gravita

### Pillar 1 — Unscaled Impact Core, Directional Camera Recoil & Pivot-Pinned Deformation

**Kinetic Rationale:** Hit-stop works by freezing *gameplay progression* while letting *impact deformation, camera recoil, and white-hot bloom* snap into place immediately. Unfreezing feedback relative to `Time.timeScale = 0f` and aligning recoil + squash along the exact collision axis makes Subject G-0 feel like a dense physical projectile rather than a sliding UI icon.

```csharp
public void ShakeCamera(Vector2 direction, float force)
{
    if (impulseSource == null || force <= 0f) return;

    Vector2 dir = direction.sqrMagnitude > 0.0001f ? direction.normalized : Vector2.down;
    // Small perpendicular jitter avoids sterile single-axis oscillation on repeated orthogonal slams
    Vector2 perp = new Vector2(-dir.y, dir.x);
    Vector2 jittered = (dir + perp * UnityEngine.Random.Range(-0.15f, 0.15f)).normalized;
    impulseSource.GenerateImpulseWithVelocity(new Vector3(jittered.x, jittered.y, 0f) * force);
}
```

```csharp
private IEnumerator HitStopRoutine(float duration)
{
    bool prevIgnoreTimeScale = cinemachineBrain != null && cinemachineBrain.IgnoreTimeScale;
    float prevTimeScale = Time.timeScale;

    if (cinemachineBrain != null)
        cinemachineBrain.IgnoreTimeScale = true;

    try
    {
        yield return new WaitForSecondsRealtime(duration);
    }
    finally

        Time.timeScale = prevTimeScale;
        if (cinemachineBrain != null)
            cinemachineBrain.IgnoreTimeScale = prevIgnoreTimeScale;
    }
}
```

**C. `Assets/Scripts/Feedback/PlayerHitFlash.cs` (New Lightweight Component on `Player`)**

```csharp
using DG.Tweening;
using UnityEngine;

public sealed class PlayerHitFlash : MonoBehaviour
{
    [SerializeField] private SpriteRenderer targetRenderer;
    [SerializeField] private Material hitFlashMaterial; // Assign Assets/Shaders/Hit/Hit Flash White.mat
    [ColorUsage(true, true)]
    [SerializeField] private Color flashColor = new Color(3.2f, 3.6f, 4.2f, 1f);
    [Range(0f, 1f)]
    [SerializeField] private float accessibilityIntensity = 1f;

    private static readonly int FlashColorId = Shader.PropertyToID("_FlashColor");
    private Material defaultMaterial;
    private MaterialPropertyBlock propertyBlock;
    private Tween restoreTween;

    private void Awake()
    {
        if (targetRenderer != null)
            defaultMaterial = targetRenderer.sharedMaterial;
        propertyBlock = new MaterialPropertyBlock();
    }

    public void Flash(float durationSeconds = 0.045f)
    {
        if (targetRenderer == null || hitFlashMaterial == null || accessibilityIntensity <= 0.01f)
            return;

        restoreTween?.Kill();
        targetRenderer.sharedMaterial = hitFlashMaterial;

        Color scaled = Color.Lerp(Color.white, flashColor, accessibilityIntensity);
        targetRenderer.GetPropertyBlock(propertyBlock);
        propertyBlock.SetColor(FlashColorId, scaled);
        targetRenderer.SetPropertyBlock(propertyBlock);

        restoreTween = DOVirtual.DelayedCall(durationSeconds, RestoreDefaultMaterial)
            .SetUpdate(true)
            .SetLink(gameObject);
    }

    private void RestoreDefaultMaterial()
    {
        if (targetRenderer == null) return;
        targetRenderer.sharedMaterial = defaultMaterial;
        targetRenderer.SetPropertyBlock(null);
    }

    private void OnDisable()
    {
        restoreTween?.Kill();
        RestoreDefaultMaterial();
    }
}
```

**D. `Assets/Scripts/Feedback/PlayerSquashStretch.cs` — Unscaled DOTween + Bottom-Center Pivot Wall Pinning**
- Ensure every tween inside `Play()` and `ResetScale()` starts with `visualTransform.DOKill()` and terminates with `.SetUpdate(true).SetLink(gameObject)`.
- Guard against `PlayerMovement.Redirect` duplicate `OnMoveStarted` triggers: subscribe to `OnRedirected` to latch `bool suppressNextMoveStart = true`, then consume that latch inside `HandleMoveStarted` and play Pillar 3's corner-whip curve instead of resetting into stationary launch squash.
- Compute pivot-pinned `localPosition` alongside `localScale` so Subject G-0's `(0.5, 0)` bottom-center pivot (`restLocalY = -0.5f`) presses directly against floor, ceiling, and side walls without pulling away from `+Y` ceilings:
```csharp
private Vector3 ComputePinnedLocalPosition(Vector2 squashDir, float sx, float sy, float pressWorldUnits)
{
    // Sprite mesh spans X:[-0.5, +0.5], Y:[0, +1] around bottom-center pivot (0, -0.5, 0).
    // Pinning the wall-contact edge to +/-0.5 holds affine linearity as scale eases back to (1,1).
    float px = squashDir.x * 0.5f * (1f - sx) + squashDir.x * pressWorldUnits;
    float pivotOffsetY = squashDir.y > 0f
        ? (1f - sy)
        : (squashDir.y < 0f ? 0f : 0.5f * (1f - sy));
    float py = -0.5f + pivotOffsetY + squashDir.y * pressWorldUnits;
    return new Vector3(px, py, 0f);
}

private void PlayPinnedImpulse(Vector2 dir, float sx, float sy, float duration, Ease ease, float pressUnits)
{
    if (visualTransform == null) return;

    visualTransform.DOKill();
    visualTransform.localScale = new Vector3(sx, sy, 1f);
    visualTransform.localPosition = ComputePinnedLocalPosition(dir, sx, sy, pressUnits);

    Sequence seq = DOTween.Sequence();
    seq.Join(visualTransform.DOScale(Vector3.one, duration).SetEase(ease));
    seq.Join(visualTransform.DOLocalMove(new Vector3(0f, -0.5f, 0f), duration).SetEase(ease));
    seq.SetUpdate(true).SetLink(gameObject);
}
```

**B. `Assets/Scripts/Feedback/VelocityRunwayFeedback.cs` (New Component on `Player`)**
```csharp
using DG.Tweening;
using UnityEngine;
using UnityEngine.Rendering;

public sealed class VelocityRunwayFeedback : MonoBehaviour
{
    [Header("References")]
    [SerializeField] private PlayerMovement playerMovement;
    [SerializeField] private SpriteRenderer playerSpriteRenderer;
    [SerializeField] private SoundManager soundManager;
    [SerializeField] private SoundEntry cruiseIgniteSfx;
    [SerializeField] private SoundEntry kineticRamIgniteSfx;
    [SerializeField] private Volume kineticPostProcessVolume; // Secondary additive Volume (weight 0..1)

    [Header("Pre-Placed Afterimage Pool (Children of static (0,0,0) GameObject)")]
    [SerializeField] private SpriteRenderer[] afterimageSlots;

    [Header("Zoom Targets")]
    [SerializeField] private float cruiseOrthoSize = 5.66f;
    [SerializeField] private float kineticRamOrthoSize = 5.88f;
    [SerializeField] private float kineticImpactSnapOrthoSize = 5.28f;

    [Header("Afterimage Tuning")]
    [SerializeField] private float cruiseSpawnInterval = 0.045f;
    [SerializeField] private float ramSpawnInterval = 0.025f;
    [SerializeField] private float cruiseGhostLifetime = 0.16f;
    [SerializeField] private float ramGhostLifetime = 0.22f;
    [SerializeField] private Color cruiseGhostColor = new Color(0.16f, 0.91f, 1f, 0.35f);
    [SerializeField] private Color ramGhostColor = new Color(0.44f, 1f, 1f, 0.60f);

    [Range(0f, 1f)]
    [SerializeField] private float accessibilityEffectScale = 1f;

    private int slotCursor;
    private float spawnTimer;
    private bool wasPhasing;
    private Tween volumeWeightTween;

    private void OnEnable()
    {
        if (playerMovement == null) return;
        playerMovement.OnVelocityTierChanged += HandleTierChanged;
        playerMovement.OnMoveStopped += HandleMoveStopped;
        playerMovement.OnPhasingChanged += HandlePhasingChanged;
    }

    private void OnDisable()
    {
        if (playerMovement != null)
        {
            playerMovement.OnVelocityTierChanged -= HandleTierChanged;
            playerMovement.OnMoveStopped -= HandleMoveStopped;
            playerMovement.OnPhasingChanged -= HandlePhasingChanged;
        }
        volumeWeightTween?.Kill();
    }

    private void Update()
    {
        if (playerMovement == null || !playerMovement.IsMoving) return;

        VelocityTier tier = playerMovement.CurrentTier;
        if (tier < VelocityTier.Cruise && !playerMovement.IsPhasing) return;

        float interval = (tier == VelocityTier.KineticRam || playerMovement.IsPhasing)
            ? ramSpawnInterval
            : cruiseSpawnInterval;

        spawnTimer -= Time.deltaTime;
        if (spawnTimer <= 0f)
        {
            spawnTimer = interval;
            StampAfterimage(tier == VelocityTier.KineticRam || playerMovement.IsPhasing);
        }
    }

    private void HandleTierChanged(VelocityTier newTier)
    {
        switch (newTier)
        {
            case VelocityTier.Cruise:
                spawnTimer = 0f;
                CinemachineCameraZoom2D.Instance?.SetSpeedZoomTarget(cruiseOrthoSize);
                TweenVolumeWeight(0.25f * accessibilityEffectScale, 0.10f);
                soundManager?.PlaySFX(cruiseIgniteSfx, 1.12f, 0.85f);
                break;

            case VelocityTier.KineticRam:
                spawnTimer = 0f;
                CinemachineCameraZoom2D.Instance?.SetSpeedZoomTarget(kineticRamOrthoSize);
                TweenVolumeWeight(0.65f * accessibilityEffectScale, 0.08f);
                soundManager?.PlaySFX(kineticRamIgniteSfx, 1.28f, 1f);
                break;

            case VelocityTier.None:
            case VelocityTier.Drift:
                CinemachineCameraZoom2D.Instance?.ResetZoomToNormal();
                TweenVolumeWeight(0f, 0.16f);
                break;
        }
    }

    private void HandlePhasingChanged(bool isPhasing)
    {
        wasPhasing = isPhasing;
```

```csharp
private bool suppressNextMoveStartFromRedirect;
private int redirectChainCount;
private Vector2 prevBounceInDir;

private void HandleRedirected(Vector2 outDir)
{
    suppressNextMoveStartFromRedirect = true;
    redirectChainCount++;

    Vector2 inDir = prevBounceInDir.sqrMagnitude > 0.01f ? prevBounceInDir : -outDir;
    Vector2 kickDir = (inDir - outDir).sqrMagnitude > 0.01f ? (inDir - outDir).normalized : -outDir;

}

private void HandleMoveStarted(Vector2 dir)
{
    if (suppressNextMoveStartFromRedirect)
    {
        suppressNextMoveStartFromRedirect = false;
        return; // Preserves chain and prevents duplicate stationary-launch FX mid-bounce
    }
    redirectChainCount = 0;
    prevBounceInDir = dir;
    // Run stationary launch FX / audio here
}
```
