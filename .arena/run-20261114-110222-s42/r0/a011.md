# Gravita — Kinetic Game Feel Diagnostic & Upgrade Blueprint

> **Goal:** Transform Gravita from functional stop-to-stop puzzle movement into a rhythmic, high-precision **"kinetic railgun"** experience where every swipe, `33.3 ms` tile hop, `Cruise` / `KineticRam` runway charge, 45° pinball deflection, and razor-thin laser near-miss feels unmistakably sharp, weighty, and addictive.

---

## Assumptions

1. **Velocity Tier Thresholds:** Although design notes sometimes refer to `Drift (1–3) / Cruise (4–7) / KineticRam (8+)`, `VelocityTier.FromTiles(int)` (`Assets/Scripts/Gameplay/VelocityTier.cs`) and `docs/gdd.md` implement **`Drift = 1–2 tiles`**, **`Cruise = 3–4 tiles`**, and **`KineticRam = 5+ tiles`**. All timings below are calibrated to the live code thresholds at `GameScene.unity`'s serialized **`PlayerMovement.moveSpeed = 30`** (`33.3 ms` per tile — `Cruise` triggers at `~100 ms`, `KineticRam` triggers at `~167 ms`).
2. **Audio Assets Baseline:** `Assets/Data/Sound/SoundConfig.asset` currently has empty `clips: []` arrays on all 23 `SoundEntry` slots. Audio sections below define exact trigger hooks, pitch ladders, voice gates, and `SoundEntry` slots to populate once WAV/OGG assets are assigned in Inspector.
3. **Architecture & Scene Rules:** Every proposal strictly forbids runtime `new GameObject(...)` or runtime `AddComponent<...>()` (consistent with `docs/GAME_ARCHITECTURE_STANDARD.md`), wires dependencies via `[SerializeField]`, reuses `ObjectPoolManager` / `VfxSpawner` / `ParticleSpawner`, and applies `.DOKill().SetUpdate(true).SetLink(gameObject)` on every DOTween animation. Code snippets labeled **Proposed Patch** or **Proposed Addition** integrate directly into verified existing classes and events.

---

## 1. Core Game Feel Diagnosis: Why Gravita Currently Feels Flat

Despite already having impulse shake, squash-and-stretch, a trailing ribbon, hit-stop, and URP post-processing in the project, five concrete root causes suppress the feel during actual play:

1. **Sub-100ms Physics vs. 200ms Scaled Tweens:** At `moveSpeed = 30` (`33.3 ms/tile`), a 1-tile `Drift` hop ends in `33 ms` and a 3-tile `Cruise` dash finishes in `100 ms`. Yet `PlayerSquashStretch` uses `stretchDuration = 0.18s` and `squashDuration = 0.22s` **without `.SetUpdate(true)`** — short hops collide before stretch peaks, and `Time.timeScale = 0` freezes the squash mid-impact.
2. **Hit-Stop Freezes the Exact Juice Meant to Sell Impact (and Can Lock `Time.timeScale = 0`):**
   - `PlayerImpactFeedback.HitStopRoutine` saves `preHitStopTimeScale = Time.timeScale`. If two `PulseHitStop` calls overlap rapidly (e.g., short deflection into wall), `preHitStopTimeScale` captures `0f` and permanently freezes the game; `OnDisable` also drops the coroutine without restoring `Time.timeScale`.
   - `PooledParticlePlayer`, `PooledAnimationPlayer`, `PlayerLineTrail`, and `CinemachineCameraZoom2D` advance via scaled `Time.deltaTime` (`0` during hit-stop), literally freezing sparks, trail retraction, and camera recovery at the climax of every slam. Meanwhile `PlayerLineTrail.smoothedMoveSpeed` clamps at `[4f, 28f]`, below `moveSpeed = 30`.
3. **The Silent 70% Majority (`Drift`, `Redirect`, `BrakeTile`, Buffered Turns):** Because `bufferTurnsUntilStop = 1` enables rapid directional chaining, most inputs are 1–2 tile hops, perpendicular pre-buffers, wedge redirects, and brake stops. Currently `GameScene.unity` sets `tier1Shake = 0`, `tier1HitStop = 0`, and `redirectShake = 0`; `Wedge.prefab`, `Brake.prefab`, `Exit.prefab`, and `Hazard.prefab` have empty `InteractionEffectPlayer`s (`effectPrefabs: []`, `defaultCameraShake: 0`); `Cracked.prefab` and `Brittle.prefab` have `defaultCameraShake = 0`; `GameplayHapticsFeedback` plays flat `HapticEvent.WallImpact` regardless of tier; and `pendingDirection` is private and visually mute.
4. **Silent Event-Order & Double-Fire Audio Bugs:**
   - `PlayerMovement` fires `OnWallImpact` **before** `StopMoving(wallImpact: true)` updates `LastImpactTier`, causing `EntityAudio.HandlePlayerWallImpact` to read the *previous* dash's tier.
   - `PlayerMovement.Redirect` invokes both `OnRedirected` and `OnMoveStarted`, causing `EntityAudio` to double-play `wedgeRedirect` + `moveStart`.
5. **Bottom-Center Pivot (`y = -0.5`) & Unwired Scene Systems:**
   - `Player/Sprite` sits at `m_LocalPosition: (0, -0.5, 0)`. Upward (`Vector2.up`) squashes pull the top edge off the ceiling, and horizontal squashes both pull away from side walls and expand asymmetrically upward around `-0.5`.
   - `CinemachineCameraZoom2D` (ortho `5.5`), `CloseCallDetector.OnCloseCallTriggered` (`0` subscribers), and `Global Volume Profile.asset` (`Bloom`, `ChromaticAberration`, `Vignette`, `ColorAdjustments`) remain static throughout gameplay.

## 2. Six Gravita-Specific Game Feel Pillars

Every dash should feel like a **3-act kinetic musical phrase**: **Tension** (buffered swipe / launch snap) → **Escalation** (harmonic runway charge) → **Discharge** (pivot-locked slam, pinball rebound, or near-miss shear).

---

### Pillar 1 — Unscaled Micro-Impact, `TimeScaleArbitrator` & Pivot-Aware Squash

#### Why It Makes Gravita Addictive
In a stop-to-stop puzzler at `30 tiles/sec`, short 1–2 tile hops must feel like crisp magnetic clicks while 5+ tile `KineticRam` slams hit like a breaching ram — and `BrakeTile` / `GravityBlock` stops (`WasLastStopWallImpact == false`) must feel distinctly *damped* rather than brittle. Fixing time ownership, impact order, and pivot-locked squashes makes every stop cleanly readable in `33–180 ms`.

#### Exact Numbers, Curves & Inspector Parameters

| Event / State | Camera Shake | Hit-Stop (`Unscaled`) | Squash Scale `(W, H)` | Tween Duration / Ease | Additive Impact Flash | Haptic (`MOST` Preset) |
|---|---|---|---|---|---|---|
| **Launch (`OnMoveStarted`)** | `0` | `0s` | `(0.80, 1.24)` along `dir` | `0.032s` `OutQuad` | `0` | `Selection` (subtle) |
| **Tier 1 `Drift` (`1–2` tiles)** | `0.035` | `0s` | `(1.16, 0.84)` | `0.030s` in / `0.070s` `OutQuad` | `0` | `LightImpact` |
| **Tier 2 `Cruise` (`3–4` tiles)** | `0.11` | `0.030s` | `(1.28, 0.72)` | `0.030s` in / `0.100s` `OutBack` | `alpha 0.30` (`0.05s`) | `MediumImpact` |
| **Tier 3 `KineticRam` (`5+` tiles)** | `0.24` | `0.068s` | `(1.38, 0.62)` | `0.035s` in / `0.145s` `OutBack` | `alpha 0.65` (`0.06s`) | `RigidImpact` |
| **Soft Anchor (`Brake` / `Gravity`)** | `0.025` | `0s` | `(1.10, 0.90)` | `0.035s` in / `0.055s` `OutQuad` | Cyan pulse `0.20` | `SoftImpact` |

* **Haptic Priority Guard (`GameHaptics.GlobalMinGapSeconds = 0.03f`):** Never fire `GameHaptics.Play` on per-tile ticks, and allow high-priority `WallImpact` / `Death` events to bypass the `0.03s` global gap in `GameHaptics` so a `BufferedTurn` or `Redirect` `15 ms` before impact never swallows the heavy slam haptic. Update `GameplayHapticsFeedback` so `WallImpact` dispatches `Drift` → `LightImpact`, `Cruise` → `MediumImpact`, `KineticRam` → `RigidImpact` (reading the fixed `LastImpactTier`).
* **Trail Clamping Fix (`PlayerLineTrail`):** Raise `smoothedMoveSpeed` max clamp from `28f` to `36f` (`> moveSpeed = 30`) and step retraction with `Time.unscaledDeltaTime` when `TimeScaleArbitrator.Instance != null && TimeScaleArbitrator.Instance.IsHitStopActive` (remaining frozen during real Pause menus).

3. **Proposed Addition (`TimeScaleArbitrator.cs`):** Priority-layered time controller replacing direct `Time.timeScale` writes in `PlayerImpactFeedback` and preventing hit-stop lockups or cutscene freezes:
   ```csharp
   using UnityEngine;

   public sealed class TimeScaleArbitrator : MonoBehaviour
   {
       public static TimeScaleArbitrator Instance { get; private set; }

       [SerializeField] private UIManager uiManager;
       [SerializeField] private CutsceneManager cutsceneManager;

       private float _hitStopUntilUnscaled;
       private float _dilationScale = 1f;
       private float _dilationHoldUntil;
       private float _dilationBlendEnd;
       private float _dilationBlendDuration = 0.05f;

       public bool IsHitStopActive => Time.unscaledTime < _hitStopUntilUnscaled;

       private void Awake() => Instance = this;

       private void OnEnable()
       {
           LevelFlowController.OnPlayerRevived += ClearTransientEffects;
           ResolveTimeScale();
       }

       private void OnDisable()
       {
           LevelFlowController.OnPlayerRevived -= ClearTransientEffects;
           ClearTransientEffects();
           Time.timeScale = 1f;
       }

       public void RequestHitStop(float unscaledDuration, bool hitStopEnabled = true)
       {
           if (!hitStopEnabled || unscaledDuration <= 0f) return;
           float targetEnd = Time.unscaledTime + unscaledDuration;
           if (targetEnd > _hitStopUntilUnscaled)
               _hitStopUntilUnscaled = targetEnd;
           ResolveTimeScale();
       }

       public void RequestDilation(float targetScale, float holdSeconds, float blendOutSeconds)
       {
           _dilationScale = Mathf.Clamp(targetScale, 0.1f, 1f);
           _dilationHoldUntil = Time.unscaledTime + Mathf.Max(0f, holdSeconds);
           _dilationBlendDuration = Mathf.Max(0.01f, blendOutSeconds);
           _dilationBlendEnd = _dilationHoldUntil + _dilationBlendDuration;
           ResolveTimeScale();
       }

       public void ClearTransientEffects()
       {
           _hitStopUntilUnscaled = 0f;
           _dilationScale = 1f;
           _dilationHoldUntil = 0f;
           _dilationBlendEnd = 0f;
           ResolveTimeScale();
       }

       private void Update() => ResolveTimeScale();

       public void ResolveTimeScale()
       {
           if (uiManager != null && uiManager.IsAnyPopupOpen)
           {
               Time.timeScale = 0f;
               return;
           }

           if (cutsceneManager != null && cutsceneManager.IsSequenceRunning)
           {
               _hitStopUntilUnscaled = 0f;
               Time.timeScale = 1f;
               return;
           }

           if (Time.unscaledTime < _hitStopUntilUnscaled)
           {
               Time.timeScale = 0f;
               return;
           }

           if (Time.unscaledTime < _dilationHoldUntil)
           {
               Time.timeScale = _dilationScale;
               return;
           }

           if (Time.unscaledTime < _dilationBlendEnd)
           {
               float t = 1f - (_dilationBlendEnd - Time.unscaledTime) / _dilationBlendDuration;
               Time.timeScale = Mathf.Lerp(_dilationScale, 1f, Mathf.SmoothStep(0f, 1f, t));
               return;
           }

           Time.timeScale = 1f;
       }
   }

   public static class FeedbackSettings
   {
       public static float ShakeScale => PlayerPrefs.GetFloat("Settings_ShakeScale", 1f);
       public static bool HitStopEnabled => PlayerPrefs.GetInt("Settings_HitStop", 1) != 0;
       public static float FlashIntensityScale => PlayerPrefs.GetFloat("Settings_FlashScale", 1f);
   }
   ```

   private Vector3 ComputePivotAnchorOffset(Vector2 impactDir, float sx, float sy, float spriteExtent, float wallPress)
   {
       if (impactDir.y > 0.5f)
           return new Vector3(0f, (1f - sy) * spriteExtent + wallPress, 0f);
       if (impactDir.y < -0.5f)
           return new Vector3(0f, -wallPress, 0f);

       float centerYFix = -(sy - 1f) * 0.5f * spriteExtent;
       float sidePinX = Mathf.Sign(impactDir.x) * (0.5f * (1f - sx) * spriteExtent + wallPress);
       return new Vector3(sidePinX, centerYFix, 0f);
   }

### Pillar 2 — Kinetic Runway Escalation ("Harmonic Cadence, Ortho Kick & Ghost Trail")

#### Why It Makes Gravita Addictive
At `30 u/s`, reaching `Cruise` (`3` tiles) takes `100 ms` and `KineticRam` (`5` tiles) takes `167 ms`. Coupling `OnTileCrossed` and `OnVelocityTierChanged` to a gated musical staircase, unscaled camera breathing, pre-pooled afterimages, and additive URP `Volume` weight lets players *hear and feel* unlocking wall-breaking velocity in real time without checking HUD gauges.

#### Exact Numbers, Curves & Inspector Parameters

* **Per-Tile Musical Cadence (`OnTileCrossed(int tiles)`):**
  * Audio voice gate: `minTileSfxGap = 0.028s` (prevents stacked audio when `AdvanceSlideStep` crosses 2 tile boundaries inside one `0.02s` `FixedUpdate`).
  * Pitch curve: `pitch = 0.92f + Mathf.Clamp(tiles - 1, 0, 8) * 0.045f` (`0.92` → `1.28`), volume `0.10` → `0.24`. Zero haptic calls per tile.
* **Tier Lock-In (`OnVelocityTierChanged`):**
  * `Cruise` (tile 3): `CinemachineCameraZoom2D` target ortho `5.5` → `5.65` (`zoomSpeed = 12f` unscaled); `KineticPulseVolume.weight` tweens `0` → `0.42` (`* flashIntensityScale`) over `0.05s`; crisp tier-2 chime (`pitch 1.0`, `vol 0.35`).
  * `KineticRam` (tile 5): target ortho `5.5` → `5.86` (`zoomSpeed = 12f`); `KineticPulseVolume.weight` tweens `0.42` → `1.0` (`* flashIntensityScale`) over `0.06s`; harmonic lock chord (`pitch 1.08`, `vol 0.48`).
* **Impact Relief Snap (`OnMoveStopped`):**
  * From `KineticRam`: punch camera ortho IN `5.86` → `5.36` over `0.05s`, then ease back to `5.5` over `0.16s` (`OutCubic`); tween `KineticPulseVolume.weight` → `0f` over `0.16s`.
  * From `Cruise`: ease ortho back to `5.5` and `KineticPulseVolume.weight` → `0f` over `0.12s`.
* **Pooled Kinetic Afterimages (`PooledGhostEcho`):**
  * Pre-warmed pool of **10** `PlayerGhost` prefabs (`ObjectPoolManager`).
  * `Drift`: `0` ghosts.
  * `Cruise`: spawn every `0.45` world units (`alpha 0.28` → `0`, scale `0.95` → `0.78`, `0.13s`, `PlayerLineTrail.cruiseHeadColor`).
  * `KineticRam`: spawn every `0.30` world units (`alpha 0.48` → `0`, scale `1.0` → `0.80`, `0.18s`, `kineticRamHeadColor`, or `phaseHeadColor` when `IsPhasing` is true). Reset `lastGhostPos` whenever step distance > `2f` (`TeleportTo` / `Phase` jump guard).

   public void SetTargetZoom(float orthoSize, float? customSpeed = null)

2. **Proposed Addition (`PooledGhostEcho.cs` + `KineticRunwayFeedback.cs`):**
   ```csharp
   using DG.Tweening;
   using UnityEngine;

   public sealed class PooledGhostEcho : MonoBehaviour
   {
       [SerializeField] private SpriteRenderer spriteRenderer;
       private Tween _fadeTween;

       public void Play(Sprite sprite, bool flipX, bool flipY, int layerId, int order, Color tint, float startScale, float endScale, float duration)
       {
           if (spriteRenderer == null) return;
           _fadeTween?.Kill();
           spriteRenderer.DOKill();
           transform.DOKill();

           spriteRenderer.sprite = sprite;
           spriteRenderer.flipX = flipX;
           spriteRenderer.flipY = flipY;
           spriteRenderer.sortingLayerID = layerId;
           spriteRenderer.sortingOrder = order;
           spriteRenderer.color = tint;
           transform.localScale = Vector3.one * startScale;

           _fadeTween = DOTween.Sequence()
               .Join(spriteRenderer.DOFade(0f, duration).SetEase(Ease.OutQuad))
               .Join(transform.DOScale(endScale, duration).SetEase(Ease.OutQuad))
               .SetUpdate(true)
               .SetLink(gameObject)
               .OnComplete(() => ObjectPoolManager.ReturnObjectToPool(gameObject));
       }

       private void OnDisable() => _fadeTween?.Kill();
   }
   ```
   ```csharp
   using DG.Tweening;
   using UnityEngine;
   using UnityEngine.Rendering;

   public sealed class KineticRunwayFeedback : MonoBehaviour
   {
       [SerializeField] private PlayerMovement playerMovement;
       [SerializeField] private SpriteRenderer playerSpriteRenderer;
       [SerializeField] private CinemachineCameraZoom2D cameraZoom;
       [SerializeField] private Volume kineticPulseVolume;
       [SerializeField] private GameObject ghostPrefab;
       [SerializeField] private SoundEntry tileCadenceSfx;
       [SerializeField] private SoundEntry cruiseLockSfx;
       [SerializeField] private SoundEntry kineticLockSfx;

       [Header("Tuning")]
       [SerializeField] private float normalOrtho = 5.5f;
       [SerializeField] private float cruiseOrtho = 5.65f;
       [SerializeField] private float kineticOrtho = 5.86f;
       [SerializeField] private float impactPunchOrtho = 5.36f;
       [SerializeField] private float minTileSfxInterval = 0.028f;
       [SerializeField] private float cruiseGhostSpacing = 0.45f;
       [SerializeField] private float kineticGhostSpacing = 0.30f;
       [SerializeField] private Color cruiseTint = new Color(1f, 0.85f, 0.25f, 0.28f);
       [SerializeField] private Color kineticTint = new Color(1f, 0.32f, 0.78f, 0.48f);
       [SerializeField] private Color phaseTint = new Color(0.72f, 0.42f, 1f, 0.45f);

       private Tween _volumeTween;
       private Vector3 _lastGhostPos;
       private float _lastTileSfxUnscaled;
       private bool _wasKinetic;

       private void OnEnable()
       {
           if (playerMovement == null) return;
           playerMovement.OnMoveStarted += HandleMoveStarted;
           playerMovement.OnTileCrossed += HandleTileCrossed;
           playerMovement.OnVelocityTierChanged += HandleTierChanged;
           playerMovement.OnMoveStopped += HandleMoveStopped;
           LevelFlowController.OnPlayerRevived += ResetVisualsImmediate;
       }

       private void OnDisable()
       {
           if (playerMovement != null)
           {
               playerMovement.OnMoveStarted -= HandleMoveStarted;
               playerMovement.OnTileCrossed -= HandleTileCrossed;
               playerMovement.OnVelocityTierChanged -= HandleTierChanged;
               playerMovement.OnMoveStopped -= HandleMoveStopped;
           }
           LevelFlowController.OnPlayerRevived -= ResetVisualsImmediate;
           ResetVisualsImmediate();
       }

       private void HandleMoveStarted(Vector2 _)
       {
           _lastGhostPos = transform.position;
           _wasKinetic = false;
       }

       private void HandleTileCrossed(int tiles)
       {
           if (Time.unscaledTime - _lastTileSfxUnscaled < minTileSfxInterval) return;
           _lastTileSfxUnscaled = Time.unscaledTime;
           float pitch = 0.92f + Mathf.Clamp(tiles - 1, 0, 8) * 0.045f;
           // Route via AudioPitchUtility / dedicated cadence AudioSource at scaled volume (0.10..0.24) and pitch
           SoundManager.Instance?.PlaySFX(tileCadenceSfx);
       }

       private void HandleTierChanged(VelocityTier tier)
       {
           if (tier == VelocityTier.Cruise)
           {
               cameraZoom?.SetTargetZoom(cruiseOrtho, 12f);
               TweenVolumeWeight(0.42f, 0.05f);
               SoundManager.Instance?.PlaySFX(cruiseLockSfx);
           }
           else if (tier == VelocityTier.KineticRam)
           {
               _wasKinetic = true;
               cameraZoom?.SetTargetZoom(kineticOrtho, 12f);
               TweenVolumeWeight(1.0f, 0.06f);
               SoundManager.Instance?.PlaySFX(kineticLockSfx);
           }
       }

       private void HandleMoveStopped()
       {
           TweenVolumeWeight(0f, _wasKinetic ? 0.16f : 0.12f);
           if (_wasKinetic)
               cameraZoom?.PunchAndRecover(impactPunchOrtho, 0.05f, normalOrtho, 0.16f);
           else
               cameraZoom?.SetTargetZoom(normalOrtho, 10f);
           _wasKinetic = false;
       }

       private void LateUpdate()
       {
           if (playerMovement == null || !playerMovement.IsMoving || playerMovement.CurrentTier < VelocityTier.Cruise || ghostPrefab == null) return;

           Vector3 pos = transform.position;
           float moved = Vector3.Distance(pos, _lastGhostPos);
           if (moved > 2f) { _lastGhostPos = pos; return; } // Teleport / Phase blink guard

           float spacing = playerMovement.CurrentTier == VelocityTier.KineticRam ? kineticGhostSpacing : cruiseGhostSpacing;
           if (moved < spacing) return;

           _lastGhostPos = pos;
           Color tint = playerMovement.IsPhasing ? phaseTint : (playerMovement.CurrentTier == VelocityTier.KineticRam ? kineticTint : cruiseTint);
           float duration = playerMovement.CurrentTier == VelocityTier.KineticRam ? 0.18f : 0.13f;

           var go = ObjectPoolManager.SpawnObject(ghostPrefab, playerSpriteRenderer.transform.position, Quaternion.identity);
           if (go != null && go.TryGetComponent(out PooledGhostEcho echo))
           {
               echo.Play(playerSpriteRenderer.sprite, playerSpriteRenderer.flipX, playerSpriteRenderer.flipY,
                   playerSpriteRenderer.sortingLayerID, playerSpriteRenderer.sortingOrder - 1, tint, 0.96f, 0.78f, duration);
           }
       }

       private void TweenVolumeWeight(float target, float duration)
       {
           if (kineticPulseVolume == null) return;
           _volumeTween?.Kill();
           float clamped = target * FeedbackSettings.FlashIntensityScale;
           _volumeTween = DOTween.To(() => kineticPulseVolume.weight, w => kineticPulseVolume.weight = w, clamped, duration)
               .SetUpdate(true)
               .SetLink(gameObject);
       }

       private void ResetVisualsImmediate()
       {
           _volumeTween?.Kill();
           if (kineticPulseVolume != null) kineticPulseVolume.weight = 0f;
           cameraZoom?.SetTargetZoom(normalOrtho, 12f);
           _wasKinetic = false;
       }
   }
   ```

### Pillar 3 — Tactile Input Buffering & Turn-Lock Intent ("No Silent Swipes")

#### Why It Makes Gravita Addictive
With `bufferTurnsUntilStop = 1` and `turnClearance = 0.35`, rapid Gravita play relies on swiping perpendicular mid-slide to pre-queue the next vector. Today `pendingDirection` is private and invisible — late or wall-facing presses give zero confirmation.

#### Exact Numbers, Curves & Inspector Parameters

* **Queued (`BufferedTurnState.Queued`):** `BufferedChevron` sprite orbits `0.56` units from Player center toward `PendingDirection`, pops scale `0.45` → `1.0` over **`0.04s`** (`OutBack`), cyan `(0.35, 0.95, 1.0, 0.95)`, tilts `Sprite` `±5°` toward turn axis, plays `25 ms` relay click (`pitch 1.18`, `vol 0.22`) + `Selection` haptic.
* **Consumed (`BufferedTurnState.Consumed`):** Chevron lunges `+0.22` units along `PendingDirection` and fades `1` → `0` over **`0.045s`** (`.SetUpdate(true)`), handing off cleanly into launch stretch.
* **Rejected / Wall-Pressed (`BufferedTurnState.Rejected`):** `Sprite` performs a `+0.07` → `0` unit nudge over **`0.065s`** (`OutQuad`, unscaled); chevron flashes amber-red `(1.0, 0.35, 0.25, 0.9)` and fades in **`0.09s`**; plays muted deadbolt tick (`pitch 0.78`, `vol 0.24`) + `SoftImpact` haptic.

#### Exact C# Integration Hooks & Proposed Code

1. **Proposed Patch (`PlayerMovement.cs`):**
   ```csharp
   public enum BufferedTurnState { Queued, Consumed, Rejected, Cleared }

   public Vector2 PendingDirection => pendingDirection;
   public event Action<Vector2, BufferedTurnState> OnBufferedTurnChanged;
   ```
   Invoke `Queued` when queuing `pendingDirection`, `Consumed` when chaining at stop, `Rejected` when an idle input or pending turn targets a blocked cell, and `Cleared` inside `HaltAt` / `TeleportTo` / `ResetLevel`.
2. **Proposed Addition (`BufferedTurnFeedback.cs`):**
   ```csharp
   using DG.Tweening;
   using UnityEngine;

   public sealed class BufferedTurnFeedback : MonoBehaviour
   {
       [SerializeField] private PlayerMovement playerMovement;
       [SerializeField] private SpriteRenderer chevronRenderer;
       [SerializeField] private Transform spriteTransform;
       [SerializeField] private SoundEntry queueClickSfx;
       [SerializeField] private SoundEntry rejectTickSfx;
       [SerializeField] private float orbitRadius = 0.56f;
       [SerializeField] private Color queuedColor = new Color(0.35f, 0.95f, 1f, 0.95f);
       [SerializeField] private Color rejectedColor = new Color(1f, 0.35f, 0.25f, 0.9f);

       private Tween _chevronTween;
       private Tween _nudgeTween;
       private Tween _tiltTween;
       private Vector3 _baseSpriteLocalPos;

       private void Awake()
       {
           if (spriteTransform != null) _baseSpriteLocalPos = spriteTransform.localPosition;
           if (chevronRenderer != null) chevronRenderer.color = new Color(queuedColor.r, queuedColor.g, queuedColor.b, 0f);
       }

       private void OnEnable()
       {
           if (playerMovement != null) playerMovement.OnBufferedTurnChanged += HandleBufferedTurn;
       }

       private void OnDisable()
       {
           if (playerMovement != null) playerMovement.OnBufferedTurnChanged -= HandleBufferedTurn;
           _chevronTween?.Kill();
           _nudgeTween?.Kill();
           _tiltTween?.Kill();
       }

       private void HandleBufferedTurn(Vector2 dir, BufferedTurnState state)
       {
           if (chevronRenderer == null) return;

           Transform ct = chevronRenderer.transform;
           _chevronTween?.Kill();
           ct.DOKill();
           chevronRenderer.DOKill();

           if (dir == Vector2.zero || state == BufferedTurnState.Cleared)
           {
               _chevronTween = chevronRenderer.DOFade(0f, 0.04f).SetUpdate(true).SetLink(gameObject);
               ResetSpriteTilt(0.05f);
               return;
           }

           if (state == BufferedTurnState.Queued)
           {
               ct.localPosition = (Vector3)(dir.normalized * orbitRadius);
               ct.localRotation = Quaternion.FromToRotation(Vector3.up, dir);
               ct.localScale = Vector3.one * 0.45f;
               chevronRenderer.color = queuedColor;
               _chevronTween = ct.DOScale(1f, 0.04f).SetEase(Ease.OutBack).SetUpdate(true).SetLink(gameObject);
               ApplySpriteTilt(dir);
               SoundManager.Instance?.PlaySFX(queueClickSfx);
           }
           else if (state == BufferedTurnState.Consumed)
           {
               _chevronTween = DOTween.Sequence()
                   .Join(ct.DOLocalMove(ct.localPosition + (Vector3)(dir.normalized * 0.22f), 0.045f).SetEase(Ease.OutQuad))
                   .Join(chevronRenderer.DOFade(0f, 0.045f))
                   .SetUpdate(true).SetLink(gameObject);
               ResetSpriteTilt(0.04f);
           }
           else if (state == BufferedTurnState.Rejected)
           {
               ct.localPosition = (Vector3)(dir.normalized * (orbitRadius * 0.85f));
               ct.localRotation = Quaternion.FromToRotation(Vector3.up, dir);
               chevronRenderer.color = rejectedColor;
               _chevronTween = chevronRenderer.DOFade(0f, 0.09f).SetUpdate(true).SetLink(gameObject);
               ResetSpriteTilt(0.04f);

               if (spriteTransform != null)
               {
                   _nudgeTween?.Kill();
                   spriteTransform.DOKill();
                   Vector3 kick = (Vector3)(dir.normalized * 0.07f);
                   _nudgeTween = DOTween.Sequence()
                       .Append(spriteTransform.DOLocalMove(_baseSpriteLocalPos + kick, 0.03f).SetEase(Ease.OutQuad))
                       .Append(spriteTransform.DOLocalMove(_baseSpriteLocalPos, 0.035f).SetEase(Ease.OutQuad))
                       .SetUpdate(true).SetLink(gameObject);
               }
               SoundManager.Instance?.PlaySFX(rejectTickSfx);
           }
       }

       private void ApplySpriteTilt(Vector2 dir)
       {
           if (spriteTransform == null) return;
           _tiltTween?.Kill();
           float tiltZ = Mathf.Abs(dir.x) > 0.5f ? -Mathf.Sign(dir.x) * 5f : Mathf.Sign(dir.y) * 3f;
           _tiltTween = spriteTransform.DOLocalRotate(new Vector3(0f, 0f, tiltZ), 0.04f)
               .SetUpdate(true).SetLink(gameObject);
       }

       private void ResetSpriteTilt(float duration)
       {
           if (spriteTransform == null) return;
           _tiltTween?.Kill();
           _tiltTween = spriteTransform.DOLocalRotate(Vector3.zero, duration)
               .SetUpdate(true).SetLink(gameObject);
       }
   }
   ```

using UnityEngine;

public sealed class PinballChainFeedback : MonoBehaviour
{
    private static readonly float[] PitchSteps = { 1.00f, 1.06f, 1.12f, 1.19f, 1.26f, 1.33f, 1.41f, 1.50f };

    [SerializeField] private PlayerMovement playerMovement;
    [SerializeField] private GameObject redirectSparkPrefab;
    [SerializeField] private SoundEntry redirectPingSfx;

    private int _chainIndex;
    private Vector2 _prevDir;

    private void OnEnable()
    {
        if (playerMovement != null)
        {
            playerMovement.OnMoveStarted += HandleStart;
            playerMovement.OnRedirected += HandleRedirect;
            playerMovement.OnMoveStopped += ResetChain;
        }
        LevelFlowController.OnPlayerRevived += ResetChain;
    }

    private void OnDisable()
    {
        if (playerMovement != null)
        {
            playerMovement.OnMoveStarted -= HandleStart;
            playerMovement.OnRedirected -= HandleRedirect;
            playerMovement.OnMoveStopped -= ResetChain;
        }
        LevelFlowController.OnPlayerRevived -= ResetChain;
    }

    private void HandleStart(Vector2 dir) => _prevDir = dir;

    private void HandleRedirect(Vector2 newDir)
    {
        int step = Mathf.Clamp(_chainIndex, 0, PitchSteps.Length - 1);
        _chainIndex = Mathf.Min(_chainIndex + 1, PitchSteps.Length - 1);

        TimeScaleArbitrator.Instance?.RequestHitStop(0.016f, FeedbackSettings.HitStopEnabled);

        if (redirectSparkPrefab != null)
        {
            Vector2 bisector = (-_prevDir + newDir).sqrMagnitude > 0.01f ? (-_prevDir + newDir).normalized : newDir;
            Quaternion rot = Quaternion.LookRotation(Vector3.forward, bisector);
            VfxSpawner.Spawn(redirectSparkPrefab, transform.position, rot);
        }

        // Play wedgeRedirect via AudioPitchUtility / dedicated AudioSource using pitch = PitchSteps[step]
        SoundManager.Instance?.PlaySFX(redirectPingSfx);

        _prevDir = newDir;
    }

    private void ResetChain() => _chainIndex = 0;
}
