# Gravita (Puzzle 2D) — Signature Game Feel Upgrade Blueprint

## Assumptions & Verified Codebase Baseline
- **Velocity Tier Thresholds**: `Assets/Scripts/Gameplay/VelocityTier.cs` currently maps `1–2` tiles → `Drift`, `3–4` tiles → `Cruise`, `5+` tiles → `KineticRam` (`VelocityTierUtil.FromTiles`), while design notes mention `1–3 / 4–7 / 8+`. Every feedback hook below observes `PlayerMovement.CurrentTier` and `OnVelocityTierChanged` dynamically rather than hardcoding tile counts, so re-tuning `VelocityTierUtil` propagates automatically.
- **Physics Timing**: `GameScene.unity` runs `PlayerMovement.moveSpeed = 30` units/sec (`1.0` unit/cell at `32 PPU`), meaning **1 tile = `33.3 ms`** (~2 frames at 60 FPS).
- **Strict Scene & Architecture Constraints**: Zero `new GameObject(...)` or runtime `AddComponent<...>()`. All new components live in `Assets/Scripts/Feedback/` (or `Audio/`), all UI/VFX/Volume slots use explicit `[SerializeField]` Inspector wiring or `VfxSpawner.Spawn(...)` (`ObjectPoolManager`), and every DOTween sequence calls `.DOKill()`, `.SetUpdate(true)`, and `.SetLink(gameObject)`. `FixedUpdate` cell-center physics and `LevelClock` determinism remain untouched.

## 1. Core Game Feel Diagnosis — Why Gravita Currently Feels "Flat"

Reading the existing feedback stack and `GameScene.unity` reveals **five concrete sensory breaks** rather than a lack of basic polish:

1. **Velocity Escalation Happens Faster Than Perception (`33.3 ms/tile`)**: At `moveSpeed = 30`, Subject G-0 reaches `Cruise` in `100 ms` and `KineticRam` in `167 ms`. Because `PlayerSquashStretch.HandleTierChanged` plays a transient `0.153s` pulse and snaps right back to `baseScale`, `EntityAudio` plays nothing on `OnTileCrossed` or `OnVelocityTierChanged`, and `CinemachineCameraZoom2D` (`normalOrthographicSize = 5.5`) is **never called anywhere in the project**, a 7-tile Kinetic Ram feels almost identical to a 2-tile Drift.
2. **Hit-Stop Freezes Visual Feedback Mid-Frame**: `PlayerImpactFeedback` drops `Time.timeScale = 0f` for `33 ms` (`Cruise`) and `83 ms` (`KineticRam`), yet:
   - `PlayerSquashStretch` omits `.SetUpdate(true)` on both `DOTween.Sequence()` calls, so sprite compression freezes until hit-stop ends.
   - `CinemachineCameraZoom2D.Update()` uses `Time.deltaTime` instead of `Time.unscaledDeltaTime`, blocking camera impact punches during hit-stop.
   - `GameScene.unity` serializes `tier1Shake = 0` and `redirectShake = 0`, leaving Drift stops and wedge chains completely flat.
3. **Smashing `CrackedBlock` Mid-Slide Has Zero Impact**: When `CrackedBlock.TryCrush` succeeds during `KineticRam`, `PlayerMovement.AdvanceSlideStep` immediately executes `continue;` and keeps sliding (`OnMoveStopped` does not fire). `PlayerImpactFeedback.HandleBlockBroken` spawns particles/animations but triggers **0 ms hit-stop, 0 camera shake, and 0 zoom punch**, turning Gravita's signature power moment into silent ghosting.
4. **Pivot Distortion & `Redirect -> MoveStarted` Double-Trigger**: The Player's child `Sprite` sits at `localPosition = (0, -0.5, 0)` (bottom-center `(0.5, 0)` pivot). Scaling around `(0, -0.5)` while adding `wallPressPx = 4f` pulls the sprite asymmetrically on Up/Left/Right wall impacts. Additionally, `PlayerMovement.Redirect` fires `OnRedirected` **immediately followed by `OnMoveStarted`**, causing `EntityAudio` to layer `moveStart` over `wedgeRedirect` and causing any `OnRedirected` squash/stretch to be overwritten 1 microsecond later.
5. **Silent Signature Systems & Dormant Hooks**:
   - `CloseCallDetector.OnCloseCallTriggered` has **0 subscribers**, and `EconomyBalanceConfig.EnableLegacyExtraRewardSystems` defaults to `false` (suppressing its `bonusCoins = 5` reward), making razor-thin dodges feel nonexistent.
   - `PlayerMovement.pendingDirection` gives **0 visual/audio cue** when `bufferTurnsUntilStop = true` holds a queued turn mid-corridor.
   - `GameplayHapticsFeedback` handles only `WallImpact` and `GravityAnchor` (while `LevelFlowController` handles `Death`), leaving `HapticEvent.PadRedirect`, `LaunchStart`, and `SwitchToggle` unused.
   - `Brake.prefab`, `Exit.prefab`, `Hazard.prefab`, and `Wedge` prefabs have empty `InteractionEffectPlayer` lists.

## 2. Five High-Impact Gravita Game Feel Pillars

### Pillar 1: Kinetic Runway Escalation & Unscaled-Time Impact Lock
**Why It Makes Gravita Uniquely Addictive**: Gravita's fantasy is **building kinetic lethality across a corridor**. When every crossed tile clicks upward in pitch, Subject G-0 locks into an aerodynamic dart posture at `Cruise`/`KineticRam`, the camera breathes subtly outward to reveal upcoming wedges, and impact snaps cleanly *during* the `Time.timeScale = 0` freeze frame (not after), a 200 ms dash feels razor-sharp and explosive.

#### Exact Specs & Curves
- **Sustained Aerodynamic Form (`PlayerSquashStretch`)**:
  - `Drift` (`TilesTraveled` in tier 1): Keep crisp neutral/light stretch (`+8%` along travel axis, `-4%` across).
  - `Cruise`: Hold sustained `+12%` along / `-6%` across (`0.05s` ease `OutQuad`, unscaled).
  - `KineticRam`: Hold sustained `+20%` along / `-10%` across (`0.05s` ease `OutQuad`, unscaled).
  - `Phasing` (`VectorLauncher` `1.6x` speed): Hold `+26%` along / `-13%` across + `phaseSpriteTint`.
  - **Bottom-Center `(0.5, 0)` Pivot Compensation**: Given `spriteWorldHeight = 1.0f` (`32 px @ 32 PPU`) and `baseLocalPosition = (0, -0.5, 0)`:
    - Keep vertical center anchored at `(0, 0)` during horizontal compression (`localPos.y = baseLocalPosition.y + 0.5f * (1f - sy / baseScale.y)`).
    - When pressing into a wall (`pressDirection != zero`), shift `localPos` so the leading face compresses **into** the wall by `wallPressPx / 32f` (`4 px = 0.125 u`), compensating `0.5f * (1f - scaleRatio)` on `+Y` ceiling hits and `±X` side hits.
- **Runway Tile-Tick Cadence (`RunwayCadenceFeedback`)**:
  - Subscribe to `PlayerMovement.OnTileCrossed(int tiles)` and `OnVelocityTierChanged(VelocityTier tier)`.
  - Ignore tile `1` (covered by `moveStart`); from `tiles >= 2`, trigger an ultra-crisp `25 ms` servo tick with rising pitch: `pitch = Mathf.Clamp(0.92f + (tiles - 2) * 0.045f, 0.92f, 1.32f)`, `volumeScale = Mathf.Lerp(0.45f, 0.85f, Mathf.Clamp01((tiles - 1) / 6f))`.
  - **Critical Timing Rule**: Set `SoundEntry.minInterval = 0.022f` (`< 33.3 ms` per tile at `moveSpeed = 30`) so `SoundManager`'s anti-spam gate never drops consecutive tile ticks.
  - On transition to `VelocityTier.KineticRam`: fire a distinct metallic lock-in chime (`SoundConfig.kineticLockIn`) + spawn a pooled sonic shock-ring (`VfxSpawner.Spawn(kineticRingPrefab, playerCenter, rot)`).
- **Unscaled Dual-Layer Camera Zoom (`CinemachineCameraZoom2D`)**:
  - Switch `Update()` from `Time.deltaTime` to `Time.unscaledDeltaTime`.
  - Separate persistent `baseTargetSize` (`normalOrthographicSize = 5.5`) from transient `punchOffset` (decayed exponentially at `punchRecoverSpeed = 14f` unscaled):
    - While in `Cruise`: `baseTarget = 5.58` (`+0.08` slight foresight).
    - While in `KineticRam`: `baseTarget = 5.72` (`+0.22` wide-corridor speed sense, `zoomSpeed = 6f`).
    - On `OnMoveStopped` (wall impact): `PunchZoom(-0.06f / -0.14f / -0.26f)` for Tiers 1/2/3 — camera snaps tight *during* the `33–83 ms` hit-stop, then springs back to `5.5`.
- **Wall Shake Values (`GameScene.unity` -> `PlayerImpactFeedback`)**:
  - Update `tier1Shake = 0.045f` (was `0`), `tier2Shake = 0.13f`, `tier3Shake = 0.25f`.
  - Distinguish floor anchor stops (`!movement.WasLastStopWallImpact`): apply `anchorStopShake = 0.04f`, `0f` hit-stop, and `PunchZoom(-0.08f)` so `BrakeTile`/`GravityBlock` feel distinct from wall collisions.

public void PlaySFX(SoundEntry entry, float pitchOverride, float volumeMultiplier = 1f)
{
    if (!entry.HasClips) return;
    AudioClip clip = entry.GetRandomClip();
    if (clip == null) return;

    float minInterval = Mathf.Max(0.01f, entry.minInterval);
    float now = Time.unscaledTime;
    if (lastPlayedTimeByClip.TryGetValue(clip, out float lastTime) && now - lastTime < minInterval)
        return;

    lastPlayedTimeByClip[clip] = now;
    float vol = Mathf.Clamp01(entry.GetResolvedVolume() * Mathf.Max(0f, volumeMultiplier));
    PlayResolvedClip(clip, vol, Mathf.Clamp(pitchOverride, 0.25f, 3f));
}

private Vector3 ComputePivotCompensatedPosition(Vector3 targetScale, Vector2 pressDirection)
{
    float syRatio = baseScale.y > 0.0001f ? targetScale.y / baseScale.y : 1f;
    float sxRatio = baseScale.x > 0.0001f ? targetScale.x / baseScale.x : 1f;
    float halfH = spriteWorldHeight * 0.5f;

    // Keep sprite visually centered at (0,0) around bottom-center (0.5, 0) pivot.
    Vector3 pos = baseLocalPosition + new Vector3(0f, halfH * (1f - syRatio), 0f);

    if (pressDirection != Vector2.zero)
    {
        float press = wallPressPx / 32f;
        Vector2 n = pressDirection.normalized;
        if (Mathf.Abs(n.y) >= Mathf.Abs(n.x))
            pos.y += n.y > 0f
                ? (halfH * (1f - syRatio) + press)   // top wall: pin top edge + press
                : (-halfH * (1f - syRatio) - press); // bottom wall: pin bottom edge - press
        else
            pos.x += n.x * (halfH * (1f - sxRatio) + press);
    }
    return pos;
}

### Pillar 2: Billiard-Chain Ricochet Crescendo (`DeflectionWedge`, `VectorPad`, `VectorLauncher`)
**Why It Makes Gravita Uniquely Addictive**: Chaining 3–5 angled rebounds to preserve `TilesTraveled` into a `KineticRam` is Gravita's defining puzzle-arcade hook. Escalating pitch, trail pulse, directional corner whip, and camera kick on every consecutive redirect turns a geometric route into a **musical pinball combo**.

#### Exact Specs & Curves
- **Chain Counter**: Increment `chainCount` on `PlayerMovement.OnRedirected(Vector2 newDir)` (resets to `0` on `OnMoveStopped` or level reset).
- **Musical Semitone Escalation**: `pitch = Mathf.Pow(1.059463f, Mathf.Min(chainCount - 1, 7))` (`1.00, 1.06, 1.12, 1.19, 1.26, 1.33, 1.41, 1.50`), `minInterval = 0.025f` so rapid adjacent wedges (`33 ms` apart) all sing cleanly.
- **Double-Sound Fix (`EntityAudio.cs`)**: Guard `HandlePlayerMoveStarted` with `if (playerMovement != null && playerMovement.TilesTraveled > 0) return;` so `Redirect()`'s trailing `OnMoveStarted` never fires `moveStart` over `wedgeRedirect`.
- **Camera Kick & Corner Whip**:
  - `redirectShake` in `PlayerImpactFeedback`: `0.055f + 0.015f * Mathf.Min(chainCount, 4)` (cap `0.115f` — replace `redirectShake = 0` in `GameScene.unity`).
  - `PlayerSquashStretch.HandleRedirected(Vector2 newDir)`: `0.055s` unscaled whip (`-14%` along `newDir`, `+16%` across `newDir` with `Ease.OutBack`) settling directly into current tier stretch.
- **Trail Corner Flare (`PlayerLineTrail`)**: On `HandleRedirected`, briefly boost `lineRenderer.widthMultiplier` to `baseTierWidth * 1.35f` and lerp smoothly back to `baseTierWidth` over `0.09s` using `Time.unscaledDeltaTime`.
- **Phase Launch Warp (`VectorLauncher` -> `OnPhasingChanged`)**: When `phasing == true`, `CinemachineCameraZoom2D.Instance.SetTargetOrthographicSize(5.78f)`, `CinemachineCameraShake2D.Instance.ShakeCamera(0.14f)`, and on `phasing == false` (landing at `KineticRam`), `PunchZoom(-0.14f)`.

public sealed class RicochetChainFeedback : MonoBehaviour
{
    [SerializeField] private SoundConfig soundConfig;
    [SerializeField] private GameObject redirectSparkPrefab;
    [SerializeField, Min(0f)] private float baseRedirectShake = 0.055f;
    [SerializeField, Min(0f)] private float shakePerChain = 0.015f;
    [SerializeField, Min(0.05f)] private float maxRedirectShake = 0.115f;
    [SerializeField, Range(1, 12)] private int maxSemitoneSteps = 7;

    private int chainCount;

    private void OnEnable()
    {
        if (movement == null) return;
        movement.OnRedirected += HandleRedirected;
        movement.OnMoveStopped += HandleStopped;
    }

    private void OnDisable()
    {

        movement.OnRedirected -= HandleRedirected;
        movement.OnMoveStopped -= HandleStopped;
        chainCount = 0;
    }

    private void HandleRedirected(Vector2 newDir)
    {
        chainCount++;
        float pitch = Mathf.Pow(1.059463f, Mathf.Min(chainCount - 1, maxSemitoneSteps));

        if (cfg != null && SoundManager.Instance != null)

            CinemachineCameraShake2D.Instance.ShakeCamera(shake);

        if (redirectSparkPrefab != null)
        {
            float angle = Mathf.Atan2(newDir.y, newDir.x) * Mathf.Rad2Deg;
            VfxSpawner.Spawn(redirectSparkPrefab, transform.position, Quaternion.Euler(0f, 0f, angle));
        }
    }

    private void HandleStopped() => chainCount = 0;
}

    [SerializeField] private float zoomPunchDelta = -0.11f;
    [SerializeField, Min(0f)] private float shakeForce = 0.085f;

    private float lastTriggerTime = float.NegativeInfinity;
    private Sequence volumeSeq;
    private Sequence badgeSeq;

    private void OnEnable()
    {
        CloseCallDetector.OnCloseCallTriggered += HandleCloseCall;

            SoundManager.Instance.PlaySFX(cfg.closeCallArc, pitch);
        }

        if (closeCallVfxPrefab != null)
            VfxSpawner.Spawn(closeCallVfxPrefab, worldPos, Quaternion.identity);

        PlayVolumeSpike();
        PlayHudBadge(streak);
    }

    private void PlayVolumeSpike()
    {
        if (closeCallPostVolume == null) return;
        volumeSeq?.Kill();
        DOTween.Kill(closeCallPostVolume);
        closeCallPostVolume.weight = 0f;
        volumeSeq = DOTween.Sequence()
            .Append(DOTween.To(() => closeCallPostVolume.weight, w => closeCallPostVolume.weight = w, 0.85f, 0.025f).SetEase(Ease.OutQuad))
            .Append(DOTween.To(() => closeCallPostVolume.weight, w => closeCallPostVolume.weight = w, 0f, 0.14f).SetEase(Ease.InQuad))
            .SetUpdate(true)
            .SetLink(closeCallPostVolume.gameObject);
    }

    private void PlayHudBadge(int currentStreak)
    {
        if (hudBadgeGroup == null) return;
        badgeSeq?.Kill();
        hudBadgeGroup.DOKill();
        hudBadgeGroup.transform.DOKill();
        if (hudBadgeText != null)
            hudBadgeText.text = currentStreak > 1 ? $"RAZOR EDGE x{currentStreak}" : "RAZOR EDGE";

        hudBadgeGroup.gameObject.SetActive(true);
        hudBadgeGroup.alpha = 0f;
        hudBadgeGroup.transform.localScale = Vector3.one * 0.82f;
        badgeSeq = DOTween.Sequence()
            .Append(hudBadgeGroup.DOFade(1f, 0.06f))
            .Join(hudBadgeGroup.transform.DOScale(1.12f, 0.08f).SetEase(Ease.OutBack))
            .Append(hudBadgeGroup.transform.DOScale(1f, 0.08f))
            .AppendInterval(0.32f)
            .Append(hudBadgeGroup.DOFade(0f, 0.18f))
            .OnComplete(() => hudBadgeGroup.gameObject.SetActive(false))
            .SetUpdate(true)
            .SetLink(hudBadgeGroup.gameObject);
    }
}
