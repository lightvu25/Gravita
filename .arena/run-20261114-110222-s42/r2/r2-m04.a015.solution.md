# Gravita (`Puzzle 2D`) — Game Feel, Kinesthetics & Audiovisual Feedback Architecture Blueprint

This document defines an actionable, event-driven Game Feel engineering blueprint for **Gravita** (`Unity 6000.4.0f1 URP`, `2D Grid Puzzle`). Every design preserves deterministic `FixedUpdate` cell-center physics (`0.02s` fixed timestep, `50 Hz`), soft-lock limits (`maxConsecutiveRedirects = 8`, `bufferTurnsUntilStop = 1`, deferred `EnergyGate` close), and strict Inspector-wired / pooled patterns inside `Assets/Scripts/Feedback/`.

---

## 1. Executive Diagnosis of Current Baseline

Inspection of the project scripts, prefabs, `Assets/Scenes/GameScene.unity`, `ProjectSettings/TimeManager.asset`, `Assets/Data/Sound/SoundConfig.asset`, and `Assets/Volume/Global Volume Profile.asset` identifies six concrete kinesthetic gaps:

1. **Suppressed Kinetic Range & Non-Wall Stop Contamination**
   - `GameScene.unity` overrides `PlayerSquashStretch.maxDeformation` down to `0.3` (below the script default `0.45f`).
   - `Player/Sprite` uses a bottom-edge sprite pivot (`Player Icon.aseprite.meta` `pivot: (0.5, 0)` at `32x32` / `32 PPU`, `localPosition: (0, -0.5, 0)`). Compressing Y during upward wall impacts shifts the sprite bottom away from North walls unless leading-edge anchored, while expanding perpendicular Y (`1.40x`) on horizontal impacts (`±1, 0`) shifts the body strictly upward unless centered via `sprite.bounds`.
   - `PlayerImpactFeedback.HandleStopped()` triggers shake and hit-stop without checking `movement.WasLastStopWallImpact`, causing `BrakeTile` stops, `GravityBlock` anchors (`GravityBlock.prefab` already has `defaultCameraShake: 0.04`), and `Freeze()` on death/exit to trigger wall impacts.
   - `PlayerImpactFeedback.HandleRedirected()` emits flat nondirectional `0` shake (`redirectShake: 0`) regardless of bend geometry.
2. **Audio Cadence Gaps & Phase-Transition Bleed**
   - `ProjectSettings/TimeManager.asset` (`Fixed Timestep = 0.02s`, `50 Hz`) combined with `GameScene.unity` (`PlayerMovement.moveSpeed = 30`, `cellSize = 1`) moves `0.60` tiles per `20 ms` step. Tile crossings alternate at `40 ms` and `20 ms` intervals (`t = 40, 80, 100, 140, 180, 200 ms`), and `30-45 FPS` frames execute two `FixedUpdate` ticks at the same `Time.unscaledTime`. A `minInterval >= 0.03f` against `Time.unscaledTime` in `SoundManager.PlaySFX` drops every third crossing and drops back-to-back frame crossings.
   - `PlayerMovement.StartPhaseLaunch` and `StepPhaseLaunch` invoke `EnforceMinimumTier` (raising `OnTileCrossed`) and `StepPhaseLaunch` emits `OnMoveStarted` after phase landing, triggering launch/whoosh/footstep audio mid-transition unless explicitly isolated.
   - `PlayerMovement.Redirect(Vector2, Vector2)` fires `OnRedirected` for `VectorPad` and `VectorLauncher` as well as `DeflectionWedge`, preventing isolated wedge harmonic escalation.
3. **Unconnected High-Emotion Haptic Cues**
   - `HapticEvent` only covers `UISelect = 0` through `Death = 6`; `CloseCallDetector` narrow escapes and `CrackedBlock` kinetic shatters emit no tactile feedback.
4. **Static Velocity Telemetry & Unconditional Prefab Effect Contamination**
   - Velocity tiers in `VelocityTier.cs` (`FromTiles`: `1-2 = Drift`, `3-4 = Cruise`, `5+ = KineticRam`) only marginally adjust `PlayerLineTrail`, with no kinetic afterimage trail, queued-turn arrow telemetry, or star-pickup scale feedback.
   - `InteractionEffectPlayer` is completely empty (`effectPrefabs: []`, `defaultCameraShake: 0`, `rules: []`) on `Brake.prefab`, `Wedge.prefab`, `Exit.prefab`, and `Hazard.prefab`, while BOTH `Brittle.prefab` (`defaultCameraShake: 0`) and `FailingTile.prefab` (`defaultCameraShake: 0.08`) place `WallImpactBreak.prefab` in unconditional `effectPrefabs` with `rules: []` — firing break shatter VFX even on `InteractionKind.Crack`.
5. **Dormant Lab Environment & Destructive Hazard Sibling Freezing**
   - `HazardActivation`, `FailingTile`, `CircuitSwitch`, and `EnergyGate` have minimal or missing continuous telegraphs. `EnergyGate.SetPowered` fires `OnGateOpenStateChanged(false)` prematurely when `pendingDeferredClose` holds physics open (`OnLevelClockTick` and `ResetSwitchState` update physics silently), and `CircuitSwitch.ResetTile()` updates visuals without firing `OnSwitchStateChanged(false)`.
   - `Hazard.FreezeTarget()` disables sibling `MonoBehaviour` components on the root (`PulseLaser.prefab` and `OverloadedFloor.prefab` have `Hazard` + `HazardActivation` on root), so any feedback script placed on root gets silently disabled when Freeze is cast and misses `LevelRoot.ResetAll()` unfreezing order (`switchables` at line 209 before `hazards` at line 217).
6. **Flat Camera, Volume & Cutscene Lifecycle**
   - `CinemachineCameraZoom2D` (`normalOrthographicSize: 5.5`, `zoomSpeed: 4`) stays static during slides and lacks lifecycle resets if zoomed during `CutsceneManager.GoalRoutine()`; `Global Volume Profile.asset` (`ChromaticAberration = 0.2`, `Vignette = 0.4`, `Bloom = 9`) sits static at baseline; `CutsceneManager.GoalRoutine()` calls `LockPlayer()` (`Freeze()` -> `OnMoveStopped`) before the shrink loop and rotates around the `(0.5, 0)` bottom-edge sprite pivot.

## 2. Core Gameplay Hook Extensions (Clean SRP Contracts)

Keep all audiovisual/tween logic strictly inside `Assets/Scripts/Feedback/`, driven by compact, deterministic hooks on gameplay scripts (preserving existing signatures and tests):

### 2.1 `PlayerMovement.cs` & `CellResolver.cs`
- **Directional & Wedge-Specific Redirect Hook (Backward-Compatible)**:
  - Add `public enum RedirectSource { Generic, Wedge, VectorPad, VectorLauncher }`.
  - Keep `public void Redirect(Vector2 newDirection, Vector2 snapPosition)` intact via optional 3rd parameter: `Redirect(Vector2 newDirection, Vector2 snapPosition, RedirectSource source = RedirectSource.Generic)`.
  - Update `CellResolver.ResolveSorted` (via an out/tuple variant) to pass the winning `ICellInteraction` type from `AdvanceSlideStep` (`Wedge`, `VectorPad`, `VectorLauncher`) and `TryTriggerRestingLauncher` (`VectorLauncher`) into `Redirect(...)`.
  - Expose `public int ConsecutiveRedirects => consecutiveRedirects;` and `public int MaxConsecutiveRedirects => maxConsecutiveRedirects;` (preserving `maxConsecutiveRedirects = 8`).
  - Add `public event Action<Vector2, Vector2> OnWedgeRedirected;` (`incomingDir, outgoingDir`), invoked inside `Redirect` **only** when `source == RedirectSource.Wedge && incomingDirection != Vector2.zero && incomingDirection != newDirection`.
- **Phase-Transition & Redirect State Flags (`try/finally` Guarded)**:
  - Expose `public bool IsRedirectMoveStart { get; private set; }` (wraps `OnMoveStarted` inside `Redirect`).
  - Expose `public bool IsStartingPhaseLaunch { get; private set; }` (wraps `StartPhaseLaunch`).
  - Expose `public bool IsPhaseLandingTransition { get; private set; }` (wraps the landing block in `StepPhaseLaunch` from `SetPhasing(false)` through `EnforceMinimumTier` and `OnMoveStarted`).
- **Centralized Buffered Turn Signal**:
  - Expose `public Vector2 PendingDirection => pendingDirection;` and `public event Action<Vector2> OnPendingDirectionChanged;`.
  - Funnel **every** write to `pendingDirection` — `QueueDirection`, `SimulateStep`, `StepPhaseLaunch` (where `pendingDirection = Vector2.zero` clears queued direction on landing), `StartPhaseLaunch`, `StopMoving`, `ResetDirectionHistory`, and `Redirect` — through a single private helper `SetPendingDirection(Vector2 dir)` that assigns and emits `OnPendingDirectionChanged` on change.

### 2.2 `EnergyGate.cs`, `CircuitSwitch.cs`, `Hazard.cs`, `CloseCallDetector.cs`, `CrackedBlock.cs`, `MazeTile.cs`
- **`EnergyGate.cs`**: Track `private bool lastNotifiedPhysicalOpen;` initialized in `Awake`/`Start` from `IsPassable`. Move `OnGateOpenStateChanged?.Invoke(open)` into `ApplyPhysicalState(bool open)` so it fires **iff** `open != lastNotifiedPhysicalOpen`. Remove the premature invoke in `SetPowered` (keep `OnPlayerInteracted(InteractionKind.Switch)` on logical toggle). This guarantees exact alignment across immediate toggles, `pendingDeferredClose` completion in `OnLevelClockTick`, and `ResetSwitchState()` during `LevelRoot.ResetAll()`.
- **`CircuitSwitch.cs`**: Invoke `OnSwitchStateChanged?.Invoke(false);` inside `ResetTile()` alongside `RefreshVisual()`.
- **`Hazard.cs`**: Expose `public bool IsFrozen => isFrozen;` (matching existing freeze state) and `public event Action<bool> OnFrozenStateChanged;` emitted from `FreezeTarget()`, `UnfreezeTarget()`, and `ResetHazard()`.
- **`CloseCallDetector.cs` / `CrackedBlock.cs` / `MazeTile.cs`**:
  - Add `public event Action<Vector2, float> OnCloseCallTriggered;` (world position, pulse force) inside `CloseCallDetector` when triggering a close call.
  - Add `public static event Action<Vector3> OnAnyBroken;` inside `CrackedBlock.Break()` when actually transitioning to broken (note: `PowerUpController` `Breaker` also calls `cracked.Break()`, firing cleanly for both kinetic ram and Breaker).
  - Add `public static event Action<MazeTile, InteractionKind> OnAnyPlayerInteracted;` fired alongside `MazeTile.RaisePlayerInteracted(...)` so feedback listeners can cleanly isolate `VectorPad` or other specific tile events.

## 3. Pillar 1: Kinetic Impact, Hit-Stop, Directional Shake & Pivot-Compensated Squash/Stretch

### 3.1 Directional Camera Impulse (`CinemachineCameraShake2D`)
- Retain `CinemachineBrain.IgnoreTimeScale = 0` in `GameScene.unity` so the camera participates in the impact freeze-frame cleanly before releasing shock motion when gameplay resumes.
- Add `public void ShakeCameraDirectional(Vector2 direction, float force)` to `CinemachineCameraShake2D`:
  - Normalize `direction` (fallback to `Vector2.down` matching `CinemachineImpulseSource.DefaultVelocity = (0, -1, 0)` if `sqrMagnitude < 1e-4f`).
  - Call `impulseSource?.GenerateImpulse((Vector3)(dir * force));`.

### 3.2 Tiered Hit-Stop, Wall-Stop Gate & Chromatic Aberration Pulse (`PlayerImpactFeedback` & `KineticPostProcessFeedback`)
Note: Gameplay mechanics (`VelocityTier.cs`) define tiers as `Drift = 1-2` (`MinTilesForTier = 1`), `Cruise = 3-4` (`MinTilesForTier = 3`), `KineticRam = 5+` (`MinTilesForTier = 5`). Parameter tuning aligns to `VelocityTier` boundaries:

| Stop / Event Type | Velocity / Condition | Camera Shake Force & Axis | Hit-Stop (`Time.timeScale = 0`) | Volume Pulse (`Global Volume Profile`) |
| :--- | :--- | :--- | :--- | :--- |
| **Non-Wall Stop (`Brake`, `GravityBlock`, `Freeze`)** | `!movement.WasLastStopWallImpact` or `movement.InputLocked` | **Suppressed** in `PlayerImpactFeedback` (`GravityBlock.prefab` owns its `0.04f` anchor shake) | `0.000 s` | None |
| **Wedge Redirect** | `movement.OnWedgeRedirected(in, out)` | `0.03f * Mathf.Pow(0.85f, Mathf.Min(ConsecutiveRedirects, MaxConsecutiveRedirects))` along `(out - in).normalized` (`<= 8` cap) | `0.000 s` | None |
| **Wall Impact — Tier 1 (`Drift`)** | `1-2` tiles (`WasLastStopWallImpact`) | `0.06f` along `-lastImpactNormal` | `0.000 s` | None |
| **Wall Impact — Tier 2 (`Cruise`)** | `3-4` tiles (`WasLastStopWallImpact`) | `0.13f` along `-lastImpactNormal` | `0.033 s` | None |
| **Wall Impact — Tier 3 (`KineticRam`)** | `5+` tiles (`WasLastStopWallImpact`) | `0.24f` along `-lastImpactNormal` | `0.083 s` | Chromatic Aberration `0.20f -> 0.45f -> 0.20f` (`0.18s` unscaled) |

- **Implementation Guardrails in `PlayerImpactFeedback`**:
  - Cache `private Vector2 lastImpactNormal;` inside `HandleWallImpact(Vector2 normal, int tiles)` and reset on movement start.
  - Gate `HandleStopped()`: `if (movement.InputLocked || !movement.WasLastStopWallImpact) return;`, preventing death/victory `Freeze()`, `BrakeTile`, and `GravityBlock` stops from firing false wall hit-stops or camera kicks.
  - Subscribe directional redirect shake **only** to `movement.OnWedgeRedirected` using `(outgoing - incoming).normalized` and `Mathf.Pow(0.85f, Mathf.Min(movement.ConsecutiveRedirects, movement.MaxConsecutiveRedirects))` (matching `maxConsecutiveRedirects = 8`), leaving `VectorPad` / `VectorLauncher` shakes strictly to their tile `InteractionEffectPlayer`.
  - **Hit-Stop & Pause Isolation**: `PulseHitStop` triggers only when `!movement.InputLocked` and pause modal state (`UIManager.ShouldFreezeTime`) is false, restoring `Time.timeScale = 1f` on disable/abort.
- **Volume Pulse Component (`KineticPostProcessFeedback`)**:
  - Dedicated Inspector-wired component holding `[SerializeField] private Volume globalVolume;`. Caches baseline `ChromaticAberration.intensity` (`0.20f` from `Global Volume Profile.asset`).
  - Pulses via `DOTween.To(...)` with `.DOKill()`, `.SetUpdate(true)`, `.SetLink(gameObject)`, pausing cleanly if `UIManager.OnPopupStackChanged` indicates `ShouldFreezeTime`, and restoring baseline intensity (`0.20f`) inside `OnDisable()` so asset state is never dirtied permanently.

### 3.3 Two-Axis `sprite.bounds` Pivot-Compensated Squash & Stretch (`PlayerSquashStretch`)
- **Inspector Tuning (`GameScene.unity`)**: Raise `PlayerSquashStretch.maxDeformation` from `0.3` back to `0.45` so Tier 3 `impactWidthPx = 28, impactHeightPx = 16` and slide elongation `20x28` execute without clamping; keep `squashDuration = 0.22f`, `stretchDuration = 0.18f`, `wallPressPx = 4f` (`0.125` units at `32 PPU`).
- **Two-Axis Anchor Compensation (`ComputeCompensatedLocalPosition`)**:
  - `Player/Sprite` (`localPosition = (0, -0.5, 0)`) uses `pivot = (0.5, 0)` on `32x32` sprites, so naive scale changes pull North-ceiling impacts away from the wall and bias horizontal-impact perpendicular expansion (`1.40x` vertical stretch) strictly upward (`+12.8 px`).
  - Compute compensated local position across **both** `axis = 0 (X)` and `axis = 1 (Y)` from `SpriteRenderer.sprite.bounds` and `baseLocalScale`:
    ```csharp
    Vector3 ComputeCompensatedLocalPosition(Vector3 deformedScale, Vector2 pressDirection)
    {
        if (spriteRenderer == null || spriteRenderer.sprite == null)
            return baseLocalPosition;

        Bounds b = spriteRenderer.sprite.bounds;
        Vector3 pos = baseLocalPosition;

        for (int axis = 0; axis < 2; axis++)
        {
            float baseS = baseLocalScale[axis];
            float newS = deformedScale[axis];
            float d = pressDirection[axis];

            if (Mathf.Abs(d) > 0.5f)
            {
                // Anchor leading wall-contact edge and press into wall by wallPressPx
                float edge = d > 0f ? b.max[axis] : b.min[axis];
                float pressOffset = Mathf.Sign(d) * (wallPressPx / pixelsPerUnit);
                pos[axis] = baseLocalPosition[axis] + edge * (baseS - newS) + pressOffset;
            }
            else
            {
                // Preserve visual sprite center on non-impact axes (prevents upward skew)
                pos[axis] = baseLocalPosition[axis] + b.center[axis] * (baseS - newS);
            }
        }
        return pos;
    }
    ```
  - Pass `pressDirection = Vector2.zero` during `PlayStretch` (in-flight elongation) and pass the wall impact direction during `PlaySquash` so North, South, East, and West impacts stay pin-accurate on both axes.
  - All `PlayerSquashStretch` tweens call `visualTransform.DOKill()` before creation and terminate with `.SetUpdate(true).SetLink(visualTransform.gameObject)`.
  - Expose `public void LockAndKillForCutscene()` (sets `isCutsceneLocked = true`, kills active tween, restores `baseLocalScale` / `baseLocalPosition`) and `public void UnlockCutscene()`.

## 4. Pillar 2: Velocity-Synced 50 Hz Audio, Pitch Escalation & Phase Isolation

### 4.1 Physics Timing Compatibility for `tileCrossTick`
- Because `TimeManager.asset` runs at `Fixed Timestep = 0.02s` (`50 Hz`) and `PlayerMovement.moveSpeed = 30` (`0.60 tiles/step`), `OnTileCrossed` triggers at alternating deltas of **`40 ms` and `20 ms`**, and frames running at `30-45 FPS` execute two `FixedUpdate` steps on the same render frame (sharing identical `Time.unscaledTime`).
- **Two-Part Fix**:
  1. Lower `SoundConfig.tileCrossTick.minInterval` from `0.03f` to **`0.015f`** (safely below the `20 ms` single-step floor).
  2. Extend `SoundManager.PlaySFX(..., bool bypassInterval = false)` so deterministic per-tile events (`OnTileCrossed`) pass `bypassInterval: true` — preventing two `FixedUpdate` steps in one `30-45 FPS` frame from muting each other at identical `Time.unscaledTime`.

### 4.2 Pitch Escalation, Tier Progression & Transition Guards (`EntityAudio` & `SoundConfig`)
- **Per-Tile Escalation (`OnTileCrossed`)**:
  - Guard at entry: `if (playerMovement.IsStartingPhaseLaunch || playerMovement.IsPhasing || playerMovement.IsPhaseLandingTransition) return;` so `EnforceMinimumTier` calls inside `StartPhaseLaunch` and `StepPhaseLaunch` never emit phantom tile ticks or early Kinetic Ram stingers.
  - Scale `tileCrossTick` pitch progressively with `tilesTraveled`:
    `pitch = Mathf.Clamp(0.88f + tilesTraveled * 0.06f, 0.88f, 1.50f)` (`0.94 -> 1.00 -> 1.06 -> 1.12 -> 1.18+`, hitting max velocity brightness right at `KineticRam` `5+` tiles).
  - Fire `tierKineticRamReach` (`volume: 0.75, pitch: 1.0`) **once per slide** when `VelocityTier.FromTiles(tiles)` first transitions to `KineticRam` (`>= 5` tiles).
- **Slide Start (`OnMoveStarted`)**:
  - Guard in `EntityAudio.HandlePlayerMoveStarted`: `if (playerMovement.IsRedirectMoveStart || playerMovement.IsPhaseLandingTransition || playerMovement.IsStartingPhaseLaunch) return;` so post-wedge redirects and phase-launch landings never replay `playerSlide` footsteps.
- **Separated Redirect Cues (Wedge Harmonic vs Pad Fixed Whoosh)**:
  - Subscribe wedge escalation **strictly** to `playerMovement.OnWedgeRedirected`:
    `float pitch = Mathf.Pow(1.059463f, Mathf.Min(playerMovement.ConsecutiveRedirects, playerMovement.MaxConsecutiveRedirects));` (`12-TET` semitone steps across redirects `0..8`, capped at `maxConsecutiveRedirects = 8`). Plays `wedgeRedirect` (`volume: 0.85`).
  - Route `VectorPad` to a distinct fixed-pitch `padRedirect` cue (`pitch: 1.0`, `minInterval: 0.05f`) via `MazeTile.OnAnyPlayerInteracted` (filter `InteractionKind.Redirect` on `VectorPad`) so pad boosts never impersonate wedge musical ladders.
- **New Tactile Audio Events in `SoundConfig`**:
  - `turnBufferLock`: snappy mechanical click on `OnPendingDirectionChanged` when `dir != Vector2.zero` (`pitch: 1.15`, `minInterval: 0.04f`, `volume: 0.55`).
  - `brakeSkid`: low hydraulic hiss on `BrakeTile` interaction (`volume: 0.65`).
  - `brittleCrack` vs `brittleBreak`: distinct crisp fracture pop (`InteractionKind.Crack`) vs deep shatter (`InteractionKind.Break` / `CrackedBlock.OnAnyBroken`).
  - `closeCallShimmer`: airy upward chime on `CloseCallDetector.OnCloseCallTriggered` (`volume: 0.80`).

## 7. Pillar 5: Living Lab Environment, Cutscene Center-Pivot Vortex & Zoom Lifecycle

### 7.2 Cutscene Center-Pivot Vortex & Camera Zoom Lifecycle (`CutsceneManager` & `CinemachineCameraZoom2D`)
- **Strict Sequence Order in `CutsceneManager.GoalRoutine()`**:
  1. **Before `LockPlayer()`**: Call `playerSquashStretch?.LockAndKillForCutscene();` *prior* to `LockPlayer()` (because `LockPlayer()` calls `Freeze()` -> `OnMoveStopped`, which otherwise starts an unguarded squash/stretch tween right before the shrink loop).
  2. **Slide-In**: Slide player to exit center cleanly while maintaining `baseLocalScale`.
  3. **Visual-Center Vortex Rotation (Zero Procedural `GameObject`)**: Because `Player/Sprite` pivots around `(0.5, 0)` at `localPosition = (0, -0.5, 0)`, direct `DORotate` swings the sprite into the cell below. Rotate around its exact local visual center without creating any runtime child pivot object using a single `DOTween.Sequence()`:
     ```csharp
     SpriteRenderer sr = visualTransform.GetComponent<SpriteRenderer>();
     Vector3 baseScale = visualTransform.localScale;
     Vector3 baseLocalPos = visualTransform.localPosition;
     Vector3 spriteCenterLocal = sr != null && sr.sprite != null ? sr.sprite.bounds.center : Vector3.zero;
     Vector3 visualCenter = baseLocalPos + Vector3.Scale(spriteCenterLocal, baseScale);

     visualTransform.DOKill();
     Sequence vortex = DOTween.Sequence();
     vortex.Join(visualTransform.DOScale(Vector3.zero, pullInDuration).SetEase(Ease.InBack));
     vortex.Join(visualTransform.DOLocalRotate(new Vector3(0f, 0f, -360f), pullInDuration, RotateMode.FastBeyond360).SetEase(Ease.InCubic));
     vortex.OnUpdate(() =>
     {
         Vector3 rotatedOffset = visualTransform.localRotation * Vector3.Scale(spriteCenterLocal, visualTransform.localScale);
         visualTransform.localPosition = visualCenter - rotatedOffset;
     });
     vortex.SetUpdate(true).SetLink(visualTransform.gameObject);
     ```
  4. **Zoom Pull-In & Immediate Behind-Curtain Reset**: Trigger `CinemachineCameraZoom2D.Instance?.SetTargetZoomOffset(-0.75f)` during exit absorption (`5.5 -> 4.75`, smoothly easing with `zoomSpeed = 4`), then **immediately after `ScreenTransition.FadeOut(...)` covers the screen**, call `CinemachineCameraZoom2D.Instance?.ResetImmediate()` (snaps `targetOrthographicSize` and `orthographicSize` back to `normalOrthographicSize = 5.5f` unseen behind the black curtain).
- **Ironclad Fallback & Menu/Restart Safety**:
  - Call `CinemachineCameraZoom2D.Instance?.ResetImmediate()` and `playerSquashStretch?.UnlockCutscene()` inside both `CutsceneManager.FinishSequence()` and `CutsceneManager.OnDisable()` (protects interrupted cutscenes, instant skips, or scene unloads).
  - Add `ResetImmediate()` on `CinemachineCameraZoom2D` and subscribe `CinemachineCameraZoom2D` directly to `LevelFlowController` lifecycle hooks (`OnLevelStarted`, `OnLevelRestarted`, `OnReturnToMapRequested`) so zero-tile restarts (`tilesTraveled == 0`), map exits, or deaths never inherit zoomed framing.
