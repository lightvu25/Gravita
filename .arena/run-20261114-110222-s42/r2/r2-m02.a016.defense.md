ATTACK 1: CONCEDE. Verified in `GameScene.unity`: both `CinemachinePixelPerfect` and URP `PixelPerfectCamera` (`32 PPU`, `320x180`) are enabled, locking `OrthographicSize` to `5.625` on 1080p/720p (and `2.8125` if only `CinemachinePixelPerfect` is disabled). Fixed by disabling both components in `GameScene.unity` and guarding them in `CinemachineCameraZoom2D.Awake()` using `Point` sprite filtering so `5.50 / 5.72 / 6.02` tier zoom and `PulseZoom` animate smoothly.

ATTACK 2: CONCEDE. Our prior spec declared `EnergyGate.OnPhysicalStateChanged` as an instance event while `LabWorldAudioFeedback` subscribed statically (`CS0120`), and emitted inside `ResetSwitchState()` called by `Awake()` and `OnLevelClockReset()`. Fixed by splitting instance `OnPhysicalStateChanged` (per-prefab `EnergyGateVisualFeedback`) from static `EnergyGate.OnAnyPhysicalStateChanged` (scene audio on real `SetPowered`/`OnLevelClockTick` transitions only), with `ResetSwitchState(notifyVisuals)` silent in `Awake()`.

ATTACK 3: CONCEDE. Verified in `WallImpactBurst.prefab`: its 3D Cone `ShapeModule` (`rotation = 0,0,0`) emits along local `+Z` rather than `+X`, so `Quaternion.Euler(0, 0, Atan2)` aims bursts straight toward the camera on every impact. Fixed by splitting `impactBurstPrefab` (`Quaternion.LookRotation((Vector3)normal, Vector3.back)`) from 2D `+X`-aligned `impactAnimationPrefab` (`Quaternion.Euler(0f, 0f, Mathf.Atan2(normal.y, normal.x) * Mathf.Rad2Deg)`).

ATTACK 4: CONCEDE. Verified in `GameHaptics.cs` (`GlobalMinGapSeconds = 0.03f`) and `HapticsTests.cs`: `TierUp` or `BlockSmash` within `<= 0.02 s` drops `KineticRamImpact`, and `WallSlide_InRealTilemapArena_FiresExactlyOneWallImpactHaptic` (`1.5 -> 5.549`) is a `4.049 u` (`4`-tile, `Cruise`) slide broken by non-Ram `TierUp`. Fixed by adding `GetPriority(evt) > lastPlayedPriority` preemption inside `GlobalMinGapSeconds`, emitting `TierUp` strictly on `KineticRam`, setting `BlockSmash` cooldown to `0.03f`, and updating the `4`-tile test to `CruiseImpact`.

ATTACK 5: CONCEDE. Verified in `PlayerMovement.QueueDirection`: `pendingDirection` is written on idle starts, blocked wall taps, and mid-slide reversals before `SimulateStep` runs, causing raw `pendingDirection` hooks to misfire `InputCoilIndicator`. Fixed by exposing semantic `BufferedTurnDirection` / `OnBufferedTurnChanged` armed strictly for perpendicular turns while sliding (`bufferTurnsUntilStop && cardinal != moveDirection && cardinal != -moveDirection`) and cleared on reversals, rest consumption, redirects, and phase launches.

ATTACK 6: CONCEDE. Verified in `GameScene.unity` and `Wedge.prefab` (`Layer 0` vs `wallLayers = 64`): `< 1 u` stops (such as starting adjacent to a blunt `DeflectionWedge` at `0.049 u`) enter `OnWallImpact` with `CurrentTier == None` before `StopMoving` sets `LastImpactTier`, replaying stale `KineticRam` feedback. Fixed in both `EntityAudio` and `GameplayHapticsFeedback` by mapping `CurrentTier != VelocityTier.None ? CurrentTier : VelocityTier.Drift` with zero `LastImpactTier` fallback.

ATTACK 7: CONCEDE. Our Diagnosis flagged `PlayerLineTrail.LateUpdate()` returning on `Time.deltaTime <= 0f` and scaled `ReturnToPool` waits, yet our solution omitted unscaled fixes for `PlayerLineTrail`, `PooledParticlePlayer`, and particle prefabs (`useUnscaledTime: 0` on `WallImpactBurst`, `WallImpactBreak`, `Particle Star`). Fixed by exposing `PlayerImpactFeedback.IsHitStopActive` (restoring `Time.timeScale` in `OnDisable`), using hit-stop-aware unscaled delta in `PlayerLineTrail`, `ReturnToPool`, and `PooledParticlePlayer`, and enabling `useUnscaledTime` on impact particle prefabs.
