# Gravita (`Puzzle 2D`) — Game Feel Engineering Blueprint

**Target Engine & Project:** Unity `6000.4.0f1` (URP 2D, `32 PPU`, `Assets/Scenes/GameScene.unity`, `Assets/Volume/Global Volume Profile.asset`).  
**Core Invariant:** Deterministic grid-slide physics (`PlayerMovement.FixedUpdate`, `AdvanceSlideStep`, `StepPhaseLaunch`, `Redirect`, `HaltAt`), trigger resolution (`MazeTile`, `CrackedBlock`, `Hazard`, `GravityBlock`, `BrakeTile`, `VectorLauncher`), and softlock detection remain unchanged. All Game Feel systems layer strictly on top of read-only state and lifecycle events with `.DOKill()`, `.SetUpdate(true)`, and `.SetLink(gameObject)` on every DOTween animation.

---

## 1. Core Game Feel Diagnosis

Inspecting `GameScene.unity`, `Assets/Scripts/Gameplay/`, `Assets/Scripts/Feedback/`, `Assets/Scripts/Audio/`, and `Assets/Prefabs/` reveals four structural causes behind Gravita's flat kinetic feel:

1. **Instant `30 u/s` Constant Velocity Without Kinetic Continuity**  
   In `Assets/Scenes/GameScene.unity`, `PlayerMovement` runs at `moveSpeed = 30` (`cellSize = 1`, `turnClearance = 0.35`, `maxConsecutiveRedirects = 8`), crossing each tile in `33.3 ms`. Because velocity goes instantaneously from `0` to `30 u/s` and back to `0` on `StopMoving`, `PlayerSquashStretch` currently applies only a gentle cruise squeeze (`movingWidthPx = 18`, `movingHeightPx = 22`) and misses `OnWallImpact`, directional wall compression, Phase Launch landing follow-through, and dynamic camera breathing. Moreover, `Player/Sprite` sits at `localPosition = (0, -0.5, 0)` with bottom-center `(0.5, 0)` pivot, so naive vertical compression pulls the sprite away from `+Y` ceilings (`wallNormal = (0, -1)`), and buffered turn indicators can strand visually if cleared inside `StepPhaseLaunch` without syncing `SetBufferedTurnIndicator`.

2. **Flat Wall Impacts & Uncoupled Hit-Stop / Particle Configuration**  
   `PlayerImpactFeedback` scales camera shake (`tier1Shake = 0.10`, `tier2Shake = 0.18`, `tier3Shake = 0.32`, `redirectShake = 0.06`) and hit-stop (`tier1HitStop = 0`, `tier2HitStop = 0.033`, `tier3HitStop = 0.083`). However:
   - `WallImpactBurst.prefab` and `WallImpactBreak.prefab` emit along local `+Z` (`ShapeModule type: 4`, `m_Rotation: {0, 0, 0}`) with `useUnscaledTime = 0`, freezing burst particles mid-hit-stop whenever `Time.timeScale = 0`.
   - `Particle Smoke.prefab` has `looping: 1`, `useUnscaledTime: 0`, and `z: 25`, making it unsafe for fire-and-forget `VfxSpawner` spawning without authoring dedicated non-looping one-shot copies.
   - `PlayerImpactFeedback.PulseHitStop` restores `preHitStopTimeScale` blindly without consulting `UIManager.UpdateTimeScale()`, risking unfreezing the Pause modal if opened mid-hit-stop.
   - Neither hit flashes (`Assets/Shaders/Hit/Hit Flash White.mat` + `HitFlashSprite.shader`), URP `Global Volume Profile.asset` kinetic spikes (`Bloom`, `ChromaticAberration`, `Vignette`), Magnetic Brakes (`InteractionKind.Brake` via `GravityBlock` / `BrakeTile`), nor Phase Launch landings (`VectorLauncher`) have dedicated audiovisual payoffs.

3. **Silent Timed-Hazard Telegraphs & Root-Collider Coupling**  
   `HazardActivation` (`HazardCyclePhase`: `Inactive`, `Warning`, `Active` via `OnPhaseChanged`) and `FailingTile` (`FailingTileState`: `Intact`, `Warning`, `Collapsing`, `Collapsed` via `OnStateChanged`) expose clean phase events, yet currently produce zero escalating pulse or pitched warning tick. Critically, `PulseLaser.prefab`, `OverloadedFloor.prefab`, `Hazard.prefab`, and `FailingTile.prefab` currently mount `SpriteRenderer` and `BoxCollider2D` together on root (`m_Children: []` on the first three; `CollapsedPitHazard` child on `FailingTile.prefab`) and directly drive `SpriteRenderer.color` (`HazardActivation.ApplyVisualState`, `FailingTile.ApplyState`, `Hazard.Awake()` `originalSpriteColors`). Scaling or tinting those roots directly would illegally grow active hazard hitboxes and fight gameplay color ownership.

4. **Shared Audio Cooldown Starvation & Unoriented Near-Misses**  
   `SoundManager.PlaySFX(SoundEntry)` currently throttles globally per `AudioClip` (`lastPlayedTimeByClip`) with no `pitchOverride` parameter, causing simultaneous multi-hazard warning ticks or rapid `30 u/s` tile clicks to drop. Meanwhile, `CloseCallDetector.TriggerCloseCall(EntityId hazardId, float now, Vector3 worldPos)` drops the `Hazard` reference at trigger time and defaults in `GameScene.unity` to an unoriented `Particle Star.prefab` (`closeCallVfxPrefab`) with no directional spark arc, ortho punch, or tension stinger.

## 2. Game Feel Pillars

### Pillar 1 — Kinetic Impulse, Anticipation & Pivot-Exact Squash-Stretch

#### Feel & Psychology Rationale
High-velocity puzzle-action feels sluggish when start/stop velocity transitions are mathematically instant without anticipation or follow-through, yet sloppy if input feel loses responsiveness. Visual elasticity on the child `Player/Sprite` preserves sub-frame grid precision (`Player` root `Transform` never diverges from physics) while communicating mass, acceleration, wall crunch, and phase-jump slams. Simultaneously, additive zoom breathing (`orthoPulseOffset` decoupled from steady runway target zoom) gives punches room without fighting speed-tier pull-back.

#### Exact Numbers, Curves & Geometry Rules
- **Launch Snap (`OnMoveStarted`):** Stretch `12 ms` into travel direction over `0.06s` (`Ease.OutCubic`) to `1.18x` along travel axis / `0.86x` perpendicular, settling into tier cruise proportion (`movingWidthPx = 18`, `movingHeightPx = 22`).
- **Redirect Shear (`OnRedirected`):** Crisp `0.84 x 1.20` corner whip over `0.055s` (`Ease.OutQuad`) + optional `-0.08f` ortho punch (`0.12s`).
- **Wall Impact Compression (`OnWallImpact(Vector2 wallNormal)`):**
  `PlayerMovement` passes **inward wall normal** (`-moveDirection` / `stopHit.normal`, e.g., `(0, -1)` at a ceiling, `(-1, 0)` at a right wall). `PlayerSquashStretch` converts this to `Vector2 intoWall = -wallNormal.normalized`.
  Because `Player/Sprite` uses a bottom-center `(0.5, 0)` pivot at `baseLocalPosition = (0, -0.5, 0)`:
  - **Horizontal wall (`|intoWall.x| > 0.5`):** `localPos.x = baseLocalPosition.x + intoWall.x * (baseScale.x * (1f - targetScale.x) * 0.5f + pressUnits)`.
  - **Ceiling (`intoWall.y > 0.5`, `wallNormal = (0, -1)`):** `localPos.y = baseLocalPosition.y + baseScale.y * (1f - targetScale.y) + pressUnits` — locks the squashed top edge flush against the ceiling instead of opening a vertical gap.
  - **Floor (`intoWall.y < -0.5`, `wallNormal = (0, +1)`):** `localPos.y = baseLocalPosition.y - pressUnits`.
  - **Tier compression ratios** (`width x height` local-oriented, `pressUnits = wallPressPx / 32f`):
    - `Drift` (`1–2` tiles): `0.78 x 1.24`, `pressUnits = 0.04f`, `0.055s` compress -> `0.10s` `Ease.OutBack` rebound (`1.04 x 0.96`) -> `0.10s` settle.
    - `Cruise` (`3–4` tiles): `0.72 x 1.32`, `pressUnits = 0.07f`, `0.055s` compress -> `0.11s` `Ease.OutBack` rebound (`1.07 x 0.93`) -> `0.12s` settle.
    - `KineticRam` (`5+` tiles): `0.65 x 1.42`, `pressUnits = 0.11f`, `0.060s` compress -> `0.13s` `Ease.OutBack` rebound (`1.10 x 0.90`) -> `0.14s` settle.
- **Phase Launch & Slam (`OnPhasingChanged`, `OnPhaseLanded`):** In flight, stretch `0.78 x 1.30` along `PhaseFlightDirection` and apply `phaseSpriteTint`. On `OnPhaseLanded`, slam to `0.72 x 1.30` (`0.07s` hold/squash) -> `1.08 x 0.92` (`0.10s`, `Ease.OutBack`) -> `(1, 1)` (`0.12s`), latching `suppressNextStopSquash = true` so same-frame `StopMoving(false)` on zero `phasePostDirection` does not kill the slam tween.
- **Buffered Turn Synchronization:** Every write to `pendingDirection` in `PlayerMovement` routes through `SetPendingDirection(Vector2)`, suppressing chevron glow while `isPhasing` and explicitly clearing `SetBufferedTurnIndicator(Vector2.zero)` on `StartPhaseLaunch` and `StepPhaseLaunch` exit.

// Assets/Scripts/Feedback/CinemachineCameraZoom2D.cs (Decoupled Target + Additive Pulse Offset)
using DG.Tweening;
using Unity.Cinemachine;
using UnityEngine;

public class CinemachineCameraZoom2D : MonoBehaviour
{
    public static CinemachineCameraZoom2D Instance { get; private set; }

    [SerializeField] private float normalOrthographicSize = 5f;
    [SerializeField] private CinemachineCamera cinemachineCamera;
    [SerializeField] private float targetOrthographicSize = 5f;
    [SerializeField, Min(0.1f)] private float zoomSpeed = 4f;
    [SerializeField] private bool enableDynamicZoom = true;

    public float NormalOrthographicSize => normalOrthographicSize;
    public bool EnableDynamicZoom => enableDynamicZoom;

    private float currentBaseOrthoSize;
    private float orthoPulseOffset;
    private Tween pulseTween;

    private void Awake()
    {
        if (Instance != null && Instance != this)
        {
            Destroy(gameObject);
            return;
        }
        Instance = this;

        if (cinemachineCamera == null)
            cinemachineCamera = GetComponent<CinemachineCamera>();

        float initialLens = cinemachineCamera != null ? cinemachineCamera.Lens.OrthographicSize : 5f;
        if (normalOrthographicSize <= 0f) normalOrthographicSize = initialLens;
        if (targetOrthographicSize <= 0f) targetOrthographicSize = normalOrthographicSize;
        currentBaseOrthoSize = targetOrthographicSize;
        ApplyOrthographicSize();
    }

    private void OnDisable()
    {
        pulseTween?.Kill();
        pulseTween = null;
        orthoPulseOffset = 0f;
        ApplyOrthographicSize();
    }

    private void OnDestroy()
    {
        pulseTween?.Kill();
        if (Instance == this) Instance = null;
    }

    private void Update()
    {
        if (cinemachineCamera == null) return;

        bool uiPaused = UIManager.Instance != null && UIManager.Instance.HasFreezeTimePopupOpen;
        float dt = uiPaused ? 0f : Time.unscaledDeltaTime;
        currentBaseOrthoSize = Mathf.Lerp(currentBaseOrthoSize, targetOrthographicSize, 1f - Mathf.Exp(-zoomSpeed * dt));
        ApplyOrthographicSize();
    }

    public void SetTargetOrthographicSize(float targetOrthographicSize)
    {
        this.targetOrthographicSize = Mathf.Max(1f, targetOrthographicSize);
    }

    public void SetNormalOrthographicSize()
    {
        SetTargetOrthographicSize(normalOrthographicSize);
    }

    public void SetNormalOrthographicSize(float size)
    {
        normalOrthographicSize = Mathf.Max(1f, size);
        SetTargetOrthographicSize(normalOrthographicSize);
    }

    public void PulseOrthographicSize(float delta, float duration = 0.14f)
    {
        if (!enableDynamicZoom || cinemachineCamera == null || duration <= 0f) return;

        pulseTween?.Kill();
        orthoPulseOffset = delta;
        ApplyOrthographicSize();

        pulseTween = DOTween.To(
                () => orthoPulseOffset,
                value =>
                {
                    if (!enableDynamicZoom || cinemachineCamera == null) return;
                    orthoPulseOffset = value;
                    ApplyOrthographicSize();
                },
                0f,
                duration)
            .SetEase(Ease.OutQuad)
            .SetUpdate(true)
            .SetLink(gameObject);
    }

    private void ApplyOrthographicSize()
    {
        if (cinemachineCamera == null) return;
        cinemachineCamera.Lens.OrthographicSize = Mathf.Max(1f, currentBaseOrthoSize + orthoPulseOffset);
    }
}

// Assets/Scripts/Feedback/PlayerSquashStretch.cs (Key Additions & Fixed Pivot Impact Math)
private bool suppressNextStopSquash;

// Subscribe / Unsubscribe in OnEnable & OnDisable:
//   movement.OnWallImpact += HandleWallImpact;
//   movement.OnRedirected += HandleRedirected;
//   movement.OnPhaseLanded += HandlePhaseLanded;
// Remember to reset suppressNextStopSquash = false in OnDisable().

private void HandleMoveStarted(Vector2 direction)
{
    suppressNextStopSquash = false;
    lastDirection = direction;
    Vector2 stretchScale = ResolveAxisScale(direction, 0.86f, 1.18f);
    Vector2 cruiseScale = ResolveAxisScale(direction, movingWidthPx / 32f, movingHeightPx / 32f);

    KillActive();
    Sequence seq = DOTween.Sequence().SetUpdate(true).SetLink(gameObject);
    seq.Append(visualTransform.DOScale(ApplyScaleRatio(stretchScale), 0.06f).SetEase(Ease.OutCubic));
    seq.Join(visualTransform.DOLocalMove(baseLocalPosition, 0.06f).SetEase(Ease.OutCubic));
    seq.Append(visualTransform.DOScale(ApplyScaleRatio(cruiseScale), stretchDuration).SetEase(Ease.OutQuad));
    activeSequence = seq;
}

private void HandleRedirected(Vector2 newDirection)
{
    suppressNextStopSquash = false;
    lastDirection = newDirection;
    Vector2 whipScale = ResolveAxisScale(newDirection, 0.84f, 1.20f);
    Vector2 cruiseScale = ResolveAxisScale(newDirection, movingWidthPx / 32f, movingHeightPx / 32f);

    KillActive();
    Sequence seq = DOTween.Sequence().SetUpdate(true).SetLink(gameObject);
    seq.Append(visualTransform.DOScale(ApplyScaleRatio(whipScale), 0.055f).SetEase(Ease.OutQuad));
    seq.Join(visualTransform.DOLocalMove(baseLocalPosition, 0.055f).SetEase(Ease.OutQuad));
    seq.Append(visualTransform.DOScale(ApplyScaleRatio(cruiseScale), 0.08f).SetEase(Ease.OutQuad));
    activeSequence = seq;
}

private void HandleWallImpact(Vector2 wallNormal)
{
    suppressNextStopSquash = false;
    Vector2 intoWall = wallNormal.sqrMagnitude > 0.0001f ? -wallNormal.normalized : lastDirection;
    VelocityTier tier = movement != null ? movement.LastImpactTier : VelocityTier.Drift;

    (float perpWidth, float alongHeight, float pressUnits, float overshoot) = tier switch
    {
        VelocityTier.KineticRam => (1.42f, 0.65f, 0.11f, 0.10f),
        VelocityTier.Cruise     => (1.32f, 0.72f, 0.07f, 0.07f),
        _                       => (1.24f, 0.78f, 0.04f, 0.04f),
    };

    // Compress along travel axis (intoWall) and bulge perpendicular to the wall.
    Vector2 ratio = Mathf.Abs(intoWall.x) > 0.5f
        ? new Vector2(alongHeight, perpWidth)
        : new Vector2(perpWidth, alongHeight);
    Vector3 targetScale = ApplyScaleRatio(ratio);

    // Exact (0.5, 0) bottom-center pivot pinning against wall face:
    Vector3 impactLocalPos = baseLocalPosition;
    if (Mathf.Abs(intoWall.x) > 0.5f)
        impactLocalPos.x += intoWall.x * (baseScale.x * (1f - ratio.x) * 0.5f + pressUnits);
    else if (intoWall.y > 0.5f) // Ceiling impact (wallNormal == (0, -1)): keep top edge flush to +Y ceiling.
        impactLocalPos.y += baseScale.y * (1f - ratio.y) + pressUnits;
    else if (intoWall.y < -0.5f) // Floor impact (wallNormal == (0, +1)): press slightly into floor bevel.
        impactLocalPos.y -= pressUnits;

    Vector3 reboundScale = ApplyScaleRatio(Mathf.Abs(intoWall.x) > 0.5f
        ? new Vector2(1f + overshoot, 1f - overshoot)
        : new Vector2(1f - overshoot, 1f + overshoot));

    KillActive();
    Sequence seq = DOTween.Sequence().SetUpdate(true).SetLink(gameObject);
    seq.Append(visualTransform.DOScale(targetScale, 0.055f).SetEase(Ease.OutQuad));
    seq.Join(visualTransform.DOLocalMove(impactLocalPos, 0.055f).SetEase(Ease.OutQuad));
    seq.Append(visualTransform.DOScale(reboundScale, 0.10f).SetEase(Ease.OutBack));
    seq.Join(visualTransform.DOLocalMove(baseLocalPosition, 0.10f).SetEase(Ease.OutQuad));
    seq.Append(visualTransform.DOScale(baseScale, 0.11f).SetEase(returnEase));
    activeSequence = seq;
}

private void HandlePhaseLanded(Vector2 flightDir)
{
    suppressNextStopSquash = true;
    Vector2 ratio = Mathf.Abs(flightDir.x) > Mathf.Abs(flightDir.y)
        ? new Vector2(0.72f, 1.30f)
        : new Vector2(1.30f, 0.72f);

    KillActive();
    Sequence seq = DOTween.Sequence().SetUpdate(true).SetLink(gameObject);
    seq.Append(visualTransform.DOScale(ApplyScaleRatio(ratio), 0.07f).SetEase(Ease.OutQuad));
    seq.Join(visualTransform.DOLocalMove(baseLocalPosition, 0.07f).SetEase(Ease.OutQuad));
    seq.Append(visualTransform.DOScale(ApplyScaleRatio(new Vector2(1.08f, 0.92f)), 0.10f).SetEase(Ease.OutBack));
    seq.Append(visualTransform.DOScale(baseScale, 0.12f).SetEase(returnEase));
    activeSequence = seq;
}

private void HandleMoveStopped()
{
    if (suppressNextStopSquash)
    {
        suppressNextStopSquash = false;
        return;
    }
    Deform(new Vector2(impactWidthPx / 32f, impactHeightPx / 32f), squashDuration);
}

### Pillar 2 — Kinetic Tier Payoff, Pause-Safe Hit-Stop & Impact Hierarchy

#### Feel & Psychology Rationale
Players read slide length subconsciously when collisions, breaks, magnetic anchors, and phase landings form a distinct tactile hierarchy. Every tier must remain **unscaled-time safe** (`Time.timeScale == 0` during hit-stop must not freeze VFX particles or camera impulses), **Pause-safe** (never overriding `UIManager.UpdateTimeScale()`), and **Speedrun-safe** (respecting `hitStopEnabled`).

private void HandleStopped()
{
    if (suppressNextStopImpact)
    {
        suppressNextStopImpact = false;
        return;
    }

    // Preserves existing tier-scaled ShakeCamera & PulseHitStop on standard stops.
    VelocityTier tier = movement != null ? movement.LastImpactTier : VelocityTier.Drift;
    float shake = tier switch
    {
        VelocityTier.KineticRam => tier3Shake,
        VelocityTier.Cruise     => tier2Shake,
        _                       => tier1Shake,
    };
    if (shake > 0f) CinemachineCameraShake2D.Instance?.ShakeCamera(shake);

    float stop = tier switch
    {
        VelocityTier.KineticRam => tier3HitStop,
        VelocityTier.Cruise     => tier2HitStop,
        _                       => tier1HitStop,
    };
    if (stop > 0f) PulseHitStop(stop);
}

private void HandleWallImpact(Vector2 normal)
{
    if (normal == Vector2.zero || movement == null) return;

    VelocityTier tier = movement.LastImpactTier;
    Vector3 contact = movement.LastImpactPoint;
    Quaternion rotation = Quaternion.LookRotation((Vector3)normal);

    if (impactBurstPrefab != null)
        ParticleSpawner.SpawnEffect(impactBurstPrefab, contact, rotation);
    if (impactAnimationPrefab != null)
        PrefabAnimationSpawner.SpawnEffect(impactAnimationPrefab, contact, rotation);

        return;

    preHitStopTimeScale = Time.timeScale;

private readonly struct ClipChannelKey : IEquatable<ClipChannelKey>
{
    public readonly AudioClip Clip;
    public readonly int ChannelId;

    public ClipChannelKey(AudioClip clip, int channelId)
    {
        Clip = clip;
        ChannelId = channelId;
    }

    public bool Equals(ClipChannelKey other) => Clip == other.Clip && ChannelId == other.ChannelId;
    public override bool Equals(object obj) => obj is ClipChannelKey other && Equals(other);
    public override int GetHashCode() => unchecked(((Clip != null ? Clip.GetInstanceID() : 0) * 397) ^ ChannelId);
}

private readonly Dictionary<ClipChannelKey, float> lastPlayedByChannel = new Dictionary<ClipChannelKey, float>();

public void PlaySFX(SoundEntry entry) => PlaySFX(entry, null, 0);

public void PlaySFX(SoundEntry entry, float? pitchOverride, int throttleChannelId)
{
    AudioClip clip = entry.GetRandomClip();
    if (clip == null) return;

    float minInterval = Mathf.Max(0.01f, entry.minInterval);
    float now = Time.unscaledTime;
    ClipChannelKey key = new ClipChannelKey(clip, throttleChannelId);

    if (lastPlayedByChannel.TryGetValue(key, out float lastTime) && (now - lastTime) < minInterval)
        return;

    lastPlayedByChannel[key] = now;
    float resolvedPitch = pitchOverride ?? entry.GetResolvedPitch();
    PlayResolvedClip(clip, entry.GetResolvedVolume(), resolvedPitch);
}

        CloseCallDetector.OnCloseCallDetailsTriggered += HandleCloseCall;
    }

    private void OnDisable()
    {
        CloseCallDetector.OnCloseCallDetailsTriggered -= HandleCloseCall;
    }

    private void HandleCloseCall(Vector3 playerPos, Vector3 hazardPos)
    {
        Vector3 delta = playerPos - hazardPos;
        Vector3 dir = delta.sqrMagnitude > 0.0001f ? delta.normalized : Vector3.up;
        Vector3 midpoint = (playerPos + hazardPos) * 0.5f;

        if (directionalSparkPrefab != null)
        {
            Quaternion rot = sparkUsesZForwardCone ? Quaternion.LookRotation(dir) : Quaternion.identity;
            VfxSpawner.Spawn(directionalSparkPrefab, midpoint, rot);
        }

        CinemachineCameraShake2D.Instance?.ShakeCamera(microShakeForce);
        CinemachineCameraZoom2D.Instance?.PulseOrthographicSize(orthoPunchDelta, 0.12f);
        velocityRunwayFeedback?.PulseVolumeSpike(0.22f, 0.14f);
    }
}
