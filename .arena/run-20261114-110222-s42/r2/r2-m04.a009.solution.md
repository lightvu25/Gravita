# Gravita — Game Feel Upgrade Blueprint

> Tài liệu chẩn đoán và thiết kế nâng cấp Game Feel cho **Gravita** (`Puzzle 2D` — Unity 6000.4.0f1 URP, 2D Top-Down, `32 PPU`), bám sát cấu hình runtime trong `Assets/Scenes/GameScene.unity`, các prefab trong `Assets/Prefabs/Gameplay/` + `Assets/Prefabs/Particles/`, và kiến trúc sự kiện 4 tầng của dự án.

### Giả Định & Cấu Hình Nền (Assumptions & Baseline)
1. **Động học trượt chuẩn**: `PlayerMovement` trong `Assets/Scenes/GameScene.unity` đang đặt `moveSpeed = 30` (**33.3 ms / ô** ở `cellSize = 1`), `bufferTurnsUntilStop = 1`, `maxConsecutiveRedirects = 8`. Ngưỡng tier thực tế trong `Assets/Scripts/Gameplay/VelocityTier.cs` là `Drift` (1–2 ô), `Cruise` (3–4 ô), `KineticRam` (5+ ô). Mọi timing được neo theo vận tốc này (`33.3–66.7 ms` cho `Drift`, `100–133.3 ms` cho `Cruise`, `>= 166.7 ms` cho `KineticRam`, và `48` u/s khi `PhaseLaunch` `1.6x`).
2. **Kho âm thanh hiện tại**: `Assets/Data/Sound/SoundConfig.asset` đang để trống (`clips: []`) ở toàn bộ entry gameplay và UI dù `Assets/Audio/Sounds/` đã có sẵn các gói SFX (Shapeforms & 400 Sounds Pack). Các bảng âm thanh bên dưới quy định rõ cách gán clip và phân phối kênh.
3. **Tách bạch Hit-Stop & UI Modal Pause**:
   - Tùy chọn `PlayerImpactFeedback.hitStopEnabled` (`Speedrun Minimal`) phải luôn được tôn trọng.
   - Trong `GameScene.unity`, các popup `Pause` (`4`), `Result` (`5`), `Revive` (`14`), `Multiplayer` (`16`), `BlindBox` (`17`) serialize `freezeTime: 1`, nên `UIManager.UpdateTimeScale()` đặt `Time.timeScale = 0f`. Mọi cơ chế unscaled phục vụ Hit-Stop **tuyệt đối không được ghi đè `Time.timeScale = 1f` khi `UIManager.IsTimeFrozen == true`** và phải đóng băng sạch camera, particle, tween lẫn post-processing khi modal Pause/Revive/Result mở.
4. **Bảo toàn Pixel-Perfect & Vật lý Lưới**: Camera phải tương thích với `PixelPerfectCamera` (`m_AssetsPPU: 32`, `320x180`, `GridSnapping: PixelSnapping`) trên `Main Camera`; mọi hiệu ứng trình diễn không bao giờ chỉnh sửa `FixedUpdate`, `Rigidbody2D`, hay `Collider2D` gốc.

## 1. Chẩn Đoán Cốt Lõi: Vì Sao Gravita Hiện Tại Vẫn Cảm Thấy "Phẳng"?

Gravita đã có nền tảng cơ bản (`PlayerImpactFeedback`, `PlayerSquashStretch`, `PlayerLineTrail`, `CinemachineCameraShake2D`, `GameplayHapticsFeedback`, `CloseCallDetector`), nhưng cảm giác điều khiển bị "lì" và thiếu độ cuốn vì **5 nút thắt kiến trúc cảm giác**:

1. **Động học 33.3 ms/ô, cấu trúc pivot đáy & khoảng trống unscaled lúc Hit-Stop**:
   - Với `moveSpeed = 30`, cú trượt `Drift` (2 ô) chỉ kéo dài **67 ms**, còn `KineticRam` (5 ô) đạt tới ở **167 ms**. Trong khi đó `PlayerSquashStretch` dùng `stretchDuration = 0.18f` (`180 ms`) và tự hồi về `baseScale` ở 40% thời lượng (`72 ms`), nên Subject G-0 chưa kịp giữ dáng khí động học đã xẹp lại giữa hành lang.
   - `Player Icon.aseprite` (`32x32` @ `32 PPU`) đặt pivot đáy `(0.5, 0)` với `Player/Sprite` tại `localPosition = (0, -0.5, 0)`, còn `PlayerCosmeticApplier` có thể đổi `spriteRenderer.sprite` sau `Awake()`. Nếu không tính toán điểm neo mặt va chạm theo `spriteRenderer.sprite.bounds` (`bounds.center + sign(dir) * bounds.extents`), mọi pha ép dẹt (kể cả giữ nguyên `pivotComp` quanh tâm) sẽ kéo mép va đập tụt khỏi tường/trần/trái/phải. Đồng thời `GameScene.unity` đang kẹp `PlayerSquashStretch.maxDeformation = 0.3`.
   - `PlayerImpactFeedback.HandleStopped()` bắn rung/hit-stop cả khi `WasLastStopWallImpact == false` (dính cả `Freeze()` khi chết bẫy và `TeleportTo()` lúc reset màn), nhưng trong lúc đóng băng `Time.timeScale = 0`, `CinemachineBrain` (`IgnoreTimeScale: 0`), `CinemachineImpulseManager`, `PlayerLineTrail.LateUpdate()`, lẫn các particle prefab `WallImpactBurst.prefab` & `WallImpactBreak.prefab` (`useUnscaledTime: 0`) lại đứng hình hoàn toàn. Còn `CrackedBlock` vỡ khi `KineticRam` húc xuyên (`Cracked.prefab` `defaultCameraShake = 0`) hoàn toàn im ắng, ngược lại cần chặn kỹ để chiêu `Breaker` từ xa (`PowerUpController.ActivateBreaker`) không kích nhầm hit-stop/nhá trắng lên nhân vật.

2. **Camera & Post-Processing bất động (và bẫy `CinemachinePixelPerfect` + `SetTargetOrthographicSize`)**:
   - `CinemachineCameraZoom2D` có sẵn trên `CinemachineCamera` (`normalOrthographicSize: 5.5`) nhưng không được gọi từ đâu cả. Trên `Main Camera`, `PixelPerfectCamera` + `CinemachinePixelPerfect` làm tròn FOV nghỉ về bội số nguyên (`CorrectCinemachineOrthoSize(5.5f) = 5.625f` tại `1280x720` và `1920x1080`). Nếu không tách `GetSnappedNormalOrthoSize()` (luôn chuẩn hóa từ `normalOrthographicSize`) khỏi `targetOrthographicSize`, việc gọi `SetTargetOrthographicSize(...)` sẽ giật/kẹp ống kính sai. Ngoài ra `CinemachinePositionComposer.TargetOffset` đang tắt và `Global Volume Profile.asset` giữ tĩnh `ChromaticAberration = 0.20`, `Vignette = 0.40`, `postExposure = -0.40`.

3. **Âm thanh phẳng, xung đột hợp đồng `StartPhaseLaunch` / `Redirect` và thiếu thang leo hòa âm**:
   - `PlayerMovement.StartPhaseLaunch` gọi `EnforceMinimumTier(minTier)` (bắn `OnTileCrossed` và `OnVelocityTierChanged`) **trước** `SetPhasing(true)` — và nếu quãng bay `<= 0.0001f` thì bỏ qua `SetPhasing(true)`, bắn `OnRedirected` rồi `OnMoveStarted`; tương tự launch không phase cũng gọi `EnforceMinimumTier` + `Redirect`. Nếu `EntityAudio` không phân biệt cờ chuyển trạng thái launch từ `PlayerMovement`, một cú dẫm `VectorLauncher` sẽ phát chồng 3 SFX (`tileCrossTick` + `tierKineticCharge` + `phaseLaunch`) hoặc phát nhầm hợp âm `wedgeRedirect`.
   - `SoundManager.cs` hiện chưa có overload nhận `pitchMultiplier` (chỉ `AudioPitchUtility.GetRandomPitch` kẹp biến thiên ngẫu nhiên `0.1f..3f`), và `OnTileCrossed`, `OnVelocityTierChanged`, `OnPhasingChanged` đang không có subscriber âm thanh.

4. **Hệ thống đặt lệnh trước (`bufferTurnsUntilStop = true`) hoàn toàn vô hình**:
   - Ở tốc độ `30` ô/giây, người chơi liên tục đặt lệnh cua trước khi tới tường, nhưng `PlayerMovement.pendingDirection` không phát sự kiện để báo "lệnh đã khóa vào hàng đợi".

5. **Detector cận tử bỏ ngỏ & Bề mặt mê cung đứng im**:
   - `CloseCallDetector.OnCloseCallTriggered` có **0 subscriber** âm thanh/camera/post-process/haptics.
   - `PlayerLineTrail` kẹp `smoothedMoveSpeed` ở `28f` (thấp hơn `moveSpeed = 30` và `PhaseLaunch = 48`).
   - Đa số prefab tile (`Wedge.prefab`, `Brake.prefab`, `EnergyGate.prefab`, `FailingTile.prefab`, `GravityBlock.prefab`) đặt `SpriteRenderer` chung root với `Collider2D` (chỉ `VectorPad.prefab` có child `Visual`), nên mọi tween biến dạng đều phải cách ly nghiêm ngặt khỏi transform có collider. Hơn nữa `EnergyGate` có cơ chế `pendingDeferredClose` (phát `OnGateOpenStateChanged(false)` sớm dù cửa vẫn mở vật lý chờ người chơi thoát ô), còn `FailingTile` chạy theo `LevelClock` (scaled time) nên feedback tile phải đồng bộ chính xác với cả `LevelClock` lẫn trạng thái khóa thời gian của `UIManager`.

## 2. Năm Trụ Cột Game Feel Đặc Trưng Cho Gravita

### Trụ Cột 1: Động Lực Học Bất Đối Xứng ("Snap-Hold-Release" Neo Mặt Va Chạm + Hit-Stop An Toàn Modal & Húc Vỡ `CrackedBlock`)

#### Tại sao khiến Gravita cuốn và độc nhất?
Bản sắc của Gravita là **trượt thẳng không kiểm soát — dồn động năng qua từng ô — va đập cực gắt hoặc kẹp dừng từ trường**. Khi Subject G-0 **giữ dáng kéo giãn tăng dần theo 3 Velocity Tier suốt pha bay**, tự động **neo đúng mép mặt va chạm** theo `sprite.bounds` thực tế (kể cả khi đổi skin từ `PlayerCosmeticApplier`) để ép dẹt **khít 0.000-unit ở cả 4 hướng tường**, đồng thời giữ cho **camera shake + white hit-flash + vệt đuôi + particle va đập tiếp tục chạy mượt ngay trong `33–83 ms` Hit-Stop** mà vẫn **ngắt/đóng băng sạch khi mở Pause/Revive/Result**, mỗi cú va chạm mang trọng lượng pít-tông cực kỳ dứt khoát.

#### Thông số & Curve
- **Giữ dáng khí động học theo Tier (`.SetUpdate(true)` trên `visualTransform`, tâm `sprite.bounds.center` giữ nguyên ở `(0, 0)`)**:
  - `Drift` (1–2 ô): scale dọc hướng trượt `+8%`, ép ngang `-4%`, thời gian vào dáng `0.028s` (`Ease.OutCubic`).
  - `Cruise` (3–4 ô): `+16% / -8%`, `0.032s`.
  - `KineticRam` (5+ ô): `+25% / -13%`, `0.035s`.
  - `IsPhasing` (`VectorLauncher`): `+32% / -16%` (yêu cầu `maxDeformation >= 0.45`).
- **Neo mặt va chạm 4 hướng (`CompensatedLocalPosition`)**:
  - Với mọi sprite bất kỳ (mặc định `32x32` @ `32 PPU`, pivot `(0.5, 0)`, `center = (0, 0.5)`, `extents = (0.5, 0.5)`), trục song song hướng va chạm neo tại `anchorAxis = bounds.center + Mathf.Sign(impactDir) * bounds.extents`, còn trục vuông góc neo tại `bounds.center`. Công thức `baseLocalPosition + Vector3.Scale(baseScale - targetScale, anchor) + pressOffset` đảm bảo mép mũi tiếp xúc giữ chặt tọa độ `±0.5` trên cả 4 hướng (`down`/`up`/`left`/`right`) ở mọi Tier, rồi `pressOffset` ấn lún thêm vào trong tường (`Drift`: `0.35 * wallPressPx`, `Cruise`: `0.75 * wallPressPx`, `KineticRam`: `1.12 * wallPressPx`, chia cho `sprite.pixelsPerUnit`).
- **Tách rạch ròi Wall Impact vs Magnetic Brake vs `Freeze()`/`TeleportTo()`**:
  - `PlayerImpactFeedback.HandleStopped()` chỉ xử lý va tường thật (`movement.WasLastStopWallImpact == true`):
    - `Drift`: shake `0.05f`, hit-stop `0s`, nén `-12% / +12%`, hồi `0.11s`.
    - `Cruise`: shake `0.12f`, hit-stop `0.033s`, nén `-24% / +24%`, hồi `0.14s`, nhá `Hit Flash White.mat` trong `0.033s` realtime.
    - `KineticRam`: shake `0.24f`, hit-stop `0.083s`, snap nén `-43% / +40%` (`16/28 - 1`, `28/20 - 1`, trong giới hạn `maxDeformation = 0.45`) trong `0.015s` để giữ nguyên dáng dẹt suốt pha đóng băng, hồi `0.165s` (`Ease.OutBack`), nhá `Hit Flash White.mat` trong `0.055s` realtime.
  - Phanh từ (`BrakeTile` / `GravityBlock`): chuyển sang lắng nghe `MazeTile.OnAnyPlayerInteracted` (`InteractionKind.Brake`) — chỉ bắn `magneticBrakeShake = 0.03f` (nếu prefab tile không tự cấu hình `InteractionEffectPlayer.HasConfiguredShake`). `Freeze()`, `TeleportTo()`, `ResetLevel()`, và dừng `PhaseLaunch` không còn bắn nhầm rung phanh hay ép nén khi đứng yên (nhờ cờ `wasMovingVisual` trên `PlayerSquashStretch`).
- **Húc vỡ `CrackedBlock` (`CrackedBlock.WasBrokenByCrush`)**:
  - Phân biệt `TryCrush` (`WasBrokenByCrush = true`) với `PowerUpController.ActivateBreaker()` / `Break()` (`WasBrokenByCrush = false`). Chỉ khi `WasBrokenByCrush == true`, `PlayerImpactFeedback` mới bắn `blockBreakShake = 0.16f` (nhường nếu prefab có custom shake), `blockBreakHitStop = 0.042s`, và `kineticFlashDuration = 0.055s` (kèm `cooldown = 0.05s`). Dùng chiêu `Breaker` từ xa không kích hoạt hit-stop hay nhá trắng lên nhân vật.
- **Hit-Stop an toàn Modal & Particle Unscaled (`UIManager.IsTimeFrozen`)**:
  - `UIManager` công bố `IsTimeFrozen` (`UpdateTimeScale()` dùng chung đúng hàm này).
  - `PlayerImpactFeedback` không vào Hit-Stop nếu `UIManager.Instance.IsTimeFrozen == true`; tạm bật `cinemachineBrain.IgnoreTimeScale = true` và `CinemachineImpulseManager.Instance.IgnoreTimeScale = true` **chỉ trong phạm vi Hit-Stop** và khôi phục cả hai giá trị gốc trong `EndHitStopImmediate(...)`. Khi `UIManager.OnPopupStackChanged` báo `IsTimeFrozen == true` giữa lúc đang Hit-Stop (ví dụ mở `Pause`, hoặc dính bẫy vào `Revive`/`Result` ngay sau cú vỡ gạch), `EndHitStopImmediate(restoreTimeScale: false)` hủy ngay Hit-Stop, trả `IgnoreTimeScale`, tắt nhá trắng và **giữ nguyên `Time.timeScale = 0f` thuộc quyền `UIManager`**.
  - `WallImpactBurst.prefab` & `WallImpactBreak.prefab` bật `ParticleSystem.main.useUnscaledTime = 1`; đồng thời `ReturnToPool` (gắn trên 2 prefab này) và `PooledParticlePlayer.MonitorParticlesRoutine()` dùng unscaled timing khi chạy hệ hạt unscaled nhưng tự `.Pause()` hệ hạt unscaled nếu `UIManager.IsTimeFrozen == true` (`!IsHitStopActive`).
- **LineTrail**: `PlayerLineTrail.LateUpdate()` chỉ đọc `Time.unscaledDeltaTime` khi `PlayerImpactFeedback.IsHitStopActive == true` (đóng băng sạch khi Pause) và nâng kẹp vận tốc `28f -> 52f`.

#### Tại sao khiến Gravita cuốn và độc nhất?
Ở tốc độ `30` ô/giây, tầm nhìn hành lang là sinh mạng. Khi camera **mở nhẹ ống kính ra lúc Subject G-0 đạt `Cruise`/`KineticRam`**, người chơi vừa cảm nhận gia tốc qua thị giác ngoại vi vừa đọc được bẫy/wedge xa hơn; ngay khoảnh khắc đâm `KineticRam` hoặc húc vỡ `CrackedBlock`, camera **giật zoom `-0.24` ortho kèm xung `ChromaticAberration`** tạo ra cảm giác "nện pít-tông" nặng nề không thể nhầm lẫn.

#### Thông số & Curve
- **Ortho Zoom tương thích `PixelPerfectCamera` + `CinemachinePixelPerfect` + API `SetTargetOrthographicSize`**:
  - Vì `GameScene.unity` dùng `PixelPerfectCamera` (`32 PPU`, `320x180`, `GridSnapping = PixelSnapping`) và `normalOrthographicSize = 5.5`, ở trạng thái nghỉ `CinemachinePixelPerfect` làm tròn FOV về bội số nguyên `snappedNormalOrtho = pixelPerfectCamera.CorrectCinemachineOrthoSize(normalOrthographicSize)` (bằng `5.625` tại `1280x720` và `1920x1080`).

  - Offset theo trạng thái (cộng lên base):
    - `Drift`: `+0.00`.
    - `Cruise`: `+0.16` (`zoomSpeed = 8`).
    - `KineticRam`: `+0.38` (`zoomSpeed = 10`).

    - **Cận tử `CloseCallDetector`**: punch `-0.14` (`decaySpeed = 15`).
- **Lookahead chủ động qua `CinemachinePositionComposer.TargetOffset`**:

```csharp
            default:
                cameraZoom?.SetSustainedZoomOffset(0f, 8f);
                targetLookaheadOffset = Vector3.zero;
                targetSustainedChromatic = baseChromaticAberration;
                break;

    }

    private void ApplyVolumeValues()
    {

            chromaticAberration.intensity.value = Mathf.Max(targetSustainedChromatic, baseChromaticAberration) + transientChromatic;

        if (vignette != null)
            vignette.intensity.value = baseVignette + transientVignette;

        if (colorAdjustments != null)
            colorAdjustments.postExposure.value = basePostExposure + transientExposure;
    }

    private void ResetRigImmediate()
    {
        targetLookaheadOffset = Vector3.zero;
        targetSustainedChromatic = baseChromaticAberration;
        transientChromatic = 0f;
        transientVignette = 0f;
        transientExposure = 0f;

        if (positionComposer != null) positionComposer.TargetOffset = Vector3.zero;
        ApplyVolumeValues();
        cameraZoom?.SetSustainedZoomOffset(0f, 12f);
    }
```

### Trụ Cột 4: Tín Hiệu Đặt Lệnh Trước Khi Cua (`BufferedTurnTelegraph` — Phản Hồi Xúc Giác Kiểu Rhythm-Action)

#### Tại sao khiến Gravita cuốn và độc nhất?
Vì `bufferTurnsUntilStop = true` và mỗi đoạn trượt chỉ mất `67–200 ms`, cảm giác "bấm trước nhịp" giống hệt game nhịp điệu (*Tomb of the Mask* kết hợp *Hotline Miami*). Khi người chơi vuốt/nhấn hướng kế tiếp lúc đang trượt, một mũi tên neo khóa sáng rực bật ra từ sườn Subject G-0 kèm cú "tách" giòn ở tay và màn hình (`55 ms` pop), rồi **bung nổ khi tiêu thụ thành công vào làn mới** (hoặc **co rụt lại nếu bị tường chặn**), giúp não bộ xác nhận độ nhạy điều khiển `100%`.

#### Thông số & Curve
- **Phơi bày trạng thái & sự kiện read-only trong `PlayerMovement.cs`**:
  - `PendingDirection` + `OnPendingDirectionChanged(Vector2)` qua `SetPendingDirection(Vector2)` (kèm `IsTransitioningLaunch` + `ExecuteRedirectLaunch(...)` phục vụ Trụ Cột 3).

Bảo toàn 100% vật lý `FixedUpdate`.
- **Mũi tên đặt trước (`BufferedTurnTelegraph`)**:

```csharp
using System.Collections;
using DG.Tweening;
using UnityEngine;

/// <summary>
/// Reusable prefab-attached visual response for DeflectionWedge, VectorPad, BrakeTile,
/// GravityBlock, FailingTile, and EnergyGate. Strictly isolates Transform deformation to a
/// collider-free child Visual and syncs tween/flash lifecycles with UIManager modal freezes.
/// </summary>
public class TilePulseFeedback : MonoBehaviour
{
    [Header("Visual Target (Must Be a Collider-Free Child for Scale/Shake)")]
    [SerializeField] private Transform visualTarget;
    [SerializeField] private SpriteRenderer spriteRenderer;

    [Header("Optional Hit Flash")]
    [SerializeField] private Material flashMaterial;
    [SerializeField, Min(0f)] private float flashDuration = 0.045f;

    private IPlayerInteractable interactable;
    private FailingTile failingTile;
    private EnergyGate energyGate;

    private bool hasSafeVisualTarget;
    private Vector3 baseScale = Vector3.one;
    private Vector3 baseLocalPos = Vector3.zero;
    private Material cachedMaterial;
    private Coroutine flashRoutine;
    private bool isFlashing;
    private bool modalSubscribed;
    private Tween activeTween;

    private void Awake()
    {
        if (!IsSafeVisualTransform(visualTarget))
            visualTarget = FindSafeVisualChild();

        hasSafeVisualTarget = IsSafeVisualTransform(visualTarget);
        if (hasSafeVisualTarget)
        {
            baseScale = visualTarget.localScale;
            baseLocalPos = visualTarget.localPosition;
        }

        if (spriteRenderer == null)
        {
            spriteRenderer = hasSafeVisualTarget
                ? visualTarget.GetComponentInChildren<SpriteRenderer>(true)
                : GetComponentInChildren<SpriteRenderer>(true);
        }

        interactable = GetComponent<IPlayerInteractable>();
        failingTile = GetComponent<FailingTile>();
        energyGate = GetComponent<EnergyGate>();
    }

    private void Start()
    {
        BindModalEvents();
    }

    private void OnEnable()
    {
        BindModalEvents();
        if (interactable != null) interactable.OnPlayerInteracted += HandleInteracted;
        if (failingTile != null) failingTile.OnStateChanged += HandleFailingStateChanged;
        if (energyGate != null) energyGate.OnPhysicalOpenStateChanged += HandleGatePhysicalStateChanged;
    }

    private void OnDisable()
    {
        UnbindModalEvents();
        if (interactable != null) interactable.OnPlayerInteracted -= HandleInteracted;
        if (failingTile != null) failingTile.OnStateChanged -= HandleFailingStateChanged;
        if (energyGate != null) energyGate.OnPhysicalOpenStateChanged -= HandleGatePhysicalStateChanged;

        KillTweens();
        StopFlashImmediate();
        if (hasSafeVisualTarget && visualTarget != null)
        {
            visualTarget.localScale = baseScale;
            visualTarget.localPosition = baseLocalPos;
        }
    }

    private void OnDestroy()
    {
        UnbindModalEvents();
        KillTweens();
        StopFlashImmediate();
    }

    private void HandleInteracted(InteractionContext ctx)
    {
        switch (ctx.Kind)
        {
            case InteractionKind.Deflect:
                if (hasSafeVisualTarget)
                {
                    Vector3 stretch = Mathf.Abs(ctx.Direction.x) >= Mathf.Abs(ctx.Direction.y)
                        ? new Vector3(baseScale.x * 1.22f, baseScale.y * 0.84f, baseScale.z)
                        : new Vector3(baseScale.x * 0.84f, baseScale.y * 1.22f, baseScale.z);
                    PlayScalePulse(stretch, 0.04f, 0.10f);
                }
                TriggerFlash();
                break;

            case InteractionKind.Brake:
                if (hasSafeVisualTarget)
                    PlayScalePulse(baseScale * 1.18f, 0.035f, 0.09f);
                TriggerFlash();
                break;

            case InteractionKind.Launch:
                if (hasSafeVisualTarget)
                    PlayScalePulse(baseScale * 1.26f, 0.04f, 0.11f);
                TriggerFlash();
                break;
        }
    }

    private void HandleFailingStateChanged(FailingTileState state)
    {
        if (!hasSafeVisualTarget)
        {
            if (state == FailingTileState.Warning || state == FailingTileState.Collapsing)
                TriggerFlash();
            return;
        }

        KillTweens();
        switch (state)
        {
            case FailingTileState.Warning:
                visualTarget.localPosition = baseLocalPos;
                visualTarget.localScale = baseScale;
                TrackTween(visualTarget.DOShakePosition(0.55f, new Vector3(0.035f, 0.02f, 0f), 26, 90f, false, false)
                    .SetUpdate(true)
                    .SetLink(gameObject));
                break;

            case FailingTileState.Collapsing:
                visualTarget.localPosition = baseLocalPos;
                TrackTween(visualTarget.DOScale(baseScale * 0.65f, 0.25f)
                    .SetEase(Ease.InBack)
                    .SetUpdate(true)
                    .SetLink(gameObject));
                break;

            case FailingTileState.Collapsed:
                visualTarget.localPosition = baseLocalPos;
                visualTarget.localScale = baseScale * 0.65f;
                break;

            default:
                visualTarget.localPosition = baseLocalPos;
                visualTarget.localScale = baseScale;
                break;
        }
    }

    private void HandleGatePhysicalStateChanged(bool isOpen)
    {
        if (!hasSafeVisualTarget)
        {
            TriggerFlash();
            return;
        }

        KillTweens();
        Vector3 start = isOpen
            ? new Vector3(baseScale.x * 1.15f, baseScale.y * 0.75f, baseScale.z)
            : new Vector3(baseScale.x * 0.85f, baseScale.y * 1.25f, baseScale.z);
        visualTarget.localScale = start;
        TrackTween(visualTarget.DOScale(baseScale, 0.12f)
            .SetEase(Ease.OutBack)
            .SetUpdate(true)
            .SetLink(gameObject));
        TriggerFlash();
    }

    private void PlayScalePulse(Vector3 peakScale, float inDur, float outDur)
    {
        if (!hasSafeVisualTarget || visualTarget == null) return;
        KillTweens();
        TrackTween(DOTween.Sequence()
            .Append(visualTarget.DOScale(peakScale, inDur).SetEase(Ease.OutQuad))
            .Append(visualTarget.DOScale(baseScale, outDur).SetEase(Ease.OutBack))
            .SetUpdate(true)
            .SetLink(gameObject));
    }

    private void TrackTween(Tween tween)
    {
        activeTween = tween;
        SyncTweenWithModalFreeze();
    }

    private void TriggerFlash()
    {
        if (spriteRenderer == null || flashMaterial == null || flashDuration <= 0f) return;
        if (IsModalTimeFrozen()) return;
        if (!isFlashing) cachedMaterial = spriteRenderer.sharedMaterial;
        if (flashRoutine != null) StopCoroutine(flashRoutine);
        flashRoutine = StartCoroutine(FlashRoutine());
    }

    private IEnumerator FlashRoutine()
    {
        isFlashing = true;
        if (cachedMaterial != flashMaterial) spriteRenderer.sharedMaterial = flashMaterial;
        yield return new WaitForSecondsRealtime(flashDuration);
        RestoreMaterial();
        flashRoutine = null;
    }

    private void StopFlashImmediate()
    {
        if (flashRoutine != null)
        {
            StopCoroutine(flashRoutine);
            flashRoutine = null;
        }
        RestoreMaterial();
    }

    private void RestoreMaterial()
    {
        if (!isFlashing || spriteRenderer == null) return;
        if (cachedMaterial != null) spriteRenderer.sharedMaterial = cachedMaterial;
        isFlashing = false;
    }

    private void KillTweens()
    {
        if (activeTween != null && activeTween.IsActive()) activeTween.Kill();
        activeTween = null;
        if (hasSafeVisualTarget && visualTarget != null) visualTarget.DOKill();
    }

    private void BindModalEvents()
    {
        if (modalSubscribed || UIManager.Instance == null) return;
        UIManager.Instance.OnPopupStackChanged += HandlePopupStackChanged;
        modalSubscribed = true;
    }

    private void UnbindModalEvents()
    {
        if (!modalSubscribed) return;
        if (UIManager.Instance != null)
            UIManager.Instance.OnPopupStackChanged -= HandlePopupStackChanged;
        modalSubscribed = false;
    }

    private void HandlePopupStackChanged()
    {
        SyncTweenWithModalFreeze();
        if (IsModalTimeFrozen())
            StopFlashImmediate();
    }

    private void SyncTweenWithModalFreeze()
    {
        if (activeTween == null || !activeTween.IsActive()) return;
        if (IsModalTimeFrozen()) activeTween.Pause();
        else activeTween.Play();
    }

    private static bool IsModalTimeFrozen() => UIManager.Instance != null && UIManager.Instance.IsTimeFrozen;

    private Transform FindSafeVisualChild()
    {
        SpriteRenderer[] renderers = GetComponentsInChildren<SpriteRenderer>(true);
        for (int i = 0; i < renderers.Length; i++)
        {
            if (renderers[i] != null && IsSafeVisualTransform(renderers[i].transform))
                return renderers[i].transform;
        }
        return null;
    }

    private bool IsSafeVisualTransform(Transform candidate)
    {
        return candidate != null
            && candidate != transform
            && candidate.GetComponent<Collider2D>() == null
            && candidate.GetComponentInChildren<Collider2D>(true) == null;
    }
}
```
