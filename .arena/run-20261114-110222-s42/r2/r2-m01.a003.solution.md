# Gravita (Puzzle 2D) — Game Feel Signature Architecture & Implementation Blueprint

## 1. Executive Vision & Engineering Contract

Gravita is a grid-locked kinetic puzzle game where one directional flick turns the player cube into a high-momentum projectile ricocheting off wedges, crushing through cracked walls, skimming past lethal hazards, and halting cleanly on brakes, gravity wells, or phase exits. Because grid step logic executes deterministically inside `PlayerMovement.FixedUpdate`, Gravita's "signature feel" cannot rely on physics perturbations or simulation delays. Instead, it is delivered through a **strictly decoupled, event-driven sensory architecture** anchored on three sensory pillars:

1. **Kinetic Acceleration & Cadence**: Every continuous tile traversed escalates motion energy (`VelocityTier`: `Drift` -> `Cruise` -> `KineticRam`) via additive camera breathing, pitch-stepped cadence ticks, directional squash/stretch, and trail intensity—snapping cleanly across 90° `DeflectionWedge` redirects and `VectorLauncher` phase exits without resetting dash state.
2. **Weighty Collision Contrast**: Micro-impacts (Tier 1) remain crisp and instantaneous; heavy stops (Tier 2/3) and `CrackedBlock` **Breakthrough** shatters deliver surgical unscaled hit-stop, additive camera zoom punches, directional bursts, and tactile haptics—never cancelled when `OnMoveStopped` runs and never overriding `UIManager` pause freeze state.
3. **Electric Precision & Musical Mastery**: Skimming past a hazard or enemy (`CloseCall`) sparks a directional midpoint arc between player and threat; chaining coins (`Collectible`) plays a single unified pentatonic scale without double-triggering existing `Coin.prefab` audio; and every power-up (`PowerUpController`) triggers pooled, color-coded radial pulses, echo markers, and valid/invalid scans with zero runtime object creation.

### Velocity Tier Threshold Reconciliation
In `Assets/Scripts/Gameplay/VelocityTier.cs`, the current codebase thresholds are:
- **Tier 1 (`Drift`)**: `1–2` tiles
- **Tier 2 (`Cruise`)**: `3–4` tiles
- **Tier 3 (`KineticRam`)**: `5+` tiles

Design cadence specifications sometimes evaluate `1–3 / 4–7 / 8+` tile brackets. **No feedback script hardcodes integer tile counts.** Every sensory module observes `PlayerMovement.CurrentTier` and `OnVelocityTierChanged`, so adjusting thresholds inside `VelocityTier.cs` propagates automatically across zoom, audio cadence, hit-stop, VFX, and haptics.

### Non-Negotiable Engineering Constraints
- **Zero `PlayerMovement.FixedUpdate` Perturbation**: Physics raycasts, step intervals, collision rules, and soft-lock detection remain deterministic and untouched. All telemetry hooks are read-only observers.
- **Zero Procedural `GameObject` or `AddComponent`**: Every VFX burst, radial pulse, echo marker, close-call spark, and SFX voice uses pre-authored prefabs spawned and returned via `ObjectPoolManager` / `VfxSpawner` (with warn-once null guards).
- **Safe DOTween Lifecycle**: Every tween chains `.DOKill()` on the target before creation, `.SetUpdate(true)` (runs cleanly during hit-stop and pause), and `.SetLink(gameObject)` (auto-cancels safely on destroy), restoring initial transform/color values before pool return.
- **Scene & Prefab Authority (`AGENTS.md` Rule 1)**: UI panels, overlays, and prefabs are authored in the Unity Inspector—never procedurally spawned at runtime or bulk-mutated via editor scripts.
- **Domain Reload Safety**: Every static runtime flag implements `[RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.SubsystemRegistration)]` reset to support Enter Play Mode without Domain Reload.

### Critical Cross-System Contracts Solved Upfront
1. **Zoom Channel Isolation (`CinemachineCameraZoom2D`)**: `RunwayCadenceFeedback` owns `runwayZoomDip`; `PlayerImpactFeedback` owns `activePulseDip`. Calling stop on a wall, `BrakeTile`, `GravityBlock`, or `VectorLauncher` clears only `runwayZoomDip = 0f`—never calling `StopCoroutine(zoomPulseRoutine)` or wiping `activePulseDip`.
2. **Dash State Continuity (`PlayerSquashStretch`)**: `PlayerMovement.Redirect` invokes `OnRedirected` immediately before `OnMoveStarted`, and `StepPhaseLaunch` invokes `SetPhasing(false)` immediately before `OnMoveStarted`. `PlayerSquashStretch` tracks `isDashActive` and `phaseLandSquashJustPlayed` so mid-dash `OnMoveStarted` updates direction and axis-rotated `restScale` without clearing `brakeSquashTriggeredThisDash` or overwriting redirect/phase-exit animations.
3. **Single-Owner Coin Audio (`Collectible` + `PickupRhythmFeedback`)**: `Coin.prefab` assigns `collectSfx`, so `EntityAudio.HandleCoinCollected` already early-returns on `coin.HasCustomCollectSfx`. `Collectible.PlayCollectFeedback()` gates its direct `SoundManager.PlaySFX(collectSfx, collectSfxVolume)` call when `IsCoin && PickupRhythmFeedback.IsActive`, letting `PickupRhythmFeedback` play `coin.CustomCollectSfx` (or fallback `coinCollect`) once per coin at rising pentatonic pitch.
4. **Build-Safe Audio Config (`Bootstrap.unity` + `SoundManager`)**: Build scene 0 (`Bootstrap.unity`, `AudioSystems`) owns the persistent `SoundManager` across scene loads. Both `Bootstrap.unity` and `AudioSystems.prefab` are wired with `SoundConfig.asset` and `PooledSfxSource.prefab`, backed by `SoundManager.EnsureConfigFallback(SoundConfig)` + a local `ResolveConfig()` helper on every audio-playing feedback script.
5. **2D Orientation Split**: `WallImpactBurst.prefab` uses a ParticleSystem `ShapeModule` Cone (`type: 4`) aimed along `+Z`, matching `Quaternion.LookRotation(normal)`. 2D Sprite/Animator VFX prefabs (`CloseCallFeedback`, `PowerUpController` directional FX) orient in the XY plane via `Quaternion.Euler(0f, 0f, Mathf.Atan2(delta.y, delta.x) * Mathf.Rad2Deg)` matching `InteractionEffectPlayer`.

#### Critical Implementation Safeguards
1. **Wall Impact Tier Availability**: Because `PlayerMovement` fires `OnWallImpact` alongside `StopMoving` resetting `LastImpactTier` / velocity state, `PlayerImpactFeedback` tracks `lastActiveTier` continuously on `OnMoveStarted`, `OnVelocityTierChanged`, and `HandleTileInteracted`, resetting `lastActiveTier` only after `HandleMoveStopped` completes. `HandleWallImpact` falls back to `lastActiveTier` whenever the incoming tier/property reads `None`, guaranteeing Tier 2/3 wall impacts never fall through to Tier 1.
2. **UI Freeze Coexistence**: `UIManager` exposes `public bool ShouldFreezeTime { get; }` wrapping the active pause/popup freeze condition read by `UIManager.UpdateTimeScale()`. `PlayerImpactFeedback` refuses hit-stop when `ShouldFreezeTime` is already true, and `RestoreHitStopState()` clears `IsHitStopActive = false` before delegating to `UIManager.Instance?.UpdateTimeScale()`. Opening a pause popup mid-hit-stop therefore remains cleanly at `Time.timeScale = 0f` when hit-stop expires.

### Pillar 3: Danger Tension & "Close Call"

- **Accurate Hazard Context**: `CloseCallDetector.FixedUpdate` emits a new `CloseCallContext(Vector3 playerPosition, Vector3 threatPosition, bool isEnemy)` via `OnCloseCallDetected` directly inside both hazard proximity branches (`hazard.transform.position` and `hazard.IsEnemy`), preserving `OnCloseCallTriggered(Vector3)` for existing listeners.
- **Spatial Midpoint & 2D Orientation**: `CloseCallFeedback` computes:
  - `Vector3 delta = ctx.ThreatPosition - ctx.PlayerPosition;`
  - `Vector3 midPoint = Vector3.Lerp(ctx.PlayerPosition, ctx.ThreatPosition, 0.5f);`
  - Default 2D XY orientation: `Quaternion.Euler(0f, 0f, Mathf.Atan2(delta.y, delta.x) * Mathf.Rad2Deg)` (with `[SerializeField] private bool useZForwardForConeParticles = false;` toggle if paired with a `+Z` ParticleSystem Cone prefab, and `Quaternion.identity` fallback if `delta.sqrMagnitude < 0.0001f`).
- **Danger Differentiation (`IsEnemy`)**:
  - Static `Hazard`: amber spark (`pitch = 1.08f`), zoom dip `0.15f` held `0.045s` (only if `ActivePulseDip <= 0.001f`), `HapticEvent.CloseCall` (`0.15f` cd).
  - Moving enemy (`ctx.IsEnemy == true`): high-tension graze flash (`pitch = 1.25f`), zoom dip `0.20f` held `0.045s`, `HapticEvent.CloseCall`.

### Pillar 4: Collectible Rhythm, Level Mastery & Exit Resonance

- **Single Audio Authority**: Because `Coin.prefab` already has `collectSfx` assigned, leaving `Collectible.PlayCollectFeedback()` unguarded creates double audio alongside `PickupRhythmFeedback`. Gating `Collectible.PlayCollectFeedback()` with `!(IsCoin && PickupRhythmFeedback.IsActive)` hands clean control to `PickupRhythmFeedback`, which reads `coin.CustomCollectSfx` (falling back to `ResolveConfig()?.coinCollect`) and dispatches through `SoundManager.PlaySFX(clip, volume, pitchOverride, bypassInterval: true)`.
- **Pentatonic Combo Ladder** (`comboResetSeconds = 1.60f`):
  - Step 0: `1.0000f` (Root C)
  - Step 1: `1.1225f` (Major 2nd D, $2^{2/12}$)
  - Step 2: `1.2599f` (Major 3rd E, $2^{4/12}$)
  - Step 3: `1.4983f` (Perfect 5th G, $2^{7/12}$)
  - Step 4: `1.6818f` (Major 6th A, $2^{9/12}$)
  - Step 5+: `2.0000f` (Octave C5) — sustains octave cleanly on extended streaks.
- **Star & Exit Finish Polish**: `StarCollectFeedback` and Exit Vortex sequences leverage pooled `PoppingVFX.prefab` / chime swells (`cfg.exitVortexSwell` in Phase 2) plus safe DOTween UI transitions (`.DOKill().SetUpdate(true).SetLink(gameObject)`).

### Pillar 5: Tactical Power-Ups, Haptics & Audio Infrastructure

#### 5.1 Pool-Only Power-Up VFX (`PowerUpController`)
Every runtime `new GameObject(...)` and `AddComponent<SpriteRenderer>()` call is removed across all 3 VFX paths:
1. **`SpawnEchoVisual`**: Spawns serialized `echoVisualPrefab` (`PlayerEchoMarker.prefab`) via `ObjectPoolManager.SpawnObject(..., ObjectPoolManager.PoolCategory.VFX)`, mirrors player `SpriteRenderer` sprite/flip/sorting, animates with `.DOKill().SetUpdate(true).SetLink(go)`, and returns via `ObjectPoolManager.ReturnObjectToPool(go)`. Unassigned prefab logs once and returns cleanly.
2. **`SpawnRadialPulseVFX`**: Spawns serialized `radialPulseVfxPrefab` (`SkillPulseVFX.prefab`) via `ObjectPoolManager.SpawnObject(..., ObjectPoolManager.PoolCategory.VFX)`, resets scale to `0.2f`, kills/links tweens on both `Transform` and `SpriteRenderer`, runs exact per-skill curves, and returns to pool on complete:
   - **Shield**: `Color(0.25f, 0.92f, 1.00f, 0.85f)`, `targetScale = 2.4f`, `duration = 0.35f`
   - **Magnet**: `Color(1.00f, 0.85f, 0.20f, 0.85f)`, `targetScale = GetMagnetRadius() * 1.4f`, `duration = 0.40f`
   - **Teleport Depart**: `Color(0.75f, 0.45f, 1.00f, 0.85f)`, `targetScale = 1.8f`, `duration = 0.28f`
   - **Teleport Arrive**: `Color(0.35f, 0.95f, 1.00f, 0.95f)`, `targetScale = 2.2f`, `duration = 0.32f`
   - **Freeze**: `Color(0.35f, 0.92f, 1.00f, 0.90f)`, `targetScale = 5.5f`, `duration = 0.45f`
3. **`SpawnDirectionalScanOrBurstVFX`**: Uses two distinct serialized prefabs oriented via `Quaternion.Euler(0f, 0f, Mathf.Atan2(dir.y, dir.x) * Mathf.Rad2Deg)`:
   - **Valid (`directionalValidBurstVfxPrefab` — `SkillValidBurstVFX.prefab`)**: Gold `Color(1.00f, 0.86f, 0.25f, 0.90f)`, `scale 0.5f -> 1.25f` (`Ease.OutBack`) + `DOFade(0f, 0.28f)` -> pool return.

4. **Power-Up Tactile Feedback**: Dispatches `GameHaptics.Trigger(HapticEvent.PowerUpActivate)` (`0.08s` cooldown) and `cfg.powerUpActivate` (Phase 2 stinger).

### 4.3 `CinemachineCameraZoom2D.cs` (Additive Multi-Channel Refactor)

```csharp
// Assets/Scripts/Feedback/CinemachineCameraZoom2D.cs — additions & updates inside existing class
// Preserves existing serialized fields: cinemachineCamera, normalOrthographicSize, zoomSpeed = 4f,
// targetOrthographicSize, and existing public API: SetTargetOrthographicSize(float), SetNormalOrthographicSize().
[SerializeField] private float minOrthographicSize = 2f;

private float runwayZoomDip;
private float activePulseDip;
private Coroutine zoomPulseRoutine;

public float RunwayZoomDip => runwayZoomDip;
public float ActivePulseDip => activePulseDip;
public float CurrentDesiredOrthographicSize =>
    Mathf.Max(minOrthographicSize, targetOrthographicSize - runwayZoomDip - activePulseDip);

private void LateUpdate()
{
    if (cinemachineCamera == null) return;

    float desired = CurrentDesiredOrthographicSize;
    ApplyOrthographicSizeSmooth(desired, zoomSpeed * Time.unscaledDeltaTime);
}

public void SetTargetOrthographicSize(float size)
{
    targetOrthographicSize = Mathf.Max(minOrthographicSize, size);
}

public void SetNormalOrthographicSize()
{
    targetOrthographicSize = normalOrthographicSize;
    runwayZoomDip = 0f;
}

/// <summary>
/// Owned exclusively by RunwayCadenceFeedback. Clearing runwayZoomDip on stop
/// never touches zoomPulseRoutine or cancels an active impact pulse.
/// </summary>
public void SetRunwayZoomDip(float dip)
{
    runwayZoomDip = Mathf.Max(0f, dip);
}

public void PulseZoom(float targetSize, float holdUnscaledSeconds)
{
    float dip = Mathf.Max(0f, targetOrthographicSize - targetSize);
    PulseZoomDip(dip, holdUnscaledSeconds);
}

public void PulseZoomDip(float dip, float holdUnscaledSeconds)
{
    if (zoomPulseRoutine != null)
    {
        StopCoroutine(zoomPulseRoutine);
    }
    zoomPulseRoutine = StartCoroutine(ZoomPulseCoroutine(Mathf.Max(0f, dip), Mathf.Max(0f, holdUnscaledSeconds)));
}

private IEnumerator ZoomPulseCoroutine(float dip, float holdUnscaledSeconds)
{
    activePulseDip = dip;
    if (holdUnscaledSeconds > 0f)
    {
        yield return new WaitForSecondsRealtime(holdUnscaledSeconds);
    }
    activePulseDip = 0f;
    zoomPulseRoutine = null;
}
```
*(In `LateUpdate()`, `ApplyOrthographicSizeSmooth` keeps the exact existing `cinemachineCamera` lens read/write used by the repo's installed Cinemachine package while driving `desired = Mathf.Max(2f, targetOrthographicSize - runwayZoomDip - activePulseDip)` with `Time.unscaledDeltaTime`.)*

### 4.4 `PlayerSquashStretch.cs` (Dash Continuity & Redirect/Phase-Exit Safety)

```csharp
// Assets/Scripts/Feedback/PlayerSquashStretch.cs — state-machine additions & handlers
// Preserves existing serialized fields/subscriptions on PlayerMovement + visual target.
private bool isDashActive;
private bool phaseLandSquashJustPlayed;

public bool IsDashActive => isDashActive;
public bool BrakeSquashTriggeredThisDash => brakeSquashTriggeredThisDash;
public bool PhaseLandSquashJustPlayed => phaseLandSquashJustPlayed;
public Vector3 CurrentRestScale => restScale;

private Vector3 ComputeDirectionRestScale(Vector2 dir)
{
    bool isHorizontal = Mathf.Abs(dir.x) >= Mathf.Abs(dir.y);
    return isHorizontal
        ? baseScale
        : new Vector3(baseScale.y, baseScale.x, baseScale.z);
}

private Vector3 ComputeAxisBiasedScale(Vector2 dir, float alongAxis, float perpAxis)
{
    bool isHorizontal = Mathf.Abs(dir.x) >= Mathf.Abs(dir.y);
    return isHorizontal
        ? new Vector3(baseScale.x * alongAxis, baseScale.y * perpAxis, baseScale.z)
        : new Vector3(baseScale.x * perpAxis, baseScale.y * alongAxis, baseScale.z);
}

public void HandleMoveStarted(Vector2 dir)
{
    lastDirection = dir;
    restScale = ComputeDirectionRestScale(dir);

    // Redirect and StepPhaseLaunch fire OnRedirected / SetPhasing(false) immediately
    // before OnMoveStarted on the same continuous dash. Preserve active dash flags
    // and avoid overwriting redirect/phase-exit tweens.
    if (isDashActive)
    {
        return;
    }

    isDashActive = true;
    brakeSquashTriggeredThisDash = false;
    phaseLandSquashJustPlayed = false;

    Transform target = GetTargetTransform();
    if (target == null) return;
    target.DOKill();
    target.localScale = ComputeAxisBiasedScale(dir, launchStretchAlong, launchStretchPerp);
    target.DOScale(restScale, launchDuration)
        .SetEase(Ease.OutQuad)
        .SetUpdate(true)
        .SetLink(target.gameObject);
}

public void HandleRedirected(Vector2 oldDir, Vector2 newDir)
{
    lastDirection = newDir;
    restScale = ComputeDirectionRestScale(newDir);
    isDashActive = true;

    Transform target = GetTargetTransform();
    if (target == null) return;
    target.DOKill();
    target.localScale = ComputeAxisBiasedScale(newDir, redirectPunchScale, 1f / Mathf.Sqrt(redirectPunchScale));
    target.DOScale(restScale, redirectDuration)
        .SetEase(Ease.OutBack)
        .SetUpdate(true)
        .SetLink(target.gameObject);
}

public void HandlePhasingChanged(bool isPhasing)
{
    Transform target = GetTargetTransform();
    if (target == null) return;

    if (isPhasing)
    {
        target.DOKill();
        target.DOScale(restScale * 0.84f, 0.08f)
            .SetEase(Ease.OutQuad)
            .SetUpdate(true)
            .SetLink(target.gameObject);
        return;
    }

    if (isDashActive)
    {
        phaseLandSquashJustPlayed = true;
    }

    target.DOKill();
    target.localScale = ComputeAxisBiasedScale(lastDirection, stopSquashAlong, stopSquashPerp);
    target.DOScale(restScale, stopDuration)
        .SetEase(Ease.OutBack)
        .SetUpdate(true)
        .SetLink(target.gameObject);
}

public void HandleMoveStopped()
{

    isDashActive = false;

    if (brakeSquashTriggeredThisDash || phaseLandSquashJustPlayed)
    {
        brakeSquashTriggeredThisDash = false;
        phaseLandSquashJustPlayed = false;
        return;
    }

    Transform target = GetTargetTransform();
    if (target == null) return;
    target.DOKill();
    target.localScale = ComputeAxisBiasedScale(lastDirection, stopSquashAlong, stopSquashPerp);
    target.DOScale(restScale, stopDuration)
        .SetEase(Ease.OutBack)
        .SetUpdate(true)
        .SetLink(target.gameObject);
```

```csharp
    [SerializeField] private SoundConfig fallbackSoundConfig;
    [Tooltip("False for 2D XY Sprite/Animator VFX (Z-Euler); true for +Z ParticleSystem Cones.")]

    [SerializeField] private float hazardZoomDip = 0.15f;
    [SerializeField] private float enemyZoomDip = 0.20f;
    [SerializeField] private float zoomHoldSeconds = 0.045f;
    [SerializeField] private float minFeedbackInterval = 0.15f;

    private float lastTriggerTime = -10f;

    private void OnEnable()
    {
        CloseCallDetector.OnCloseCallDetected += HandleCloseCallDetected;
    }

    private void OnDisable()
    {
        CloseCallDetector.OnCloseCallDetected -= HandleCloseCallDetected;
    }

    public static void ComputeSpawnTransform(
        CloseCallContext ctx,
        bool useZForwardCone,
        out Vector3 midPoint,
        out Quaternion rotation)
    {
        Vector3 delta = ctx.ThreatPosition - ctx.PlayerPosition;
        midPoint = Vector3.Lerp(ctx.PlayerPosition, ctx.ThreatPosition, 0.5f);

        if (delta.sqrMagnitude < 0.0001f)
        {
            rotation = Quaternion.identity;
            return;
        }

        if (useZForwardCone)
        {
            rotation = Quaternion.LookRotation(delta.normalized);
        }
        else
        {
            float angleDeg = Mathf.Atan2(delta.y, delta.x) * Mathf.Rad2Deg;
            rotation = Quaternion.Euler(0f, 0f, angleDeg);
        }
    }

    private void HandleCloseCallDetected(CloseCallContext ctx)
    {
        if (Time.unscaledTime - lastTriggerTime < minFeedbackInterval) return;
        lastTriggerTime = Time.unscaledTime;

        ComputeSpawnTransform(ctx, useZForwardForConeParticles, out Vector3 midPoint, out Quaternion rot);

        if (closeCallSparkPrefab != null)
        {
            VfxSpawner.Spawn(closeCallSparkPrefab, midPoint, rot);
        }

        var zoom = CinemachineCameraZoom2D.Instance;
        if (zoom != null && zoom.ActivePulseDip <= 0.001f)

            zoom.PulseZoomDip(ctx.IsEnemy ? enemyZoomDip : hazardZoomDip, zoomHoldSeconds);
        }

        GameHaptics.Trigger(HapticEvent.CloseCall);

        SoundConfig cfg = ResolveConfig();
        if (cfg != null && SoundManager.Instance != null)
        {
            SoundManager.Instance.PlaySFX(cfg.closeCall, ctx.IsEnemy ? 1.25f : 1.08f, bypassInterval: false);
        }
    }

    private SoundConfig ResolveConfig()
    {
        SoundManager sm = SoundManager.Instance;
        if (sm != null)
        {
            sm.EnsureConfigFallback(fallbackSoundConfig);
            if (sm.Config != null) return sm.Config;
        }
        return fallbackSoundConfig;
    }
}
```
