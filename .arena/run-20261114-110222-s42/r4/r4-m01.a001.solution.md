# Gravita (Puzzle 2D) — Game Feel Signature Blueprint

## 0. Executive Feel Diagnosis & Architectural Principles

**Target Project**: `Puzzle 2D` (Unity `6000.4.0f1`, URP 2D, Cinemachine, DOTween, `ObjectPoolManager`, deterministic `FixedUpdate` grid physics at `moveSpeed = 30`).

### Root Feel Bottlenecks Diagnosed in Current Baseline
1. **Hit-Stop & Camera Desynchronization (`Main Camera` + `Player`)**: In `Assets/Scenes/GameScene.unity`, `Main Camera`'s `CinemachineBrain` uses `UpdateMethod = SmartUpdate` (`2`) and `IgnoreTimeScale = false` (`0`), while tracking `Player` (`Rigidbody2D.m_Interpolate = 0`). Cinemachine's `UpdateTracker` classifies an uninterpolated `Rigidbody2D` under `UpdateClock.Fixed`, causing `CameraUpdateManager` to skip `SmartLate` whenever `Time.timeScale == 0f`—freezing camera impulse shakes right when impact freeze-frames should reverberate.
2. **Overloaded `OnMoveStarted` Event Semantics (`PlayerMovement.cs`)**: `PlayerMovement` currently fires `OnMoveStarted` not only on genuine player directional inputs in `SimulateStep`, but also inside `Redirect()`, non-phase `StartPhaseLaunch()`, and `StepPhaseLaunch()` arrival. Because `LevelFlowController.HandlePlayerMoveStarted` increments `movesUsedThisRun++` and `PlayerSquashStretch` / `EntityAudio` react to `OnMoveStarted`, wedges, vector pads, launchers, and phase landings inflate move counters and misfire start audio/deformation.
3. **Scaled-Time VFX Timers & Broken 2D Cone Rotation (`PlayerImpactFeedback` + Pools)**: `WallImpactBurst.prefab`, `WallImpactBreak.prefab`, and `Particle Star.prefab` run with `useUnscaledTime = 0`, `PoppingVFX.prefab` runs with `AnimatorUpdateMode.Normal` (`m_UpdateMode = 0`), `PooledParticlePlayer` / `PooledAnimationPlayer` accumulate `Time.deltaTime`, and `ReturnToPool` yields `WaitForSeconds(delay)`. In addition, `WallImpactBurst.prefab` uses a `(0, 0, 0)` `+Z` cone combined with `Quaternion.LookRotation((Vector3)normal)` in `PlayerImpactFeedback.HandleWallImpact`, which collapses when `normal == (0, ±1, 0)` (collinear with `Vector3.up`) and blasts particles toward `+Z` instead of the XY rebound plane.
4. **Unfiltered Wedge Deflection VFX & Over-Broad Stop Feedback**: `DeflectionWedge.cs` emits `InteractionKind.Hit` on blunt stops and `InteractionKind.Deflect` on reflections, while `InteractionEffectPlayer.TriggerEffects` executes `effectPrefabs` and `defaultCameraShake` unconditionally for every `InteractionKind`. Separately, only `BrakeTile` and `GravityBlock` return `CellOutcome.Stop(requireFreshInput: true)`, whereas blunt hits on `DeflectionWedge` and blocked `VectorLauncher` cells return `CellOutcome.Stop(requireFreshInput: false)`—so stop juice must distinguish magnetic anchor stops from blunt collision halts.
5. **Under-Signaled High-Speed Escalation & Lifecycle Edge Cases**: Moving at `moveSpeed = 30` across corridors lacks tier-scaled afterimage trails (`KineticRam` / `IsPhasing`), pentatonic redirect escalation, modal-pause arbitration during Hit-Stop, and close-call / level-settle cadence.

### Engineering Non-Negotiables
- **Zero Deterministic Physics Drift**: Grid snapping, raycasts, and slide stepping remain untouched in `PlayerMovement.FixedUpdate` / `SimulateStep`. All feel systems consume read-only state and events.
- **Zero Runtime UI/VFX GameObject Construction**: No `new GameObject(...)` or runtime `AddComponent<...>()` for UI, VFX, or audio helpers. All transient objects come from authored `.prefab` assets pooled through `ObjectPoolManager`.
- **UI & Scene Discipline**: Inspector wiring stays explicit (no hidden `GetComponent` discovery or unrequested opacity dimming). All DOTween sequences use `.DOKill()`, `.SetUpdate(true)`, and `.SetLink(gameObject)`.
- **Strict Pause Arbitration**: Modal UI popups (`UIManager.IsTimeFrozenByModal`) always freeze Hit-Stop, unscaled particles, animators, pool timers, and afterimages without trapping `Time.timeScale` or `IsAnyHitStopActive`.

### Pillar 1 — Kinesthetic Launch, Elastic Squash-Stretch & Clean Event Separation

#### 1.1 Event Hygiene & Anchor-Stop Distinction (`Assets/Scripts/Gameplay/PlayerMovement.cs`)
Refactor `PlayerMovement` events so every subscriber reacts to exact, unambiguous gameplay semantics without boolean suppression flags or frame-counter heuristics:

- **Event Contracts on `PlayerMovement`**:
  - `public event Action<Vector2> OnMoveStarted;` — fired **exclusively** inside `SimulateStep` on genuine player input initiation or buffered turn commit. `LevelFlowController.HandlePlayerMoveStarted` increments `movesUsedThisRun++` only here.
  - `public event Action<Vector2> OnRedirected;` — fired **exclusively** inside `Redirect(Vector2 newDirection, Vector2 snapPosition)` for `DeflectionWedge` and `VectorPad` (`CellOutcomeType.Redirect`). Remove `OnMoveStarted?.Invoke(moveDirection);` from `Redirect()`.
  - `public event Action<Vector2> OnLauncherRedirected;` — new event fired exclusively for `VectorLauncher` / `CellOutcomeType.Launch` velocity redirections and `PhaseLaunch` portal starts.
  - `public event Action<Vector2> OnPhaseLaunchLanded;` — new event fired exclusively when `StepPhaseLaunch` reaches `phaseTargetPosition` (`postDirection` if continuing slide, `Vector2.zero` if halting at target).
  - `public event Action<bool, bool> OnMoveStopped;` — `(bool wallImpact, bool anchorStop)` so subscribers distinguish wall collisions (`wallImpact = true`), magnetic anchor halts (`anchorStop = true`), and neutral halts (`false, false`).

- **Unified Launcher Helper & Call Sites**:
  ```csharp
  private void ExecuteLauncherRedirect(Vector2 newDirection, Vector2 snapPosition, bool countRedirect = true)
  {
      if (countRedirect)
      {
          consecutiveRedirects++;
          if (consecutiveRedirects >= maxConsecutiveRedirects)
          {
              StopMoving(wallImpact: false, anchorStop: false);
              return;
          }
      }

      SetAwaitingFreshInput(false);
      MoveBodyImmediate(snapPosition);
      moveDirection = CardinalDirectionUtil.SnapToCardinal(newDirection);
      lastMoveDirection = moveDirection;
      SetPendingDirection(Vector2.zero);
      OnLauncherRedirected?.Invoke(moveDirection);
  }
  ```
  - **Non-Phase `CellOutcomeType.Launch` (`AdvanceSlideStep` & `TryTriggerRestingLauncher`)**: calls `EnforceMinimumTier(outcome.MinTier);` then `ExecuteLauncherRedirect(outcome.Direction, cellCenter, countRedirect: true);` (never `OnMoveStarted` or `OnRedirected`).
  - **`StartPhaseLaunch`**:
    - When `willPhase == true`: calls `SetPhasing(true);` -> `EnforceMinimumTier(minTier);` -> `OnLauncherRedirected?.Invoke(lastMoveDirection);`.
    - When `willPhase == false`: calls `EnforceMinimumTier(minTier);`; if `resolvedDir != Vector2.zero`, calls `ExecuteLauncherRedirect(resolvedDir, origin, countRedirect: false);`.
  - **`StepPhaseLaunch` Arrival** (`(next - phaseTargetPosition).sqrMagnitude <= 0.0001f`):
    ```csharp
    MoveBodyImmediate(phaseTargetPosition);
    SetPhasing(false);
    EnforceMinimumTier(phaseMinTier);
    if (phasePostDirection != Vector2.zero)
    {
        moveDirection = phasePostDirection;
        lastMoveDirection = phasePostDirection;
        SetPendingDirection(Vector2.zero);
        OnPhaseLaunchLanded?.Invoke(phasePostDirection);
    }
    else
    {
        LastSafePosition = phaseTargetPosition;
        OnPhaseLaunchLanded?.Invoke(Vector2.zero);
        StopMoving(wallImpact: false, anchorStop: false);
    }
    ```
  - **Anchor-Stop Separation (`AdvanceSlideStep` handling `CellOutcomeType.Stop`)**:
    - Pass `anchorStop: outcome.RequireFreshInput` into `StopMoving(wallImpact: false, anchorStop: outcome.RequireFreshInput)`.
    - Verified tile contract: `BrakeTile` and `GravityBlock` return `CellOutcome.Stop(requireFreshInput: true)` (`anchorStop = true`), whereas blunt `DeflectionWedge` faces and blocked `VectorLauncher` tiles return `CellOutcome.Stop(requireFreshInput: false)` (`anchorStop = false`). Magnetic anchor compression and lock SFX therefore fire strictly on true anchor tiles.

#### 1.2 Elastic Volume-Preserving Deformation (`Assets/Scripts/Feedback/PlayerSquashStretch.cs`)
- **Clean Event Subscriptions**:
  - `OnMoveStarted(dir)` -> update `lastDirection = dir; ApplySustainedStretch(dir, movement.CurrentTier);`.
  - `OnLauncherRedirected(dir)` -> update `lastDirection = dir; ApplySustainedStretch(dir, movement.CurrentTier);`.
  - `OnPhaseLaunchLanded(postDir)` -> if `postDir != Vector2.zero`, update `lastDirection = postDir; ApplySustainedStretch(postDir, movement.CurrentTier);` (when `Vector2.zero`, immediate `StopMoving(false, false)` invokes `HandleMoveStopped` -> `ResetScale()`).
  - `OnVelocityTierChanged(tier)` -> if `movement.IsMoving`, call `ApplySustainedStretch(lastDirection, tier)`.
  - `OnRedirected(newDir)` -> run crisp orthogonal turn-snap `Squash` followed immediately by `ApplySustainedStretch(newDir, movement.CurrentTier)`.
  - `OnWallImpact(normal)` / `OnBlockBroken` -> trigger normal-aligned compression weighted by velocity tier (`VelocityTier.KineticRam` applies deepest squeeze before springing back to `Vector2.one`).
  - `OnMoveStopped(bool wallImpact, bool anchorStop)` -> if `anchorStop`, trigger brief inward magnetic squeeze `(0.84f, 0.84f)` before springing to `Vector2.one`; otherwise call `ResetScale()`.
- **Tier-Scaled Stretch Formula**:
  ```csharp
  private void ApplySustainedStretch(Vector2 direction, VelocityTier tier)
  {
      if (direction.sqrMagnitude < 0.01f)
          return;

      float tierBonus = tier == VelocityTier.KineticRam
          ? 0.14f
          : ((int)tier > 0 ? 0.06f : 0f);

      float stretchAlongAxis = 1.18f + tierBonus;
      float compressCrossAxis = 1f / Mathf.Sqrt(stretchAlongAxis);
      bool horizontal = Mathf.Abs(direction.x) >= Mathf.Abs(direction.y);
      Vector2 targetScale = horizontal
          ? new Vector2(stretchAlongAxis, compressCrossAxis)
          : new Vector2(compressCrossAxis, stretchAlongAxis);

      Deform(targetScale, stretchDuration);
  }
  ```
- **DOTween Compliance**: Every tween in `PlayerSquashStretch.Deform` / `ResetScale` calls `.DOKill()`, `.SetUpdate(true)`, and `.SetLink(gameObject)` so deformation finishes smoothly during Hit-Stop while aborting safely on destroy.

### Pillar 2 — Unscaled Hit-Stop, Modal-Safe VFX Pooling & Directional Impact Juice

#### 2.1 Hit-Stop Arbitration & Explicit Cancellation (`Assets/Scripts/Feedback/PlayerImpactFeedback.cs` + `Assets/Scripts/UI/Core/UIManager.cs`)
- **`UIManager` Modal Pause Contract**:
  - Expose `public bool IsTimeFrozenByModal => ...` (true whenever any modal/pause overlay in `UIManager`'s popup stack holds time at `0`).
  - In `UIManager.UpdateTimeScale()`:
    1. If `IsTimeFrozenByModal`, force `Time.timeScale = 0f;`.
    2. Else if `PlayerImpactFeedback.IsAnyHitStopActive`, preserve `Time.timeScale = 0f;` (prevents non-freezing popup dismissal from unfreezing an active Hit-Stop early).
    3. Else restore `Time.timeScale = 1f;`.
  - Expose/maintain `public event Action OnPopupStackChanged;` (triggered on `PushPopup`, `CloseTopPopup`, `CloseAllPopups`, `ClosePanelIfOpen`).
- **`PlayerImpactFeedback` Complete Hit-Stop State Machine**:
  ```csharp
  public static bool IsAnyHitStopActive { get; private set; }

  private float preHitStopTimeScale = 1f;
  private float hitStopEndRealtime;
  private Coroutine hitStopRoutine;

  [RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.SubsystemRegistration)]
  private static void ResetStaticState()
  {
      IsAnyHitStopActive = false;
  }

  private void OnEnable()
  {
      // Existing PlayerMovement subscriptions + popup arbitration
      if (UIManager.Instance != null)
          UIManager.Instance.OnPopupStackChanged += HandlePopupStackChanged;
  }

  private void OnDisable()
  {
      if (UIManager.Instance != null)
          UIManager.Instance.OnPopupStackChanged -= HandlePopupStackChanged;

      CancelHitStop(restoreTimeScale: true);
  }

  private void HandlePopupStackChanged()
  {
      if (UIManager.Instance != null && UIManager.Instance.IsTimeFrozenByModal)
          CancelHitStop(restoreTimeScale: false);
  }

  public void CancelHitStop(bool restoreTimeScale)
  {
      if (hitStopRoutine != null)
      {
          StopCoroutine(hitStopRoutine);
          hitStopRoutine = null;
      }

      bool wasActive = IsAnyHitStopActive;
      IsAnyHitStopActive = false;
      hitStopEndRealtime = 0f;

      if (wasActive && restoreTimeScale && (UIManager.Instance == null || !UIManager.Instance.IsTimeFrozenByModal))
      {
          Time.timeScale = preHitStopTimeScale;
      }
  }

  private void PulseHitStop(float durationRealtime)
  {
      if (durationRealtime <= 0f)
          return;

      if (UIManager.Instance != null && UIManager.Instance.IsTimeFrozenByModal)
          return;

      float candidateEnd = Time.realtimeSinceStartup + durationRealtime;
      if (IsAnyHitStopActive)
      {
          if (candidateEnd > hitStopEndRealtime)
              hitStopEndRealtime = candidateEnd;
          return;
      }

      preHitStopTimeScale = Time.timeScale > 0f ? Time.timeScale : 1f;
      hitStopEndRealtime = candidateEnd;
      IsAnyHitStopActive = true;
      Time.timeScale = 0f;
      hitStopRoutine = StartCoroutine(HitStopRoutine());
  }

  private IEnumerator HitStopRoutine()
  {
      while (IsAnyHitStopActive && Time.realtimeSinceStartup < hitStopEndRealtime)
      {
          if (UIManager.Instance != null && UIManager.Instance.IsTimeFrozenByModal)
          {
              hitStopRoutine = null;
              CancelHitStop(restoreTimeScale: false);
              yield break;
          }
          yield return null;
      }

      hitStopRoutine = null;
      CancelHitStop(restoreTimeScale: true);
  }
  ```
- **Why This Is Soft-Lock Free**: `StopCoroutine` bypasses `finally` blocks in Unity coroutines; having `CancelHitStop(bool)` own coroutine shutdown, static flag clearing, and guarded `preHitStopTimeScale` restoration guarantees neither modal pauses nor `OnDisable()` / scene unloads / Fast Domain Reloads can trap `IsAnyHitStopActive == true`.
- **Calibrated Hit-Stop Durations**:
  - Wall impact (`HandleWallImpact`): `0.030s` standard, `0.045s` when `movement.CurrentTier == VelocityTier.KineticRam`.
  - Cracked block shatter (`HandleBlockBroken`): `0.055s`.
  - Wedge deflection / Launcher boost / Phase portal: `0.000s`.

#### 2.2 Time-Unscaled Prefabs & Modal-Safe Pool Lifecycle
- **Prefab Configurations**:
  - `Assets/Prefabs/Particles/WallImpactBurst.prefab`: `useUnscaledTime = 1`, `ShapeModule.m_Rotation = (0, 90, 0)` (`+X` emission cone).
  - `Assets/Prefabs/Particles/WallImpactBreak.prefab`: `useUnscaledTime = 1`, `ShapeModule.m_Rotation = (0, 90, 0)`.
  - `Assets/Prefabs/Particles/Particle Star.prefab`: `useUnscaledTime = 1`.
  - `Assets/Prefabs/VFX/PoppingVFX.prefab`: `Animator.updateMode = AnimatorUpdateMode.UnscaledTime` (`m_UpdateMode = 2`).
- **Pool Player Updates (Hit-Stop Active, Modal-Pause Frozen)**:
  - **`PooledParticlePlayer.cs` (`MonitorParticlesRoutine`)**:
    - Track `bool isModalPaused` and cache each child `ParticleSystem` unscaled preference.
    - While `UIManager.Instance != null && UIManager.Instance.IsTimeFrozenByModal`: pause playing `ParticleSystem` instances (setting `isModalPaused = true`) and skip advancing `elapsed` or returning to pool.
    - When modal freeze ends: call `.Play()` on paused systems and resume monitoring.
    - Step `elapsed += (anyUnscaled || PlayerImpactFeedback.IsAnyHitStopActive) ? Time.unscaledDeltaTime : Time.deltaTime;`.
  - **`PooledAnimationPlayer.cs` (`MonitorLifecycleRoutine`)**:
    - While `UIManager.Instance != null && UIManager.Instance.IsTimeFrozenByModal`: set `animator.speed = 0f;` and hold `elapsed`. On unpause, restore `defaultAnimatorSpeed`.
    - Step `elapsed += (animator.updateMode == AnimatorUpdateMode.UnscaledTime || PlayerImpactFeedback.IsAnyHitStopActive) ? Time.unscaledDeltaTime : Time.deltaTime;`.
  - **`ReturnToPool.cs`**:
    - Replace fixed-delay `yield return new WaitForSeconds(delay);` with an accumulator loop pausing child `ParticleSystem` / `Animator.speed` while `UIManager.IsTimeFrozenByModal` is `true`, and advancing via `Time.unscaledDeltaTime` whenever unscaled playback or `PlayerImpactFeedback.IsAnyHitStopActive` applies (else `Time.deltaTime`).

#### 2.3 Exact 2D Planar Rotation & Shake Separation (`Assets/Scripts/Feedback/PlayerImpactFeedback.cs`)
- **XY-Plane Normal Rotation Fix**:
  Replace `Quaternion.LookRotation((Vector3)normal)` inside `HandleWallImpact(Vector2 normal)` with pure 2D Z-rotation matching `InteractionEffectPlayer.ResolveRotation`:
  ```csharp
  Quaternion rotation = Quaternion.Euler(0f, 0f, Mathf.Atan2(normal.y, normal.x) * Mathf.Rad2Deg);
  ```
  Paired with `ShapeModule.m_Rotation = (0, 90, 0)` on both `WallImpactBurst.prefab` and `WallImpactBreak.prefab`, vertical normals `(0, ±1)` and horizontal normals `(±1, 0)` fan sparks cleanly across the XY game plane without gimbal/collinearity collapse, and keep 2D `PoppingVFX` sprite decals flat toward the camera.
- **Event Separation Inside `PlayerImpactFeedback`**:
  - `HandleRedirected(Vector2 _)`: increments `redirectChainCount` (reset in `HandleMoveStarted` and `HandleMoveStopped`) and pulses light escalating wedge shake.
  - `HandleLauncherRedirected(Vector2 _)`: optional subtle boost shake (`0.06f`), **no** `redirectChainCount` increment.
  - `HandlePhaseLaunchLanded(Vector2 _)`: fires crisp exit shake (`0.16f`), **no** `redirectChainCount` increment.

### Pillar 3 — Kinetic Runway, Wedge Deflection & Phase-Portal Readability

#### 3.1 Kinetic Afterimage Runway (`KineticRunwayFeedback` & `AfterimageGhost` — New Components + Prefab)
Attach a new `KineticRunwayFeedback` component (`Assets/Scripts/Feedback/KineticRunwayFeedback.cs`) to `Player`, spawning a new pooled `AfterimageGhost.prefab` (carrying `SpriteRenderer` + new `AfterimageGhost.cs` component):

```csharp
public class KineticRunwayFeedback : MonoBehaviour
{
    [Header("References")]
    [SerializeField] private PlayerMovement movement;
    [SerializeField] private SpriteRenderer playerSpriteRenderer;
    [SerializeField] private Transform playerVisualTransform;
    [SerializeField] private GameObject afterimagePrefab;

    [Header("Afterimage Tuning")]
    [SerializeField] private float afterimageInterval = 0.032f;
    [SerializeField] private float afterimageDuration = 0.16f;
    [SerializeField] private float afterimageEndScale = 0.86f;
    [SerializeField] private Color kineticAfterimageColor = new Color(1f, 0.32f, 0.78f, 0.62f);
    [SerializeField] private Color phaseAfterimageColor = new Color(0.72f, 0.42f, 1f, 0.70f);

    private float afterimageTimer;

    private void OnEnable()
    {
        if (movement == null) return;
        movement.OnVelocityTierChanged += HandleVelocityTierChanged;
        movement.OnPhasingChanged += HandlePhasingChanged;
        movement.OnMoveStopped += HandleMoveStopped;
    }

    private void OnDisable()
    {
        if (movement == null) return;
        movement.OnVelocityTierChanged -= HandleVelocityTierChanged;
        movement.OnPhasingChanged -= HandlePhasingChanged;
        movement.OnMoveStopped -= HandleMoveStopped;
        afterimageTimer = 0f;
    }

    private void HandleVelocityTierChanged(VelocityTier tier)
    {
        if (tier == VelocityTier.KineticRam && !movement.IsPhasing)
            afterimageTimer = 0f;
    }

    private void HandlePhasingChanged(bool phasing)
    {
        if (phasing)
            afterimageTimer = 0f;
    }

    private void HandleMoveStopped(bool _, bool __)
    {
        afterimageTimer = 0f;
    }

    private void Update()
    {
        if (movement == null || afterimagePrefab == null || playerSpriteRenderer == null)
            return;

        if (UIManager.Instance != null && UIManager.Instance.IsTimeFrozenByModal)
            return;

        if (Time.timeScale <= 0f && !PlayerImpactFeedback.IsAnyHitStopActive)
            return;

        bool shouldSpawn = movement.IsMoving && (movement.IsPhasing || movement.CurrentTier == VelocityTier.KineticRam);
        if (!shouldSpawn)
        {
            afterimageTimer = 0f;
            return;
        }

        afterimageTimer -= Time.unscaledDeltaTime;
        if (afterimageTimer <= 0f)
        {
            afterimageTimer = afterimageInterval;
            SpawnAfterimage();
        }
    }

    private void SpawnAfterimage()
    {
        Vector3 spawnPos = playerVisualTransform != null ? playerVisualTransform.position : transform.position;
        GameObject ghostObj = ObjectPoolManager.SpawnObject(
            afterimagePrefab,
            spawnPos,
            Quaternion.identity,
            null,
            ObjectPoolManager.PoolType.GameObject);

        if (ghostObj != null && ghostObj.TryGetComponent(out AfterimageGhost ghost))
        {
            Color tint = movement.IsPhasing ? phaseAfterimageColor : kineticAfterimageColor;
            ghost.Play(playerSpriteRenderer, playerVisualTransform, tint, afterimageDuration, afterimageEndScale);
        }
    }
}
```

- **Pivot Alignment Note**: `Player/Sprite` in `GameScene.unity` sits at local `(0, -0.5, 0)` (bottom-center squash pivot). Assigning `playerVisualTransform` explicitly to `Player/Sprite` aligns every ghost sprite directly on top of the visual mesh rather than floating `+0.5` units above `Player.transform.position`.
- **`AfterimageGhost.cs`**: Copies `sprite`, `flipX`, `flipY`, `sortingLayerID`, `sortingOrder - 1`, and world scale (`playerVisualTransform.lossyScale`), then uses DOTween (`SetUpdate(true)`, `SetLink(gameObject)`, `DOKill()`) to fade alpha `tint.a -> 0` and scale to `afterimageEndScale` over `afterimageDuration` before calling `ObjectPoolManager.ReturnObjectToPool(gameObject)`. Kills active tweens on `OnDisable()`.

#### 3.2 Wedge Deflection-Only Filtering (`Assets/Prefabs/Gameplay/Wedge.prefab` + `InteractionEffectPlayer`)
- `DeflectionWedge.cs` emits `InteractionKind.Hit` on blunt stops and `InteractionKind.Deflect` on deflections; `InteractionEffectPlayer.TriggerEffects` runs `effectPrefabs` and `defaultCameraShake` unconditionally across every `InteractionKind`.
- **Setup on `Wedge.prefab`**:
  - Leave `InteractionEffectPlayer.effectPrefabs` **empty (`[]`)** and `defaultCameraShake = 0`.
  - Add one rule inside `InteractionEffectPlayer.rules`:
    - `triggerOn = InteractionKind.Deflect`
    - `effectPrefab = WedgeDeflectSparks.prefab` (new authored particle prefab with `ShapeModule.m_Rotation = (0, 90, 0)`, `useUnscaledTime = 1`)
    - `anchor = SpawnAnchor.VisualCenter`
    - `alignToDirection = true`
    - `cameraShake = 0.07f`
- **Result**: Hitting the flat back of a wedge triggers clean `InteractionKind.Hit` wall/stop behavior without spurious deflection sparks or redirect shake; deflecting off the angled wedge face snaps directional sparks along the outgoing vector.

#### 3.3 Continuous Corner Ribbon (`Assets/Scripts/Feedback/PlayerLineTrail.cs`)
- Update `PlayerLineTrail` event wiring to subscribe `HandleRedirected` to **both** `movement.OnRedirected` and `movement.OnLauncherRedirected` (plus corner anchoring on `OnPhaseLaunchLanded` when `postDir != Vector2.zero`).
- Prevents line trails from shortcutting diagonally across launcher/pad turn vertices.

### Pillar 4 — Synchronized Audio & Haptic Counterpoint

#### 4.1 Event-Accurate Audio Cadence (`Assets/Scripts/Audio/EntityAudio.cs` + `SoundConfig.cs`)
- Eliminate `OnMoveStarted` overloading inside `EntityAudio` and replace overlapping triggers with clean 1-to-1 bindings (zero frame-counter heuristics):
  - `movement.OnMoveStarted` -> triggers launch/whoosh `moveStart` SFX **only** for actual player moves.
  - `movement.OnRedirected` -> triggers pentatonic-escalating `wedgeRedirect` SFX (`0, +2, +4, +7, +9, +12` semitones scaled from `redirectChainCount` reset on move start/stop).
  - `movement.OnPhasingChanged(true)` & `movement.OnLauncherRedirected` (when `!movement.IsPhasing`) -> triggers phase/launcher boost cue without colliding with `moveStart` or `wedgeRedirect`.
  - `movement.OnPhaseLaunchLanded` -> triggers phase portal exit cue.
  - `movement.OnWallImpact` / `movement.OnBlockBroken` -> scales pitch/gain by velocity tier (`VelocityTier.KineticRam` adds heavier low-end accent).
  - `movement.OnMoveStopped(bool wallImpact, bool anchorStop)` -> stops loop cleanly and plays crisp magnetic anchor lock SFX **only** when `anchorStop == true`.
- All new sound cues live in `SoundConfig` asset (`AudioSystems.prefab`) and route through `SoundManager` / `MusicManager` mixer groups.

#### 4.2 Haptic Counterpoint (`Assets/Scripts/Feedback/GameplayHapticsFeedback.cs` + `GameHaptics.cs` + `HapticEvent.cs`)
- Preserve clean separation inside `GameplayHapticsFeedback.HandleTileInteracted` so bounce/deflection pulses trigger on `InteractionKind.Deflect` rather than blunt `InteractionKind.Hit` collisions.
- Add crisp tactile mapping aligned with audio/VFX moments:
  - Light transient tap on genuine `OnMoveStarted` / `OnLauncherRedirected`.
  - Sharp rhythmic snap on `OnRedirected` (`DeflectionWedge` / `VectorPad`).
  - Tiered impact thump on `OnWallImpact` (deep double-tap on `OnBlockBroken` or `VelocityTier.KineticRam` break).
  - Micro-tick on `CloseCallDetector` near-miss and reward chime pulse on `StarCollectFeedback` / completion settle.
- Enforce short per-category cooldown guards inside `GameHaptics` so high-speed multi-tile traversal never saturates hardware haptics.

### Pillar 5 — Camera Interpolation, Micro-Framing & Pause-Safe Level Flow

#### 5.1 Camera & Physics Display Synchronization (`Assets/Scenes/GameScene.unity` + `PlayerMovement.cs`)
- **Required Configuration**:
  - `Main Camera` -> `CinemachineBrain`: set `UpdateMethod = LateUpdate` (`1`), keep `BlendUpdateMethod = LateUpdate` (`1`), and set `IgnoreTimeScale = true` (`1`).
  - `Player` -> `Rigidbody2D`: set `m_Interpolate = 1` in `GameScene.unity` and enforce `if (Application.isPlaying) rb.interpolation = RigidbodyInterpolation2D.Interpolate;` inside `PlayerMovement.EnsureInitialized()`.
- **Architectural Necessity**:
  1. Switching `UpdateMethod` to `LateUpdate` removes Cinemachine's binding to `UpdateTracker`'s `Fixed` clock so `CameraUpdateManager` runs `CinemachineCamera`, `CinemachineImpulseListener`, and `CinemachineCameraZoom2D` during Hit-Stop (`Time.timeScale == 0f`).
  2. Enabling `RigidbodyInterpolation2D.Interpolate` eliminates 50 Hz physics vs display-rate visual judder at `moveSpeed = 30` and keeps `Player`, `PlayerLineTrail`, and `CinemachineCamera` visually locked together without changing a single line of deterministic grid collision logic in `FixedUpdate`.

#### 5.2 Dynamic Framing, Close Calls & Victory Settle (`CinemachineCameraZoom2D`, `CloseCallDetector`, `StarCollectFeedback`, `LevelFlowController`)
- **`CinemachineCameraZoom2D`**: Applies subtle FOV/orthographic breathing around `GameScene.unity`'s `OrthographicSize: 5.5` during `VelocityTier.KineticRam` / `IsPhasing` runs and crisp recovery on stop (paused while `UIManager.IsTimeFrozenByModal`).
- **`CloseCallDetector` & `StarCollectFeedback`**: Pair `Particle Star.prefab` (`useUnscaledTime = 1`) with subtle chime and light haptic when narrowly clearing hazards or collecting stars, continuing smoothly across brief Hit-Stop windows.
- **`LevelFlowController` Settle Beat**: Preserves exact `movesUsedThisRun` accuracy (`OnMoveStarted` only) and lets any concurrent break/wall Hit-Stop complete cleanly inside `SettleLevelCompletion` before popping completion UI through `UIManager`.
- **UI Animation Rule**: Any popup/banner tween uses explicit serialized references (never auto-`GetComponent`) with `.DOKill()`, `.SetUpdate(true)`, and `.SetLink(gameObject)`, keeping item/chest icons at full opacity unless explicitly configured via state sprites.
