# Gravita — Kinetic Lab Game Feel Upgrade Blueprint

> **Codebase Calibration Note (Current Truth vs. Design Targets)**
> 1. **Speed & Velocity Tiers**: In `Assets/Scenes/GameScene.unity`, `PlayerMovement.moveSpeed` is `30` units/sec (`cellSize = 1`), meaning Subject G-0 traverses **1 tile every `33.3 ms`** (and **`48 u/s`** during `StepPhaseLaunch` at `1.6x`). In `VelocityTier.cs` (and `docs/gdd.md`), `VelocityTierUtil.FromTiles(int tilesTraveled)` maps `0` -> `None`, `1–2` -> `Drift`, `3–4` -> `Cruise`, and `5+` -> `KineticRam` (reaching max tier in **`167 ms`**), whereas the high-level spec describes `1–3 / 4–7 / 8+`. Every timing below is calibrated to the live `33.3 ms/tile` (`30 u/s`) loop and scales automatically if `FromTiles` is tuned later.
> 2. **Economy & Revive Flags**: `Assets/Resources/EconomyBalanceConfig.asset` sets `enableLegacyExtraRewardSystems: 0` (suppressing `CloseCallDetector`'s `bonusCoins: 5`), `enableMidGameplayRevive: 0` (`LevelFlowController.CanRevive` is always `false` and `OnPlayerRevived` never fires), and `grantWalletCoinsFromInLevelPickups: 0` (`EconomyManager.OnCoinsChanged` does not increment per in-level coin pickup). Near-misses must therefore pay off through immediate audiovisual and post-FX surge, coin streak HUD pulses must hook `Collectible.OnAnyCoinCollected`, and respawn polish must hook active restart/respawn paths rather than revive.
> 3. **Camera Pixel-Perfect Lock**: `Assets/Scenes/GameScene.unity` currently enables both `CinemachinePixelPerfect` (`m_Enabled: 1`) on `CinemachineCamera` and URP `PixelPerfectCamera` (`m_Enabled: 1`, `m_AssetsPPU: 32`, `320x180`, `CropFrame: 0`) on `Main Camera`. Every dynamic tier zoom and lens pulse requires disabling **both** overrides.

## Target End-State Experience

When a player clears a chamber after these upgrades:
1. Every `33.3 ms` tile crosses on an ascending harmonic synth tick (`minInterval = 0.01f` so zero ticks drop); crossing 5 tiles kicks the camera out smoothly (`5.50 -> 5.72 -> 6.02`) and trails crisp afterimages while `PulseZoom`, directional impulses, ribbons, particles, and 2D impact anims all keep animating smoothly through `Time.timeScale = 0` hit-stop.
2. Swiping a perpendicular corner turn while still sliding lights a subtle directional "Input Coil" chevron on Subject G-0 (never falsely triggering on idle starts, blocked taps, or instant reversals) and whips cleanly through chained `DeflectionWedge` / `VectorPad` bounces with bisector sparks and ascending pitch—without inflating move counts or re-firing move-start sounds on redirects or phase-launch arrivals.
3. Crashing into a wall punches the camera *along the slide vector*, pins Subject G-0 flush against the collision face during unscaled hit-stop, plays the exact impact tier (never stale `LastImpactTier`), and fires unmistakable `MediumImpact` / `RigidImpact` haptics—while `BrakeTile` and `GravityBlock` give a soft magnetic settle with zero wall slam.
4. Threading past an arming `PulseLaser` or `SentinelDronePatrol` flashes an unscaled URP `Overclock` burst (`Bloom.intensity`, `ChromaticAberration`, `Vignette`, `-0.28` lens snap, world-space 3D `TextMeshPro` toast, directional shake), lab hazards/switches run silently on spawn/reset while telegraphing live ticks cleanly, and hazard deaths snap to the Result modal in `~0.60 s`.

## 1. Core Game Feel Diagnosis: Why Gravita Currently Feels "Flat"

Gravita's deterministic stop-to-stop physics, velocity tiers, squash/stretch, trails, shake, and hit-stop are cleanly separated—but six concrete implementation leaks cancel out speed and impact weight in live play:

1. **Pixel-Perfect Camera Lock, Cinemachine Update Freezing & Scaled Hit-Stop Conflicts**
   - `CinemachineCameraZoom2D` currently has **zero callers** anywhere in code and uses scaled `Time.deltaTime`. Even when called, `CinemachinePixelPerfect.PostPipelineStageCallback` overwrites `state.Lens.OrthographicSize` to integer `PPU` steps (locking `1920x1080` and `1280x720` to `5.625` across `4.82–6.75` and `4.50–7.50`), and disabling *only* `CinemachinePixelPerfect` leaves `PixelPerfectCamera.m_CinemachineCompatibilityMode == false` so `PixelPerfectCamera.OnBeginCameraRendering` forces `m_Camera.orthographicSize` down to `2.8125` at `1080p`.
   - `Main Camera`'s `CinemachineBrain` serializes `UpdateMethod: 2` (`SmartUpdate`) and `IgnoreTimeScale: 0` while `CinemachineCamera` targets `Player` (which moves in `PlayerMovement.FixedUpdate()`), locking `UpdateTracker` to `UpdateClock.Fixed`. During `Time.timeScale = 0f` hit-stop (`33 ms` `Cruise`, `40 ms` `CrackedBlock`, `70 ms` `KineticRam`), Unity skips `FixedUpdate`, so `CameraUpdateManager.UpdateVirtualCamera` skips updating `CinemachineCamera.State` in `LateUpdate` and `CinemachineImpulseManager.Instance.IgnoreTimeScale` (`false`) freezes `CinemachineImpulseListener` and `PulseZoom` for the entire hit-stop window.
   - Simultaneously, `PlayerLineTrail.LateUpdate()` returns early on `Time.deltaTime <= 0f`, `ReturnToPool` uses scaled `WaitForSeconds`, `PooledParticlePlayer` tracks `Time.deltaTime`, existing particle prefabs (`WallImpactBurst.prefab`, `WallImpactBreak.prefab`, `Particle Star.prefab`) serialize `useUnscaledTime: 0`, `PoppingVFX.prefab` runs its `Animator` in `Normal` (`0`) update mode, and `PlayerImpactFeedback.OnDisable()` stops `hitStopRoutine` without restoring `Time.timeScale` or `CinemachineBrain`.
2. **Pivot Offset Mismatch, False Brake/Gravity Slams & Stale/Sub-Tile Impact Reads**
   - `Player/Sprite` in `GameScene.unity` sits at `localPosition (0, -0.5, 0)` with bottom-center `(0.5, 0)` pivot and `0.37 x 0.36` world bounds. `PlayerSquashStretch.Play()` applies only raw `pressDirection * (wallPressPx / 32f)` without compensating for sprite height or pivot, so upward ceiling hits compress *away* from the top wall face.
   - `PlayerImpactFeedback.HandleStopped()` listens to `OnMoveStopped` **without checking `movement.WasLastStopWallImpact`**, causing cushioned stops on `BrakeTile` and `GravityBlock` to trigger wall-impact shake and hit-stop.
   - `PlayerMovement` invokes `OnWallImpact` *before* `StopMoving(wallImpact: true)` writes `LastImpactTier`, so reading `LastImpactTier` inside `OnWallImpact` plays the **previous** dash's tier. Conversely, stops under `1.0 u` (such as starting adjacent to a blunt `DeflectionWedge` on `Layer 0` vs `wallLayers = 64`, halting at `0.049 u`) enter `OnWallImpact` with `CurrentTier == VelocityTier.None`—meaning falling back to `LastImpactTier` would replay a stale `KineticRam` slam on a sub-tile tap.
3. **Omnidirectional Shake, Particle Axis Mismatch & Empty/Colliding Per-Prefab Feedback**
   - `CinemachineCameraShake2D.ShakeCamera(float force)` calls `impulseSource.GenerateImpulse(force)` against a fixed `DefaultVelocity = (0, -1, 0)`, kicking the camera downward regardless of travel direction—and `InteractionEffectPlayer`, `CloseCallDetector`, `StarCollectFeedback`, and `BreachSequencer` all invoke that 1-arg downward path.
   - `WallImpactBurst.prefab`, `WallImpactBreak.prefab`, and `Particle Star.prefab` use a 3D Cone `ShapeModule` (`rotation = 0,0,0`) emitting along local **`+Z`**, whereas `InteractionEffectPlayer.ResolveRotation` applies 2D Z-axis `Atan2` rotation intended for `+X` 2D Animator sprites (`PoppingVFX.prefab`, `impactAnimationPrefab`). Meanwhile `tier1Shake`, `redirectShake`, `impactAnimationPrefab`, and `blockBreakAnimationPrefab` are zero/null in `GameScene.unity`, `CrackedBlock.OnAnyBroken` triggers zero hit-stop/shake, and `Wedge.prefab`, `Brake.prefab`, `Exit.prefab`, and `Hazard.prefab` have empty `InteractionEffectPlayer`s.
4. **167ms "Runway Blindness", Phase Clipping, 3-Site `OnMoveStarted` Double-Fire & Unfiltered Input State**
   - At `30 u/s`, Subject G-0 reaches `KineticRam` in `0.167 s` without per-tile audio escalation or afterimages, while `PlayerLineTrail` clamps `instSpeed` to `[4f, 28f]`—clipping both `30 u/s` runs and `48 u/s` `StepPhaseLaunch` phasing.
   - `PlayerMovement` fires redundant `OnMoveStarted` at three non-idle sites: `StepPhaseLaunch` arrival (`line 463` after `SetPhasing(false)`), `StartPhaseLaunch` zero-distance (`line 516`), and `Redirect()` (`line 998`), inflating `LevelFlowController.movesUsedThisRun`, double-playing `moveStart` + `wedgeRedirect`/`phaseExit`, and wiping `PlayerSquashStretch`'s `KineticRam` elongation mid-dash.
   - `PlayerMovement.QueueDirection` writes raw `pendingDirection` on normal idle launches, blocked adjacent-wall swipes, and mid-slide reversals, so visual turn indicators cannot read raw `pendingDirection` safely.
5. **Audio Pool Hijack Risk, Unsubscribed/Spawn-Leaking World Hooks & Unscaled Post-FX Calibration**
   - `SoundConfig.asset` has `clips: []` on all `23` `SoundEntry` fields. Worse, `AudioSystems.prefab` orders `MusicManager` before `SoundManager` and leaves `SoundManager.poolContainer: null`, `pooledAudioSourcePrefab: null`, `fallbackAudioSource: null`, `musicSource: null`, and `ambientSource: null`—meaning wiring `musicSource`/`ambientSource` without a dedicated `poolContainer` causes `SoundManager.InitializePool()` to sweep all child `AudioSource`s into `sfxPool` and overwrite `outputAudioMixerGroup` to `sfxMixerGroup`.
   - `CloseCallDetector.OnCloseCallTriggered` has **0 subscribers**, `Global Volume Profile.asset` is static at runtime, `EnergyGate.OnLevelClockTick` clears `pendingDeferredClose` silently, and adding static broadcasts on `HazardActivation` / `FailingTile` without `Awake`/`OnLevelClockReset` suppression would trigger burst SFX/shake on every spawn and restart.
6. **Flat Haptic Priority Blocking & `1.60 s` Failure Loop**
   - `GameHaptics.EventCount = 7` emits identical `LightImpact` across all wall speeds, while `GlobalMinGapSeconds = 0.03f` silently suppresses higher-priority `KineticRamImpact` when `TierUp` or `BlockSmash` fires on the same tick (`0.000 s`) or one `FixedUpdate` tick prior (`0.020 s` at `30 u/s`).
   - `CutsceneManager.DeathRoutine` uses `deathFallbackDuration = 0.8f` + `endFadeDuration = 0.4f` (~`1.60 s` total delay before showing the Result panel).

## 2. Six High-Impact Game Feel Pillars

All systems below obey Gravita's 4-layer architecture, create **zero** runtime `new GameObject(...)` or `AddComponent<...>()`, preserve deterministic `SimulateStep` grid physics, and guard every DOTween tween/sequence with `.DOKill()` (or `?.Kill()`), `.SetUpdate(true)`, and `.SetLink(gameObject)`.

### Pillar 1: Kinetic Runway Engine ("33ms-per-Tile Escalation & Hit-Stop-Live Unscaled Lens")

#### Why It Makes Gravita Uniquely Addictive
Because slides finish in fractions of a second (`167 ms` to reach `KineticRam`), static trail color swaps aren't enough for the player's nervous system to *feel* acceleration. Turning every crossed tile into an ascending harmonic synth tick paired with unscaled additive camera zoom-out, crisp `KineticRam` afterimages, and trail/particle/camera playback that stays 100% live during `Time.timeScale = 0` hit-stop turns long corridors into an accelerating slingshot.

#### Exact C# Integration Hooks
- **`SoundManager.cs`**: Add `PlaySFXWithPitch(SoundEntry entry, float pitch, float volumeScale = 1f)` clamping pitch to `[0.5f, 2.0f]` and passing it directly to `PlayResolvedClip` without mutating `SoundConfig` or randomizing pitch. Ensure `SoundConfig` entries triggered every tile (`tileTick`, `coinCollect`) use `minInterval = 0.01f`.
- **`PlayerImpactFeedback.cs` (Hit-Stop Brain & TimeScale Guard)**:
  Serialize `[SerializeField] private CinemachineBrain cinemachineBrain;` (`Unity.Cinemachine`, resolved in `Awake()` from `Camera.main` if unassigned). Expose `public static bool IsHitStopActive { get; private set; }` with `[RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.SubsystemRegistration)] private static void ResetStaticState() => IsHitStopActive = false;`. Snapshot pre-hit-stop state **only when `!hasActiveHitStop`** so chained hit-stops never capture `Time.timeScale = 0f` or `UpdateMethods.LateUpdate`:
  ```csharp
  private bool hasActiveHitStop;
  private float preHitStopTimeScale = 1f;
  private CinemachineBrain.UpdateMethods preHitStopBrainUpdateMethod;
  private bool preHitStopBrainIgnoreTimeScale;

  private IEnumerator HitStopRoutine(float duration)
  {
      if (!hasActiveHitStop)
      {
          hasActiveHitStop = true;
          IsHitStopActive = true;
          preHitStopTimeScale = Time.timeScale;
          if (cinemachineBrain != null)
          {
              preHitStopBrainUpdateMethod = cinemachineBrain.UpdateMethod;
              preHitStopBrainIgnoreTimeScale = cinemachineBrain.IgnoreTimeScale;
              cinemachineBrain.UpdateMethod = CinemachineBrain.UpdateMethods.LateUpdate;
              cinemachineBrain.IgnoreTimeScale = true;
          }
      }
      Time.timeScale = 0f;
      yield return new WaitForSecondsRealtime(duration);
      RestoreHitStopState();
  }

  private void RestoreHitStopState()
  {
      if (!hasActiveHitStop) return;
      Time.timeScale = preHitStopTimeScale;
      if (cinemachineBrain != null)
      {
          cinemachineBrain.UpdateMethod = preHitStopBrainUpdateMethod;
          cinemachineBrain.IgnoreTimeScale = preHitStopBrainIgnoreTimeScale;
      }
      IsHitStopActive = false;
      hasActiveHitStop = false;
      hitStopRoutine = null;
  }
  ```
  Call `RestoreHitStopState()` inside `OnDisable()` as well. Keeping `SmartUpdate` and `IgnoreTimeScale = false` on `CinemachineBrain` at all other times preserves jitter-free `FixedUpdate` tracking at `Time.timeScale == 1` (`Rigidbody2D` `Interpolate = None`) and freezes camera updates when Pause Menu sets `Time.timeScale = 0f` (`IsHitStopActive == false`).
- **`CinemachineCameraZoom2D.cs` (`[DefaultExecutionOrder(-10)]` + `LateUpdate` Composition)**:

  ```csharp
  [DefaultExecutionOrder(-10)]
  public class CinemachineCameraZoom2D : MonoBehaviour
  {
      private float currentBaseSize;
      private float pulseOffset;
      private Sequence pulseSequence;

      private void Awake()
      {
          // ... existing singleton setup ...
          if (disablePixelPerfectOverrides)
          {
              if (cinemachinePixelPerfect != null) cinemachinePixelPerfect.enabled = false;
              if (urpPixelPerfectCamera != null) urpPixelPerfectCamera.enabled = false;
          }
          currentBaseSize = normalOrthographicSize > 0f ? normalOrthographicSize : 5.5f;
          if (targetOrthographicSize <= 0f) targetOrthographicSize = currentBaseSize;
      }

      private void LateUpdate()
      {
          if (cinemachineCamera == null) return;
          float dt = PlayerImpactFeedback.IsHitStopActive ? Time.unscaledDeltaTime : Time.deltaTime;
          if (dt <= 0f) return;
          float alpha = 1f - Mathf.Exp(-zoomSpeed * dt);
          currentBaseSize = Mathf.Lerp(currentBaseSize, targetOrthographicSize, alpha);
          cinemachineCamera.Lens.OrthographicSize = Mathf.Max(1f, currentBaseSize + pulseOffset);
      }

      public void PulseZoom(float orthoDelta, float inDuration, float outDuration)
      {
          pulseSequence?.Kill();
          pulseSequence = DOTween.Sequence()
              .Append(DOTween.To(() => pulseOffset, x => pulseOffset = x, orthoDelta, inDuration).SetEase(Ease.OutQuad))
              .Append(DOTween.To(() => pulseOffset, x => pulseOffset = x, 0f, outDuration).SetEase(Ease.OutSine))
              .SetUpdate(true)
              .SetLink(gameObject)
              .OnKill(() => pulseOffset = 0f);
      }
  }
  ```

  {

      private Sequence fadeSequence;

      public void Play(SpriteRenderer source, Color tint, float fadeDuration)
      {
          if (spriteRenderer == null || source == null) return;
          spriteRenderer.sprite = source.sprite;
          spriteRenderer.flipX = source.flipX;

      }

      private void OnDisable()

          fadeSequence = null;
      }
  }

### Pillar 2: Directional Impact Physics, Wall-Face Compression & Break/Brake Fidelity

#### Why It Makes Gravita Uniquely Addictive
In a stop-to-stop maze, impact *is* the punctuation mark of every swipe. Fixing directional camera kick across every caller, keeping Subject G-0 pinned flush against ceilings and walls during hit-stop compression, distinguishing soft `BrakeTile`/`GravityBlock` stops from hard wall slams, routing 3D `+Z` particles vs. 2D `+X` animations onto their real emission axes in *both* `PlayerImpactFeedback` and `InteractionEffectPlayer`, and ensuring sub-tile stops never replay stale `KineticRam` sounds makes every collision feel physically honest.

| `PlayerImpactFeedback.tier2Shake` / `tier3Shake` | `0.1` / `0.2` | `0.13` / `0.28` | Clear contrast between Cruise and KineticRam |
