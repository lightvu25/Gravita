# Gravita (*Puzzle 2D*) — Game Feel Signature Architecture & Engineering Blueprint

**Project:** `Puzzle 2D` (Unity `6000.4.0f1` URP, 2D Grid Puzzle, 32 PPU)  
**Target Loop:** Deterministic cardinal sliding (`moveSpeed = 30 u/s`, `PhaseLaunch` up to `48 u/s`, `1 u = 32 px`) across kinetic wedges, vector pads, launchers, brittle/failing floors, timed hazards, switches, collectibles, and close-call threats.

---

## 0. Architectural Invariants & Non-Negotiable Constraints

1. **Deterministic Grid Physics & Solvability Invariance:** `PlayerMovement.FixedUpdate` (`SimulateStep`), `CellResolver`, `Hazard`, `LevelClock`, and all `Collider2D` dimensions/layers remain untouched in physics timing and hitbox geometry. Every game-feel driver attaches to existing events (`PlayerMovement`, `MazeTile`, `IPlayerInteractable`, `BrittleFloor`, `FailingTile`, `HazardActivation`, `CircuitSwitch`, `EnergyGate`, `CloseCallDetector`, `Collectible`, `LevelRoot`, `UIManager`) and mutates **only** collider-free visual children, shaders/materials, camera impulses/zoom, audio voices, haptics, and pooled VFX.
2. **Zero Runtime Ad-Hoc Hierarchy Mutation:** Never call `new GameObject(...)` or `AddComponent<T>(...)` for UI, VFX, or managers. Every voice/VFX/overlay component is wired in Inspector via `.prefab` assets (`PooledSfxVoice.prefab`, `CloseCallRingVFX.prefab`, `WallImpactBurst.prefab`) or static child hierarchy (`Player/TurnTelegraphPivot`).
3. **Timebase Discipline (`Time.timeScale` vs. Unscaled UI/Audio/Camera):**
   - **Physics & Gameplay-Clocked Animation:** `LevelClock`, `FailingTile`, `HazardActivation`, `TilePulseFeedback`, `TurnTelegraphFeedback`, and world-space `ParticleSystem` bursts (`useUnscaledTime = false`) follow scaled game time (`.SetUpdate(false)`), so **both** Hit-Stop (`PlayerImpactFeedback`, `Time.timeScale = 0f`) and Modal Pause (`UIManager.IsTimeFrozen`, `Time.timeScale = 0f`) halt gameplay presentation in lockstep.
   - **Cinemachine Impulse Clock:** `CinemachineImpulseManager.Instance.IgnoreTimeScale` is locked to `true` once at initialization and **never toggled back to `false`** across Hit-Stop boundaries, eliminating epoch jumps and negative-offset muting. Only `cinemachineBrain.IgnoreTimeScale` toggles during Hit-Stop, while Modal Freeze clears all active impulses via `CinemachineImpulseManager.Instance.Clear()`.
   - **Modal-Pause Isolation:** `UIManager.UpdateTimeScale()` publishes `public bool IsTimeFrozen { get; private set; }`. Unscaled pooled VFX/Animator lifecycles (`ReturnToPool`, `PooledParticlePlayer`) track per-emitter modal pause flags (`pausedByModalFlags[]`) so modal menus pause live unscaled effects without retriggering completed bursts or `StopEmitting` loopers.
4. **Editor Tooling Scope:** Editor scripts/CLI may only generate `.asset` (`ScriptableObject`) data or non-UI `.prefab` assets and run `recompile` / `run_tests`. No programmatic modification of `Assets/Scenes/GameScene.unity` UI hierarchy.

## 1. Signature Sensory Identity — *Kinetic Precision in the Glitch Vault*

Gravita sits at the intersection of pinpoint arcade puzzle routing and tactile synth-cybernetic physics. Because `PlayerMovement` glides cleanly at `30 u/s` (and `48 u/s` under `1.6x` `PhaseLaunch`) across a `32 PPU` grid, game feel hinges on **sub-frame micro-contrast**:

- **Sharp Anticipation (Queue & Turn Telegraph):** Swiping perpendicular mid-slide (`bufferTurnsUntilStop = true`) immediately lights `Player/TurnTelegraphPivot/ArrowSprite` along the queued vector in current tier color (`Cyan` Drift / `Gold` Cruise / `Magenta` KineticRam), giving instant spatial confirmation before wall impact.
- **Velocity Runway Escalation (`VelocityTierUtil`):**
  - `Drift` (`1–2` tiles): Cyan energy palette (`#59F2FF`), crisp subtle squash/stretch, zero camera shake.
  - `Cruise` (`3–4` tiles): Gold shift (`#FFD940`), wider trail (`1.2x`), `0.033s` Hit-Stop + `0.10` directional camera impulse + burst sparks.
  - `KineticRam` (`5+` tiles) & `PhaseLaunch`: Electric Magenta (`#FF52C7`) / Violet Phase (`#B86BFF`), `1.45x` trail width, `0.083s` Hit-Stop + `0.20` impulse + `Hit Flash White.mat` frame snap + shockwave particles.
- **Combinatorial Audio Musicality:** Overlapping wall slides, coin pickups, and wedge redirects play on a true polyphonic `AudioSource` voice pool (`12` pre-seeded voices, `24` cap) with zero pitch-bleed onto already-ringing tails, `0ms` cooldown on deterministic impulse gameplay triggers (`wedgeRedirect`, `coinCollect`, `starCollect`), and streak counters committed **only after** `SoundManager.TryPlaySFX` confirms voice emission.
- **Per-Mechanic World Tactility:** Multi-visual and state-driven tiles (`FailingTile`, `HazardActivation` on `PulseLaser`/`OverloadedFloor`, `BrittleFloor`, `CircuitSwitch`, `EnergyGate`, `SentinelDronePatrol`, `DeflectionWedge`, `VectorPad`, `VectorLauncher`, `BrakeTile`, `GravityBlock`, `CrackedBlock`, `LevelExit`) respond uniformly through `TilePulseFeedback` using safe material-swap white flashes (`Hit Flash White.mat`) and collider-free child transforms.

## 2. Pillar 1 — Camera Impulse, Hit-Stop & Freeze Integrity

### 2.1 Root Timebase Guarantee
In `CinemachineImpulseManager`, `CurrentTime` switches between `CinemachineCore.CurrentTime` (`Time.time`) and `Time.realtimeSinceStartup` depending on `IgnoreTimeScale`. Toggling `IgnoreTimeScale` from `false` to `true` when entering Hit-Stop makes `CurrentTime` leap forward by `(Time.realtimeSinceStartup - Time.time)` (all accumulated pause, load, and earlier hit-stop time), causing previously triggered `Legacy` impulses (`SustainTime = 0.2s`, `DecayTime = 0.7s * sqrt(|v|)`) to expire on frame 0. Conversely, reverting `IgnoreTimeScale` from `true` back to `false` when exiting Hit-Stop makes `CurrentTime` jump backward, muting Hit-Stop-generated impulses until `Time.time` catches up.

**Invariant Solution:**
1. Set `CinemachineImpulseManager.Instance.IgnoreTimeScale = true` **once** during initialization in both `CinemachineCameraShake2D.Awake()` and `PlayerImpactFeedback.Awake()`. Never write `false` back to `CinemachineImpulseManager.Instance.IgnoreTimeScale` in `EndHitStopImmediate` or `OnDisable`.
2. During Hit-Stop (`PulseHitStop`), toggle **only** `cinemachineBrain.IgnoreTimeScale = true` so `CinemachineImpulseListener` and camera blends evaluate during `Time.timeScale == 0f`, restoring `cinemachineBrain.IgnoreTimeScale = false` when Hit-Stop ends.
3. Expose `public bool IsTimeFrozen { get; private set; }` from `UIManager.UpdateTimeScale()` and `public static bool IsHitStopActive { get; private set; }` from `PlayerImpactFeedback`.
4. Suppress `CinemachineCameraShake2D.ShakeCamera(...)` whenever `UIManager.Instance != null && UIManager.Instance.IsTimeFrozen`. On `UIManager.OnPopupStackChanged`, if `IsTimeFrozen` becomes `true`, call `EndHitStopImmediate(restoreTimeScale: false)` and `CinemachineImpulseManager.Instance.Clear()` so active shakes terminate immediately on pause.

```csharp
/// <summary>True whenever the active modal popup stack freezes scaled game time (Time.timeScale == 0).</summary>
public bool IsTimeFrozen { get; private set; }

private void UpdateTimeScale()
{
    bool shouldFreeze = false;
    for (int i = 0; i < popupStack.Count; i++)
    {
        if (GetFreezeTime(popupStack[i]))
        {
            shouldFreeze = true;
            break;
        }
    }

    IsTimeFrozen = shouldFreeze;
    Time.timeScale = shouldFreeze ? 0f : 1f;
}
```

### 2.3 Code Specification — `CinemachineCameraShake2D.cs`

```csharp
using Unity.Cinemachine;
using UnityEngine;

/// <summary>
/// Centralized 2D camera impulse driver. Locks CinemachineImpulseManager onto the
/// monotonic realtime clock so pre-, intra-, and post-Hit-Stop impulses stay coherent,
/// while honoring UIManager modal freezes.
/// </summary>
public class CinemachineCameraShake2D : MonoBehaviour
{
    public static CinemachineCameraShake2D Instance { get; private set; }

    [SerializeField] private CinemachineImpulseSource impulseSource;
    [SerializeField, Range(0.5f, 2f)] private float directionalBias = 1.15f;

    private void Awake()
    {
        if (Instance != null && Instance != this)
        {
            Destroy(this);
            return;
        }

        Instance = this;

        if (impulseSource == null)
            impulseSource = GetComponent<CinemachineImpulseSource>();

        // Lock once onto unscaled monotonic timebase; never toggle back to false across Hit-Stops.
        if (CinemachineImpulseManager.Instance != null)
            CinemachineImpulseManager.Instance.IgnoreTimeScale = true;
    }

    private void OnDestroy()
    {
        if (Instance == this)
            Instance = null;
    }

    public void ShakeCamera(float force)
    {
        if (force <= 0f || impulseSource == null)
            return;

        if (UIManager.Instance != null && UIManager.Instance.IsTimeFrozen)
            return;

        impulseSource.GenerateImpulse(force);
    }

    public void ShakeCamera(Vector2 direction, float force)
    {
        if (force <= 0f || impulseSource == null)
            return;

        if (UIManager.Instance != null && UIManager.Instance.IsTimeFrozen)
            return;

        Vector2 normalized = direction.sqrMagnitude > 0.0001f ? direction.normalized : Vector2.down;
        impulseSource.GenerateImpulse((Vector3)(normalized * (force * directionalBias)));
    }
}
```

### 2.4 Code Specification — `PlayerImpactFeedback.cs`

```csharp
using System.Collections;
using Unity.Cinemachine;
using UnityEngine;

/// <summary>
/// Coordinates impact camera impulses, hit-stop micro-freezes, and pooled wall/shatter VFX.
/// Synchronizes CinemachineBrain unscaled updates across Hit-Stop while keeping
/// CinemachineImpulseManager strictly on IgnoreTimeScale = true.
/// </summary>
[DisallowMultipleComponent]
[RequireComponent(typeof(PlayerMovement))]
public class PlayerImpactFeedback : MonoBehaviour
{
    public static bool IsHitStopActive { get; private set; }

    [Header("Camera Shake Force")]
    [SerializeField, Min(0f)] private float tier1Shake = 0f;
    [SerializeField, Min(0f)] private float tier2Shake = 0.10f;
    [SerializeField, Min(0f)] private float tier3Shake = 0.20f;
    [SerializeField, Min(0f)] private float redirectShake = 0.04f;
    [SerializeField, Min(0f)] private float closeCallShake = 0.05f;

    [Header("Hit-Stop Duration (seconds, unscaled)")]
    [SerializeField, Min(0f)] private float tier1HitStop = 0f;
    [SerializeField, Min(0f)] private float tier2HitStop = 0.033f;
    [SerializeField, Min(0f)] private float tier3HitStop = 0.083f;
    [SerializeField, Min(0f)] private float closeCallHitStop = 0.025f;
    [SerializeField] private bool hitStopEnabled = true;

    [Header("Pooled VFX Prefabs")]
    [SerializeField] private GameObject impactBurstPrefab;
    [SerializeField] private GameObject impactAnimationPrefab;
    [SerializeField] private GameObject blockBreakParticlePrefab;
    [SerializeField] private GameObject blockBreakAnimationPrefab;
    [SerializeField] private GameObject closeCallRingPrefab;

    [Header("Camera Integration")]
    [SerializeField] private CinemachineBrain cinemachineBrain;

    private PlayerMovement movement;
    private Coroutine hitStopCoroutine;
    private float preHitStopTimeScale = 1f;

    private void Awake()
    {
        movement = GetComponent<PlayerMovement>();

        if (cinemachineBrain == null && Camera.main != null)
            Camera.main.TryGetComponent(out cinemachineBrain);

        if (CinemachineImpulseManager.Instance != null)
            CinemachineImpulseManager.Instance.IgnoreTimeScale = true;
    }

    private void OnEnable()
    {
        if (movement == null)
            movement = GetComponent<PlayerMovement>();

        if (movement != null)
        {
            movement.OnWallImpact += HandleWallImpact;
            movement.OnRedirected += HandleRedirected;
        }

        CloseCallDetector.OnCloseCallTriggered += HandleCloseCall;

        if (UIManager.Instance != null)
            UIManager.Instance.OnPopupStackChanged += HandlePopupStackChanged;
    }

    private void OnDisable()
    {
        if (movement != null)
        {
            movement.OnWallImpact -= HandleWallImpact;
            movement.OnRedirected -= HandleRedirected;
        }

        CloseCallDetector.OnCloseCallTriggered -= HandleCloseCall;

        if (UIManager.Instance != null)
            UIManager.Instance.OnPopupStackChanged -= HandlePopupStackChanged;

        EndHitStopImmediate(restoreTimeScale: UIManager.Instance == null || !UIManager.Instance.IsTimeFrozen);
    }

    private void HandlePopupStackChanged()
    {
        if (UIManager.Instance != null && UIManager.Instance.IsTimeFrozen)
        {
            // UIManager owns Time.timeScale = 0f during modal pause; abort hit-stop and clear pending shake.
            EndHitStopImmediate(restoreTimeScale: false);
            CinemachineImpulseManager.Instance?.Clear();
        }
    }

    private void HandleWallImpact(Vector2 normal)
    {
        if (normal == Vector2.zero)
            return;

        VelocityTier tier = movement != null ? movement.LastImpactTier : VelocityTier.Drift;
        float shake = ResolveTierShake(tier);
        float stop = ResolveTierHitStop(tier);

        if (shake > 0f && CinemachineCameraShake2D.Instance != null)
            CinemachineCameraShake2D.Instance.ShakeCamera(-normal, shake);

        if (stop > 0f)
            TriggerHitStop(stop);

        Vector3 spawnPos = movement != null ? (Vector3)movement.LastImpactPoint : transform.position;
        Quaternion rot = Quaternion.Euler(0f, 0f, Mathf.Atan2(normal.y, normal.x) * Mathf.Rad2Deg);

        if (impactBurstPrefab != null)
            ParticleSpawner.SpawnEffect(impactBurstPrefab, spawnPos, rot);

        if (impactAnimationPrefab != null)
            PrefabAnimationSpawner.SpawnEffect(impactAnimationPrefab, spawnPos, rot);
    }

    private void HandleRedirected(Vector2 outgoingDir)
    {
        if (redirectShake > 0f && CinemachineCameraShake2D.Instance != null)
            CinemachineCameraShake2D.Instance.ShakeCamera(outgoingDir, redirectShake);
    }

    private void HandleCloseCall(Vector3 midpoint)
    {
        if (closeCallShake > 0f && CinemachineCameraShake2D.Instance != null)
            CinemachineCameraShake2D.Instance.ShakeCamera(closeCallShake);

        if (closeCallHitStop > 0f)
            TriggerHitStop(closeCallHitStop);

        if (closeCallRingPrefab != null)
            ParticleSpawner.SpawnEffect(closeCallRingPrefab, midpoint, Quaternion.identity);
    }

    public void SpawnBlockBreakEffects(Vector3 position, Vector2 impactDirection)
    {
        Quaternion rot = impactDirection.sqrMagnitude > 0.001f
            ? Quaternion.Euler(0f, 0f, Mathf.Atan2(impactDirection.y, impactDirection.x) * Mathf.Rad2Deg)
            : Quaternion.identity;

        if (blockBreakParticlePrefab != null)
            ParticleSpawner.SpawnEffect(blockBreakParticlePrefab, position, rot);

        if (blockBreakAnimationPrefab != null)
            PrefabAnimationSpawner.SpawnEffect(blockBreakAnimationPrefab, position, rot);
    }

    private float ResolveTierShake(VelocityTier tier) => tier switch
    {
        VelocityTier.KineticRam => tier3Shake,
        VelocityTier.Cruise => tier2Shake,
        VelocityTier.Drift => tier1Shake,
        _ => 0f
    };

    private float ResolveTierHitStop(VelocityTier tier) => tier switch
    {
        VelocityTier.KineticRam => tier3HitStop,
        VelocityTier.Cruise => tier2HitStop,
        VelocityTier.Drift => tier1HitStop,
        _ => 0f
    };

    private void TriggerHitStop(float duration)
    {
        if (!hitStopEnabled || duration <= 0f)
            return;

        if (UIManager.Instance != null && UIManager.Instance.IsTimeFrozen)
            return;

        if (hitStopCoroutine != null)
            StopCoroutine(hitStopCoroutine);
        else
            preHitStopTimeScale = Time.timeScale > 0f ? Time.timeScale : 1f;

        hitStopCoroutine = StartCoroutine(HitStopRoutine(duration));
    }

    private IEnumerator HitStopRoutine(float duration)
    {
        IsHitStopActive = true;
        Time.timeScale = 0f;

        if (cinemachineBrain != null)
            cinemachineBrain.IgnoreTimeScale = true;

        float elapsed = 0f;
        while (elapsed < duration)
        {
            if (UIManager.Instance != null && UIManager.Instance.IsTimeFrozen)
            {
                EndHitStopImmediate(restoreTimeScale: false);
                yield break;
            }

            elapsed += Time.unscaledDeltaTime;
            yield return null;
        }

        EndHitStopImmediate(restoreTimeScale: true);
    }

    private void EndHitStopImmediate(bool restoreTimeScale)
    {
        if (hitStopCoroutine != null)
        {
            StopCoroutine(hitStopCoroutine);
            hitStopCoroutine = null;
        }

        if (cinemachineBrain != null)
            cinemachineBrain.IgnoreTimeScale = false;

        // Note: CinemachineImpulseManager.Instance.IgnoreTimeScale remains true intentionally.
        if (IsHitStopActive)
        {
            IsHitStopActive = false;
            if (restoreTimeScale && (UIManager.Instance == null || !UIManager.Instance.IsTimeFrozen))
                Time.timeScale = preHitStopTimeScale > 0f ? preHitStopTimeScale : 1f;
        }
    }
}
```

## 3. Pillar 2 — Polyphonic Audio Engine, Substep Cooldowns & Concrete `SoundConfig` Mapping

### 3.1 Root Causes Eliminated
1. **Single-Source Pitch Bending:** `AudioSystems.prefab` previously carried one root `AudioSource` (`m_PlayOnAwake: 1`, `pooledAudioSourcePrefab: null`), causing `SoundManager.PlayResolvedClip` to overwrite `source.pitch` before `PlayOneShot` and bend the pitch of already-ringing notes in memory.
2. **Sub-Frame & Fast-Phase Trigger Suppression:** Clamping `Mathf.Max(0.01f, entry.minInterval)` against `Time.unscaledTime` dropped calls triggered inside consecutive `FixedUpdate` steps of the same frame (where `Time.unscaledTime` does not advance) or fast `PhaseLaunch` traversal (`48 u/s` = `20.8 ms/cell`).
3. **Silent Combo/Streak Desync:** `SoundManager.PlaySFX` returned `void`, causing `EntityAudio` to increment `redirectCombo++` and advance `coinStreak` before knowing whether a voice actually emitted.

### 3.2 `PooledSfxVoice.prefab` & `AudioSystems.prefab` Wiring
- **New Asset `Assets/Prefabs/Audio/PooledSfxVoice.prefab`:** Single `GameObject` (`PooledSfxVoice`) with one `AudioSource`:
  - `Play On Awake = false`, `Loop = false`, `Mute = false`, `Spatial Blend = 0` (2D), `Output = SFX` mixer group (matching `AudioSystems.prefab`).
- **`Assets/Prefabs/Manager/AudioSystems.prefab`:**
  - Root `AudioSource`: set **`m_PlayOnAwake = 0`** (eliminates spurious scene-load burst).
  - `SoundManager` Inspector: assign `pooledAudioSourcePrefab = Assets/Prefabs/Audio/PooledSfxVoice.prefab`, `initialPoolSize = 12`, `maxPoolSize = 24`.
  - Pre-populate `12` child `PooledSfxVoice` instances in `AudioSystems.prefab` (or clean up any null `sfxPool` slots such as the `{fileID: 0}` scene override in `InitializePool()` before topping up to `initialPoolSize`).

### 3.3 `SoundManager.cs` Specification

```csharp
using System;
using System.Collections.Generic;
using UnityEngine;

public partial class SoundManager : MonoBehaviour
{
    [Header("Polyphonic Pool Configuration")]
    [SerializeField] private AudioSource pooledAudioSourcePrefab;
    [SerializeField, Min(1)] private int initialPoolSize = 12;
    [SerializeField, Min(4)] private int maxPoolSize = 24;
    [SerializeField] private List<AudioSource> sfxPool = new List<AudioSource>();

    private readonly Dictionary<SoundEntry, float> lastPlayedByEntry =
        new Dictionary<SoundEntry, float>(32);
    private readonly Dictionary<AudioClip, float> lastPlayedByClip =
        new Dictionary<AudioClip, float>(32);

    private void InitializePool()
    {
        for (int i = sfxPool.Count - 1; i >= 0; i--)
        {
            if (sfxPool[i] == null)
                sfxPool.RemoveAt(i);
            else
                ConfigurePooledVoice(sfxPool[i]);
        }

        if (TryGetComponent(out AudioSource rootSource))
            rootSource.playOnAwake = false;

        if (pooledAudioSourcePrefab == null)
            return;

        while (sfxPool.Count < initialPoolSize)
        {
            AudioSource voice = Instantiate(pooledAudioSourcePrefab, transform);
            voice.name = $"PooledSfxVoice_{sfxPool.Count:00}";
            ConfigurePooledVoice(voice);
            sfxPool.Add(voice);
        }
    }

    private static void ConfigurePooledVoice(AudioSource voice)
    {
        voice.playOnAwake = false;
        voice.loop = false;
        voice.spatialBlend = 0f;
    }

    private float GetSampleTime()
    {
        return Time.inFixedTimeStep ? Time.fixedUnscaledTime : Time.unscaledTime;
    }

    private bool IsOnCooldown(SoundEntry entry, float minInterval, float now)
    {
        if (minInterval <= 0f)
            return false;

        if (lastPlayedByEntry.TryGetValue(entry, out float lastTime))
        {
            float elapsed = now - lastTime;
            if (elapsed >= 0f && elapsed < minInterval)
                return true;
        }
        return false;
    }

    private bool IsClipOnCooldown(AudioClip clip, float minInterval, float now)
    {
        if (minInterval <= 0f)
            return false;

        if (lastPlayedByClip.TryGetValue(clip, out float lastTime))
        {
            float elapsed = now - lastTime;
            if (elapsed >= 0f && elapsed < minInterval)
                return true;
        }
        return false;
    }

    /// <summary>Backward-compatible UnityEvent / fire-and-forget wrapper.</summary>
    public void PlaySFX(SoundEntry entry)
    {
        TryPlaySFX(entry);
    }

    /// <summary>Backward-compatible clip wrapper.</summary>
    public void PlaySFX(AudioClip clip, float volume = 1f, bool randomPitch = true)
    {
        float pitch = randomPitch ? AudioPitchUtility.GetRandomPitch() : 1f;
        TryPlayClipWithMultiplier(clip, volume, pitch, minInterval: 0f);
    }

    /// <summary>
    /// Attempts to play a SoundEntry with dedicated pitch isolation and non-clamped cooldowns.
    /// Returns true strictly when an AudioSource voice actually begins playback.
    /// </summary>
    public bool TryPlaySFX(
        SoundEntry entry,
        float pitchMultiplier = 1f,
        float volumeMultiplier = 1f)
    {
        if (entry == null || entry.clips == null || entry.clips.Count == 0 || !CanEmitSfx()) // uses SoundManager's mute/enabled gate
            return false;

        float minInterval = Mathf.Max(0f, entry.minInterval);
        float now = GetSampleTime();
        if (IsOnCooldown(entry, minInterval, now))
            return false;

        AudioClip clip = entry.clips[UnityEngine.Random.Range(0, entry.clips.Count)];
        if (clip == null)
            return false;

        float basePitch = entry.randomizePitch
            ? AudioPitchUtility.GetRandomPitch(1f - entry.pitchVariance, 1f + entry.pitchVariance)
            : 1f;
        float finalPitch = Mathf.Clamp(basePitch * pitchMultiplier, 0.25f, 3f);
        float finalVolume = Mathf.Clamp01(entry.volume * volumeMultiplier) * CurrentSfxVolume(); // existing SoundManager SFX volume scale

        if (!TryPlayResolvedClip(clip, finalVolume, finalPitch))
            return false;

        if (minInterval > 0f)
        {
            lastPlayedByEntry[entry] = now;
            lastPlayedByClip[clip] = now;
        }
        return true;
    }

    public bool TryPlayClipWithMultiplier(
        AudioClip clip,
        float volumeMultiplier = 1f,
        float pitch = 1f,
        float minInterval = 0f)
    {
        if (clip == null || !CanEmitSfx())
            return false;

        float clampedMin = Mathf.Max(0f, minInterval);
        float now = GetSampleTime();
        if (IsClipOnCooldown(clip, clampedMin, now))
            return false;

        if (!TryPlayResolvedClip(clip, Mathf.Clamp01(volumeMultiplier) * CurrentSfxVolume(), Mathf.Clamp(pitch, 0.25f, 3f)))
            return false;

        if (clampedMin > 0f)
            lastPlayedByClip[clip] = now;
        return true;
    }

    private bool TryPlayResolvedClip(AudioClip clip, float volume, float pitch)
    {
        if (clip == null || volume <= 0.0001f)
            return false;

        if (TryAcquireIdleSource(out AudioSource idleSource))
        {
            idleSource.pitch = pitch;
            idleSource.clip = clip;
            idleSource.volume = volume;
            idleSource.Play();
            return true;
        }

        // Hard cap saturated: allow PlayOneShot only on an identically pitched playing voice so
        // previously triggered tails are NEVER pitch-warped.
        for (int i = 0; i < sfxPool.Count; i++)
        {
            AudioSource active = sfxPool[i];
            if (active != null && Mathf.Abs(active.pitch - pitch) <= 0.01f)
            {
                active.PlayOneShot(clip, volume);
                return true;
            }
        }

        return false;
    }

    private bool TryAcquireIdleSource(out AudioSource source)
    {
        for (int i = 0; i < sfxPool.Count; i++)
        {
            AudioSource candidate = sfxPool[i];
            if (candidate != null && !candidate.isPlaying)
            {
                source = candidate;
                return true;
            }
        }

        if (pooledAudioSourcePrefab != null && sfxPool.Count < maxPoolSize)
        {
            AudioSource spawned = Instantiate(pooledAudioSourcePrefab, transform);
            spawned.name = $"PooledSfxVoice_{sfxPool.Count:00}";
            ConfigurePooledVoice(spawned);
            sfxPool.Add(spawned);
            source = spawned;
            return true;
        }

        source = null;
        return false;
    }
}
```

### 3.4 `EntityAudio.cs` Combo & Cooldown Integrity
In `EntityAudio`:

### 4.1 `ReturnToPool.cs` — Modal Pause Check First, Per-Emitter Resume, Silent Disable
`ReturnToPool` must pause unscaled emitters unconditionally whenever `UIManager.IsTimeFrozen` is true—even on `useFixedDelay = true` prefabs—and never restart finished bursts or `StopEmitting` loopers upon unpause or `OnDisable`.

```csharp
using System;
using UnityEngine;

public class ReturnToPool : MonoBehaviour
{
    [SerializeField] private bool useFixedDelay;
    [SerializeField, Min(0f)] private float time = 0.5f;
    [SerializeField] private Animator animator;
    [SerializeField] private ParticleSystem[] particleSystems;

    private bool isReturned;
    private float delayElapsed;
    private bool isPausedByModal;
    private bool[] pausedByModalFlags;
    private bool pausedAnimatorByModal;
    private float preModalAnimatorSpeed = 1f;
    private bool hasUnscaledParticles;

    private void Awake()
    {
        if (animator == null)
            animator = GetComponent<Animator>();

        if (particleSystems == null || particleSystems.Length == 0)
            particleSystems = GetComponentsInChildren<ParticleSystem>(true);

        pausedByModalFlags = new bool[particleSystems.Length];
        RefreshTimebaseFlags();
    }

    private void OnEnable()
    {
        isReturned = false;
        delayElapsed = 0f;
        isPausedByModal = false;
        pausedAnimatorByModal = false;

        if (pausedByModalFlags != null)
            Array.Clear(pausedByModalFlags, 0, pausedByModalFlags.Length);

        RefreshTimebaseFlags();
    }

    private void OnDisable()
    {
        // Clear tracking flags ONLY. Never call ps.Play(false) during pool deactivation.
        isPausedByModal = false;
        if (pausedByModalFlags != null)
            Array.Clear(pausedByModalFlags, 0, pausedByModalFlags.Length);

        if (pausedAnimatorByModal && animator != null)
        {
            animator.speed = preModalAnimatorSpeed;
            pausedAnimatorByModal = false;
        }
    }

    private void Update()
    {
        if (isReturned)
            return;

        bool shouldModalPause = UIManager.Instance != null && UIManager.Instance.IsTimeFrozen;
        SyncModalPause(shouldModalPause);

        if (isPausedByModal)
            return;

        if (useFixedDelay)
        {
            float dt = hasUnscaledParticles ? Time.unscaledDeltaTime : Time.deltaTime;
            delayElapsed += dt;
            if (delayElapsed >= time)
                ReturnNow();
            return;
        }

        if (animator != null)
        {
            AnimatorStateInfo info = animator.GetCurrentAnimatorStateInfo(0);
            if (!animator.IsInTransition(0) && info.normalizedTime >= 1f && !info.loop)
            {
                if (!AreAnyParticlesAlive())
                    ReturnNow();
            }
            return;
        }

        if (!AreAnyParticlesAlive())
            ReturnNow();
    }

    private void SyncModalPause(bool shouldPause)
    {
        if (shouldPause && !isPausedByModal)
        {
            isPausedByModal = true;
            for (int i = 0; i < particleSystems.Length; i++)
            {
                ParticleSystem ps = particleSystems[i];
                if (ps != null && ps.main.useUnscaledTime && ps.isPlaying)
                {
                    ps.Pause(false);
                    pausedByModalFlags[i] = true;
                }
                else
                {
                    pausedByModalFlags[i] = false;
                }
            }

            if (animator != null && animator.updateMode == AnimatorUpdateMode.UnscaledTime)
            {
                preModalAnimatorSpeed = animator.speed;
                pausedAnimatorByModal = true;
                animator.speed = 0f;
            }
        }
        else if (!shouldPause && isPausedByModal)
        {
            isPausedByModal = false;
            for (int i = 0; i < particleSystems.Length; i++)
            {
                if (!pausedByModalFlags[i])
                    continue;

                ParticleSystem ps = particleSystems[i];
                if (ps != null && ps.isPaused)
                    ps.Play(false);

                pausedByModalFlags[i] = false;
            }

            if (pausedAnimatorByModal && animator != null)
            {
                animator.speed = preModalAnimatorSpeed;
                pausedAnimatorByModal = false;
            }
        }
    }

    private void RefreshTimebaseFlags()
    {
        hasUnscaledParticles = false;
        if (particleSystems == null) return;
        for (int i = 0; i < particleSystems.Length; i++)
        {
            if (particleSystems[i] != null && particleSystems[i].main.useUnscaledTime)
            {
                hasUnscaledParticles = true;
                return;
            }
        }
    }

    private bool AreAnyParticlesAlive()
    {
        if (particleSystems == null) return false;
        for (int i = 0; i < particleSystems.Length; i++)
        {
            if (particleSystems[i] != null && particleSystems[i].IsAlive(false))
                return true;
        }
        return false;
    }

    public void ReturnNow()
    {
        if (isReturned) return;
        isReturned = true;
        ObjectPoolManager.ReturnObjectToPool(gameObject);
    }
}
```

### 4.2 `PooledParticlePlayer.cs` — Exact Modal-Freeze Preservation
In `PooledParticlePlayer`:
1. Maintain a `private bool[] pausedByModalFlags;` array sized to the cached child `ParticleSystem[]` array, plus `private bool isPausedByModal;` and `private bool hasUnscaledSystem;`.
2. In `Update()`: evaluate `bool shouldPause = UIManager.Instance != null && UIManager.Instance.IsTimeFrozen;` first:
   - Transitioning into pause (`shouldPause && !isPausedByModal`): for each cached `ParticleSystem` at index `i`, ONLY call `ps.Pause(false); pausedByModalFlags[i] = true;` when `ps != null && ps.main.useUnscaledTime && ps.isPlaying`.
   - Transitioning out of pause (`!shouldPause && isPausedByModal`): ONLY call `ps.Play(false)` when `pausedByModalFlags[i] && ps != null && ps.isPaused && !ps.isStopped`, then clear `pausedByModalFlags[i] = false`. Thus already-finished emitters and `StopEmitting`-drained loopers never re-emit.
3. In `MonitorParticlesRoutine()`: accumulate elapsed wait duration using `hasUnscaledSystem ? Time.unscaledDeltaTime : Time.deltaTime` and skip incrementing/completion checks while `isPausedByModal` is `true`, so modal pause never clips active bursts or miscounts duration.
4. In `OnDisable()` / `CompleteAndReturn()`: reset `isPausedByModal = false` and `Array.Clear(pausedByModalFlags, 0, pausedByModalFlags.Length)` without invoking `Play()`.

```csharp
            playerMovement.OnVelocityTierChanged -= HandleTierChanged;
        }

        KillTween();
        holdingQueuedPreview = false;
        SetAlpha(0f);
    }

    private void HandleDirectionQueued(Vector2 queuedDir)
    {
        if (queuedDir == Vector2.zero) return;

        // While already sliding in strict stop-to-stop mode, keep a steady crisp preview chevron.
        if (playerMovement != null && playerMovement.IsMoving)
        {
            holdingQueuedPreview = true;
            OrientAndTint(queuedDir);
            KillTween();
            telegraphPivot.localScale = new Vector3(0.85f, 0.85f, 1f);
            SetAlpha(queuedSteadyAlpha);
            activeSequence = DOTween.Sequence()
                .Append(telegraphPivot.DOScale(1.05f, 0.08f).SetEase(Ease.OutBack))
                .SetUpdate(false)
                .SetLink(gameObject);
        }
    }

    private void HandleMoveStarted(Vector2 dir) => PlayFlare(dir);

    private void HandleRedirected(Vector2 dir) => PlayFlare(dir);

    private void HandleMoveStopped()
    {
        if (playerMovement != null && playerMovement.HasPendingDirection)
            return;

        holdingQueuedPreview = false;
        KillTween();
        SetAlpha(0f);
    }

    private void HandleTierChanged(VelocityTier tier)
    {
        if (holdingQueuedPreview && playerMovement != null && playerMovement.HasPendingDirection)
            OrientAndTint(playerMovement.PendingDirection);
    }

    private void PlayFlare(Vector2 dir)
    {
        if (dir == Vector2.zero || arrowRenderer == null || telegraphPivot == null) return;

        holdingQueuedPreview = false;
        OrientAndTint(dir);
        KillTween();

        telegraphPivot.localScale = new Vector3(0.55f, 0.55f, 1f);
        SetAlpha(1f);

        activeSequence = DOTween.Sequence()
            .Append(telegraphPivot.DOScale(new Vector3(1.18f, 1.18f, 1f), flareDuration * 0.45f).SetEase(Ease.OutBack))
            .Join(arrowRenderer.DOFade(0f, flareDuration).SetEase(Ease.InQuad))
            .SetUpdate(false)
            .SetLink(gameObject);
    }

    private void OrientAndTint(Vector2 dir)
    {
        float angleDeg = Mathf.Atan2(dir.y, dir.x) * Mathf.Rad2Deg + spriteFacingAngleOffsetDeg;
        telegraphPivot.localRotation = Quaternion.Euler(0f, 0f, angleDeg);

        Color targetColor = ResolveTierColor();
        float currentAlpha = arrowRenderer != null ? arrowRenderer.color.a : 1f;
        targetColor.a = currentAlpha;
        if (arrowRenderer != null)
            arrowRenderer.color = targetColor;
    }

    private Color ResolveTierColor()
    {
        if (playerMovement != null && playerMovement.IsPhasing)
            return phaseColor;

        VelocityTier tier = playerMovement != null ? playerMovement.CurrentTier : VelocityTier.Drift;
        return tier switch
        {
            VelocityTier.KineticRam => kineticColor,
            VelocityTier.Cruise => cruiseColor,
            _ => driftColor
        };
    }

    private void SetAlpha(float a)
    {
        if (arrowRenderer == null) return;
        Color c = arrowRenderer.color;
        c.a = a;
        arrowRenderer.color = c;
    }

    private void KillTween()
    {
        activeSequence?.Kill(false);
        activeSequence = null;
        telegraphPivot?.DOKill(false);
        arrowRenderer?.DOKill(false);
    }
}
```

## 5. Pillar 4 — Multi-Visual, LevelClock-Synced `TilePulseFeedback` & Complete Mechanic Coverage

### 5.1 Design Architecture
To unify world feedback cleanly across every tile, hazard, switch, and drone without interfering with hitboxes or tint systems:
1. **Hit-Stop & Modal Freeze Lockstep (`.SetUpdate(false)`):** Every tween created by `TilePulseFeedback` uses `.SetUpdate(false)` (scaled game time) rather than `.SetUpdate(true)`. Because both `PlayerImpactFeedback` Hit-Stop and `UIManager.UpdateTimeScale` set `Time.timeScale = 0f`, tile telegraph shakes, `FailingTile` Warning/Collapsing animations, and `HazardActivation` charge pulses automatically pause and resume in **exact lockstep with `LevelClock`**.
2. **Multi-Visual Target Resolution:** Instead of caching a single `Transform` / `SpriteRenderer`, `TilePulseFeedback` accepts `[SerializeField] private Transform[] visualTargets;` and `[SerializeField] private Renderer[] flashRenderers;`. Any transform equal to `transform` or carrying a `Collider2D` is strictly ignored for scale/position animation so physics geometry is **never** distorted. When pulsing a state transition (e.g., `FailingTile`'s `intactVisual`/`warningVisual`/`collapsingVisual`/`collapsedVisual` or `HazardActivation`'s `inactiveVisual`/`warningVisual`/`activeVisual`), only active child visuals (`activeInHierarchy`) are animated.
3. **Stage-1 Safe Material-Swap White Flash (`Hit Flash White.mat`):**
   - `Hazard.FreezeTarget()` caches `originalSpriteColors` and overwrites `SpriteRenderer.color`, while `HazardActivation`, `EnergyGate`, and `CircuitSwitch` also drive `SpriteRenderer.color`. Overwriting `SpriteRenderer.color` creates visual tint conflicts.
   - Instead, `TilePulseFeedback` flashes by temporarily assigning `Assets/Shaders/Hit/Hit Flash White.mat` (`Shader "Echoes/VFX/Solid White Sprite"`, which preserves per-renderer `color.a` and `_MainTex` alpha) onto `Renderer.sharedMaterial` for `0.045s` (`DOVirtual.DelayedCall(flashDuration, RestoreMaterials).SetUpdate(false)`), and restores `cachedSharedMaterials[i]` cleanly on completion or `OnDisable()`.
   - Even when `Hazard.FreezeTarget()` disables sibling `MonoBehaviour`s on the root object (`Hazard.cs:285-292`), `TilePulseFeedback.OnDisable()` fires **immediately before** `FreezeTarget` tints sprites, cleanly restoring original `sharedMaterial` with zero stuck white artifacts!
   - Thus, **Stage 1** delivers crisp white hit-flashes on all single-root collider prefabs (`Wedge`, `Brake`, `GravityBlock`, `CircuitSwitch`, `Brittle`, `EnergyGate`, `SentinelDrone`) **with zero Transform/Collider risk**, while **Stage 2** splits dedicated child `Visual` GameObjects (`VectorPad.prefab` pattern) to unlock scale/shake deformation alongside the flash.
4. **Full Event Subscription Matrix:**
   - `IPlayerInteractable.OnPlayerInteracted` (covers `DeflectionWedge`, `VectorPad`, `VectorLauncher`, `BrakeTile`, `GravityBlock`, `BrittleFloor`, `FailingTile`, `CrackedBlock`, `CircuitSwitch`, `EnergyGate`, `Hazard`, `LevelExit`):
     - `Deflect`: directional lateral squash (`1.22 x 0.82`) + white flash (`0.04s`)
     - `Brake`: heavy axial compress (`0.84` Y squash) + white flash (`0.045s`)
     - `Launch`: spring recoil & release stretch (`1.28 x 0.78`) + white flash (`0.05s`)
     - `Crack`: tremor micro-shake (`0.04 u` amplitude) + white flash (`0.04s`)
     - `Break`: pre-hide pop punch (`1.24x`) + white flash (`0.045s`)
     - `Switch`: tactile depress (`0.86` scale punch) + white flash (`0.04s`)
     - `Hit`: rigid impact shudder (`0.06 u` horizontal/normal punch) + white flash (`0.045s`)
     - `Exit`: harmonic arrival bloom (`1.18x` EaseOutBack) + flash (`0.06s`)
   - `FailingTile.OnStateChanged(FailingTileState)`:
     - Intact / Reset -> `KillTweensAndRestoreVisuals()`
     - Warning (`warningVisual` active) -> `LevelClock`-locked looping tremor on `warningVisual`
     - Collapsing (`collapsingVisual` active) -> accelerating `1.0 -> 0.15` shrink on `collapsingVisual`
     - `Collapsed` -> restore rest scale & materials cleanly
   - `BrittleFloor.OnShattered` -> shatter pop + white flash.
   - `HazardActivation.OnPhaseChanged(HazardCyclePhase)` (drives **both** `PulseLaser` & `OverloadedFloor`):
     - Warning (`warningVisual` active) -> looping telegraph pulse (`1.0 <-> 1.07`) on `warningVisual`
     - Active (`activeVisual` active) -> snap strike punch (`1.15 -> 1.0`) + white flash on `activeVisual`
     - Inactive (`inactiveVisual` active) -> kill loop & restore resting visuals
   - `CircuitSwitch.OnSwitchStateChanged` & `EnergyGate.OnGateOpenStateChanged` -> remote toggle tactile punch + flash.
   - `SentinelDronePatrol.OnStepMoved` *(1-line `event Action<Vector2>` hook emitted on patrol tick advance)* -> subtle hover cadence bob (`1.04x` scale punch) & directional pulse on patrol beat.

### 5.3 Complete `TilePulseFeedback.cs` Implementation

```csharp
using System;
using System.Collections.Generic;
using DG.Tweening;
using UnityEngine;

/// <summary>
/// Unified multi-visual tactile feedback controller for all MazeTiles, Mechanics,
/// Hazards, Switches, Gates, Brittle/Failing Floors, and Sentinel Drones.
///
/// Safety Guarantees:
/// 1. Transform scale/position tweens ONLY touch collider-free child Transforms.
/// 2. Flash feedback swaps sharedMaterial to Hit Flash White.mat (never touching SpriteRenderer.color)
///    so Hazard.FreezeTarget / HazardActivation / EnergyGate tinting never conflicts.
/// 3. All tweens use .SetUpdate(false) (scaled game time) to stay synchronized with LevelClock
///    across both Hit-Stop freezes and UIManager modal pauses.
/// </summary>
[DisallowMultipleComponent]
public sealed class TilePulseFeedback : MonoBehaviour
{
    [Header("Inspector-Wired Visual Targets (Collider-Free Children Only)")]
    [SerializeField] private Transform[] visualTargets;
    [SerializeField] private Renderer[] flashRenderers;

    [Header("Optional Multi-Visual State Role Roots")]
    [Tooltip("Assign FailingTile/HazardActivation warning/collapsing/active child objects when present.")]
    [SerializeField] private GameObject warningVisualRoot;
    [SerializeField] private GameObject collapsingVisualRoot;
    [SerializeField] private GameObject hazardWarningVisualRoot;
    [SerializeField] private GameObject hazardActiveVisualRoot;

    [Header("White Hit-Flash Material (Stage 1 & Stage 2)")]
    [Tooltip("Assign Assets/Shaders/Hit/Hit Flash White.mat")]
    [SerializeField] private Material hitFlashMaterial;
    [SerializeField, Min(0.01f)] private float defaultFlashDuration = 0.045f;

    [Header("Pulse Tuning")]
    [SerializeField, Min(0.05f)] private float punchDuration = 0.16f;
    [SerializeField, Min(0.01f)] private float warningJitterAmplitude = 0.045f;
    [SerializeField, Min(0.05f)] private float collapseDuration = 0.18f;

    private readonly List<Transform> safeVisualTransforms = new List<Transform>(4);
    private Vector3[] baseScales = Array.Empty<Vector3>();
    private Vector3[] baseLocalPositions = Array.Empty<Vector3>();
    private Material[] originalSharedMaterials = Array.Empty<Material>();

    private IPlayerInteractable interactable;
    private FailingTile failingTile;
    private BrittleFloor brittleFloor;
    private HazardActivation hazardActivation;
    private CircuitSwitch circuitSwitch;
    private EnergyGate energyGate;
    private SentinelDronePatrol dronePatrol;

    private Tween activeFlashRestoreTween;
    private Tween activeLoopTween;
    private bool isFlashing;

    private void Awake()
    {
        CacheVisualTargetsAndMaterials();
    }

    private void OnEnable()
    {
        interactable = GetComponent<IPlayerInteractable>();
        failingTile = GetComponent<FailingTile>();
        brittleFloor = GetComponent<BrittleFloor>();
        hazardActivation = GetComponent<HazardActivation>();
        circuitSwitch = GetComponent<CircuitSwitch>();
        energyGate = GetComponent<EnergyGate>();
        dronePatrol = GetComponent<SentinelDronePatrol>();

        if (interactable != null)
            interactable.OnPlayerInteracted += HandlePlayerInteracted;

        if (failingTile != null)
            failingTile.OnStateChanged += HandleFailingStateChanged;

        if (brittleFloor != null)
            brittleFloor.OnShattered += HandleBrittleShattered;

        if (hazardActivation != null)
            hazardActivation.OnPhaseChanged += HandleHazardPhaseChanged;

        if (circuitSwitch != null)
            circuitSwitch.OnSwitchStateChanged += HandleSwitchToggled;

        if (energyGate != null)
            energyGate.OnGateOpenStateChanged += HandleGateToggled;

        if (dronePatrol != null)
            dronePatrol.OnStepMoved += HandleDroneStepMoved;
    }

    private void OnDisable()
    {
        if (interactable != null)
            interactable.OnPlayerInteracted -= HandlePlayerInteracted;

        if (failingTile != null)
            failingTile.OnStateChanged -= HandleFailingStateChanged;

        if (brittleFloor != null)
            brittleFloor.OnShattered -= HandleBrittleShattered;

        if (hazardActivation != null)
            hazardActivation.OnPhaseChanged -= HandleHazardPhaseChanged;

        if (circuitSwitch != null)
            circuitSwitch.OnSwitchStateChanged -= HandleSwitchToggled;

        if (energyGate != null)
            energyGate.OnGateOpenStateChanged -= HandleGateToggled;

        if (dronePatrol != null)
            dronePatrol.OnStepMoved -= HandleDroneStepMoved;

        KillAllTweensAndRestore();
    }

    private void CacheVisualTargetsAndMaterials()
    {
        safeVisualTransforms.Clear();

        if (visualTargets != null && visualTargets.Length > 0)
        {
            for (int i = 0; i < visualTargets.Length; i++)
                TryAddSafeVisual(visualTargets[i]);
        }
        else
        {
            // Auto-discover direct/child visual Transforms that have a Renderer and NO Collider2D.
            Renderer[] allRenderers = GetComponentsInChildren<Renderer>(true);
            for (int i = 0; i < allRenderers.Length; i++)
            {
                if (allRenderers[i] != null)
                    TryAddSafeVisual(allRenderers[i].transform);
            }
        }

        baseScales = new Vector3[safeVisualTransforms.Count];
        baseLocalPositions = new Vector3[safeVisualTransforms.Count];
        for (int i = 0; i < safeVisualTransforms.Count; i++)
        {
            baseScales[i] = safeVisualTransforms[i].localScale;
            baseLocalPositions[i] = safeVisualTransforms[i].localPosition;
        }

        if (flashRenderers == null || flashRenderers.Length == 0)
            flashRenderers = GetComponentsInChildren<Renderer>(true);

        originalSharedMaterials = new Material[flashRenderers.Length];
        for (int i = 0; i < flashRenderers.Length; i++)
        {
            if (flashRenderers[i] != null)
                originalSharedMaterials[i] = flashRenderers[i].sharedMaterial;
        }
    }

    private void TryAddSafeVisual(Transform candidate)
    {
        if (candidate == null || candidate == transform)
            return;

        if (candidate.GetComponent<Collider2D>() != null)
            return;

        if (!safeVisualTransforms.Contains(candidate))
            safeVisualTransforms.Add(candidate);
    }

    private void HandlePlayerInteracted(InteractionContext ctx)
    {
        switch (ctx.Kind)
        {
            case InteractionKind.Deflect:
                PlaySquashPulse(ctx.Direction, alongScale: 0.84f, acrossScale: 1.20f, punchDuration);
                TriggerWhiteFlash(defaultFlashDuration);
                break;

            case InteractionKind.Brake:
                PlaySquashPulse(ctx.Direction, alongScale: 0.80f, acrossScale: 1.18f, punchDuration * 1.1f);
                TriggerWhiteFlash(defaultFlashDuration);
                break;

            case InteractionKind.Launch:
                PlaySquashPulse(ctx.Direction, alongScale: 1.26f, acrossScale: 0.82f, punchDuration * 1.15f);
                TriggerWhiteFlash(defaultFlashDuration * 1.1f);
                break;

            case InteractionKind.Crack:
                PlayPositionShudder(warningJitterAmplitude, punchDuration * 0.85f);
                TriggerWhiteFlash(defaultFlashDuration * 0.9f);
                break;

            case InteractionKind.Break:
                PlayUniformPunch(1.24f, punchDuration * 0.7f);
                TriggerWhiteFlash(defaultFlashDuration);
                break;

            case InteractionKind.Switch:
                PlayUniformPunch(0.86f, punchDuration * 0.8f);
                TriggerWhiteFlash(defaultFlashDuration * 0.9f);
                break;

            case InteractionKind.Hit:
                PlayPositionShudder(warningJitterAmplitude * 1.25f, punchDuration * 0.9f);
                TriggerWhiteFlash(defaultFlashDuration);
                break;

            case InteractionKind.Exit:
                PlayUniformPunch(1.18f, punchDuration * 1.2f);
                TriggerWhiteFlash(defaultFlashDuration * 1.3f);
                break;
        }
    }

    private void HandleFailingStateChanged(FailingTileState _)
    {
        KillLoopAndRestoreTransforms();

        if (warningVisualRoot != null && warningVisualRoot.activeInHierarchy)
        {
            TriggerWhiteFlash(defaultFlashDuration * 0.9f);
            StartActiveVisualShakeLoop(warningJitterAmplitude);
        }
        else if (collapsingVisualRoot != null && collapsingVisualRoot.activeInHierarchy)
        {
            PlayActiveCollapseShrink();
        }
        else
        {
            RestoreOriginalMaterials();
        }
    }

    private void HandleBrittleShattered(BrittleFloor _)
    {
        KillLoopAndRestoreTransforms();
        PlayUniformPunch(1.20f, punchDuration * 0.65f);
        TriggerWhiteFlash(defaultFlashDuration);
    }

    private void HandleHazardPhaseChanged(HazardCyclePhase _)
    {
        KillLoopAndRestoreTransforms();

        if (hazardWarningVisualRoot != null && hazardWarningVisualRoot.activeInHierarchy)
        {
            StartActiveVisualPulseLoop(1.08f, 0.14f);
        }
        else if (hazardActiveVisualRoot != null && hazardActiveVisualRoot.activeInHierarchy)
        {
            PlayUniformPunch(1.16f, punchDuration * 0.9f);
            TriggerWhiteFlash(defaultFlashDuration);
        }
        else
        {
            RestoreOriginalMaterials();
        }
    }

    private void HandleSwitchToggled(bool _)
    {
        PlayUniformPunch(0.88f, punchDuration * 0.8f);
        TriggerWhiteFlash(defaultFlashDuration * 0.85f);
    }

    private void HandleGateToggled(bool _)
    {
        PlayUniformPunch(1.10f, punchDuration * 0.85f);
        TriggerWhiteFlash(defaultFlashDuration * 0.85f);
    }

    private void HandleDroneStepMoved(Vector2 stepDir)
    {
        PlaySquashPulse(stepDir, alongScale: 1.07f, acrossScale: 0.95f, punchDuration * 0.65f);
    }

    private void PlayUniformPunch(float peakFactor, float duration)
    {
        for (int i = 0; i < safeVisualTransforms.Count; i++)
        {
            Transform target = safeVisualTransforms[i];
            if (target == null || !target.gameObject.activeInHierarchy) continue;

            target.DOKill(false);
            Vector3 rest = baseScales[i];
            target.localScale = rest * peakFactor;
            target.DOScale(rest, duration).SetEase(Ease.OutBack).SetUpdate(false).SetLink(gameObject);
        }
    }

    private void PlaySquashPulse(Vector2 dir, float alongScale, float acrossScale, float duration)
    {
        bool horizontal = Mathf.Abs(dir.x) >= Mathf.Abs(dir.y);
        float sx = horizontal ? alongScale : acrossScale;
        float sy = horizontal ? acrossScale : alongScale;

        for (int i = 0; i < safeVisualTransforms.Count; i++)
        {
            Transform target = safeVisualTransforms[i];
            if (target == null || !target.gameObject.activeInHierarchy) continue;

            target.DOKill(false);
            Vector3 rest = baseScales[i];
            target.localScale = new Vector3(rest.x * sx, rest.y * sy, rest.z);
            target.DOScale(rest, duration).SetEase(Ease.OutQuad).SetUpdate(false).SetLink(gameObject);
        }
    }

    private void PlayPositionShudder(float amplitude, float duration)
    {
        for (int i = 0; i < safeVisualTransforms.Count; i++)
        {
            Transform target = safeVisualTransforms[i];
            if (target == null || !target.gameObject.activeInHierarchy) continue;

            target.DOKill(false);
            target.localPosition = baseLocalPositions[i];
            target.DOShakePosition(duration, amplitude, vibrato: 22, randomness: 90f, snapping: false, fadeOut: true)
                .SetUpdate(false)
                .SetLink(gameObject);
        }
    }

    private void StartActiveVisualShakeLoop(float amplitude)
    {
        for (int i = 0; i < safeVisualTransforms.Count; i++)
        {
            Transform target = safeVisualTransforms[i];
            if (target == null || !target.gameObject.activeInHierarchy) continue;

            target.localPosition = baseLocalPositions[i];
            activeLoopTween = target.DOShakePosition(0.25f, amplitude, vibrato: 18, randomness: 90f, snapping: false, fadeOut: false)
                .SetLoops(-1, LoopType.Restart)
                .SetUpdate(false)
                .SetLink(gameObject);
            break;
        }
    }

    private void StartActiveVisualPulseLoop(float peakFactor, float halfPeriod)
    {
        for (int i = 0; i < safeVisualTransforms.Count; i++)
        {
            Transform target = safeVisualTransforms[i];
            if (target == null || !target.gameObject.activeInHierarchy) continue;

            Vector3 rest = baseScales[i];
            target.localScale = rest;
            activeLoopTween = target.DOScale(rest * peakFactor, halfPeriod)
                .SetEase(Ease.InOutSine)
                .SetLoops(-1, LoopType.Yoyo)
                .SetUpdate(false)
                .SetLink(gameObject);
            break;
        }
    }

    private void PlayActiveCollapseShrink()
    {
        for (int i = 0; i < safeVisualTransforms.Count; i++)
        {
            Transform target = safeVisualTransforms[i];
            if (target == null || !target.gameObject.activeInHierarchy) continue;

            target.DOKill(false);
            Vector3 rest = baseScales[i];
            target.DOScale(rest * 0.15f, collapseDuration)
                .SetEase(Ease.InBack)
                .SetUpdate(false)
                .SetLink(gameObject);
        }
    }

    private void TriggerWhiteFlash(float duration)
    {
        if (hitFlashMaterial == null || flashRenderers == null || flashRenderers.Length == 0)
            return;

        activeFlashRestoreTween?.Kill(false);

        if (!isFlashing)
        {
            for (int i = 0; i < flashRenderers.Length; i++)
            {
                Renderer r = flashRenderers[i];
                if (r != null && r.enabled && r.gameObject.activeInHierarchy)
                    r.sharedMaterial = hitFlashMaterial;
            }
            isFlashing = true;
        }

        activeFlashRestoreTween = DOVirtual.DelayedCall(duration, RestoreOriginalMaterials, ignoreTimeScale: false)
            .SetUpdate(false)
            .SetLink(gameObject);
    }

    private void RestoreOriginalMaterials()
    {
        activeFlashRestoreTween?.Kill(false);
        activeFlashRestoreTween = null;
        isFlashing = false;

        if (flashRenderers == null || originalSharedMaterials == null) return;
        int len = Mathf.Min(flashRenderers.Length, originalSharedMaterials.Length);
        for (int i = 0; i < len; i++)
        {
            if (flashRenderers[i] != null && originalSharedMaterials[i] != null)
                flashRenderers[i].sharedMaterial = originalSharedMaterials[i];
        }
    }

    private void KillLoopAndRestoreTransforms()
    {
        activeLoopTween?.Kill(false);
        activeLoopTween = null;

        for (int i = 0; i < safeVisualTransforms.Count; i++)
        {
            Transform target = safeVisualTransforms[i];
            if (target == null) continue;
            target.DOKill(false);
            target.localScale = baseScales[i];
            target.localPosition = baseLocalPositions[i];
        }
    }

    private void KillAllTweensAndRestore()
    {
        KillLoopAndRestoreTransforms();
        RestoreOriginalMaterials();
    }
}
```
